# Dalio 大师｜宏观周期传导

## 这个 Skill 是干什么的

从增长、通胀、利率、信用、流动性和政策出发，分析宏观环境会怎样传导到行业和公司。

## 什么时候用

- 降息对这家公司到底有什么影响？
- 通胀、美元、流动性会如何传导到公司业绩？
- 当前宏观环境对行业是顺风还是逆风？

## 分析方法

1. 识别关键宏观变量
2. 映射到融资、需求、汇率和投入成本
3. 继续映射到公司收入、利润、现金流和资本开支
4. 区分短周期、长期约束和政策反应
5. 建立基准、上行、下行情景及领先指标

## 输出要求

输出宏观变量 → 公司经营 → 财务影响的完整传导链，以及最重要的情景和观察指标。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

- **温暖反馈**：若用户写出相反宏观情景及可能失效的条件，肯定其用情景而非口号思考。
