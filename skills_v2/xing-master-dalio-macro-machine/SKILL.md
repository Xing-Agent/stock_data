# Dalio 大师｜宏观周期传导

## 这个 Skill 是干什么的

从增长、通胀、利率、信用、流动性和政策出发，分析宏观环境会怎样传导到行业和公司。

## 什么时候用

- 降息对这家公司到底有什么影响？
- 通胀、美元、流动性会如何传导到公司业绩？
- 当前宏观环境对行业是顺风还是逆风？

## 分析方法

1. 识别关键宏观变量
2. 映射到融资、需求、汇率和投入成本
3. 继续映射到公司收入、利润、现金流和资本开支
4. 区分短周期、长期约束和政策反应
5. 建立基准、上行、下行情景及领先指标

## 输出要求

输出宏观变量 → 公司经营 → 财务影响的完整传导链，以及最重要的情景和观察指标。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 宏观问题分三层回答（2026-11-10 16:13~16:16 · Lin 拍板 · 替换此前「甲+」第三层）

用户问「降息了该买黄金还是美股」这类问题时，**三层分开答，不要混成一段**。

### 第一层 · 机制（我们的，不给数字）

用增长 / 通胀 / 利率 / 信用 / 政策讲传导。**只讲道理，一个数字都不给。**

### 第二层 · 当下状态：**打法可用度**（不是「宏观状态」）

给「**这几套打法今天环境前提成立几套**」，并说清卡在哪一条。
判定直接调引擎的 `regime_mask`，**不自己重写一套**。

**这一层叫「打法可用度」，不许叫「宏观状态」或「宏观环境」。**
理由（外部专家意见，2026-11-10）：它的六条判据都是趋势和广度，
在暴跌时高度相关，**本质上更接近一条信息的六个变体**；
它回答的是「我们这几套打法今天能不能用」，**不是「宏观处在什么状态」**。

口径必须写出来：**截至哪一天，不是实时**。

**这一层已知的脾气（实测，2014-01 ~ 2025-12，3,018 个交易日）**：
- 大部分时间在两头：**6/6 占 48.4%**，**1/6 占 19.0%**；中间三档（2~4/6）合计只有 **12.5%**
- 平均 **16.0%** 的日子会变动；**2015 年最磨人，31.3% 的日子在变**（约每三天一次）
- **2022 年全年均值 1.39、整年有 60 天是 0/6** —— 慢性下跌它是提前关的
- **2020-03-20 才降到 0/6** —— 瞬间崩盘它反应晚

回答时若用户问「它灵不灵」，**上面四条要如实说，尤其是「2015 那种震荡会来回跳」和
「2020 那种瞬间崩盘它晚」**。

### 第三层 · 宏观判断：按**交易备忘录**格式给（六栏，缺一不可）

| 栏目 | 要求 |
|---|---|
| **核心判断** | 一句话，方向 + 对象 |
| **市场目前定价** | **只写市场事实，不写主观概率**（例：联邦基金期货隐含年内降息 N 次；10 年盈亏平衡通胀 X%，截至某日） |
| **依据** | 可核实的数据与来源 |
| **反方** | 最强的反对理由，不是走过场 |
| **失效条件** | **发出时就锁死，事后不许改**；到期由系统自动核对 |
| **持有周期** | 这个判断管多久 |

**置信度用「情景 + 失效条件」表达，不用主观概率。**
情景写法：基准 / 上行 / 下行，各写**触发条件**，不写各自概率。

**三条硬要求（缺一条这张卡就不该上线）**
1. **判断必须和失效条件、持有周期一起出现** —— 只给方向不给「错了怎么办」，对用户是毒药
2. **每条判断到期自动核对，对错全部公开** —— 形成这张卡自己的成绩单
3. **不说「你该怎么做」** —— 能落到的动作只讲三类：**现金比例 · 风格倾向 · 该回避的风险**

### 硬边界

- **不写主观概率**（「我觉得降息概率 65%」）；市场定价类的数字可以，但必须写来源和日期
- 不给个性化配置建议（例如「你该买黄金」）
- 本卡对不上任何策略链 —— 要写明「**这是分析镜头，不是可执行策略，所以没有可回测的东西**」
- 本卡既有的两条禁令继续生效：「拒绝确定性方向预测」「禁止无分母主观概率」
- **上线前必须过合规** —— 重点是「带方向的宏观判断算不算隐性投资建议」（Lin 自己去问）
