# Dalio 大师｜宏观周期传导｜方法速查

## 核心用途

从增长、通胀、利率、信用、流动性和政策出发，分析宏观环境会怎样传导到行业和公司。

## 典型问题

- 降息对这家公司到底有什么影响？
- 通胀、美元、流动性会如何传导到公司业绩？
- 当前宏观环境对行业是顺风还是逆风？

## 核心检查框架

- 识别关键宏观变量
- 映射到融资、需求、汇率和投入成本
- 继续映射到公司收入、利润、现金流和资本开支
- 区分短周期、长期约束和政策反应
- 建立基准、上行、下行情景及领先指标

## 建议输出

输出宏观变量 → 公司经营 → 财务影响的完整传导链，以及最重要的情景和观察指标。
