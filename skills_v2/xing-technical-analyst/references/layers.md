# 六层详解 · 每层要什么、往下传什么

默认不读这份。用户要完整推导、或者要知道某个结论是怎么一层层推出来的时候才读。

---

## 层与层之间传什么

每一层给下一层的不是「结论」，是**约束**。下一层在这个约束里工作。

```
层1 看多久·大环境
  └→ 有效窗口还剩几天 · 大盘状态 · 这只票跟大盘的联动程度
层2 走得直不直
  └→ 波动是在收缩还是扩张 · 价格走得直不直(0到1) · 趋势类工具能不能用(能/不能)
层3 在走趋势还是在震荡
  └→ 方向状态(向上/向下/来回摆)
      └ 这决定层4 用哪套算法:走趋势用通道和摆动高低点,来回摆用区间上下沿
层4 位置与空间
  └→ 关键位清单(带容差带宽) · 净空间% · 失效价位
      └ 层5 只在这些关键位附近看量价。不在关键位的量价变化不解读
层5 最近几天的量价
  └→ 发生了什么事件(吸收/耗竭/扫过回收) · 买卖哪边更主动
层6 什么情况算走坏·多久过期
  └→ 状态怎么迁移 · 这个分析多久失效
```

**层 4 给层 5 的那个约束是硬的**：不在关键位附近的量价异动不解读。满图扫形态会扫出一堆没有意义的东西。

---

## 层 1 · 看多久 · 大环境

**要回答：** 这个问题的时间尺度是多少？大盘什么状况？行业顺风逆风？有没有硬事件把窗口砍短？

**要的数据：**

| | 有没有 |
|---|---|
| SPY 日线/周线 200 日均线位置与斜率 | **有** |
| 50 日与 200 日均线交叉 | **有** |
| 个股与大盘的联动系数 | 能算 |
| 等权指数(发现市值加权骗了我们的唯一办法) | **没有** |
| 板块 ETF(11 个) | **没有** |
| 道指工业 + 运输(道氏互认) | **没有** |
| 全市场涨跌家数 | **没有** |
| 成分股在 50 日均线上方的占比 | **没有** |
| 财报日历 | **没有** |

**大盘怎么作用于个股 —— 分三档，不是一刀切：**

- **常规**：大盘弱 → 个股上方空间按联动程度打折；大盘逆风 → 向上突破要求的放量倍数提高
- **硬停机**：以下两种必须停止任何个股的做多推演
  - 全市场齐跌 + 恐慌指数期限结构严重倒挂 → 此时所有个股的技术形态都会被强制平仓盘击穿，个股分析失去独立性
  - 触发全市场熔断，或个股因监管停牌

**硬事件怎么用：** 它不是看多看空因素，是把有效窗口砍短。表达成「有效窗口剩 N 天，任何需要 N 天以上才能走出赔率的结构现在处在暴露状态」。

---

## 层 2 · 走得直不直

**要回答：** 波动大还是小、在收缩还是扩张？价格走得直还是来回折腾？

**要的数据：** 日线真实波幅均值、带宽变化、效率比（同样的净位移，路上走了多少冤枉路）。全部**有**。

**三个波动相位 —— 它决定了后面哪类做法有效：**

| 相位 | 样子 | 谁的战场 |
|---|---|---|
| **刚要爆发** | 波动从极低位开始放大 | 突破做法 |
| **稳定推进** | 波动稳定或偏高，价格线性漂移 | 趋势跟随 |
| **走过头了** | 偏离中枢过远，加速度转负 | 震荡/逆势做法 |

**这一层对下面的否决权：** 价格走得极度不直（效率比趋近 0）时，直接把层 5 的形态证据判为无效 —— 不是降低权重，是失效。那种市场里的形态突破，统计期望为负。

---

## 层 3 · 在走趋势还是在震荡

**要回答：** 经过第 2 层过滤之后，这是有方向的位移还是来回摆？

**为什么必须在第 2 层之后：** 不先看信噪比，一段高波动的随机游走看起来和一段趋势一模一样。

**往下传的：** 走趋势 → 层 4 用通道和摆动高低点；来回摆 → 层 4 用区间上下沿和中枢。**两套算法，不能混用。**

---

## 层 4 · 位置与空间

**要回答：** 关键位在哪？上下各有多少空间？扣掉摩擦还剩多少？

**要的数据：**

| | 有没有 |
|---|---|
| 历史摆动高低点 | **有** |
| 20/50/200 日均线 | **有** |
| 整数关口、跳空缺口边界 | 能算 |
| 分价成交量分布 | **没有** |
| 实时买卖价差 | **没有**（只能用成交额粗估） |

**位置和结构必须一起算，不能分开。** 「它站得高还是低」是相对的 —— 没有先划出边界，这句话没有坐标系。

**关键位不是一条线，是一条带。** 多个前高前低聚成一个关键位时，容差取多少决定了这个位置存不存在。容差必须按这只票自己的波动算，不能用固定百分比（300 只票的日波动相差近 10 倍）。

**净空间必须给：**

```
实际可用空间 = 名义阻力空间 - 2 ×（半价差 + 冲击成本）
```

名义 3.4%、价差吃掉 1.2% 的话，实际只有 1.0%。只说「上方有空间」，用户算不了赔率。

---

## 层 5 · 最近几天的量价

**要回答：** 在关键位附近，最近的量和 K 线说明什么？

**只在层 4 给出的关键位附近看。** 别处的量价变化不解读。

**这一层区分两种东西，别混：**

- **状态量**：成交量的分布、换手水平 —— 慢变量
- **事件**：某一根 K 线的放量、长影线 —— 脉冲

混在一起会导致跨时间尺度的数据穿透：用一根 K 线的事件去推翻一个慢变量的结论。

**真正的流动性吸收判据需要盘口和逐笔数据，我们没有。** 现在能做的是日线和 5 分钟级别的降级版（量能异常 + 收盘位置），**必须说明这是降级版**。

---

## 层 6 · 什么情况算走坏 · 多久过期

**要回答：** 什么价格、什么条件出现说明判断错了？这个分析多久失效？

**失效位必须三件事一起给：**

1. 价位
2. **收盘算还是盘中触及算** —— 这两个是完全不同的东西，用户默认以为是盘中
3. 为什么是这个位置（结构上的理由，不是一个百分比）

**失效位不能落在一天的正常波动之内。** 一个距现价只有 0.5 倍日波动的止损，被随机噪音打掉的概率接近必然 —— 给出这种位置，等于让用户白白承担摩擦成本。

**有效期（多久过期）也要给：**

> 「这个形态的推演只在未来 N 根日线内有效。横盘超过 N 天还没突破，这条分析整条作废。」

没有有效期的分析会被用户无限期持有，直到他用一个三周前的结论做今天的决定。

## 跨层矛盾的裁决规则（可直接写进代码）

**规则一 · 大级别压制小级别**
大级别下行 + 小级别反弹 → **禁止命名为「反转信号」**，强制降级为「下跌趋势中的反抽」。
依据：道氏理论 —— 低级别运动不能逆转高级别主趋势，直到主趋势的高低点结构被破坏。

**规则二 · 信噪比一票否决**
层 2 判定「趋势类工具不可用」时，层 5 检测到的任何「向上突破前高」事件，解释权强制覆写为「高概率假突破」。

**规则三 · 空间不足否决微观动能**
层 4 算出的净空间小于失效位所需距离（赔率 < 1）时，无论层 5 的量价多强，适应度状态强制置为「未激活」。
微观动能不能覆盖空间上的物理缺陷。

## 最后：这份文件里没有一个具体阈值

这是故意的。

效率比多少算「走得不直」、价差多少算「崩塌」、容差取几倍波动 —— 这些是参数，**参数在引擎里，不在这里**，而且每一个都要标明是原著的还是我们校准的。

写进 Skill 的阈值会被当成权威，然后在没人注意的时候和引擎里的实际值分叉。
