## 安装方法

解压后进入 `skills/` 目录，每个子目录就是一个独立 Skill。按 XING 平台的“安装 Skill”流程选择相应目录或单独打包该目录。每张卡已自带共同边界和对应的文本参考文件，避免跨目录读取失败。仅安装对应目录即可，无需安装 `INTEGRATION` 或测试代码。

## 范围和验收

本包优化的是 Skill 内容、路由说明、来源标注、方法教学边界与参考文件结构。**纯文本 Skill 不会自动修复平台的网关误拦、13:32 后的回答失败、返回截断、证据标记泄漏或真实数据接口缺口。** 本次为文档结构检查，不等于线上全部功能通过。

## 方法与资料原则

- 规则出处区分原著、行业改进、XING 修正、用户自定义及未经核查资料；缺来源应显式显示待核实。
- 未经过正式用途审核的技术方法只作教学与研究展示，不当作交易信号、实时止损或自动仓位计算。
- 没有可靠数据就明确列出缺失项，不编造、不把历史数据当实时数据。
