# 分行业研究适配表

| 行业类型 | 关注变量 | 默认禁止的机械套用 | 启用前提 |
|---|---|---|---|
| 银行 | 净息差、存款成本、NPL、拨备、CET1、ROE/PB | 工业现金流、净债务、安全闸门 | 银行专项模型和真实字段 |
| 保险 | 新业务价值、保费、赔付、偿付能力 | 工业企业 EBITDA 与 PE 直接对比 | 保险专项来源 |
| 券商 | 经纪/自营/投行结构、净资本、周期 | 牛市单季利润永续化 | 券商周期及资本模型 |
| 公用事业 | 核定收益/费率、监管资产、负债 | 通用工业 ROIC 绝对阈值 | 专项费率基准 |
| REIT | FFO/AFFO、NOI、净资产、LTV | 单独看 PE | FFO/AFFO 可验证 |
| SaaS/软件 | ARR/NRR、留存、合同负债、SBC | 存货周转与收入增速等价 | 合同披露可得 |
| 半导体/硬件 | 真实订单、客户验证、库存、毛利/产能 | 概念标签代表订单 | 公司披露或可靠供应链证据 |
| 医药/生物 | 临床阶段、试验终点、现金跑道、知识产权 | 无利润时用 PE | 临床/监管一手资料 |
| 周期资源 | 价格、供需、库存、产能、单位成本 | 峰值利润低 PE = 便宜 | 周期位置证据 |

默认 XING V2 美股工业模型不适用的类别须**停用不适用的判定**，但允许解释已确认事实。扩展为 A 股/港股需另外验证证券标识、报表制度、币种、公告时点和市场日历，不凭研究 Skill 的抽象兼容宣称已覆盖。
