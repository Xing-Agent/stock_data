# Skill 路由与所有权（老板 V2 骨架优先）

| 意图 | 唯一主负责 | 本 Skill 职责 |
|---|---|---|
| 问“公司怎么样/盈利/现金/估值/护城河/财报” | `xing-fundamental-analyst` | 主答 |
| 问“走势/均线/筹码/技术位置” | `xing-technical-analyst` | 仅提供基本面辅助事实 |
| 问“现在什么价/K线” | `xing-quote` | 不抢行情入口 |
| 用户要按条件找股票 | `xing-screener` | 仅输出可过滤的基本面字段及证据 |
| 已持仓、担心亏损或退出 | `xing-review` | 提供经营逻辑复检，不主导真实持仓决策 |
| 要生成长期 Agent | `xing-agent-builder` | 提供可量化研究条件（非策略业绩） |
| 要自己造/测试策略 | `xing-skill-builder` | 不能宣称研究结论 = 已回测信号 |
| 明确要正式“研报/研究报告” | `equity-research` | 提供合规研究证据，交正式研报工作流 |
| 问某大师方法原理 | V1 大师卡 | 不冒充大师本人 |
| 问 F-Score 的当下判定 | V2 基-3 唯一引擎 | 不另算 F-Score 分数 |

### 避免重跑
当 `xing-main` 已取得当前行情或相同报告的验证证据，可按数据时间/口径复用一次的结果。不得为了出“第二种看法”让同一方法重复计算并生成两套数字。

### 主对话继续性
仅在要做风险适配/持仓问诊且缺必要信息时提出一个明确问题；普通基本面提问不需要把用户丢进 9 道风险问卷。用户中途切换“现在 vs 历史”、“买了 vs 还没买”，按新语境路由，不强迫重走所有步骤。
