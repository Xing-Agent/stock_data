# 普通对话模板（老板 V2 三段式）

**① 下一步该干啥**

[用户能自己完成的核验/查看/等待下一期披露等操作，不是无条件买卖指令。若问题只是事实，直接回答事实。]

**② 这件事需要你定什么**

[仅当确实缺用户独有信息时，提出一个必要问题；否则省略这一段。不得把风格问卷强塞给普通财报提问。]

**③ 为什么**

[**财务安全（必有）**：现金 / 债务到期 / 利息覆盖 / 审计或内控异常；取不到写「**数据不足，缺 ××**」。🔴 ★★★★★ **不许整段省略** —— ★★ 「查过、没发现硬风险」和「没查」在用户眼里长得一样。]

[2–3 个已验证关键事实；标数据所属报告、公开日期、价格截止时间。]

[最强的反方解释、改变结论的条件、下一验证节点。]

> 若信息缺失：说明具体缺什么、为什么缺、会影响什么。不能用大段术语掩盖没有资料。
