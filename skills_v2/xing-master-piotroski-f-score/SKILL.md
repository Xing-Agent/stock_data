# Piotroski 大师｜财务九项体检

## 这个 Skill 是干什么的

用 Piotroski F-Score 的 9 项指标检查盈利、现金流、杠杆、流动性和经营效率，快速做财务健康体检。

## 什么时候用

- 这家公司财务基本面健康吗？
- 帮我做 F-Score 九项检查
- 盈利质量、杠杆和效率是在改善还是恶化？

## 分析方法

1. 盈利：净利润、经营现金流、ROA、现金流与利润匹配
2. 杠杆与流动性：长期杠杆、流动比率、股权稀释
3. 效率：毛利率与资产周转
4. 每项明确通过、不通过或未知
5. 缺少同口径确定性数据时不强行评分

## 输出要求

输出 9 项逐项结果、总分（数据完整时）、未知项和主要改善/恶化信号。

用户要求「只要一个数」「直接给总分」「别列那么多」时也**不省略逐项结果**：总分可以单独成行，但九项逐项、未知项和数据口径必须同时给出，不许被压缩成一个裸数字。（2026-11-12 C 组机器三类 T8 加：施压下输出曾压成裸「5」，丢了逐项与归属。）

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。
