# 大师方法与 V2 核心 Skill 的跨包契约（V2.3）

此文件为统一集成说明，不替代任何方法原著，也不创造新参数。按需在每个大师方法研究前读取；始终先遵守 `references/shared/common_boundaries.md`。

1. **方法研究≠ V2 正式判定**：旧方法卡的计算、阈值、回测、预期区间不得绕过正式引擎；若只有解释性方法、没有正式状态对象，则使用条件/证据分析，而不是产生 `MATCHED/BUY/SELL` 等认证状态。
2. **出处标签**：公开原作者规则 / XING 解释 / 用户自定 / 未核查资料分别列明；无法核实原著具体数值时注明“待核”，不得把编译时知识变成作者原话。
3. **同一证券单一读数**：现价统一 `xing-quote`；财务/经营判断统一 `xing-fundamental-analyst` 的真实数据层；技术状态统一 `xing-technical-analyst`；选股统一 `xing-screener`；持仓动作统一 `xing-review`。
4. **V2 当前数据 vs 历史回测**：当前用户展示与历史 PIT 回放严格隔离；回测禁止使用历史未知的财报、成分样本、共识或价格。
5. **按用户问题加载**：普通公司问题不必遍历大师卡；点名具体方法时调用那一张，复杂论点可挑 1–3 张互补方法；点名原著方法且有禁令时禁令优先。
6. **训练、评分、排序**：无真实样本外验证，不声称胜率、年化收益、排名或大师背书；未批准的统一综合评分停用。原著的可复算原生评分如 F-Score，须通过正式算子验证后展示。
7. **路由依赖**：`implied-expectations-valuation`、`xing-master-feynman-plain-language` 为兼容别名，不得独立发现。`xing-master-mentor` 非默认自动触发。
8. **不强制感情陪伴**：可按用户意图切换研究 / 学习 / 复盘 / 决策计划；不要让教学语气污染专业研究，不输出承诺性交易指令。
