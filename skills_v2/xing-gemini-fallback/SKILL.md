# 一、什么时候转（满足任何一条）

| 情况 | 例子 |
|---|---|
| 问题对不上任何一张卡 | 「半导体这轮周期到哪了？」「这家公司护城河是什么？」 |
| 我们缺数据 | 非美股；刚上市没几季财报；行业数据、产品出货量；最新新闻 |
| 需要卡外的方法 | 分部估值、DCF 细节、期权定价、宏观传导 |
| 用户明确要「更多背景」 | 「为什么大家都在说 AI 泡沫？」 |

**不转的**：卡里有规则、我们有数据的（价位、门槛打勾、四道 / 五道闸、证伪条件）—— 这些必须我们自己算，不许交给 Gemini。
一次回答里可以「我们答一半 + Gemini 补一半」：我们的部分照卡；补的部分单独成段。

# 二、转的时候怎么问

1. 设定照 Lin 的习惯：「假设你是华尔街顶级的 ×× 分析大师」（技术面 / 基本面 / 行业）。
2. **同题同约束**：把我们卡里相关的边界一起发过去（不说「现在买」、没把握的数说「经验，没有统计」、不编数字、新闻写来源和日期）。
3. 只发问题本身和必要的公开信息（票名、周期、我们已算出的数字）；**不发用户的身份、账户、持仓金额**。
4. 要求它「先给 3 行结论，再展开」，方便我们截取。

# 三、拿回来要过的 4 道检查（任何一道不过，就删掉那一段或改写）

| # | 检查 | 不过怎么办 |
|---|---|---|
| ① | **说话边界**：有没有「现在买 / 现在卖 / 一定 / 必涨 / 胜率最高」、有没有替用户定仓位 | 删掉或改成「如果……就……」 |
| ② | **数字能核的先核**：价格、涨跌幅、估值倍数、财报数字，用我们的数据核一遍 | 对不上：用我们的数，并注明「已按 XING 数据更正」；核不了：标「外部模型给出，未核实」 |
| ③ | **新闻和事件要有来源和日期** | 没来源的事实性说法删掉 |
| ④ | **和我们的卡不打架**：它的结论和我们卡算出来的矛盾时，以我们卡为准，并把分歧写出来 | 写成「我们的规则算出来是 A；外部模型认为 B，理由是……」，不偷偷改成它的 |

另外：去掉无条件的夸奖和附和（Gemini 在技术面对话里有开口先夸的习惯）。

# 四、怎么标注

- 来自 Gemini 的段落，开头写：**「以下来自外部模型，XING 已检查说话边界和可核数字。」**
- 标注放在段落开头，不放在全文末尾的小字里。

# 五、每次都记下来（这个比例就是我们的进度指标）

每次转都记一条：时间、用户问题（去掉个人信息）、为什么转（对应第一节哪一条）、Gemini 原文、过检查后实际回给用户的内容、4 道检查各自过没过。
- 每周统计「转出去的比例」—— 越来越低，说明我们吸收得越来越多。
- 每周挑出现最多的 3 类问题，写成新卡或补进现有的卡。

# 六、出错和超时

- Gemini 报错、超时（例如 60 秒没回）、或 4 道检查后什么都不剩：回答用户「这部分我们暂时答不好」，说清楚我们能答的部分，不硬编。
