# Feynman 大师｜复杂金融讲人话｜方法速查

## 核心用途

把复杂公司、财务和投资研究结论翻成普通人能听懂、能复述的人话，同时保留关键数字和风险条件。

## 典型问题

- 这段研报太专业，帮我讲人话
- 用非金融专业的人也能懂的方式解释公司
- 把复杂逻辑拆成简单因果链

## 核心检查框架

- 先锁定原文中的数字、条件、语气和风险强度
- 回答“它是什么、为什么、影响谁、最终影响什么”
- 去掉不必要术语，但不改变原意
- 必要时保留一句话版、人话版和保真版
- 无法简化而不失真时明确指出理解缺口

## 建议输出

优先给出清晰的人话解释；关键数字、时间、单位、条件和不确定性必须保留。
