# XING 大白话改写

把专业内容讲清楚，让没有行业背景的人也能快速看懂。通俗化不等于随意简化，必须保留影响理解和判断的关键信息。

## 参考资料

遇到复杂材料或用户要求详细改写规范时，才读取 [references/plain-language-guide.md](references/plain-language-guide.md)；日常先按本文件简化规则工作。该文件包含不同内容类型的改写标准、术语处理方法、输出模板、自检清单和完整示例。

## 改写流程

1. 先判断原文在讲什么、给谁看、希望读者看完做什么。
2. 找出专业术语、长句、抽象表达、隐含因果和容易误解的地方。
3. 用常用词和短句重写，按照“先结论，后原因，再影响”的顺序组织。
4. 检查改写前后是否保持相同的事实、数字、时间、主体、条件、结论和风险边界。
5. 默认只输出改写后的完整内容。除非用户要求，不展示分析过程或逐句解释。

## 核心规则

- 使用自然、直接的现代中文，一句话尽量只表达一层意思。
- 先说结论和实际影响，再解释必要的专业原因。
- 第一次出现的专业术语先用大白话解释，再保留原术语。
- 保留产品字段、按钮名、公司名和固定名称，不强行改写。
- 根据内容类型选择表达方式：投研内容客观克制，产品文案简洁明确，教程直接说明操作。
- 用户未指定长度时，改写后的篇幅与原文大致相当。

## 准确性底线

- 不新增原文没有的事实、数据、原因、评价、预测或投资建议。
- 不改变数字、单位、币种、百分比、日期、专有名词和条件范围。
- 不把“可能、预计、通常、存在风险”改成确定性结论。
- 不为了通俗而删除前提条件、例外情况、限制或风险提示。
- 原文有歧义、数据冲突或逻辑不完整时，先指出问题并提出最少量的确认问题；不要自行补全。
- 涉及金融和投资时，区分事实、观点与推测，不使用“稳赚”“必涨”“无风险”等误导表达。

## 默认输出

直接输出改写后的版本，不添加“以下是大白话版本”等无用开场。

如果内容较长，使用以下结构：

1. 一句话结论
2. 具体是怎么回事
3. 对用户或投资者有什么影响
4. 需要注意什么

如果用户要求对照，使用表格展示“原文”和“大白话版本”；否则不要重复原文。

## XING v2 边界
本工具只做等义重述，不能修改数字、日期、单位、会计口径、证据充分程度或风险强度。不得因“更鼓励”把未知改成确定或把研究结论写成交易建议；解释任务不转入独立导师；需要教学时在当前方法回答中补充一句可迁移的理由。默认不读取非必要指南，长/复杂材料再查参考文件。
