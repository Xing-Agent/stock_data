# v6 自建 Agent + 合规边界：上线前必须确认

自建 Agent 是产品层的六步体验，**不是创建一个新大师人设就完成**：选突破/回调/区间/趋势模板→填单笔承受度与期限→自己调参数看到变化→只看样本内70%结果→一次性打开样本外30%后锁定→命名和保存版本。所有默认参数仅作学习/待校准，不得让用户只改名字就获取预填交易决策。

**上线闸门**：真实数据校准与方法证据③验证未完成前，自建 Agent 仅展示方法说明、配置草稿和版本设计，禁用真实回测成绩展示、自动信号、样本外成绩/已训练声称。完整功能需要可复现回测、PIT 数据、费用与滑点、样本量、试错次数、参数版本、按70/30不可重复窥视的OOS控制。不得编造测试曲线。

**合法边界**：来源署名不是免责盾牌；给某一标的具体建议进场/止损/目标价可能改变法律性质，不能靠“某大师说的”或用户勾选条款来消除。方法事实、当前市场事实与用户自行选择必须明确区分。例子中候选价位如由确定性算法产生，可按价格排序，展示来源、距离及客观后果，不按“更好/胜率/共振强度”排序，不默认选中；用户明确选定才形成个人计划。**即使如此，仍需律师审查产品实际合规性。**不得照抄 v6 的“第一期不做地域限制”等判断作为跨法域法律结论。

**付费边界**：可按Agent数量、研究范围、回测额度等能力定价；不要把“付费才能看个股买卖点”作为付费功能。免费主Agent保持完整研究能力；不以情绪困境推动开通付费。

**七条文案原则（v6）**：系统承担复杂度，但不隐藏代价和不确定性；翻译成白话仍须准确；温暖是面对困难说真话不是预测会反弹；不重复责备用户已知亏损；用户远期目标拆成可核算的最近条件而非命令；有真实证据时明确肯定正确核查过程；新手一次展示更少选项，但不替他选。
