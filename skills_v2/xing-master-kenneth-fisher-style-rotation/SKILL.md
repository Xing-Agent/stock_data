## 能力卡
- 人物：肯尼斯·费雪（Kenneth Fisher），不是菲利普·费雪（Philip Fisher）。用户仅说“费雪”且上下文无从区分时问一句澄清。
- 正式方法卡：`基-11`；能力：`action.strategy.fundamental`、`research.macro.market_breadth`（研究辅助），实际执行落 **Portfolio 组合层**，不是个股 Selection。
- 能做：研究风格切换的证据：市值风格、成长/价值、利率、收益率曲线、市场广度，以及风格信号反转的条件。
- 不做：将PSR作为未验证的独立交易信号；把风格研究当个股买卖指令；猜测作者未公开的轮动阈值；与菲利普费雪的一手访谈法混同。

## 触发与交互
1. “最近成长股和价值股谁更强、依据是什么？” → 研究主线，给窗口/指数/分类体系/行情时点与真实反例；没数据时给核验框架。
2. “肯尼斯·费雪如何看组合配置？” → 只讲基-11作者的框架、何时用、最难受的滞后代价、当前证据③与④限制。
3. “按他的策略帮我买哪些？” → 不默认配仓/挑股；研究请求正常回答；用户确实想交易时，给可选方法与个人约束的自行比较，不输出执行价、份额或真实回测结果。
4. “费雪的闲聊调研？” → 应选菲利普·费雪的`xing-master-fisher-scuttlebutt`，不是本Skill。

## 分析与回答模板
- **一句话**：没有永远占优的风格，切换要看可验证的市场特征；风格信号的切换可能明显滞后。
- **三项事实**：规模风格（大/小）；价值与成长；利率/曲线/广度；每项带窗口、基准、最新可用时点与测量口径。
- **反方与失效**：风格标签能否一致？窗口一变是否反转？利率与广度是否给相反证据？缺字段直接“无法计算”。
- **来源与可用性**：框架来自作者著述；轮动信号具体阈值**没有作者标准公开规则**，任一XING阈值必须标“XING·待校准”；手册v13中第③栏尚无本方法验证，第④栏仅教育研究/展示。
- **输出**：风格事实 → 证据表（窗口/基准）→ 当前可检验的分歧 → 方法失效条件 → 需要补的数据。仅在用户希望学习时增加不超过一问的练习。
