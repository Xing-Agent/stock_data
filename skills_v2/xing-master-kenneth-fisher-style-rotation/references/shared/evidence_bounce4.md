# 实证卡 · 阶段四内反弹的四个数

> **归属:`我们·已校准`**
> 任何 Skill 引用这四个数,必须带上这张卡的链接。
> **界面上不许只写比例、不写样本。**

---

## 这四个数回答什么

用户套在一只下跌的票里,问的是「还能不能反弹 / 能坏到什么程度」。
这四个数把那个回答从「看牌面的经验之谈」变成有样本的东西。

---

## 结果

### 一 · 创新低之后,连反弹都不成立的比例

| | |
|---|---|
| 新低样本 | **8,615 次** |
| 20 天内出现过 ≥1 倍日波动的回升 | **24.4%** |
| **直接继续往下** | **75.6%** |

**对用户的说法:**「这种结构下创新低之后,四次里有三次连一次像样的反弹都没有。」

### 二 · 反弹能走到哪儿(反弹样本 2,849 次)

| 走到哪儿 | 次数 | 占比 |
|---|---|---|
| **止步在上方第一个密集成交区下方** | 1,998 | **70.1%** |
| 进了那个区,但没穿过去 | 312 | 11.0% |
| **穿透** | 539 | **18.9%** |
| └ 穿透后连续 5 天站住 | 320 | 占穿透的 59.4% |

**穿透并站住的,只占全部反弹的 11.2%。**

### 三 · 幅度与窗口

| | 中位 | 10 / 90 分位 |
|---|---|---|
| 反弹幅度 | **+11.6%** | +4.4% / +37.1% |
| **低点到反弹高点的天数** | **6 天** | 2 / 29 天 |
| 反弹高点之后 60 天内最低 | **-19.3%** | -45.6% / -5.1% |

**★ 窗口中位只有 6 天。**这是「条件必须提前挂上」的实证依据 ——
等用户看见反弹起来了再商量怎么办,一半窗口已经过去了。

### 四 · 穿透之后并不等于警报解除

| 走到哪儿 | 高点后 60 天内最低(中位) | 90 分位 |
|---|---|---|
| 止步区下 | -20.9% | -7.0% |
| 进区未穿 | -18.2% | -5.0% |
| **穿透** | **-14.0%** | -1.4% |

**穿透只是从「很差」变成「比较差」。**
所以穿透那一支的结论只能是「**阶段四可能结束了,方法要重新判定**」,
**绝不能写成「可以拿着了」。**

## 口径(这部分必须可复现)

| | |
|---|---|
| 样本池 | 264 只美股,2005–2025 |
| 阶段判定 | 三分法 `stages3`,日线 150 日均线(约合 30 周) |
| 「阶段四」 | `stages3` 判出 4 的连续段,且段长 ≥ 30 个交易日 |
| **反弹启动** | 段内维护「至今最低收盘」;某天收盘高出它 **1.0 倍该票自己的日波动**(ATR14/收盘)时算启动,起点 = 那个最低收盘日 |
| **上方第一个密集区** | 启动日之前 250 个交易日,按 **0.5 倍 ATR** 宽度分箱累计成交额;只看启动价之上的箱,取**最近的一个厚度 ≥ 上方平均厚度 1.5 倍**的箱 |
| 反弹结束 | 跌回起点低点 / 站上阻区上沿 / 阶段四段结束 / 满 120 天,先到为准 |
| 「站住」 | 穿透后连续 5 个交易日收盘不低于阻区下沿 |
| 不含 | 做空、杠杆、交易成本 —— 这四个数描述价格路径,不是一笔交易的盈亏 |

**★ 反弹启动的定义故意不用 swing low(前后各看 N 天)**,因为那要用未来数据,
做出来的数字实盘复现不了。

## 两条必须对用户说出来的局限

### 一 · 生存者偏差 —— 这次它特别要命

池子里不含已退市的股票。而我们查过:原始 300 只里 30 只已停止交易,
**基本都是被溢价收购的赢家**(ATVI、CERN、ABMD、ALXN、CTXS、DFS),
真正跌到退市的输家本来就不在池子里。

**所以 75.6% 和 -19.3%,真实世界比这更差,不会更好。**

**界面必须写:**「这些数字来自一个不含退市股的池子 —— **真实的最差情况比这更差**。」

### 二 · 「第一个密集区」的定义敏感

第一版把它实现成「**最厚**的那个箱」,得到的是 94.2% 止步区下 ——
那不是反弹弱,是阻区太远(下跌段里最厚的成交堆通常在当初派发的高位)。

**「第一个」是距离,「最厚」是厚度。**两个词,两件事。
生产口径取**最近的够厚的那个**。换定义会让比例从 70% 跳到 94%,
所以界面上出现这个比例时,**定义必须跟着出现**。
