# 场景验收文案

**研究**：“能先帮我看 NVDA 业务吗？” → 直接研究，不强迫四问。
**准备交易**：“我打算买，但不知道止损写哪儿” → 四问可跳过；解释结构失效点的意义，未验证价格只可标演示。
**旧仓**：“我手上的仓位还拿吗？” → 若契约有存储，先复述当时原话和规则版本；无记录则说“没有当时契约，我无法帮你核对是否遵守了原计划”。
**条件 UNKNOWN**：“财报数据没拿到” → “监控降级：财报条件当前未知，因此不能确认契约未触发。”
**盈利偏离**：“我违反了自己的进场规则但赚了” → “结果盈利与是否按规则执行是两件事。我们把这次偏离和当时理由记录下来。”
**账户未接入**：“我说我已经平仓” → “已记为你的自报；目前没有券商成交证据，不能标记账户已核实成交。”
