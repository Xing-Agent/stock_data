# XING 术语表

> **用途:**三个人写六个 Skill,不用同一套词就会分叉。
> 这里只收**已经定了的**说法。拿不准的不要自己发明 —— 问策略组。
>
> **规则:**左栏是对用户说的话,右栏是内部概念。**只写左栏,不写右栏。**

---

## 一 · 三条线(画在 K 线图上的)

| 对用户说 | 它是什么 | 绝对不能说成 |
|---|---|---|
| **条件线** | 这套方法的前提成立的位置 | ❌ 买点 / 入场价 / 建议买入位 |
| **证伪线** | 跌破它说明这次判断错了 | ❌ 止损价(可以挂止损,但那是用户的动作) |
| **兑现线** | 这套方法管到这儿为止 | ❌ 目标价 / 卖点 |

**兑现线最容易说错。**它不是「该卖了」,是**「这套方法的前提不再成立,它管不了你了」**。
实测依据:1,598 次转出 100% 落在「说不清」,一次都没直接进下一个明确阶段 ——
**所以系统说不出「该卖了」,只说得出「我管不了了」。**

## 二 · 五个状态(方法对一只票的判断)

| 对用户说 | 什么时候 |
|---|---|
| **这套方法的前提全部成立** | 所有入场条件都满足 |
| **条件还没满足** | 差一条或几条,但方向清楚 |
| **这套方法不适用** | 结构上就不该用这套 |
| **判断不了** | **真的测不准** —— 证据互相矛盾或数据不足 |
| **我们没有策略** | 这种情况我们库里没有对应方法 |

❌ **第一个绝对不能说成「可以做」。**
「可以做」的主语隐含是用户,那是一张通行证 —— 而判据是我们自己写的。
**我们能说的只是「这套方法的前提成立」,做不做是他的事。**

**另外还有一个状态,它不是五态之一:**

| **前提正在松动** | 从「成立」往外走的过程中 —— **这是离场提示,不是沉默** |
|---|---|

## 三 · 四种出处标注

| 对用户说 | 什么时候用 | 点开要看到 |
|---|---|---|
| **原著** | 规则和数字都来自某本书 | 书名、章节、原文逻辑 |
| **我们·已校准** | 原著没给数,我们测出来的 | **实证卡**:样本全集、样本内外分割、笔数、显著性、参数敏感度 |
| **我们·待校准** | 我们定的,还没测 | 说明它还没被验证 |
| **通行惯例·无主** | 大家都这么干,说不清谁先提的 | **我们采用的量化定义具体是什么**(因为无主,定义必须我们自己说清) |
| **外部模型·未核** | 外部模型给的,还没核 | 来源 + 尚未验证 |

❌ **自研规则严禁套用大师的名字。**
❌ **原著给全了的规则,不要标成「我们的实现」。**(那对用户是弱化 —— 他以为这条没依据)

## 四 · 五个流派(策略赌什么)

| 流派 | 赌什么 | 代价的典型形状 |
|---|---|---|
| **突破** | 波动率瞬间扩张 | 低胜率、极高赔率、阶梯跳跃 |
| **趋势跟随** | 长期自相关 | 中胜率、曲线较平滑、需要很宽的止损 |
| **均值回归** | 钟摆回摆 | 高胜率、低赔率、有肥尾风险 |
| **价差收敛** | 统计价差修复 | 极高胜率、极低回撤 |
| **价值重估** | 定价错配修复 | 极低频、极长持有 |

**同流派内的代价数字才可比。跨流派放在一个列表里按胜率排序是有害的。**

**同一时间尺度上几乎全互斥**(只有价差收敛能共存);**跨时间尺度可以主从镶嵌** ——
小周期的信号作大周期的扳机。

## 五 · 代价七个数 + 一个

**绑定之前必须全部摆出来,不能藏在二级页面。**

| 对用户说 | 注意 |
|---|---|
| 胜率 | |
| 赔率 | |
| **最长不赚钱** | **包含空仓干等的时间**。用户的体感是「我账户里的数,N 个月没比之前最高点更高过」 |
| **最大连亏** | ❌ 不能只说「最大连亏 27」<br>✅ **「你要准备好连着错 27 次,而且它们会挤在一起来」** |
| **过程中最大浮亏** | 赢的那些单,中途最多亏到多少。**这个数回答「我能不能拿住」** |
| 信号频率 | |
| 假信号率 | |
| **可执行率** | 第八个。有些止损方式在大部分机会上根本算不出来 |

## 六 · 说话的两档

| 在讨论什么 | 语气 |
|---|---|
| **市场 / 某只资产** | **克制** —— 只报客观结构和条件,不给方向 |
| **系统 / 参数 / 配置** | **主动** —— 该指出参数问题就指出 |

**按讨论对象分,不按所在 Skill 分。**用户在配 agent 时顺口问「这票怎么样」,
那一刻谈的是市场,必须切回克制。

## 七 · 几个反复出错的说法

| ❌ 不要说 | ✅ 要说 |
|---|---|
| 适合你的策略是…… | **这几套方法的前提现在成立 / 不成立** |
| 匹配度 85% | **10 条前提里成立 8 条,不成立的是:相对强弱为负** |
| 我们建议你…… | (只在谈参数配置时才能说"建议") |
| 置信度 / 把握 / 大概率 | **离失效还有多远**(一个距离,不是一个分数) |
| 主力 / 庄家 / 聪明钱 / 洗盘 | **该价位聚集了保护性止损单,触及后触发集中换手** |
| 帮您避免了损失 | (不说。邀功归因) |
| 温斯坦会告诉你…… | **用温斯坦的方法看** |
| 日线阶段 | **阶段判定 · 150 日均线(约合 30 周)** |

**最后一条的理由:**原著在周线上定义阶段,我们用日线 150 日均线(窗口等价)。
说「日线阶段」会让人以为我们压缩了时间尺度 —— **把窗口说出来,这个误解就没了。**
实测两套口径 84.5% 一致。

## 八 · 拿不准的时候

而那时候已经没人记得它是什么时候、为什么那么定的。
