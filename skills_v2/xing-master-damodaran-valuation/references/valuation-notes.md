# DCF 方法笔记（教育和研究，不是实时估值算子）

## 财务口径

- `FCFF = EBIT × (1 - 现金/边际有效税率假设) + D&A - CapEx - Δ非现金营运资本`。仅在可靠、同期间字段完整且明确有非营业调整时展示；税率应按情景而非简单机械使用账面税率。
- `FCFE = 净利润 + D&A - CapEx - Δ非现金营运资本 + 净新增借款`。资本结构变化、融资受限时需另行调整。
- `EV(FCFF) = Σ FCFF_t/(1+WACC)^t + TV/(1+WACC)^N`。权益价值需要减净债务等项目并调整非经营资产、少数股东等；不同数据日期不直接混算。
- `Equity Value(FCFE) = Σ FCFE_t/(1+Ke)^t + EquityTerminalValue/(1+Ke)^N`。
- `TV` 的永续增长形式只有在 `r > g`、稳定增长经济假设成立时才可用；成长、再投资与终值阶段资本回报应一致。

## 正式估值计算的前置门槛

1. PIT/当前财务及价格数据有独立状态与版本；计算器校验与公式追溯。
2. 盈利、终值、再投资、税率、资本成本等假设有来源和敏感性。
3. 金融机构、资源/周期等不适配通用公式时切换专用估值框架。
4. 对模型反方、不确定性和风险闸门做完整展示；禁止单一点位承诺。
5. 产品/策略/合规已同意 `RESEARCH_PLUS` 启用，实际数据和计算模块均已部署。
