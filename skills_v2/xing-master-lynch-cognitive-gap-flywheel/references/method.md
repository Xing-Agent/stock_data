# Lynch 大师｜认知差与成长飞轮｜方法速查

## 核心用途

寻找业务容易理解、市场可能低估且能持续验证的成长故事，并拆解产品、渠道、客户或规模形成的增长飞轮。

## 典型问题

- 市场是不是忽视了这家公司的成长点？
- 这个产品为什么可能形成飞轮？
- 成长故事有哪些可以持续验证的数据？

## 核心检查框架

- 判断公司类型和成长阶段
- 用简单语言写出核心成长故事
- 识别市场共识与潜在认知差
- 拆解产品、渠道、数据、网络或规模飞轮
- 检查客户、单位经济和资产负债表
- 设定可验证的关键节点

## 建议输出

输出核心成长逻辑、潜在认知差、飞轮结构、验证数据和飞轮可能断裂的位置。
