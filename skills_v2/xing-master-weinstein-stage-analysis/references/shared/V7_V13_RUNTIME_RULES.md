# XING 大师方法与决策运行规则

**生效基准**：2026-10-20；方法/数据归属以《大师策略手册 v13》四附—八附优先于旧正文；交互/状态以《大师策略决策流程 v7》附录“结构修正六条”优先于旧正文。该文件只规定 AI/产品语义，不能替代服务端计算或法务审批。

## 1. 规则优先级与五态
1. 研究为默认：用户问事实、解释、大师视角，不要强制填交易四问。只有明确意图才进入决策分支。
2. **研究方法**允许主动补盲区并列示来源；**行动方法**先过滤禁令和硬门槛，再并列教育性候选，不排名、不预选、不合成适合度分。
3. 五态统一语义：`CAN_DO`（该方法的前提成立）、`NEAR`（有定义且可计算的接近态）、`CANNOT_DO`（前提明确不满足或命中禁令）、`UNKNOWN`（必需数据缺失/过期/无法校验）、`TRANSITION`（阶段过渡，不是任意强判）。不得将缺失默认当通过或不通过；即使 CANNOT_DO 也要给“规则要求—当前差多少—代价—如何验证”的出口。
4. 相同方法出现多时间框架：顶部**只能一个主状态**并标`timeframe`，另一状态作为次级、明确说明不一致。**主状态日/周选择待策略组拍板**，客户端必须使用配置而非在 Prompt 自行决定。临时展示不得把日线150MA等同于作者周线口径，标“阶段二（日线口径）”或“阶段二（周线口径）”。技-3 优先读取已存在的 w_ 周线数据，不得因路由未接线误报缺周线数据。
5. **跨周期收盘**：未收盘周期的条件不能计“已满足”；用于 N 选 M 触发计数时该条件本轮返回`NOT_YET_CLOSED`（触发计数为 0，显示等待收盘），与真正数据缺失 `UNKNOWN` 严格区分。周线以该证券交易日历定义的当周最后一个交易时段收盘为准，**遇节假日不能机械假设每周五交易**。半日市 65/195 分钟周期若不完整，标`INCOMPLETE`并排除共振计数；5分钟完整 K 线可正常计。
6. 两个互不互斥的分支同时成立：输出 `MULTIPLE_BRANCHES` 及各自依据，进入策略组定义的更保守分支；**哪个分支“更保守”尚须配置确认，未知则不推进自动动作**。每次比较必须写“触发条件变易/变难”与“结果更保守/更激进”，禁用含混的“更严/更松”单独陈述。

## 2. 状态生命周期和不可绕过的统计
- 休眠必须有退出条件；后台在有授权、服务正常时继续判定但停止主动打扰，条件从“不能做”变“接近/可以做”可唤醒。没有授权或后端能力不能宣称已监控或已自动唤醒。用户可自主恢复/删除，但任何休眠状态不得永久无出口。
- 调参次数按 `(user_id, strategy_family_id)` 计数，不绑实例ID，删除实例不清零；展示累计次数/限制原因。调参限制需要后端持久化实现，Prompt 不能自称已经阻断。
- 保存计划 ≠ 开启监控 ≠ 券商下单。契约版本不可覆盖；触发、自报、成交核实是三个不同事实。未知行情/规则过期必须展示，不能写“没触发”。
- 统计应附分子/分母、时间窗、对象、样本选择、数据版本；禁止“靠系统避免损失”式邀功归因。

## 3. v13 方法与验证
- **技-3 温斯坦**：周线原著与日线150MA实现不可混称；当前两者阶段2重合19.1%这一实测存在，策略组尚未拍板。v13第七附已有状态分布与离场成本的有限验证：**仅可教学与研究展示**，不得进入交易决策和风险计算；模型也不能承诺实时撮合、自动执行或填写缺失的4项统计。离开阶段2经实测是进入 transition，表述为“当前方法的前提已不成立”，不得写“进入阶段三、该卖了”。兑现线是方法管辖权终点，不天然是交易卖点。
- **技-12 康纳斯**：旧版v13曾列作第一期决策候选，2026-11-04已撤销该用途；现在仅可教学与研究展示。其原著没有单笔止损定义，不得捏造一个作为证伪线。介绍方法时明确“本方法未提供单笔固定止损，可能承受较大单笔下行风险”；两项对应风险统计无法由该原著机制给出。
- **其他59条正文策略及12条状态判定**：v13未提供同等当前验证，教学/研究/规则说明为主；不能借技-3或技-12的实测通行证。两条的可用范围仍依赖引擎/数据/合规正式就绪，不自动开实盘。
- 原版条目61条 + 新增6条状态 = 67条正式条目：技术14、基本面23、套利5、配置7、模块6、状态12。11个`LENS-`为暂定研究镜头，不计入正式67条。谨防将“手册 v13”封面仍印“v11”的历史正文误当生效版本。

## 4. 禁令、归属与可解释数据
- **作者禁令**先于策略门槛判断。12条细目在`V13_RULES_AND_PROVENANCE.md`，区分已核与待核。禁止全局自动开启做空；预留做空禁令不是做空功能已经上线。原则上全局禁止向下摊平仍**待策略组拍板**，作为显式风险提示，但不能将待拍板建议伪装成正式上线强制门。
- 高紧旗形技-8：形态来源欧奈尔《How to Make Money in Stocks》第四版第二章；赞格补充3–5天时间止损。技-4 的原始杯柄概念与 XING 的具体量化定义应分开：原方法卡将量化定义归 XING 实现，具体枢纽点与跳动等参数的原著引文尚未一手核实，不得直接标“原著已验证”。技-10的海龟汤与2B不同来源/不同触发，不可折成一条无差别算法。状-1道氏原理与ZigZag/ATR后人算法分开，状-4“触及未破”是 XING 术语。
- 原著写死的数字不准做XING阈值调优；原著没给的标XING·待校准；同一规则有原著+XING算法，两个来源并排列。
- 相对强弱输出**窗口+基准+算法/分位口径**：RS Rating全市场分位不等于相对SPY/QQQ超额收益。方法卡应绑定不可缺省`rs_window`、`rs_benchmark`，没有则不能形成“跑赢谁”的事实判断。
- 原生方法计分（F-Score 8/9、原著RS Rating）可以给原始公式与逐项依据；不得对标的/匹配/研报审校造0–100综合分。行为执行率可用带分母的可复算比率。
- 发布链路必须对活跃Prompt/用户可见模板跑静态违禁措辞断言，命中阻断，而不仅是README提醒。详见`policy_lint.py`。不允许主观无分母概率断言和系统邀功。
- 回测发现数字将继续随 v14 变化：本文记录的历史值只能在历史实测板块显示，**实时说明不得硬编码这些值**，应由具有`source_version`的引擎结果提供。
