# 退市股怎么结算（回复手册 81 · C1）· 2026-11-06

> **三秒版：不买 CRSP。1,053 只「最后一根 K 线早于 2026-11-04」的票，逐只到 SEC 申报记录里查了「为什么没了」，分成 8 类。每只都给了「建议的退市收益」和依据：被收购的按最后收盘价结算；破产或摘牌的按学术上通行的近似打折（Shumway：纽交所 -30%、纳斯达克 -55%）。**

## 二 · 要知道的几件

1. **-30% / -55% 是行业近似（②档），不是逐只核过的值。**
   - 出处：Shumway (1997, *Journal of Finance*) 和 Shumway & Warther (1999, *Journal of Finance*)。CRSP 查不到退市后价格时，学术界通行这样补。
   - 考卷那 23 只破产股是逐只读过 8-K 原文的（有的明确归 0），**这里不覆盖考卷**。
2. **结算价 = 最后收盘 × (1 + 建议收益)。** 比如纳斯达克破产股最后收盘 0.30 美元，按 0.30 × 0.45 = 0.135 美元结算。
3. **「留空」不是 0。** 那 68 只（判不了 25 + 什么都没找到 43）证据不够，按最后收盘还是按 Shumway 由你们定。我倾向按 Shumway 打折：保守一点，免得高估收益。
4. **每只都附了 SEC 证据**（`sec_evidence` 列：表格、日期、8-K 项目号、申报号），可以抽查。
5. 想更准的话，可以把破产那 120 只逐只读 8-K 原文，查清普通股到底是清零还是有剩余（考卷就是这么做的）。大约半天工作量，要做再说。
