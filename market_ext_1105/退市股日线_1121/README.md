## 一 · 文件
- `退市于2005.parquet` … `退市于2025.parquet`：按退市年份（没有退市日的按最后交易日）分，标普补充的也按年份放进去了。
- 列和之前的日线一样：
  - 原始价 `open high low close volume`；
  - 只折拆股的 `*_adj`、`adj_factor`、`split_coefficient`；
  - 加 `polygon_composite_figi`、`cik`（Polygon 给的内部编号，防代码被别的公司接着用；老的退市股很多没有 figi，但大多有 cik）、`trades`、`source_ticker`。
- `总表.csv`：每只一行，列有：
  - 代码、公司名、交易所；
  - Polygon 编号（composite_figi、share_class_figi、cik）；
  - 退市日（Polygon 记的）、数据起、最后交易日、最后收盘价、交易天数、拆股；
  - 说明。取不到的也在里面，说明里写了原因，也写了这只是从哪一步来的。
- `折算后单日涨跌超3倍的日子.csv`：893 天，涉及 690 只，见第四节。

## 二 · 怎么取的
1. **名单（第一步）**：Polygon 参考库里所有「已不活跃」的普通股，主板在 NYSE / NASDAQ / AMEX，退市日在 2005-01-01 ~ 2025-12-31 之间，一共 5,905 只。按代码去掉两个面板里已有的 977 只，剩 4,928 只。
2. **日线**：每只取 2003-09 到退市日的原始日线。
   - Polygon 日线是按代码给的，代码被别的公司用过的话会混在一起，所以只要退市日以前那段；
   - 再往前碰到停牌超过 60 天的空档、或者同一代码更早一家公司的退市日，就从那以后算起。
   - 例子：FRC 2007 年被美林私有化、2010 年重新上市，所以从 2010-12-09 起。
3. **标普补充（第二步）**：
   - 拿标普 500 历史成分里 2005–2025 调出的名字对一遍，名单里没有的 71 个（Polygon 参考库漏的，比如贝尔斯登、WaMu、Wachovia）按代码直接取日线，只要调出日前后停止交易的那段；
   - 放了 53 只，其余是改名、被并后代码还在用。
4. **拆股**按 Polygon 拆股记录折，只用这只票自己那段时间里的。
5. **补 2005–2015 年漏的（第三步，11-21 晚加的）**：
   - Polygon 参考库对这段时间纳斯达克的退市股几乎没收录，但日线有。办法：
     - 2004-12 ~ 2017-06 每个月取一天「全市场所有代码的当天行情」（只含交易所上市的，不含场外）；
     - 找出 2005-01 ~ 2016-06 之间最后一次出现、之后再没出现过的 1–4 个字母代码，一共 4,918 个；
     - 再查每个代码当时的公司名和 CIK。
   - 去掉：
     - CIK 现在还在交易的（改名，比如 Arkansas Best 改成 ArcBest）530 个；
     - CIK 在两个面板里的；
     - 名字像权证、优先股、基金、ETF、存托凭证的，或 Polygon 标了非普通股的，一共 1,087 个；
     - 查不到公司名的 211 个。
   - 剩 3,090 个去取日线，放了 2,939 只。
   - **这一步取到的多数交易所 Polygon 没记**。4 个字母的代码在 2015 年以前只有纳斯达克用，所以按纳斯达克算，总表里交易所那一列空着，说明里写了。

## 四 · 用的时候留意
- **代码按「代码」去重**：面板里已有同名代码的 977 只没放。其中有些面板里的其实是后来用这个代码的另一家公司（比如 BBBY 在 2005–2014 面板里），这次没逐只核。第二、三步加了 CIK 核对，面板里同名、但是不同公司的写成了带后缀的代码。
- **单日涨跌超过 3 倍的 893 天**：
  - 多数原始价也是这么跳的，多是几毛钱的小票，真行情或者 Polygon 漏了并股；
  - 少数在拆股当天，是 Polygon 的拆股日期或方向和价格对不上。
  - 清单在 `折算后单日涨跌超3倍的日子.csv`，用的时候建议跳过这些天，或者整只不用。
- **最后收盘价**：1,595 只低于 1 美元，2,891 只低于 5 美元。退市原因 Polygon 不给，按你们说的没判。
- Polygon 数据只能内部研究用。
