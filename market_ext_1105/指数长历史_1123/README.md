## 要知道的几件事
- **列名和 `指数ETF_1993起_1122` 一样**,末尾多一列 `数据完整度`,每天标明是:
  - `完整`:开高低收都是真的。
  - `只有收盘`:开高低留空。
  - `开盘=前一天收盘`:当年没记开盘价，数据商照抄了前一天收盘;**最高、最低、收盘是真的**。
- **标普 1962–2005 绝大多数天开盘价不可用**(每年 200 多天是照抄前收),2006 年以后才基本正常。最高、最低从 1962 年起都是真的。
  - 所以按月找大顶大底：1962 年以后用月内最高 / 最低没问题;1962 年以前只能用月内最高 / 最低收盘。
- **道指早年来自另一个来源**(Yahoo 只有 1992 年以后)。1992 全年两个来源逐天比对，254 天收盘最大差 0.002%,接得上。比对明细在 `道指_1992年两个来源比对.csv`。
- **周六**:1952 年以前纽交所周六也开市。道指(MeasuringWorth)有周六，共 1,085 天;标普(Yahoo)没有周六。做月线不受影响。
- 单日涨跌超过 10% 的日子都核过，全是真行情:1929 年大崩盘、1931–1933、1939-09、1987-10-19(标普 −20.5%、道指 −22.6%)、2008-10、2020-03、2025-04-09。明细在 `说明_每只.csv`。
- 指数不用复权:`*_adj`、`adjusted_close` 和原值一样。
- 旧的 `指数ETF_1993起_1122/标普500指数_日线_1993起.csv` 没动;这里的标普文件已经包含那一段，以后用这里的。
