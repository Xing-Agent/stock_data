# 标普 500 历史成分 · 2005–2025 · 数据组 · 2026-11-21(回手册 338 第二样)

> **三秒版：找到一份能用的公开来源，已整理好；2005–2014 年每天少 1–5 只，要知道这个缺口。**
> - 来源：GitHub 上的公开项目 **fja05680/sp500**（MIT 许可，用的是 2026-09-07 那版）。
>   - 2019 年以前来自 Andreas Clenow《Trading Evolved》书里附的成分表，他用的是 Norgate 的数据；
>   - 2019 年以后由作者按维基百科和新闻逐条补。
> - 2005-01 ~ 2025-12 一共 992 次调入、调出。
> - 点名查过：雷曼、贝尔斯登、Countrywide、美林、WaMu、房利美、房地美、FRC、SIVB、SBNY、BBBY 都在，调出日期和公开报道对得上。
>   - 例如 SIVB 2023-03-15 调出，FRC 2023-05-04 调出，雷曼 2008-09-17 调出。

## 已知缺口（用之前要知道）
1. **2005–2014 年成分数只有 495–499 只**（应该是 500 左右），每天少 1–5 只。作者自己也说早年可能漏了几只，没有办法独立核对。2015 年以后是 503–507 只，和实际一致（有的公司有两类股）。
2. **代码是「当时」的写法，而且破产股带 Q**：比如雷曼写成 `LEHMQ`、WaMu 写成 `WAMUQ`、房利美 `FNMA`、房地美 `FMCC`。和 Polygon、我们面板里的代码（LEH、WM 等）要对一下才能接上。
3. **改代码会显示成同一天「调出旧代码 + 调入新代码」**，比如 FB→META。这不是真的换成分，`调入调出_2005_2025.csv` 里看同一天进出各一只、公司一样的就是改名。
4. 这是一份民间整理的表，不是标普官方的，标普官方的历史成分要付费。日期以「生效日」为准，个别可能差一两天。

## 文件
- `调入调出_2005_2025.csv`：日期、调入/调出、代码，加当天一共进出几只。
- `每次变动后的成分_2004_2025.csv`：每次变动后的完整名单。查某一天的成分，就取那天或之前最近的一行。
- `每只票在标普里的时间段.csv`：每只票哪天进、哪天出；进出多次的分几行写，出为空就是现在还在。

脚本和原始文件在 `probe/做空_1120/标普500_1121/`。
