# 2005–2014 面板的营收、净利润（2009 年起）· 数据组 · 2026-11-23(回手册 398 补 2)

> **三秒版：2009 年起能补，2004–2008 拿不到。** 面板 1,042 家里 1,040 家有数据：
> - 2009 年有 877 家、2010 年 929 家、2011 年起 970 家以上；
> - 2008 年有 636 家，但只是 2009 年财报里附带的「去年同期」数。
> - 来源是 SEC 的结构化财报（XBRL）。SEC 2009 年才开始要求，大公司 2009 年中开始，其余 2011 年。**2004–2008 年免费渠道没有**，要的话得买 Compustat 一类。

## 文件：`营收净利润_2008至2016_SEC.csv`
| 列 | 意思 |
|---|---|
| 代码、cik、公司名 | 面板里的代码和 SEC 编号 |
| 期末 | 这个报告期的最后一天 |
| 期间 | `季`（约 3 个月）或 `年`（约 12 个月）。注意：年报里第四季度一般不单列，要用全年减前三季算 |
| 营收、营收科目 | 各公司用的科目不一样，按 Revenues → SalesRevenueNet → 新收入准则科目 → … 的次序，这家公司这一期有哪个用哪个 |
| 净利润、净利润科目 | 优先 NetIncomeLoss（归母净利润） |
| 首次公布日期 | 这个数第一次出现在 SEC 申报里的日期。**用它当「能看到的那天」，不会用到未来数据** |
| 申报类型 | 10-Q 季报 / 10-K 年报 |

## 要留意
- **同一期的数取第一次公布的**，后来重述的不用。这样回测里「当时知道什么」是对的。
- **2008 年那些数的「首次公布日期」是 2009 年的**：它们是 2009 年财报里附带的去年同期数，2008 年当年真正公布时还没有结构化格式。用 2008 年的数算增长时，公布日期按 2009 年那天算，会晚一年，但不会偷看未来。
- 银行、保险的「营收」口径和工业公司不一样（用利息收入、净营收等科目），比增长率可以，比绝对值别混在一起。
