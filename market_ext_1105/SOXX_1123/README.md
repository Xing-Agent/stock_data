## 要知道的几件事
- **改过名**:这只基金 2010-10-14 以前代码是 **IGW**(同一只基金),Polygon 分两段存,这里接成一条;`source_ticker` 列写着每天来自哪段。接缝那天 +0.41%,正常。
- **2001-07 到 2003-09-09 只有日线**,来自 Yahoo(Polygon 2003-09-10 才有)。Yahoo 和 Polygon 重叠的 8 天收盘价完全一致。这段没有小时线。
- **两次 3 拆 1**:2024-03-07、2026-11-05。`split_coefficient` 列在这两天是 3,之前的价格都除以 3(两次都在前的除以 9)。
  - 2024-03-07 折算后当天 +3.4%,正常。
  - **2026-11-05 折算后当天 −12.2%**:不是拆股没折对,是当天真跌。开盘就低开约 5%(143.08 对比前收 450.41÷3=150.14),盘中最低 130.75、收 131.90,成交量是前一天的 3.9 倍(按拆后股数);Yahoo 的数也是 −12.2%,两边一致。
- **坏点**:小时线里只扫出 3 根影线特别长的。2010-05-06 闪崩那天有几笔离谱的成交(最低记成 14.03),按《356》的办法用 1 分钟线剔掉,最低改成 38.63(闪崩里真实成交到的价)。另两根(2008-09-19 开盘、2025-04-07 那次关税假消息)1 分钟线看是连续的真行情,没改。
- **小时线只到 2026-11-19**:Polygon 目前没有 11-20 的盘中数据(30 分钟、1 分钟都是空的),日线有。等 Polygon 补上再加。
- 小时线和日线逐天比:每天常规时段最高价和日线最高价,5,837 天全部在 1% 以内。
