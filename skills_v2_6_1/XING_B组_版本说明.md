# XING B 组功能 Skill · V2.6.1

版本日期：2026-11-09

## 版本范围

六张独立功能 Skill：`xing-quote`、`xing-screener`、`xing-review`、`xing-condition-engine`、`xing-skill-builder`、`xing-agent-builder`。各 Skill 独立携带执行说明、数据契约、共用约束副本与答复模板；不要求共享目录或合并 Markdown。

## 核心修订

| Skill | 调整内容 |
|---|---|
| quote | 修正常规日涨跌幅可以跨交易日比较“现价与对应前收盘”的口径；细分盘前、盘中、收盘与盘后基准，明确 20 日高点的有效交易日样本 |
| screener | 区分已执行但数据不足和未执行的股票记录；新增未处理数量与批次完整性核对；按市场及规范化代码去重 |
| review | 浮盈亏计算明确需要真实持仓、成本与有效估值价格；增加事件证据和市场跌幅的区分 |
| condition-engine | 等号统一为 `==`（接受输入 `=` 后规范化），补足动态阈值的 `cross_below` / `cross_above`；分离规则待澄清、规则非法、未执行、已执行但未知 |
| skill-builder | 区分规则定义验证与策略收益验证；草稿中的未确认阈值不能直接绑定自动执行 |
| agent-builder | 将配置保存、规则校验、调度启用、真实检查和通知投递拆分记录，避免单一“运行中”状态掩盖未执行 |

## 发布边界

本版完成离线结构及规则一致性检查，不代表 XING 平台已成功安装、调用、拉取行情、筛选股票或调度推送。确认上线前应分别测试 6 张 Skill 的实际自动路由、数据接口、响应终态及回执。
