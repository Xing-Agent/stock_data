# 保本止损:到底是净正还是净负?—— 用我们自己的流水实测(1029)

## 三秒版

**按我们自己的数据:保本止损是【净负】,但负得很小 —— 每笔大约 −0.02 ~ −0.05 个百分点。**

一句话的原因:**救下来的那批单子每笔只省下 0 ~ 0.5 个百分点,而被砍掉的那批单子每笔要赔掉 2.4 ~ 5.3 个百分点。**
被砍的笔数比被救的少,所以两边几乎抵平 —— 但每一条样本够用的链上,**都是砍掉的那一边更大**。

还有一条更要紧的话:**我们原来是拿技-13 的「回吐率 91.3%」当作装保本止损的理由的,而技-13 和技-10 这两条链的前十笔占了总盈利的 100% 和 99.8% —— 这两条链的收益数字不可用。**
也就是说:**最初引出这个问题的那两条链,恰恰是最不能用来回答这个问题的。** 结论只能靠技-14 / 技-5 / 技-11 这几条集中度正常的链得出。

**结论:不要装保本止损。** 不是因为它有害(它的伤害很小),而是因为**它不解决任何问题** —— 它换不来收益,还要多一条规则、多一处可以出错的地方。原始前提「回吐率高 → 该装保本止损」在我们自己的数据上**不成立**。

## 先把一件事说清楚:题目里的第(1)问量的不是保本止损的代价

题目第(1)问是:「原实现下被止损或亏损离场的交易中,有多少笔在离场之后又回到过 +1R 以上」。

这个数我照口径算了(见下文「代价A」),但它量的是**原有止损本身砍掉了多少好苗子** —— 跟保本止损没关系。原因:**保本止损只作用在已经摸到 +1R 的那批单子上**;一笔从没摸到过 +1R 就被止损掉的单子,保本止损对它根本不起作用,它的止损位从来没被挪动过。

所以报告里给三个数,不是两个:

| 代号 | 问的是什么 | 对应题目 |
|---|---|---|
| **代价A** | 原有止损砍掉了多少好苗子(事后回到 +1R) | 第(1)问,照口径算 |
| **代价B** | **保本止损真正的代价**:摸到 +1R → 回踩成本价被砍掉 → 但原实现下它最终是赚钱的 | 第(1)问该问的 |
| **收益** | 摸到 +1R → 回踩成本价 → 原实现下最终亏钱收场,保本止损救下多少 | 第(2)问 |
| **净效应** | 全样本逐笔重放:原口径 vs 保本口径的每笔平均收益率之差 | 第(3)问 |

净效应**不是**手工加减出来的,是全样本重放算的;「收益 − 代价B」的对账结果与重放**逐链完全吻合**(见附录A),所以两条路互为验证。

## 口径(执行情况)

| 项 | 执行 |
|---|---|
| 触达 +1R | **按收盘价** `Close ≥ entry_price + risk_per_share`。**全程未使用盘中最高价。** |
| 保本触发 | +1R 那天**之后**,首次收盘 ≤ `entry_price` |
| 成交价 | **两个边界都报**:乐观界 = 成本价成交;悲观界 = 触发日收盘价成交(承认跌穿时的滑点)。**结论一律取悲观界**,避免自我美化。 |
| 计量 | **每笔收益率 %,不用 R**(部分链 `risk_per_share ≈ entry_price`,R 在那里无意义) |

| 并行 | **串行,单进程。** 机器 2 核 / 7GB,先确认了资源;全程 8 秒、峰值 RSS 309 MB,**没有并行**。 |
| 摩擦 | 沿用流水里的 `friction_bps`,双边计 |

用的流水目录(与上一轮时间止损测量同一组,口径可比):`ledgers_1029_A0十二条_新拆股口径`、`ledgers_1029_技术派六条三版`、`ledgers_1029_批五修正`,共 54 条链。

大白话:**绝大多数摸到 +1R 的单子,在收盘价回到成本价之前就已经被原有的离场规则平掉了。** 保本止损想插手,但轮不到它。这正好解释了为什么净效应的绝对值这么小 —— 它不是「两股大力量恰好抵平」,而是**这条规则在我们现有的离场体系下基本不起作用**。

## 最后一句明确回答

> **按我们自己的数据:保本止损是【净负】。**

- **方向明确**:11 条样本够用的链里 9 条净负,2 条净正而且是同一条链的两个版本、触发笔数刚过门槛。
- **幅度很小**:每笔 −0.02 ~ −0.05 个百分点,扣掉摩擦后基本在噪音量级。
- **机制清楚且一致**:救下来的每笔省 0 ~ 0.5 pp,砍掉的每笔赔 2.4 ~ 5.3 pp,后者是前者的 5~10 倍;被砍的笔数更少,所以两边接近抵平,**但每一条链都是砍的那边更大**。
- **符号对假设敏感**:如果假定止损单总能在成本价成交(乐观界),净效应会翻成微正(+0.003 ~ +0.16 pp)。所以**这不是一个「保本止损有害」的强结论,而是一个「保本止损换不来任何东西」的结论** —— 它的符号完全由成交假设决定,而真实成交更接近悲观界。
- **外部模型的分歧,我们这边的数据站在「反对」那一侧**:撒普/威廉姆斯说的「过早出局砍掉好苗子」在我们数据里确实存在(代价B,每笔 −2.4 ~ −5.3 pp),而且**它比保本止损省下来的钱大一个量级**。

**建议:不装。** 理由不是它危险,是它**不解决问题**:净收益在噪音里,却要多一条规则、多一处实现和运维上可以出错的地方。

**原始推理链在数据上不成立,要改口径**:「回吐率 91.3% → 该装保本止损」这一步是跳步的。回吐率高只证明**利润没守住**;我们的数据显示利润守不住的原因**不是止损位挂得不对,而是离场时机本身太晚** —— 真正该查的是出场规则,而不是在现有出场规则上再加一道保本止损。

**同时暴露出一个更值钉住的问题**:技-13 / 技-10 这两条链的前十笔占总盈利 100% / 99.8%。**我们之前用它们的回吐率推导风控规则,这件事本身是不安全的** —— 这两条链的任何收益类数字都不可用。下一步该先解决的是这两条链的收益集中度,而不是给它们加止损规则。
