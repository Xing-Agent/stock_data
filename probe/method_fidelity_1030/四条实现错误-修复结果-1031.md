## 第 3 条 · trend_following(署名海龟但三部件都不是)

### 原来装的是什么

`engine/configs/trend_following.yaml` 的 `meta.master` 写着「Richard Donchian / Curtis Faith(海龟)」,而三个关键部件都不是海龟 —— **并且这三处的 `source` 全都写着「原著」**:

| 部件 | 它标的 source | 原著 | 它实际装的 |
|---|---|---|---|
| ⑥ 离场 | 原著 | System 2 = **20 日反向通道** | `close_below_ma(50)` ★ 一条唐奇安反向通道都没有 |
| ⑤ 移动止损 | 原著 | 原著**没有**移动止损 | 吊灯 3.0×ATR20,浮盈 +2R 启动 |
| ⑦ 仓位 | 原著 +「**已核实**」 | 1 单位 = 账户 1%/N,配 2N 止损 ⇒ 单笔风险 **2%** | `risk_per_trade: 0.01` = **原著的一半** |

### 现在装的是什么

**新开一份** `engine/configs/trend_following-原著-唐奇安反向通道离场.yaml`,只把这三处改回原著:

- ⑥ 离场 → `close_below_lowest_low(20)` + 初始止损照常生效
- ⑤ 移动止损 → `type: none`
- ⑦ 仓位 → `risk_per_trade: 0.02`

并注册进 `engine/run_orig_exits_1029.VARIANTS`(和技-1 原著 Sys1/Sys2、以及「装错的那一版对照」摆在同一组),★ 否则这个修只存在于文件里、没人跑。

**原来那一份(专家/行业版)的数值一个都没动**,只把 **4 处写错的出处**改了(`regime` 块 / `sizing` / `stop_trail` 块 / `exit` 的 MA50 与块级):一律从「原著」改成「行业惯例」,并在每一处写明为什么。

### 原著原文依据

- **离场**:技-1 方法卡 ②离场 对照表「**10 日 / 20 日反向通道**(两套系统各自对应)」;System 2 入场 55 日 → 出场 20 日。
- **为什么必须写成离场规则、不能写成移动止损**:原著的反向通道**可以往下跑**,引擎的移动止损有「只许单向上移」铁律(`engine/ops_a0.py:336`),两者不等价。这一点 `技-1.yaml` 本来就做对了。
- **移动止损**:方法卡「原版无移动止损」;吊灯是 LeBeau (1992),该文件自己底下那一条也标着「行业惯例」。
- **仓位**:原著「1 单位 = 账户 **1% / N**」,止损 2N → 单笔风险 = 2%;引擎 `risk_per_trade` 的定义是「到止损为止亏多少」。**同一条原著规则 `技-1.yaml` 推导对了(0.02,换算逐字写在 source 里)。**

### 为什么这不是调参数

1. 三个值每一个都有原著依据、且是**换算或照抄**出来的,不是挑出来的。
2. 方向上三处都**不利于**成绩:离场更松 → 持仓更长;去掉吊灯 → 少一道保护;仓位翻倍 → 波动翻倍。40 只票的冒烟实测(**不是结论,只是证明机制跑通**):原著版 172 笔 / 平均持仓 34.2 天 / 每笔净 R **+0.1095**;行业版 182 笔 / 25.4 天 / **+0.1289** —— ★ **原著版更差。**
3. **行业版的阈值一个没动**:同一组 40 只票上,改标注前后 **182 笔 / +0.1289,完全一致**。
4. **同类链同步装**:唐奇安反向通道离场在技-1 那一脉已经装过,本次补的是同一脉里漏掉的那一条,不是只给看起来有救的那几条装。
