# ★★★ 五 · 最可信的一条:它给了我们要的反方证据

**我在批四里特意要求「优先给反方」。它给了,而且给了真文献:**

```
★ Bailey, Borwein, López de Prado, Zhu (2014)
  《Pseudo-Mathematics and Financial Charlatanism:
    The Effects of Backtest Overfitting on Out-of-Sample Performance》
  Notices of the American Mathematical Society, 61(5), pp. 458–471

★ Harvey, Liu, Zhu (2016)
  《… and the Cross-Section of Expected Returns》
  The Review of Financial Studies, 29(1), pp. 5–68
```

★★ **这两篇是真的,我能确认。** 而且它的结论和我们自己的纪律完全一致:

> 「只要系统加入『If Regime == A 则用离场 1,Else 用离场 2』,策略的历史探索路径和隐性参数数量就呈指数级翻倍……经 Deflated Sharpe Ratio 调整后,**绝大多数状态自适应离场在样本外的衰减幅度高达 60%~80%**,显著劣于一条简单、鲁棒、全天候运行的静态出场规则。」

★ 它还给了一个机制论证,是我没想到的:**状态判定是低通滤波器,必然有相位滞后 ——**

```
★ 系统终于确认"进入强趋势"并切换为宽止损时,这轮趋势通常已经消耗了大部分动能
  → ★ 换上宽止损,正好完整吃下见顶后的急跌
★ 系统确认"大势转弱"并收窄止盈时,大盘往往已到超卖震荡的尾声
  → ★ 精准割在主升浪启动前的洗盘里
```

★★★ **我的判断:对你那条「行情强就一直拿、转弱就在重要位置分批止盈」——**

```
★★ 作为你本人的判断,它是对的,而且是十年经验的东西。
★★★ 但作为代码里的规则,证据是明确反对的:它会让参数翻倍,样本外衰减 60~80%。

★ 所以我的建议是分开:
   ① ★ 代码里装静态离场(一条规则,全周期不变)—— 这是能验证的那部分
   ② ★ 行情强弱作为给用户的「说明」出现(「现在是阶段三,这类策略历史上在阶段三……」)
      ★★ 而不是作为自动切换规则
★ ★ 这正好也是我们自己的纪律:每多一组参数,就多一组要过四格硬关的东西。
```

★ **唯一的例外是它给的一条有原著出处的:欧奈尔的 8 周持有规则** —— 突破后 1~3 周涨幅达 20% 的,强制持有满 8 周、期间忽略 25% 止盈线。★ 这条是**写死的、单一分支、作者自己定的**,所以它不属于"我们自己加的状态条件化"。可以进原著版。

# ★★★ 六 · 你昨天提的那条产品红线,它给了成熟解法

**我昨天说:如果离场让用户自由调,我们就不能对任何组合说"验证过了"。**

**它给了三类产品的做法,其中第三类直接解了这个问题:**

| 产品 | 做法 | 怎么处理"用户自己调的参数没验证过" |
|---|---|---|
| **QuantConnect / TradeStation** | 完全放开 | 平台免责,但**强制提供参数稳定性热力图**:参数从 2.0 变到 2.1 收益就断崖 → 警告这是过拟合尖峰 |
| **Thinkorswim / IB** | 只给受限预设 | 禁止逻辑交叉嵌套,只能在预设滑块里选,下单页**强制弹出最大敞口试算** |
| ★★★ **Composer.trade** | **按打法锁定 + 沙盒** | ★★ **用户 Fork 后改了出场逻辑 → 系统强制剥离官方认证徽章**<br>★★ **改过核心出场的,回测引擎强制用近 2 年未参与训练的样本外盲测打分**<br>★★★ **未经蒙特卡洛压力测试的自定义策略,数据库层面禁止发布到公开广场** |

★★★ **我的判断:直接采用 Composer 那套。** 它和我们的纪律是同一个形状 ——

```
★ 官方预设(过了四格硬关的)→ 带认证标记,可以说"验证过"
★★ 用户改过出场的 → ★ 自动掉标记,界面上明说"这是你改的,我们没验过"
★★★ 而且禁止把改过的配置分享出去 —— ★ 这条最关键,它堵住了"一个没验证的配置被当成我们的结论传播"

★ 这就把我昨天那条红线从"要你拍"变成"有现成答案照做"。
```
