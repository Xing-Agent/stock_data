## 结论(必须先看这四句,每句一个数)

> **① 路径敏感确实存在,但在我们的数据上没发作:按点名的四个起点重算,571,570 个格子里 0 个变号 —— 0.00%。**
> 要把起点一路推到「这一格背后只剩不到 500 个**交易日**历史」才开始出现变号;推到极限,上界也只有 **4.08%**。
> ★★★ 所以:**这不是实现的病,是「历史不够长」的病。** 上一轮看到的现象,主要确实是两套口径的历史不同造成的。
>
> **② 顶底混淆的面很大:全池 52.88% 的格子是「走平」格子,它们的一/三之分 100% 由路径决定 —— 当天的读数一点信息都不给。**
> 其中最容易编反的那一档(刚从 ≥60 个交易日的长期趋势里出来、60 个交易日内方向还没确立)占走平格子的 **24.1%**(= 全池 12.8%)。
>
> **③ 编反对 技-3 的后果是 0.0000 R —— 因为 技-3 一次都没读过阶段号。**
> 运行时哨兵实测:技-3 五份配置整链跑通,`状-2` 出阶段号的三个函数**一次都没被调到**。全部 67 条配置里也没有任何一条规则类型吃阶段号。
> ★ 但**假如**按原著在阶段号上加一道闸(只在阶段一/二买),翻转一↔三会让每笔 R 变动 **−0.13 到 +0.32 R** —— 比链子本身的边际还大。所以阶段号现在不是要害,一旦上闸就是要害。
>
> **④ 运行时判据:有,但它不是形态判据,是数据长度判据。**
> 「走平格子 + 这只票手上历史 <400 个**交易日**」→ 标存疑,精确率 **32.1%**(基线错号率 1.21%,提升 26 倍)、召回 32.0%。
> 反过来:历史 ≥1,000 个交易日的走平格子,错号率只有 **0.01%**。
> ★ 所有「看形态」的判据(离上次趋势确认多久、离走平确认多久)**全部失败** —— 最好的精确率 17.1%,基线 7.5%,等于没信息量。

**大白话:** 我们怕的是「同一个画面,因为之前走过的路不同,被编了不同的阶段号」。实测结果是:
**这个病真的有,但它只在「票的历史太短」的时候发作。** 老票(有四年以上数据)的阶段号是稳的,基本不会随起点变;
新票、新上市、刚补进池子的票,阶段号有一半是靠不住的。
而且有一个更要紧的发现:**代码在「完全没有历史」的时候,把走平默认编成「阶段一 = 底部 = 该买」** —— 不是判断,是缺省值,而缺省方向是买(见第四节)。

## 一 · 换起点重算:阶段号会变吗(问题一)

**测法:** 把同一只票的收盘序列从第 *o* 个**交易日**切开喂进去,从切点重算 SMA150 / 原始读数 / 确认序列,再比同一个交易日的阶段号。
★ 换起点**不改原始读数**(除了切点后那 220 个交易日的预热),它改的只有**已确认历史的前缀** —— 这正是要测的东西,不多不少。

| 起点集合 | 可比格子 | 阶段号变了的格子 | 比例 |
|---|---|---|---|
| **点名的四个(第 1 / 60 / 120 / 250 个交易日)** | 571,570 | **0** | **0.0000%** |
| 密扫 40 个起点(0 ~ 780,每 20 个交易日一档) | 571,570 | 23,321 | **4.0802%** |

**★ 第一次出现变号的起点:偏移 520 个交易日。** 0 ~ 500 这 26 个起点,一格都不变。

★★★ 真正的规律不是「起点」,是**这一格背后手上有多少历史**。把每一格按它被算出来时可用的历史长度分桶:

| 手上历史(**交易日**) | 走平格子 | 阶段号和全历史不同 | **错号率** |
|---|---|---|---|
| < 250 | 4,313 | 2,117 | **49.1%** |
| 250 ~ 400 | 137,593 | 43,491 | **31.6%** |
| 400 ~ 550 | 342,221 | 43,052 | 12.6% |
| 550 ~ 700 | 539,305 | 26,368 | 4.9% |
| 700 ~ 1,000 | 1,595,153 | 26,662 | 1.7% |
| **≥ 1,000** | 9,169,298 | 965 | **0.01%** |

(格子数是 39 个起点累计,所以大于 571,570;全部格子口径的同一张表在附录二。)

**大白话:一只票至少要有 1,000 个交易日(约四年)的历史,它的「这是顶还是底」才算编得住。少于一年的,一半是瞎编的。**

**哪些格子会变:** 几乎全是 **阶段三 → 阶段一** 这一个方向 —— 143,586 次「格子 × 起点」的变号实例里,**3→1 占 99.35%**(142,655 次),剩下 931 次是零散的「某档 → transition」。按基线标签拆:

| 基线标签 | 可比格子 | 会变 | 比例 |
|---|---|---|---|
| **阶段三(顶部)** | 194,749 | **22,722** | **11.67%** |
| 阶段四 | 123,935 | 371 | 0.30% |
| 阶段二 | 145,144 | 207 | 0.14% |
| 阶段一(底部) | 107,508 | 21 | 0.02% |
| transition | 234 | 0 | 0 |

★ **方向是单边的:会变的几乎都是「本该是顶部,历史不够就被编成底部」。** 反向(本该是底被编成顶)只有 21 格。
★ 这和代码对得上:FLAT 确认时 `上一个已确认阶段 == 2 → 编三`,否则(含**没有历史**)→ **编一**。历史被切掉 → 那个「阶段二」看不见了 → 顶被编成底。
★ 涉及 117 只票(共 300 只),最集中的一只 764 格。

### ★★ 顺带回答了上一轮的一个问号

上一轮 65% 的「真分歧」是 1↔3 这一对。那会不会其实是**实现不稳**?实测:**不是。**
周线口径也做了同一个换起点测试(627 根周线 bar):**起点偏移 112 根周线 bar 之内,一格都不变。**
实际起点(2014-01-02,可比窗口前面有约 208 根周线 bar)远在安全侧。
→ **上一轮那 65% 的 1↔3 是两套口径的已确认历史真的不一样,不是哪一边算得不稳。上一轮的读法成立。**

## 二 · 顶底混淆到什么程度(问题二)

### 1 · 走平格子里,阶段号靠路径定的占多少 → **100%**,而走平格子占全池 **52.88%**

| | 格子 | 占可比格子 |
|---|---|---|
| **label ∈ {阶段一, 阶段三}(= 走平被确认)** | **302,257** | **52.88%** |
| 其中今天的原始读数还是「走平」 | 259,268 | 45.4% |
| 其中今天读数已经不走平了、阶段号还挂着 | 42,989 | 7.5% |
| 阶段三(顶部) | 194,749 | 34.1% |
| 阶段一(底部) | 107,508 | 18.8% |

**这 302,257 格的一/三之分,100% 由路径决定** —— 不是我挑的口径,是实现就这么写的:
原始读数只有 FLAT / ADV / DEC / TRANS 四种,**FLAT 里没有任何「这是顶还是底」的信息**;
一和三的分叉只有一行代码:`上一个已确认阶段 == 2 → 三;== 4 或没有 → 一`。
→ 所以**凡是阶段一或阶段三的格子,它的阶段号都是从历史里搬过来的,不是从当天读出来的。**

阶段号的来路拆开看(两类都是干净的,没有混的):

| 阶段三的前序 | 格子 | | 阶段一的前序 | 格子 |
|---|---|---|---|---|
| 前序 = 阶段二 | **194,749**(100%) | | 前序 = 阶段四 | 91,148(84.8%) |
| 其他 | 0 | | ★ **前序 = 没有(序列开头)** | **16,360(15.2%)** |

### 2 · 最容易编反的那一段:**占走平格子 24.1%**

定义(★ 我们填的,原著没有):**前一个已确认阶段是趋势阶段(二/四)且持续 ≥60 个交易日(=「长期趋势」),而这一格距走平确认 ≤N 个交易日(= 方向还没确立)。**

| N(**交易日**) | 走平格子 | 占走平格子 | 其中前序趋势 ≥60 个交易日 | 占走平格子 |
|---|---|---|---|---|
| ≤20 | 35,508 | 9.4% | 28,357 | 7.4% |
| ≤40 | 65,981 | 17.4% | 52,555 | 13.9% |
| **≤60** | 91,913 | 24.1% | **72,970** | **19.2%** |

→ 口径最宽的那一档(≤60 个交易日):**24.1% 的走平格子**处在「刚从趋势里出来、方向还没确立」的区段(= 全池 12.8%)。

**★★★ 这一条是本轮最该先说清的事实,所以用运行时哨兵实测、不靠 grep:**

然后把 技-3 的五份配置**整链跑一遍**。结果:**五份全部跑通,哨兵一次都没响。**

## 四 · ★★★ 本轮的额外发现:「没有历史」时,代码默认编成「底部 = 该买」

这不在任务里,但它比上面三问更该修。

`engine/state_axis_tri_1029.py` 的 `_confirm_sequence` 里,走平确认时只有三个分支:

```
上一个已确认阶段 == '2'        → 编成 阶段三(顶部)
上一个已确认阶段 in ('1','3')  → 保持原样
否则(含「还没有任何已确认阶段」)→ 编成 阶段一(底部)      ★ 问题在这一行
```

**「我们不知道」和「历史是阶段四(跌下来的)」走的是同一条分支,都编成阶段一。**
而阶段一在产品里的含义是**底部筑底、该准备买**。→ **缺省值的方向是「买」。**

实测这一类格子:

| | |
|---|---|
| 格子数 | **16,360**(占走平格子 5.41%,占全池 2.86%) |
| 涉及票数 | **58 只**(共 300 只 = 19.3%) |
| 日期范围 | 2018-01-02 ~ 2021-09-09,中位 2018-10-15 |
| 按自然年 | 2018 年 9,714 格 / 2019 年 5,297 / 2020 年 1,330 / 2021 年 19 |
| 最集中的票 | NEU 665 · ED 625 · AGNC 601 · EXC 601 · PPG 599 · BDN 597 · OCSI 594 · DTE 593 |

★ ED / EXC / DTE 这些是上市几十年的公用事业股 —— 它们不是「新票」。它们是**从我们的数据起点(2014)开始就一直走平、从没确认过趋势阶段**,于是整段被缺省值编成「阶段一 = 底部」,一路挂到 2019 年。
★★ **这不是编错号(换起点也不变),这是「代码在没有依据时替我们表了态,而且表的是看多」。** 这一条要不要改,我列在要拍板的事里。

## 附录六 · 本文件自己填的口径(凡是原著/配置没给、代码必须有答案的)

1. **「换起点」的实现**:把收盘序列从第 *o* 个交易日切开(`cl[o:]`),从切点重算 SMA150 / raw / 确认序列。★ 预热跟着往后挪,所以只在「所有起点都已出标签」的格子上比 —— 实测剔掉 **0** 格(偏移 ≤780 时 2018 年初都还有标签)。
2. **起点集合**:点名的 4 个(0/60/120/250)+ 密扫 0~780 每 20 一档(40 个)。周线口径 0~152 每 8 根周线 bar 一档(20 个)。
3. **「长期趋势」的长度门槛 60 个交易日**:★ 我们填的,原著没给。选 60 的理由只有一个 —— 它是「最短持续 4 周 = 20 个交易日」的三倍,够把一次确认和一段趋势分开。★ 换成 40 或 100 这张表会变,正文那个 24.1% 对这个门槛敏感。
4. **「方向还没确立」的 N**:20 / 40 / 60 个交易日三档全报,不挑一个好看的。
5. **反事实闸门的写法**:「只在进场日 label ∈ {1,2} 时才买」。翻转 = 把 1 和 3 互换,所以翻转后的闸门等价于「label ∈ {3,2}」。★ 这是**后验筛台账**,不是重跑整链 —— 所以它**只能回答「闸门会不会改变成绩」,不能回答「加闸后槽位竞争会怎么变」**。后者要重跑,本轮没做。
6. **真值(ground truth)**:「这一格的阶段号在 40 个起点扫描下至少变过一次」。★ 这是一个**能测到的下界** —— 起点再推下去可能还会变更多。
7. **阈值**:两套口径的参数全部沿用 `tri.STAGE_VERSIONS['XING版']`(走平 0.5%/周、最短持续 4 周),★ 一个数都没改。
