## 五 · 第二件:1.96 / 2.5 / 3.0 三档的代价(★ 全部自己核算,不抄)

```
测试次数 × 单侧尾概率 = 纯噪音期望过关数
  Z ≥ 1.645  p = 0.04998  →  300 次测试期望过 14.995 ≈ 15.0 个
  Z ≥ 1.96   p = 0.02500  →  300 次测试期望过  7.499 ≈  7.5 个
  Z ≥ 2.5    p = 0.00621  →  300 次测试期望过  1.863 个
  Z ≥ 3.0    p = 0.00135  →  300 次测试期望过  0.405 ≈  0.4 个
★ 和任务书给的数逐条对上(15.0 / 7.5 / 0.4)。
★ 本轮实际只测 45 条,同样四档的期望过关数 = 2.25 / 1.13 / 0.28 / 0.06。
★★ 「≥300 次」这个前提自己核过:仓库里登记的策略链 182 条(流水文件 183 份),
   每条至少一次判据 → ≥182;四格硬关每条再贡献 4 格 → 182 + 728 = 910。
   ★ 所以「全库测试次数 ≥ 300」成立,而且是宽松的下限。
```

### ★★★ 一处必须报出来的矛盾 —— 不替它圆

外部意见的**正文**说「必须提高到 **t ≥ 3.0**」(引 Harvey / Liu / Zhu 2016
"…and the Cross-Section of Expected Returns"),★ 但它**最终给的矩阵里写的是 Z ≥ 1.96**。

| 门槛 | 300 次测试下纯噪音过关数 | 全周期真 t=2.0 的策略被这道门挡掉的概率 |
|---|---|---|
| **1.96**(矩阵里写的) | **7.5 个** | **48.4%**(门几乎就在 2.0 上,过关率 51.6%) |
| 2.5 | 1.86 个 | **69.2%** |
| **3.0**(正文说的) | **0.4 个** | **84.1%** |

★ 第三列的算法:真效应 t=2.0 时观测 Z ~ N(2.0, 1) → 过关率 = Φ(2.0 − 门槛)。

★★ 这两个数差很远:**1.96 放进来的噪音是 3.0 的 18.5 倍**(7.5 / 0.405)。
→ ★★★ 本轮**按 1.96 实现**(照矩阵),但三档的结果全部算出来并列报出,
  让策略组看到换门槛的代价。★ 不给一个数,也不替外部意见决定哪个才是它的本意。

## 六 · 第三件:为什么要换掉「四格符号一致」(★ 全部自己核算)

```
旧门:把 2018–2025 切成 2 段 × 2 堆票 = 四格,要求四格的 Z ★ 符号全正。
     ★ 切成四等份之后,每格样本是全周期的 1/4 → 单格 t = 全周期 t ÷ 2(t ∝ √n)。

全周期真 t=2.0(华尔街合格水平) → 单格 t=1.0 → P(单格>0)=Φ(1.0)=0.8413
   → 四格全正概率 = 0.8413⁴ = 0.5011   ★ 一半的好策略被误杀
全周期 t=1.65 → 单格 0.825 → Φ=0.7953 → 四格全正 = 0.4001
全周期 t=2.5  → 单格 1.25  → Φ=0.8944 → 四格全正 = 0.6398
全周期 t=3.0  → 单格 1.5   → Φ=0.9332 → 四格全正 = 0.7584
★ 四个数和任务书逐条对上。
```

### ★★★ 任务书要求必须写进报告、不许省的那个数

```
若那 13 个版本**都是** t=2.0 的真策略,它们**全部**被这道门误杀的概率
    = (1 − 0.5011)¹³ = 0.00011873 = **0.0119%**(约一万次里一次)

→ ★★★ 所以:这道门误杀一半是真的,但它**解释不了「13 个过 0 个」**。

反推:要让「13 过 0」的概率达到 5%,单策略通过率最高只能
    1 − 0.05^(1/13) = 1 − 0.79418 = **0.20582**(20.6%)
  → Φ(t/2) = 0.20582^(1/4) = 0.67355 → t/2 = 0.44974
  → ★★★ 对应全周期 **t ≈ 0.90**
★ 四个数(0.0119% / 20.6% / 0.90)全部复核一致。
```

★★ **结论是两条同时成立,不是二选一:**
① **这道门该换** —— 它对真 t=2.0 的策略误杀率 49.9%,而且「切成四块各自都要赚」
   这个要求本身没有统计依据(它惩罚的是样本量,不是策略)。
② **这批策略的真实效应也确实弱** —— 因为「13 过 0」只有在单策略真实 t≈0.90
   的量级上才算常见。
★ 不许把结论写成「全是门的问题」或者「全是策略的问题」。

## 七 · 新门的实现与反向自测

### 7.1 回归式

```
R_i = β · 真信号_i + 行业固定效应(SIC 两位) + 年月固定效应 + ε_i
                     ↑ 标准误:按 entry_date 与 symbol **双向聚类**
判据:β 的 cluster-robust t > 2.0
```

**大白话**:把这条链的真实交易和它的 50 条「同环境随机进场」对照流水摞在一起,
问一句:**在同一个行业、同一个月里**,真信号那一批的每笔 R 是不是比随机那一批高?
算 t 的时候承认两件事会让交易彼此牵连 —— 同一天开仓的会一起涨跌、同一只票的多次交易彼此像。
★ 不承认这两件事,t 会虚高。

★ 不物理切块,保留完整时间序列(这正是和旧门的根本差别)。
★ 出处:Petersen (2009) RFS;Cameron, Gelbach & Miller (2011) JBES;Thompson (2011) JFE。
★ 实现用 `statsmodels 0.15.0`(装之前先 import 确认过:仓库里原来**没有**
  statsmodels 也没有 linearmodels;用 `pip install --break-system-packages` 装的)。
