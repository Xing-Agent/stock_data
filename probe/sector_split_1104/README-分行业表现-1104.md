## 二 · 行业码是怎么按时点取的

| 项 | 做法 |
|---|---|
| 数据源 | `pilot_300/<代码>/fundamentals.json` → `sic_versions`(★ 250 只里 **249 只**有这个字段;唯一没有的是 `FRC`) |
| 取法 | 一笔交易用它**进场那天**生效的那个版本:取所有 `observed_from` 的日期 ≤ 进场日 的版本里**最晚**的那个 |
| ★★★ 没有回填 | **没有**用最新版本去填历史。进场日早于该票首次 SIC 披露的交易 → 记「行业未知」,不猜 |
| 严格一点会不会变 | 如果把判据改成 `observed_from < 进场日`(把披露当天也算成还没生效),**全部 46545 笔里只有 2 笔**会换一个 SIC 码 |
| 时区 | `observed_from` 是带时区的 UTC 时刻,只取前 10 位当日期用;流水的 `entry_date` 是交易日 |

### 问题二 · 跨板块的离散度有多大?和噪声比呢?

大白话:**「同一条策略换个行业,成绩差多少」和「同一条策略什么都不换、纯粹因为笔数有限而抖动的幅度」,哪个大?**

做法(逐条链算,只用笔数 ≥ 30 的板块):

- **实测离散度** = 该链各板块「每笔净R」的标准差
- **噪声水平** = 各板块那个均值本身的标准误(= 该格 R 的标准差 ÷ √笔数)的均方根 —— 这是「假设行业完全没影响」时,光靠抽样噪声也会出现的离散度
- **倍数** = 实测 ÷ 噪声。**1.00 = 看到的全是噪声**
- `Q` = Cochran 异质性统计量(逐格按 1/方差 加权),`df = 板块数 − 1`,`p` 是它的卡方 p 值
- `I²` = 实测离散里「超出噪声」的那一份占比,0 = 全是噪声
