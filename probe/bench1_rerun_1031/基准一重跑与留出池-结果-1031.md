## 三 · ★★★ 本轮新查出的第三处缺陷:退化 R

**大白话**:止损价正好落在进场价上 → 1R = 0 → 那一笔的 R 变成 1.75 万亿 → **一笔就把 50 个种子的均值毁掉**。

**实测**:

| | |
|---|---|
| 45 条里**至少有一笔**退化 R 的 | **35 条** |
| 其中**数值已经被毁掉**(\|基准一\| > 10) | **★ 5 条**,全是技-10 族 |
| 真链流水里的退化笔 | **★ 0 笔 —— 45 条全是对照组那边出的** |

| 链 | 原样(垃圾) | 剔掉退化笔后(参考,**不是结论**) | 对照退化笔 |
|---|--:|--:|--:|
| 技-10 · 持仓 2 天(严格端) | −3.14e+09 | −0.0494 | 61 / 56,714 |
| 技-10 · 持仓 3 天(中值) | −5.26e+09 | −0.0379 | 60 / 56,174 |
| 技-10 · 持仓 5 天(宽松端) | −6.02e+09 | −0.0368 | 58 / 55,085 |

> 技-10 的 3 条在「原著离场」和「剔污染」两个批次下各出现一次,所以 5 条里只有 **3 份独立结果**。

**另外 30 条**虽然也有退化笔,但影响在小数第三位(例:技-5 原著版 0.55 中值,−0.005722 → −0.006778)。**不影响结论,但要登记。**

### 根因(查清了)

技-10 的止损是 `day_low_minus_tick`:3 根 K 线最低价 − $0.01。当进场价刚好落在那个最低价下方 1 tick 时,**止损价 == 进场价**,`risk_per_share` = 3.55e-15(浮点尘埃)。

实例:BGS 2019-12-16,进场 16.67,止损 16.67,R = 1.75e+14。

另外 WPG 的进场价是 5.18004 —— **小数点后 5 位**,说明这个写死的 $0.01 tick 是加在**拆股调整后**的价格序列上的,而调整后 $0.01 已经不是真实的最小报价单位。

**引擎里没有任何「1R 不许小于某个值」的下限。**

### ★★ 这一条我不自己定,登记成待拍板

「止损价 == 进场价 时 1R 等于多少」—— **本身没有定义**。三种补法(剔掉这笔 / 置 NaN / 用进场价当分母)**会改变全库每一个 R**。这是口径决定,不是实现细节。

- 判据阈值 `risk_per_share / entry_price < 1e-4` 是 **★ XING 填的,不是原著**
- 我**没有**改 `analyze.py` 的 R 定义,只做了检测和隔离
- 受影响的 5 条,基准一**一律不出数**(不许把 −31 亿当成一个数渲染)

## ★ 要你拍板的(一条)

**「止损价 == 进场价」时 1R 等于多少?**

这个量**本身没有定义**,而它已经把技-10 族 3 份独立结果的基准一算成了 −31 亿。三种补法:

- **甲 · 剔掉这笔**(我的倾向)—— 1R 没有定义的笔,不进 R 的统计。代价:会少掉极少量笔数(对照组万分之一量级)
- 乙 · 置 NaN 再按 NaN 规则走 —— 效果接近甲,但要逐处确认 `nanmean` 都用对了
- 丙 · 用进场价当分母 —— 和「无止损」那 5 条的处理一致,但会让这些笔的 R 变成收益率,**混进有止损的那一列**

**我的倾向是甲。** 理由:它改动最小,而且和「无止损整条链单独排序」那条既有纪律不冲突 —— 丙会把退化笔偷偷混进有止损的列里排序。

★ 这件事我没自己定,因为它会改变全库每一个 R。
