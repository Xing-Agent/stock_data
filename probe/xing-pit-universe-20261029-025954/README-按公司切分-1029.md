# 按「公司」切分的历史时点名单 · 2026-10-29

> **三秒版:名单从「按代码」改成「按段」。同一个代码换过公司 → 切成两段;一家公司改了代码 → 两段接起来,前一段不算退市。**
> **已知案例全对(FB/META/HHH/PCLN/BBT 切开,FB→META、ANTM→ELV 等接上,SIVB/FRC/XLNX/ALXN 标退市)。改名接续抽查约 85% 对,★ 回测里不要拿它把两段价格拼起来,只当标签用。**

文件:`pit_company_segments.csv`(28,960 段;2015-12-01 以后还在册的才列)

## 一 · 列的意思

| 列 | 说明 |
|---|---|
| seg_id | 段编号(一只代码可以有好几段) |
| company_id | 公司编号:改名接上的几段共用一个 |
| ticker / seg_no | 代码 / 这个代码的第几段 |
| first_seen / last_seen / days | 这一段第一天、最后一天、有成交的天数 |
| cut_reason | 为什么从这里开始新的一段:`start` / `缺席N个交易日` / `缺席N天后价格变X倍` |
| renamed_from / renamed_to | 改名接续:从哪个代码来 / 改成了哪个代码 |
| **end_type** | **样本末尾仍在交易** / **改名(公司还在)** / **消失(退市/被收购/到期)** / 消失(可能改名,候选不唯一) |

## 二 · 规则

**切开(换公司):**
- 同一代码**连续**缺席 ≥ 30 个交易日 → 切(3,393 处)
- 缺席 5–29 天、回来时价格差 3 倍以上、又不是整数拆股比 → 切(147 处)
- ★ 和 v2 的区别:v2 看的是「累计缺多少天」,冷门小票会被大量误抓;这里看「一次连续断多久」

**接上(改名):** 代码 A 最后一天之后 1–2 个交易日内,代码 B 第一次出现,并且:
- B 的开盘价和 A 的收盘价差 < 3%,成交量在 0.3–3.3 倍之间
- 两边都是普通股样式代码,日成交量 ≥ 5 万股
- 价格不在 $9.4–10.6(SPAC 扎堆)和 $24–26(优先股/小额债券扎堆)
- 一对一:有多个候选的不接,标「候选不唯一」(55 个)

## 三 · 验证

| 案例 | 应该 | 结果 |
|---|---|---|
| FB | 2022-06-08 前是 Facebook → 改名 META;2025-06 后是别的产品 | ✅ 切成两段,第一段接 META |
| META | 2021-06 → 2022-01 是一只 ETF(后改名 METV);2022-06-09 后是 Meta | ✅ 两段,第一段接 METV,第二段接自 FB |
| HHH | 2021-10 → 2022-07 别的产品;2023-08 后是 Howard Hughes | ✅ 两段,第二段接自 HHC |
| PCLN / BBT / LB | 改名后旧代码被别人重新用 | ✅ 都切成两段 |
| ANTM→ELV · PCLN→BKNG · BBT→TFC · NRZ→RITM · PKI→RVTY · IIVI→COHR · MDA→MAXR | 改名 | ✅ 全部接上 |
| SIVB · FRC · XLNX · ALXN · TWTR · ATVI · CTXS | 退市/被收购 | ✅ 全部「消失」 |
| **LB → BBWI** | 改名(同日分拆维多利亚的秘密) | ❌ **没接上**:分拆那天价格跳了,价格匹配接不上 |

**随机抽 25 条「改名」:约 85% 对。** 错的那种:一只票被现金收购的最后一天,碰巧第二天有只新股上市、价格差不多(ORBC→SLGC、NFH→CRDO)。

## 四 · ★ 怎么用

1. **修幸存者偏差**:选池按「段」选,不按代码。`end_type = 消失` 的就是期间死掉的,回测里持仓要在它 `last_seen` 那天按最后价出场
2. **★ 不要用 renamed_to 把两段价格拼成一条连续序列。** 15% 的接续是错的,拼错了等于把仓位转进一只毫不相干的新股。接续只用来回答「这只票消失是不是因为改名」
3. 这仍然是没有公司编号时的近似。要做准:用 Massive 账号拉它的 tickers 接口(带 `cik` 和 `composite_figi`),按编号重做
4. 名单里仍然包含 ETF、权证、优先股、SPAC 单位 —— 选个股池时要另外剔
