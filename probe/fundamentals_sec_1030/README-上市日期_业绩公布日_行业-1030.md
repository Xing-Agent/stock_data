## 一 · 历史长度 / 上市日期（解锁「历史不够长就不给阶段号」那道闸和技-9）

**大白话**：段表原来只从 2013 年算起，2013-01-02 就在交易的票其实可能已经交易了十年。这次用 2004 年起的日线往前补，切法和段表完全一样：缺席 ≥30 个交易日就切；缺席 ≥5 天且价格变 3 倍以上、又不是拆股比，也切。

**怎么用**：
- 按 `seg_id` 和池子表（`pool_FULL_ALL.csv`）对上。**用 `company_history_start`**，它会沿着改名链取最早那段，比如 META 会追到 FB 的 2012-05-18
- 某天 D 的历史长度 = 从 `company_history_start` 到 D 的交易日数
- `company_start_censored = true` 表示起点就是数据开头 2004-01-02，实际只会更长。这些票到 2014 年已经有 ≥2,500 个交易日，闸门照放行
- 全量池里，每年基准日时历史 <250 个交易日的占 **8.5%**，250–400 的占 5.5%，≥1,000 的占 69%

**技-9 用的新股**：`new_listing_candidate = true`
- 判定条件：起点不是数据开头；不是改名接上来的；同一个代码之前没出现过，或者已经消失 ≥250 个交易日
- `spac_like_price = true`：第一天收盘价在 9.5–10.5 美元，像 SPAC 空壳，建议剔除
- 这一列包括 ETF、权证、优先股，要和池子表对上才干净
- 验证：TSLA 2010-06-29、FB 2012-05-18、ABNB 2020-12-10、RIVN 2021-11-10 都对；SIVB 不算新股（2005 年数据里缺了 101 天，已经排除）

**局限**：
- 这是「在我们数据里第一天交易」，不是法律意义上的上市日。2004 年以前上市的看不到
- 数据源本身偶尔缺几个月，会把起点算晚，SIVB 就是例子。对「够不够长」的判断是偏保守的方向，不会把短的算成长的

## 二 · 真正的业绩公布日（8-K 第 2.02 项）

**大白话**：公司公布业绩当天要向 SEC 交一份 8-K，勾上「2.02 经营业绩」。这份的提交时间就是公布时间。

**列**：
| 列 | 说明 |
|---|---|
| `announce_date` / `announce_time_et` | 公布日期、美东时间。SEC 原始记录是 UTC，已经换算，含夏令时 |
| `session` | 盘前（<9:30）/ 盘中 / 盘后（≥16:00） |
| **`first_tradable_date`** | **市场第一个能反应的交易日**：盘前、盘中公布就是当天，盘后公布就是下一个交易日。**事件策略用这一列** |
| `period_end` | 对应哪一期，取之后最近那份 10-Q/10-K 的报告期 |
| `periodic_filed` / `days_before_filed` | 10-Q/10-K 递交日，以及公布日比递交日早几天 |
| **`main_release`** | **正式业绩 = true**。同一期可能有好几份 2.02，比如 TSLA 每季初公布交付量也勾 2.02。正式业绩取「报告期结束后、10-Q/10-K 递交前，最晚的那一份」 |

**数字**：
- 正式业绩 13,641 条，每只票中位 50 条，大约 12 年 × 4 个季度
- 比递交日早：中位 1 天，90% 在 19 天以内，36% 是同一天（BA 这类公司当天一起交）
- 时段：盘后 49%，盘前 43%，盘中 7%
- 抽查对得上：META 2024-07-31 16:11 盘后、TSLA 2024-07-23 盘后（同月 07-02 那份交付量已标非正式）、WMT 2024-08-15 06:59 盘前、BA 2024-07-31 07:37 盘前

**注意**：
- 「盘中」那 7% 大多是盘前发了新闻稿、开盘后才交 8-K。SEC 的时间只会比实际公布晚，不会早，所以按它做事件日不会偷看未来。最多晚半天
- 8 只没有 2.02：OCSI、FRC、MTR 不在 SEC；CDZI、TRNO、EQS、ELSE、LIXT 是业绩不走 8-K 的公司。这几只事件策略里先剔除
- 有 253 个报告期挑不出正式业绩（公布日不在「报告期结束 → 递交」之间），`main_release` 全为 false，按缺失处理

## 三 · 4 位行业代码（SIC）

- `sic4` 是 4 位代码，比现在的 2 位细一层。297 只里一共 136 个 4 位代码（2 位只有 53 个）
- 例子：TXN、MPWR、QRVO 同为 3674 半导体；VSH 是 3670 电子元件；CDNS 是 7372 软件
- ★ **两个局限**：
  1. **这是 SEC 现在的分类，不是当年的**。公司转型以后不会回改，比如 QCOM 还挂在 3663「广播通讯设备」
  2. **主题关联分不开**。NVDA、VRT、SMCI 同挂 AI 建设供应链，SIC 里是三个不同行业。集中度安全带光靠行业分类装不全，建议再加一道「近 60 天收益相关性 > 0.7 的算同一组」
