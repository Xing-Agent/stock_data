## 二、★ 价格复权（先回答这个，更要紧）

**1. 300 只回测用的是什么价？**
- 源头是 **Alpha Vantage 的原始价**（`daily.json` 里 `adjustment: raw`），每根 K 线带一个 `split_coefficient`（拆股系数），另附一份公司行动清单（拆股和分红）
- 引擎 `engine/data.py` 的 `load_daily()` 读进来以后，在 `_apply_split_fix()` 里**按拆股系数往前复权**：拆股日之前的价格乘 1/系数，成交量除以 1/系数，多次拆股会自动连乘（TSLA 2020 年 ×1/5、2022 年 ×1/3，最早那段 ×1/15）
- 数据里有断裂、系数又解释不了的，按 `engine/split_gate` 里有 SEC 证据的手工清单，**把序列切开**，不编系数
- **分红没复权。** 默认口径是纯价格收益；`total_return_daily()` 能算总收益，但默认关着

**2. 拆股系数从哪来？**
- Alpha Vantage 的 `split_coefficient`。分红来自 FMP，两边对过账（`corporate_actions.provider = reconciled`）
- 引擎自检实测：66 个拆股事件，当天的价格比值都和系数吻合，说明源头价格确实没调整过，不会重复复权

**3. 需要复查以前的回测吗？**
- **10-29 以后的结果不用。** 那天改成读源头系数，之前用的是手工清单，被技术方核出 5 条错。10-29 以前用旧清单跑出来的结论，技术方已经用 `run_split_bias.py` 专门测过影响
- NVDA 不在这 300 只里

**4. ★ 考卷那几千只怎么办**
- 全量日线（Polygon 的全市场日线）**只有原始价，没有拆股系数**
- 要和 300 只一模一样，就得：**拿到每只票的拆股系数 → 塞成同样的 `split_coefficient` 格式 → 走同一个 `load_daily()`**。分红同样默认不算
- 拆股系数从哪来，三个办法：

| 办法 | 优点 | 缺点 |
|---|---|---|
| **A. Polygon 拆股接口**（`/v3/reference/splits`，用 Lin 的代理） | 一次拉全市场，**退市的票也有** | 和 300 只的来源（Alpha Vantage）不同 |
| B. Alpha Vantage（和 300 只同一个来源） | 来源完全一样 | 退市的票基本拿不到，几千只要很久 |
| C. 我们自己从价格跳空认拆股（全量池早就这么做了） | 不用新数据 | 是推算的，有误判风险 |

**我的建议：用 A，再用 300 只验一遍。** 用 Polygon 拉那 300 只的拆股，和 Alpha Vantage 的 66 个事件逐条对：日期、系数全部对上，才算「同一种处理」，再用到考卷上；对不上的逐条查。C 只拿来做第三道核对：价格跳了、却没有拆股记录的，标出来人工看。

## 一、status 列

**文件**：`probe/fundamentals_sec_1030/sec_fin10_status_1101.csv`
- 主表只有「报了的数」，没报的那一期本来就没有行，所以 status 放不进主表
- 另做了这张格子表：每家公司 × 每个指标 × 每份 10-K/10-Q 一行，有数的那一行也带上数值

| status | 意思 | 建议 |
|---|---|---|
| `has` | 这一期有数 | 用 |
| `never` | 2014 年以来一次都没报过 | 可以按 0 |
| `never_in_10q` | 年报里报过，季报里从来不报（广告、研发很常见） | 季报这一期按缺失，**用年报的数** |
| `gap` | 报过，这一期没有 | 按缺失 |
| `gap_shares_up` | 发新股收入是 gap，但这一期股本比上一期多 0.5% 以上 | **绝不能当 0** |

- 年报和季报分开判断；`before_first_report = true` 表示这一期在它第一次报之前（gap 里约 1/3 是这种）
- 每份财报的股本放在 `shares` / `shares_prev` 两列，可以自己换门槛

**★ 一个要知道的情况**：现金流量表里的项目（发新股、期权行权、短期借款），**那一年是 0 的时候，公司在电子财报里常常干脆不填这一行**。所以这几项的 `gap` 里，有相当一部分其实就是 0。按 Gemini 的意见一律按缺失是保守的做法，不会算错，只是少用一些数据。将来要放宽，最稳的办法是只把「gap 且股本没增加」的发新股收入按 0。
