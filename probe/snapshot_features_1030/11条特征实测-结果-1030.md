# ★★★ 二 · 哪几条不能说成「这只票的脾气」

**★ 判别办法(就是你给的那个):一条特征如果在两段里对大部分票给不同答案,它测的是"那几年的市场",不是"这只票的脾气"。**

★★ 我多加了一个对照段把「真的变了」和「判据不稳」分开:

```
★ 主测  : 2018-2022  vs  2023-2025   ← 隔着一个市场环境
★★ 对照 : 2018-2020  vs  2021-2022   ← 同一个时代内部切两半

★★★ 读法:
   ★ 对照段稳、主测段不稳  → 「真的变了」(市场换了环境,票的行为跟着变)
   ★★ 对照段也不稳          → 「判据不稳」(跟年份无关,这个判据本身就是在量噪音)
```

| 特征 | 主测 kappa | 对照 kappa | 对照 Spearman | ★★★ 判定 |
|---|---|---|---|---|
| **T4 假突破率** | −0.13 | **−0.05** | **−0.11** | ★★★ **判据不稳** —— 同一个时代内部切两半照样是 0。不是市场变了,是这条判据本身在量噪音 |
| **F4 均线反应** | −0.01 | **−0.09** | **−0.04** | ★★★ **判据不稳** —— 同上 |

```

❌ 「这只票假突破多,是海龟汤的猎场」         ← T4,★★★ kappa −0.13,比瞎猜还差

   ✓ 「这只票平常一个来回是 −12% / +15%」            ← T3,kappa +0.32 / Spearman +0.71

# ★★★ 三 · T4 假突破率 —— ★ 这一条最值得单独说

```
★★ 它是 11 条里**分布最漂亮**的一条:
   ★ 覆盖率 100% · 中位 0.485 · 四分位 0.434–0.552 · 没有堆在任何一档。
   ★★ 任何人看这个分布都会说「这条特征有区分力,上界面」。

★★★ 而它是**纯噪音**:
   ★ 两段一致率 0.436,★★ 偶然一致率 0.500 —— **比抛硬币还差**。
   ★ kappa −0.13 · Spearman +0.05(p 不显著)
   ★★ 同一个时代内部切两半(2018-2020 vs 2021-2022):kappa −0.05 · Spearman −0.11。
   ★★★ 所以不是「市场变了」。★ 是这条判据本身在量噪音。

★ 为什么:中位每只票 8 年只有 33 次突破事件 → 一段里 15~21 次(2018-2022 段中位 21 次)。
  ★★ 一个真实比率 50% 上下、样本只有 18 个的量,它的抽样噪音本身就有 ±12 个百分点
     —— 这比票和票之间的真实差异(四分位宽 12 个百分点)一样大。
  ★★★ 也就是说:★ 我们看到的那个"漂亮分布",**全部宽度都可以用抽样噪音解释完**。
```

**★★ 这条对设计的直接影响:** 设计文档写「**海龟汤(技-10)恰好做的就是假突破 —— 假突破率高的票是它的猎场**」。**实测不支持这句话。** 我们区分不出「假突破率高的票」—— 本期高的票下一期就不高了。**技-10 的选股不能用这个指标筛。**

# ★★★ 七 · T1「它怎么做顶」还能不能救 —— ★ 查到了,答案是「数能对上,但结论反过来」

**★ 第一个发现是结构性的,和参数无关:**

```
★★★ 一个双顶的两个峰之间的那个坑,★ 按定义**小于** ZigZag 的阈值 ——
   ★ 否则中间就会多出一个摆动点。
★★★ 所以用同一把 k×ATR 的尺子既找「重要顶部」又认「二次触顶」是自相矛盾的:
   ★★ 尺子大到能把顶部叫「重要」,两个峰就被并成了**一个**摆动点。
★ 这就是 T1 在 k=6/8 上「二次触顶占比」中位 = 0.000 的原因
  (k=6 有 55.9% 的票取 0,k=8 有 97.0% 取 0)—— ★ 不是市场里没有双顶,是**这把尺子看不见双顶**。
```

**★★ 所以我换了个两尺度定义**:大尺度(修好的 ZigZag,k=8)只负责**找到重要顶部在哪**;小尺度(那个顶部前后各 60 个交易日的窗口)负责数**那个价位被摸过几次**(两次之间要先跌破顶部 −6%)。

| k | 顶部次数 | 二次触顶占比 中位 | ≥0.5 的票 | 两段一致 / 偶然 / kappa | Spearman |
|---|---|---|---|---|---|
| 6 | 8 年 14 次(每年 1.8) | **0.667** | 94.6% | 0.758 / 0.755 / **+0.01** | **+0.00**(p=0.97) |
| 8 | 8 年 **8 次**(每年 1.0) | **0.523** | 64.9% | 0.555 / 0.541 / **+0.03** | **+0.04**(p=0.70) |

**★★★ 两条结论,方向相反,都要说:**

```
✅ ★ 好消息:文档那句「7 次重要顶部,5 次是二次触顶」★★ 数量级是对的。
   ★ k=8 给 8 年 8 个重要顶部(≈ 文档的 7 次),★ 其中 52% 是二次触顶(文档说 71%)。
   ★★ 「重要顶部会被回踩」这件事是真的 —— ★ 全池中位有一半以上的重要顶部被摸过第二次。

❌ ★★★ 坏消息:它是**全市场规律**,不是**这只票的脾气**。
   ★ kappa +0.03 · Spearman +0.04(p=0.70)—— ★★ 两段之间**零相关**。
   ★★★ 而文档想用它的方式恰恰是逐票的:
      「★★ 如果这只票历史上就是二次触顶型,那条规则对它特别有效;
        如果是尖顶型,那条规则会让你错过离场」
   ★ 这句话**实测不支持**。★★ 我们分不出「二次触顶型的票」和「尖顶型的票」。
```

**★ 那这条怎么用:** 改成**全局规则**,不要做成逐票特征 ——「**重要顶部里约一半会被回踩第二次**(全池,k=8,8 年中位 8 个顶部)」。★★ 这条足以支撑你说的那个做法(「第二次触摸顶部时卖掉大部分」),**但它对每只票是同一句话**,所以不该占第④行的位置,该写在那条规则自己的说明里。
