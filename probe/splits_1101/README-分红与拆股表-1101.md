# 分红 + 拆股（考卷用）· 2026-11-01 · 给主对话

> **三秒版：分红全市场拉好了，和 300 只原来的数据 98% 对得上，对不上的地方大多是原数据漏了，Polygon 反而更全。拆股日期已经对齐到价格真正跳的那一天。剩下要人工看的，等考卷名单定了再看。**
> **★ 一个新发现：Polygon 的参考数据有时把改名公司的老历史挂在新代码下（BB&T 2016 年的分红挂在 TFC 下），有时又挂在老代码下。所以要按「公司」对，不能按代码对。**

都在 `probe/splits_1101/`，只取了参考数据和行情结构，**没跑策略、没算收益**。

## 一 · 分红
- `polygon_dividends_1101.json.gz`：美股 2004 年以来 695,198 条（已去掉 4 个字母 + X 的共同基金）。字段：代码、除息日、金额、币种、类型（`CD` 普通、`SC` 特别）、频率、派息日
- **和 300 只原来的数据对账**（`div_recon_300_1101.csv`，2016–2025 年）：

| 结果 | 条数 | 说明 |
|---|---|---|
| 对上 | 7,322 | 原数据 7,485 条的 97.8% |
| 只有 Polygon | 172 | 多半是**原数据漏了**：COLM 原数据一条分红都没有；IFF 2016–2020 年全缺 |
| 只有原数据 | 149 | 多半是**代码对不上**：VMRK、MRSH、MZTI 是改名后的代码，Polygon 挂在老代码下 |
| 金额不同 | 14 | 特别分红、浮动分红的拆法不同（DVN、MKC、SGA），影响很小 |

**结论：考卷用 Polygon 的分红没问题，而且比 300 只原来的数据更全。** 默认口径照旧只算价格收益，分红只在显式开总收益时用。

## 二 · 拆股
- `polygon_splits_aligned_1101.csv`：2015 年以后的每条拆股，都在记录日前后 3 个交易日里找到「价格真正跳的那天」：

| 核对结果 | 条数 | 怎么用 |
|---|---|---|
| 确认 · 同一天 | 3,742 | 直接用 |
| 确认 · 日期改了 | 191 | 用改过的日期（BMI、USNA 就属于这类） |
| 价格没跳 | 734 | **不用**。比如 ZG 2015 年那条其实是多发一类股票，价格根本没动，用了反而会错 |
| 无行情 | 9,710 | 场外或境外的票，我们的行情里没有，用不上 |

- **第三道核对**（`unexplained_jumps_largemid_1101.csv`）：只扫了大中盘（全量池里成交额前 2,000 名出现过的票），隔夜跳 1.8 倍以上、或跌到 0.55 倍以下、又没有拆股记录的：
  - **疑似漏记的拆股**（跳的倍数正好接近 2、3、5、10 这种整数比）：149 次 / 105 只
  - **真涨跌、分拆或其他**：764 次 / 426 只（比如 CSC 2015-11-30 分出 CSRA，CMRX 新药失败）
  - **ZVZZT 这类是纳斯达克的测试代码**，混进了全量池，选考卷时要剔掉

## 三 · ★ 用之前要注意的
1. **按公司对，不按代码对。** 一家公司的分红和拆股，要在它整条改名链的所有代码下都找一遍（段表里有改名链），只认落在这个代码当时交易区间里的。比如 ELV 2007 年以来的分红都挂在 ELV 下，但那时它的代码是 ANTM
2. **分拆清单还没做**（Lin 已定：考卷和 300 只都抹平分拆）。第三道核对里「真涨跌、分拆或其他」那 764 次，要在考卷名单定了以后，只看考卷里的票，再从中挑出分拆、人工确认
3. 考卷名单还缺三个条件：市值、交易所、是否 ADR。市值用 SEC 股本 × 价格算；交易所和 ADR 可以用 Lin 朋友的 Polygon 入口取 `/v3/reference/tickers?date=2015-12-31`，现在我能直接用浏览器连上这个入口了
