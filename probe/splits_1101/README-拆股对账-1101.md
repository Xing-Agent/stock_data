# 拆股对账：Polygon vs Alpha Vantage（300 只）· 2026-11-01

> **三秒版：没有全部对上。真正的拆股基本一致；对不上的主要是两件事：① 分拆（spin-off）两边记法不一样；② Polygon 有 2 次把日期记早了一天。按 Lin 的规矩，先不用到考卷上，交主对话定。**

文件：`polygon_splits_1101.json.gz`（全市场 2004 年以来 27,691 条）· `av_splits_300.json`（300 只原来用的 82 条）· `split_recon_300_1101.csv`（逐条对账）

## 结果
- Alpha Vantage 的 82 条：**64 条完全对上**，2 条日期差一天，16 条 Polygon 没有
- 反过来，Polygon 有、Alpha Vantage 没有的：8 条

## 对不上的，逐条看（都拿全量日线的原始价核对过）

**① 分拆（spin-off）——两边记法不一样，最要紧**
- Alpha Vantage 把分拆记成一个「拆股系数」，Polygon 不记：DTE、EXC、FMC、MSGS、NUAN、WDC、BWA、ILMN、HHH、BDX、FWONA，共 12 条
- 反过来，Polygon 把 YUM（2016 年分出百胜中国）、DHR（2016 年分出 Fortive）记成拆股，Alpha Vantage 不记
- 分拆那天股价会掉一截（DTE 掉了 14%，YUM 掉了 28%）。300 只的引擎**按 Alpha Vantage 的系数把这一截抹平了**。考卷如果只用 Polygon，**大多数分拆不会被抹平**，就会被算成一次真跌。两边口径对不齐

**② 日期差一天**：BMI、USNA。原始价是在 Alpha Vantage 那一天减半的，**Alpha Vantage 对，Polygon 早了一天**。所以用 Polygon 时，日期要以价格真正跳的那天为准

**③ Alpha Vantage 漏了的真拆股**：
- AMRS 2017-06-06，1 股并 15 股（价格从 0.22 跳到 2.76）
- UHAL 2022-11-10，相当于 1 拆 10（价格从 513 掉到 54）
- 这两只在 300 只的引擎里，是靠手工切断序列处理的。**Polygon 在这两处反而更对**

**④ 小票**：HAPN、LFMD、POCI、PROP、FTLF 的反向拆股，全量日线里这个代码那几天没有交易（可能在场外，或者代码不同）。考卷门槛是市值 ≥20 亿美元，基本碰不到这类票

**⑤ 送股**：PKBK 送 10%、RKDA 1.001，Alpha Vantage 没记。影响很小

## 建议（给主对话定）
1. **拆股用 Polygon，日期一律对齐到「价格真正跳的那一天」**（前后 2 天内找跳空），这样 BMI、USNA 这类就不会错
2. **分拆要单独定口径，而且考卷和 300 只必须一样。** 两个办法：
   - **a.** 两边都不抹平分拆：300 只也去掉 Alpha Vantage 里那 12 个分拆系数，重跑。口径最干净，但分拆那天会被算成下跌（少数票、一年一两次）
   - **b.** 两边都抹平：考卷需要一份分拆清单。Polygon 没有，得另找来源（SEC 的 8-K，或者用第三道「价格跳空」核对把分拆认出来再人工确认）
   - 我倾向 **b**：分拆不是真亏钱，抹平才对。代价是考卷要多一步人工确认
3. 第三道「价格跳空」核对照原计划做，正好兼顾找分拆
