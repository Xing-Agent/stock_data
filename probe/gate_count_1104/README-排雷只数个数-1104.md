## ★★★ 八 · 顺手多算的第六列：Merton 违约距离

★ 口径 = **Merton (1974) 的 naive DD**(Bharath & Shumway 2008 的闭式解)。
★★ 归属标成「**原著 + 行业简化**」,★★★ **不标纯原著** ——
原著要的「资产价值 V / 资产波动率 σ_V」**看不见**,naive DD 是行业里公认的可算代理。

```
★★ 大白话:把一家公司的**股票**看成「对公司资产的一份看涨期权」。
   ★ 股价越抖、负债越重、市值越薄 → 离「还不上钱」那条线越近。
   ★★★ **违约距离 = 还差几个标准差才撞线。数越小越危险。**
★ 公式三样输入就是任务单点的那三样:**市值 + 股价波动率 + 负债**。
   σ_E = 过去 252 个交易日对数收益的年化标准差
   σ_V = E/(E+F)·σ_E + F/(E+F)·(0.05 + 0.25·σ_E)
   DD  = [ ln((E+F)/F) + (μ − 0.5·σ_V²)·1 ] / σ_V
★★★ **本轮不当闸用** —— ★ 阈值**没有定**(任务单要求只给分布)。
```
