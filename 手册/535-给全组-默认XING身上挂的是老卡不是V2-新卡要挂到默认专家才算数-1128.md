# 535 · 给全组：默认 XING 身上挂的是老卡，不是 V2 —— 新卡要挂到默认专家上才算数（2026-11-28）

## 三秒版

**用户在主 chat 里问问题，用的是「默认 XING 专家」，只会调用挂在它身上的卡。**
**我们写的 V2 卡，只上传、不挂到默认 XING 身上，用户就一张都用不到。**

**不只是主 chat。产品里所有带 AI 的地方，背后用的都是同一个「默认 XING 专家」：**

| 入口 | 用的是谁 |
|---|---|
| 主 chat（New research） | 默认 XING |
| 发现页「AI 筛选」 | 默认 XING |
| 发现页「开始对比研究」 | 默认 XING（实测：自动切回默认，预填英文问题） |
| 个股页的问答、「今日研究简报」「深入研究」 | 默认 XING |
| 「我的 skills」里用 AI 编辑、创建卡（AI assistant） | 默认 XING |
| 「我的专家」里用 AI 创建专家（Continue with AI） | 默认 XING |

**这些入口都没法换成我们自己建的专家**，也用不到只挂在别的专家身上的卡。
所以：**新卡只有挂到默认 XING 身上，整个产品才都能用到；只挂在新建专家上，就只有在主 chat 里手动切到那个专家时才生效，其他入口全都用不到。**

（入口那张表：「开始对比研究」是我今天实测确认的，其余是 Lin 的判断，请技术逐个核实后回一句。）

到今天下午为止，测试网的默认 XING 身上一直是 **25 张系统内置的老卡**。所以：
- 只有手动切到「V2.6.10 测试专家」的时候，才是 V2 在答。
- 其他所有地方，答的都是老卡。包括主 chat、发现页的「开始对比研究」、个股页的问答。

Lin 今天在主 chat 里问「苹果现在能买吗」，得到的是「我不能给买入建议」。这是老卡的原话，V2 早就作废了。

## 一、平台是怎么用卡的（大白话）

| 概念 | 是什么 |
|---|---|
| 卡（skill） | 我们写的一份份说明书，比如技术面大师、基本面大师、总路由 |
| 专家（expert） | 一个「装卡的盒子」。AI 回答时，只读当前专家盒子里的卡 |
| 默认 XING 专家 | 用户什么都不选时用的那个盒子。**用户 99% 的时候都在用它** |
| 上传 | 只是把卡放进「我的 skills」仓库，**还没进任何盒子** |
| Install（安装） | 把卡放进**默认 XING** 这个盒子 |

**一张卡要被用户用到，必须两步都做：上传，再挂到用户实际在用的专家上（就是默认 XING）。**
只上传不挂 = 白写。

## 二、今天踩到的几个坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | 默认 XING 身上那 25 张是**系统内置**的，标着「System · Read-only」，**卸不掉** | 我们把 V2 的 41 张装上去以后，默认 XING 现在是 66 张：25 张老的 + 41 张新的，其中 22 张同名。AI 可能读到老的那一张 |
| 2 | 有几个入口会**自动切回默认 XING**，比如发现页「开始对比研究」 | 以前默认 XING 是老卡时，用户从这些入口进去就碰不到 V2 |
| 3 | 上传一张卡的新版本，会把**自建专家**身上的旧版本**自动摘掉**，新版本却不会自动挂上去 | 今天「V2.6.10 测试专家」因此从 41 张掉到 34 张 |
| 4 | 编辑专家点「保存」**没反应**，后台也没收到请求 | 掉下去的卡没法手动加回来 |
| 5 | 回答里只显示「Research skill · Loaded」，**不显示是哪张卡** | 出了问题查不出是哪张卡在答 |
| 6 | 用户根本不知道「卡要装进专家才生效」 | 用户上传了自己的卡，以为能用，其实没用 |

## 三、现在测试网是什么状态（11-28 15:20 起）

- **默认 XING**：66 张 = 25 张系统老卡（卸不掉）+ 41 张 V2 新卡（V2.6.10 + 今天改的 7 张）。
- **「V2.6.10 测试专家」**：34 张，不全，**先别用它测**。
- 在主 chat 里直接问，已经能看到 V2 的效果。例如「NVDA 现在怎么样」，回答是一句话定调加上 4 项证据。

## 四、要干啥

### 技术
1. **把系统内置的老卡换成 V2**：要么直接替换，要么允许我们从默认 XING 上把它们卸掉。同名卡不能两份并存。
2. **卡更新版本时，所有挂着旧版本的专家自动换成新版本**，不要只摘不挂。
3. **修好「编辑专家 → 保存」**。
4. **回答里显示用了哪几张卡的名字**，不要只写「Research skill」。
5. **所有入口跟着用户选的专家走**：主 chat、AI 筛选、对比研究、个股页问答和简报、AI 编辑卡、AI 创建专家，现在一律写死用默认 XING。要么都跟用户当前选的专家走，要么至少让这些入口能选专家。在这之前，**我们的卡必须挂在默认 XING 上**。
6. **上传卡的页面加一句提示**：「上传后要安装到专家里才会生效」。

### 运营
1. **以后一律在默认 XING 上测**，不要另建测试专家。用户用什么，我们就测什么。
2. 每次测之前看一眼输入框下面的专家名，确认是「XING」。
3. 发现回答像老卡（比如说「不能给买入建议」「不提供目标价」），截图并记下会话编号，报给 Lin。

### 产品
- 「卡要装进专家才生效」这件事，在产品上要让用户看得懂。比如「我的 skills」里每张卡标出「已在哪些专家里生效」。

## 附：怎么确认默认 XING 身上挂的是哪些卡
测试网 → 我的 skills → 点开任意一张卡 → 看「Used by experts」，有「XING」就是挂上了。
系统老卡会标「System · Read-only」，我们的 V2 卡标「Mine · Package (read-only)」。
