## 二、★★★★★ 「档位」到底是什么（★ 这是这件事的核心）

### ★★ 先讲清七格

| # | 格 | 大白话 |
|---|---|---|
| ① | **选股范围** | 从哪一堆票里挑 |

| ⑥ | **离场** | 除了止损，还有什么情况走 |
| ⑦ | **仓位/排序/成本/基准** | 一笔下多少钱、信号多了先买谁 |

### ★★★ 「档位」= **同一条策略的几套七格配置**

```
★ Lin 分的三种用户：
   ① **不懂参数的** —— ★★ 但知道自己要「稳一点」还是「激进一点」→ ★★★★★ **给档位**
   ② **懂一些的（师弟师妹）** —— ★★ 不懂参数，但懂这些概念 → ★ 让他们自己配
   ③ **像他自己** —— ★★★ 直接配零件

★★★★★ 所以「档位」要解决的是**第①②类** ——
   ★ 用户选「稳 / 中 / 激进」，★★ 背后换的是**七格里几个数**。
```

🔴 ★★★★★ **这件事最大的坑，一开始就要防住**：
```
★ 「稳一点 / 激进一点」是**感觉**，★★ 而七格里的是**数**。
★★★★★ 把感觉翻译成数的那一步，**就是在发明阈值** ——
   🔴 而 XING 有一条红线：「**自己定一个阈值，就等于自己发明一个闸，
      然后把它标成原著**」。
✅ 所以档位里每一个数都必须满足：
   ① **标清归属** —— 原著 / 行业惯例 / XING 自测（★★ 三档并排，不许混）
   ② ★★★ **跑过「相邻三点」** —— ★ 把那个数上下各挪一档，看结论是否同向
      · 三点同向 → ✅ 这个参数**可以让用户调**
      · 三点翻了 → 🔴 **锁死**，并告诉用户「换一档结论会翻」
   ③ ★★★★★ **不许写「建议用哪个档」** —— ★ 只摆数，★★ 选哪档是用户的事
```
