## 一 · Lin 的原话整理
**共同前提**：做的时候，顶部的派发形态已经形成。

**纳指（QQQ，图01、图02）**
1. 关键在二次顶之后：有一个假突破，假突破之后的反弹没过（小周期上能看到），然后就下来了。
2. 下来之后走得很强势。中间基本就是：反弹 → 做空；跌破颈线位 → 又空。一路空下来，每一次都是这个逻辑。
3. 归纳：顶部出现派发形态 → 每个派发形态跌破 → 做空；颈线位 → 做空。

4. **（18:44 补）假突破说明什么**：纳指如果真要走、而且是强势走，是不会有这种假突破的，它会直接上去。所以走出假突破，我们就认为是盘整。既然是盘整，第一步只看到区间下沿（空单看到下沿，或者多单考虑减仓）。没想到它走得非常强势，直接全部跌破。
5. **（18:44 补）结论**：大涨过程中的空单，先只看区间下沿；但有一个核心位置是确定的 —— **跌破颈线位之后，空就非常明确了，先空**。空也要小心，要看它能跌到哪。

**半导体（SOXX，图03、图04）**
1. 非常漂亮的大型顶部派发形态（图03，5~7 月，指标连续背离），之后跌破。
2. 走出了 A 浪（Lin 也叫一浪）。
3. 二浪（B）反弹：反弹到核心位置，0.618 没过，而且在小周期的顶部又出现派发形态 —— 那个时候可以直接做空。
4. 这一笔「更爽」：因为 B 浪反弹没过，预期它要走 C 浪（第三浪）。C 浪走得非常快、很强势，中间同样是反弹颈线位没过 → 做空、做空、做空。
5. 现在走的是很经典的一浪、二浪、三浪；三浪还没走完，还差一点。能不能走出四、五浪不知道，到时候看。
6. 逻辑点：浪走到核心位置没有过，就可以去看下一步的浪形。

7. **（18:46 确认）A、B、C 就是一、二、三浪。每一步都是「看反弹过不过核心位置」**：
   - 一浪走完，二浪反弹。如果它直接上去了，那是另一回事（强势行情，所谓的二浪就不存在）。
   - 二浪走出来了、但没过核心位置 → 开启三浪。三浪很重要，下跌行情里三浪就是大跌。
   - 三浪走完，四浪反弹；四浪反弹到核心位置又没过 → 看五浪。

8. **（18:48）核心位置就是「一念之间」**：反弹到颈线位不过，去小周期里看，会有派发形态；如果它过了，那就是另外一件事。多和空，尤其在核心位置，就在一念之间，要很快决定。这也是最好的时机点 —— 想做狙击手、想赚大钱，就是那一下确定了：止损很好设，瞬间就走出来，后面还可以逐步加仓。

9. **（18:48 更正）「核心位置」不是光一个 0.618**：是 0.618 那个位置，再配合其他东西 —— 前期的重要压力位等等 —— 凑在一起的一个组合。0.618 本身是比较重要的一个关口；既是 0.618、又叠着一堆别的东西，那个位置就是阻力位。

10. **（18:50）这次比较经典；美股的范围要分清**：这次是又一次相对比较大的跌。美股大指数（标普、纳指）一年可能就这么一次大跌的机会，所以空单一般在小周期里、或者在个股、或者在某些领域（小的板块）上做 —— 那些地方可能不一样，可能容易得多。前面说「美股只是阶段性调整」指的是大指数。

## 二 · 我的理解：美股这套能直接拆成能算的四步
| 步 | Lin 在看什么 | 能算的写法（初稿，都要测、都要跑相邻三点） |
|---|---|---|
| ① 顶部派发已形成 | 双顶 / 三顶、指标背离、二次顶后的假突破 | 卡里「大顶派发」和预警四项已有；加一条「创新高后几天内收回前高之下」 |
| ② 跌破，走出第一段（A） | 跌破派发形态的下沿 / 颈线 | 收盘跌破派发区间低点；A 段跌幅至少多少（按 ATR 或百分比）才算一段 |
| ③ 反弹（B）不过核心位置 | 反弹到一个「几样东西凑在一起」的阻力位没过：0.618 回撤 + 前期重要压力位（原来的支撑 / 颈线 / 跌破位）+ 均线等；小周期顶部又出派发 | 核心位置 = 0.618 回撤附近（±0.5 倍 ATR）还叠着至少一样：前一个跌破位 / 颈线、成交密集区、向下的 50 日线。反弹最高点碰到这个区、没有收盘站上去；然后出现转弱（收盘跌破前一天最低 / 小周期跌破颈线）→ 空。测试时按「只有 0.618」「0.618 + 1 样」「0.618 + 2 样以上」分开数 |
| ④ 赌第三段（C） | C 段走得快，反弹到颈线不过继续空 | 止损 = B 段最高点上方；第一目标 = C = A（1 倍等距），第二目标 = 1.618 倍；途中每次反抽不过前一个跌破位可以再进 |

**和今天测过的差在哪**
- 《352》《353》四种波段做空、《389》破位反抽空：都没有第 ① 步（不要求前面有一个走完的顶部派发），也没有第 ③ 步的「B 段反弹不过 0.618」。等于把「下跌途中随便一次反弹」都拿来空了。
- 这四步可以直接在指数和行业 ETF、流动性好的个股上扫一遍历史：出现过多少次、之后 C 段走没走出来、走了多远。这是下一组测试。
