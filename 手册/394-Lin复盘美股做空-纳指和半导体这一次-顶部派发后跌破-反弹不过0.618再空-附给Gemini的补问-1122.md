## 一 · Lin 的原话整理
**共同前提**：做的时候，顶部的派发形态已经形成。

**纳指（QQQ，图01、图02）**
1. 关键在二次顶之后：有一个假突破，假突破之后的反弹没过（小周期上能看到），然后就下来了。
2. 下来之后走得很强势。中间基本就是：反弹 → 做空；跌破颈线位 → 又空。一路空下来，每一次都是这个逻辑。
3. 归纳：顶部出现派发形态 → 每个派发形态跌破 → 做空；颈线位 → 做空。

**半导体（SOXX，图03、图04）**
1. 非常漂亮的大型顶部派发形态（图03，5~7 月，指标连续背离），之后跌破。
2. 走出了 A 浪（Lin 也叫一浪）。
3. 二浪（B）反弹：反弹到核心位置，0.618 没过，而且在小周期的顶部又出现派发形态 —— 那个时候可以直接做空。
4. 这一笔「更爽」：因为 B 浪反弹没过，预期它要走 C 浪（第三浪）。C 浪走得非常快、很强势，中间同样是反弹颈线位没过 → 做空、做空、做空。
5. 现在走的是很经典的一浪、二浪、三浪；三浪还没走完，还差一点。能不能走出四、五浪不知道，到时候看。
6. 逻辑点：浪走到核心位置没有过，就可以去看下一步的浪形。

## 二 · 我的理解：美股这套能直接拆成能算的四步
| 步 | Lin 在看什么 | 能算的写法（初稿，都要测、都要跑相邻三点） |
|---|---|---|
| ① 顶部派发已形成 | 双顶 / 三顶、指标背离、二次顶后的假突破 | 卡里「大顶派发」和预警四项已有；加一条「创新高后几天内收回前高之下」 |
| ② 跌破，走出第一段（A） | 跌破派发形态的下沿 / 颈线 | 收盘跌破派发区间低点；A 段跌幅至少多少（按 ATR 或百分比）才算一段 |
| ③ 反弹（B）不过核心位置 | 反弹到 A 段的 0.5~0.618 附近没过，小周期顶部又出派发 | 反弹最高点在 A 段回撤的 0.382~0.618 之间，没有收盘站上 0.618；然后出现转弱（收盘跌破前一天最低 / 小周期跌破颈线）→ 空 |
| ④ 赌第三段（C） | C 段走得快，反弹到颈线不过继续空 | 止损 = B 段最高点上方；第一目标 = C = A（1 倍等距），第二目标 = 1.618 倍；途中每次反抽不过前一个跌破位可以再进 |

**和今天测过的差在哪**
- 《352》《353》四种波段做空、《389》破位反抽空：都没有第 ① 步（不要求前面有一个走完的顶部派发），也没有第 ③ 步的「B 段反弹不过 0.618」。等于把「下跌途中随便一次反弹」都拿来空了。
- 这四步可以直接在指数和行业 ETF、流动性好的个股上扫一遍历史：出现过多少次、之后 C 段走没走出来、走了多远。这是下一组测试。
