## 第 0 页 · 我们到底要解决什么（★ 一句话）

```
★★★ 我们要把「技术面大师」这件事,从「一个会聊天的模型」变成「一套我们自己能编码的东西」。
```

**现状：** 我们已经有一部分了 ——「分析一只票」的体检五行和整屏草图已经做了设计。
**缺的是：** ★★★ **一个技术面大师该会什么，我们从来没系统性问过。**

所以这一轮不是问「某一本书的方法」，是问**一个岗位的能力清单**。

### ★ 为什么要分用例问，而不是问「技术分析包括哪些内容」

因为「技术分析包括哪些内容」会得到一份教科书目录，**那个我们编不了码**。
我们要的是：**用户真实开口问的那五句话，每一句背后的分析流程是什么。**

---

## 第 1 页 · 每个用例我们要的三样东西（★ 这一节是整份的核心）

对五个用例里的每一个，我们都要同样的三样：

```
① **按什么顺序看** —— 第一步看什么、第二步看什么。★ 顺序本身就是知识
② **每一步能不能落成代码** —— 哪些是算得出来的,哪些只能靠人眼和经验
③ **★★★ 这一步凭什么知道(出处)** —— 为什么是这个顺序、这个阈值
```

### ★★★ 第三样是关键，而且它决定我们编不编

```
说得出「凭什么」的  → 我们编码进系统
说不出「凭什么」的  → ★ 挂第五档「外部模型回答·未经我们测试」,不编码
```

**所以第三样不是客套话，是分流闸。** 它答不出出处的部分，我们不会假装那是知识。

## 第 2 页 · 五个用例（★ 分五次问，一次一个）

```
① 「帮我看看这只票现在什么情况」        ← 结构读图流程
② 「我想做突破,该怎么做」
③ 「我想做震荡,该怎么做」
★★★ ④ 「我现在该把止盈止损放哪」        ← 最具体,★ 建议第一个问
⑤ 「我已经持仓了,下一步看什么」
```

### 为什么建议 ④ 先问

因为它**最具体，最容易验证它是不是在编**。
如果它在 ④ 上就给不出可计算的判据和出处，那后面四个也别指望。

## 第 3 页 · 粘贴模板（★ 五次都用这一套，只换中间那一段）

```
假设你是华尔街顶级的技术派分析大师。

我在搭一套系统,要把「技术面大师的分析能力」变成可编码的流程。
这一轮我不讨论任何回测成绩,★ 也请不要问我们测出来怎样。

────────────────────────────────
【这一次的用例】

用户对大师说:「【★ 从第 2 页五个用例里挑一个,原样填进来】」

请告诉我:一个顶级技术派大师,收到这句话之后,脑子里按什么顺序走。
────────────────────────────────

【回答规则 —— ★ 请严格遵守】

1. 请把你的分析流程拆成**有编号的步骤**。
   ★ 顺序很重要 —— 请说明为什么是这个顺序,而不是别的顺序。

2. ★★★ 每一步后面必须标三样:

   (A) 【要什么数据】—— 具体到字段。
       例:「日线收盘价 + 成交量 + 20 日均线」,
       不要写「价格行为」这种我没法取数的说法。

   (B) 【能不能落成代码】—— 只能选三个之一:
       [可计算]   —— 给得出明确的公式或判据
       [半可计算] —— 大体能算,但有一步要靠判断。★ 请说清是哪一步
       [只能靠人] —— 算不出来。★ 请直接承认,不要勉强给一个公式

   (C) 【凭什么】—— 出处,只能选这五个之一:
       [原文] —— 某本书/某篇论文里有,★ 必须给出书名作者 + 原文那句话
       [通行] —— 原著没写,但行业里普遍这么做
       [你的推断] —— 你自己补的
       [不确定]
       [有争议] —— ★ 业内两派打架。请把两派都说出来

   ★★★ 如果你拿不出原文那句话,就不许标 [原文],改标 [你的推断]。
   ★★★ 不许给我任何你估的数字范围。估的就标 [你的推断]。

3. ★★ 如果某一步根本没有公认做法,直接写「没有公认做法」。
   **不要替它补一个看起来合理的。**

4. ★★★ 最后请单独回答两条:

   (甲) 这个用例里,**哪一步最容易被做错**?★ 新手和老手的差别在哪一步?
   (乙) ★★★ **这个流程在什么情况下会给出错的答案**?
        请给出具体的市场情形。不要说「市场有风险」这种话。

5. ★ 不许在这一轮给我任何买卖方向建议,也不许推荐具体股票。

【我的数据边界 —— ★ 超出这个范围的做法请直接说"你们没有这个数据"】
  日线 OHLCV,2014-01 至 2025-12
  VIX · SPY/QQQ/XLK · 市场广度(50日/200日均线上方占比、52周新高新低、涨跌家数)
  SEC 财务数据(35 个指标)· 行业代码 · 上市日期 · 业绩公布日
  ★ 没有:分钟级 / tick / 盘口 / 期权链 / 资金流 / 新闻文本
```

## 第 4 页 · 第五次问完之后，再追加这一轮（★ 收口）

五个用例都问完了，再单独问这一次：

```
上面五个用例你都答完了。现在请回答三个收口问题。

(一) ★★★ 把五个用例的步骤合起来看,**有哪些步骤是重复出现的**?
     ★ 那些重复出现的,是不是就是「技术面大师的核心能力」?请列出来。

(二) ★★★ 一个技术派大师的能力清单,**除了这五个用例覆盖到的,还缺什么**?
     ★ 我们是拿用户会开口问的话来倒推的,所以一定有漏的。请补。

(三) ★★★ 在你上面所有标了 [只能靠人] 的步骤里,
     ★ 哪几步是「**再过几年也还是只能靠人**」,
       哪几步是「**现在算不出来,但原则上是能算的,只是没人做**」?
     ★★ 这两类请分开列。

【回答规则】
★ 第 (三) 问请不要客气。如果你认为大部分都能算,就这么说;
  如果你认为核心的东西算不出来,也请这么说。
★ 我们要的是真实判断,不是让我们高兴的答案。
```

### 为什么要第 (三) 问

★★★ 因为它直接决定**我们自己编多少、Gemini 兜多少**。

```
「再过几年也只能靠人」的那几步     → ★ 我们不编,老实挂第五档让 Gemini 兜
「原则上能算,只是没人做」的那几步   → ★★★ 这是我们的机会,主体就在这里
```

## 第 5 页 · 回来之后我们怎么处理（★ 不用你做，写在这里是为了让你知道为什么要这么问）

```
□ 1. 它标 [原文] 的 → ★ 去方法卡原文 grep 那句话。grep 不到的全降成「我们填的」
□ 2. 它标 [可计算] 的 → ★ 对着我们的算子清单逐条点。算不出的记「缺算子」
□ 3. 它标 [有争议] 的 → ★★★ 这些最值钱 —— 两派打架的地方,
      说明那里有真东西,而且不是一句话能定的
□ 4. 所有阈值抄成一张表 → ★ 看打不打架。打架的原文转录回去追问它自己选一个
□ 5. 凡提到某本书 / 某家公司 / 某个产品 → ★★★ 追问「哪一章、哪一年、哪个产品」
      答不出具体的 → 整条作废
```

**第 3 条单独说一句：** 它标 [有争议] 的地方，**对我们是最有价值的**。
因为那说明这件事没有标准答案 —— ★★★ **而没有标准答案的地方，才是我们能往前跳一跳的地方。**
