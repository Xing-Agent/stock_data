### ★★★ 为什么「短期借款按 0」比「长期负债按 0」危险

★★ 这两件事看起来是同一类,★★★ **但缺失的原因不一样**:

```
★★ 长期负债缺失  → 大概率**真的没有长期借款**(很多科技公司就是不借钱),
                     SEC 里本来就不报这一行。★ 所以按 0 接近事实。

★★★ 短期借款缺失 → 更可能是**公司把它合并报在别的行里了**。
     ★ 证据:13,613 个格子里,「只有 LongTermDebtCurrent」3,962 个 ·
       「只有 ShortTermBorrowings」874 个 · 「只有 DebtCurrent」1,154 个 ——
     ★★★ 三者是**互补**关系(同时有 stb 和 ltdc 的只有 834 个),
        说明公司报哪一个取决于**它自己的披露习惯**,不是有没有。
     ★★ 所以按 0 等于假设「这家公司没有短期有息负债」,而事实可能是
        「它把短期借款报在了我们没接的那个标签里」。
```

★★ **我的倾向:丙。** ★ 理由:v1 已经在 20.1% 上跑过了,v2 在同样的 21.8% 上跑,★★★ **两版第一次真正可比**(样本几乎同一批)——
★ 这正是你定「v1 保留不动」想要的那个效果。★★ 等第 7 条把标签补齐(或把 `DebtCurrent` 接进映射表),可算率自己会上去,
★★★ 那时候再做一版 v3,而不是现在用一个我们造的 0 去换覆盖率。
