# 第一页 · 我们卡在哪（★ 大白话）

```
★ 有一种估值做法:★★ **公司值多少钱 = 它每年能赚的钱 ÷ 一个折扣率**。
★ 那个折扣率行业里叫 **WACC**(加权平均资本成本)——
  ★★ 大白话就是「你的钱放在这里,应该要求多少回报」。

★★★ 问题:**这一个数,决定一半的估值。**
   ★ 同一家公司每年赚 1 亿:
     折扣率 8%  → 值 **12.5 亿**
     折扣率 12% → 值 **8.3 亿**
   ★★★ **同样的利润,估值差 50%** —— 全部差别来自这一个数。

★★★ 而 WACC 的公式第一项是「**无风险利率**」= 美国国债利率,
   ★ 我们的数据库里**没有利率**。
→ ★★ 所以我们**把这一步整步停用了**,没有编一个数填进去。
```

★★★ **为什么不编一个填进去（★ 这一条请一并告诉 Gemini，让它知道我们的立场）：**
```
★ 如果塞一个 9% 进去,★★ 界面上会显示「这家公司值 1,240 亿美元」——
★★★ 一个精确到个位、看起来**和真算出来的一模一样**的数字。
★ 用户没有任何办法知道:那里面有一个我们随手填的 9%。
★★★ 这不是「不准」的问题,是「**看不出来不准**」的问题 ——
   ★ 比「这只票很有潜力」危险得多,因为后者用户知道是看法,前者长得像事实。
```
