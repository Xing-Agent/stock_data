## 一 · 日线震荡：区间打法
| 项 | 规则 |
|---|---|
| 箱体 | 过去 60 根 4 小时线的最高、最低（约 3 周） |
| **做多（主做）** | 最近 3 根 1 小时线里有一根刺穿箱底至少 0.1 倍 ATR，当前这根收盘回到箱底之上（假跌破收回）→ 收盘进场 |
| 止损 | 刺穿的最低点再下 0.5 倍 ATR |
| 第一目标 | 箱体中轴：到了平一半、止损推到成本价 |
| 第二目标 | 箱顶下方一点（箱高的 10%） |
| 一个结构一枪 | 做过一次后，价格回到中轴附近才允许再做 |
| **做空（少做）** | 只在经典派发形态出现时（顶部假突破收回 + 指标背离 / 一个顶比一个弱，见 v0.4），**小仓（半仓）**，目标只看中轴；回答里写明「这条没有统计支持」，不给胜率 |
| 中段禁区 | 闸① 照旧管区间打法：价格在箱体中间三分之一，不做 |
| 另外保留 | 震荡里「4 小时下降趋势的反抽做空」照顺势规则做（回测 178 笔每笔 +0.30R），它和「箱顶做空」不是一回事 |

## 二 · 仓位上限（加到仓位部分）
- 每笔风险建议 **0.5% 账户**（按「每笔最多亏多少」反推仓位）。
- 同类票（例如几只半导体 / 纳指杠杆 ETF）**同一时间最多持 2~3 笔**。
- 理由写进回答：「这几只票走势很像，同一天可能一起止损；回测里 5 只一起做，最深回撤约 36~40 倍单笔风险。」
