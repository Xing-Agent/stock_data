> 背景：《220》里补丁 1（上升趋势等回踩做多）在 45 个时点上只进了 4~8 次，几乎全被止损，样本太少说明不了问题。
> Lin 11:19 给了口诀：强势回踩 0.382~0.5、一般 0.618、弱的超过 0.618（多空一样），再结合其他几项；11:20：先把每只票的历史读一读，看它自己的技术特点。
> 所以这次改成：用每只票**全部历史 K 线**，把每一段顺势波段找出来（波段 = 价格走了 3 倍 ATR 以上才算一段；只算创了新高的上涨段、创了新低的下跌段），看它回踩多深、回踩之后有没有接着创新高（新低）。

## 三秒版
```
① 口诀方向是对的：回踩越浅，后面接着创新高（新低）的比例越高。5 只票 7 组数据都是这样。
② 真正的分水岭在 0.786 和「跌破起涨点」：0.618 以内大多还有 6~8 成接着走；
```

**各票一句话（初步，样本小）：**
- **SOXL**：回踩到 0.786 以内都还常接着走（约 8 成）；过了 0.786 才明显变坏。→ 等待区可以放深一点。
- **TQQQ**：最「教科书」，越深越差，0.5 以后掉到 6 成。→ 强势时 0.382~0.5 就该准备。

- **BTC、ETH 日线**：0.5~0.618、甚至 0.786~1 还很常接着走（大级别牛市里深回踩是常态）。

## 三 · 为什么《220》补丁 1 的几笔还是亏
上面的深度是**事后**量的（等回踩走完才知道最低点在哪）。实盘时我们在回踩**半路**看到一根阳线就进了，之后价格继续往下回踩到更深，把止损扫掉——8 笔里有 3 笔在被扫之前已经朝有利方向走了 4~5 倍风险，说明方向对了、进早了。
→ 下一步要测的是**扳机**：等价格进入这只票自己的等待区之后，要求「假跌破收回」或「回踩不破前针尖」再进（就是卡里原本的扳机），而不是一根阳线就进。

## 四 · 给主 chat 的规则草案（默认值，没回测完）
1. 等待区按强弱分档：强（用时短 + 缩量）0.382~0.5；一般 0.5~0.618；弱的超过 0.618。
2. 失效线：回踩超过 0.786 → 这段趋势判断作废；跌破起涨点 → 改判趋势。
3. 每只票一张「脾气表」（第一节那张），回答时带上：「这只票过去回踩到这个深度，之后接着走的比例是 X%（N 次，时间段）」—— 这正好就是卡里「几种可能的走势」要的历史统计。
4. 扳机仍按卡里原文，不能用「一根阳线」代替。
