再补两个问题：
- **⑤ 官方开盘价、收盘价**：分钟线里没有。我们的日线库有（日线的开盘、收盘就是交易所官方开盘价和收盘竞价价，《147》已经实测过），边界那两根用日线的替换就行。
- **⑥ 复权因子表**：分钟线目录里没有。我们自己有：`probe/market_1105/polygon_splits_aligned_1107.csv`，2004 年起的拆股，日期对齐到价格真正跳的那天；分红在日线文件的 `dividend_amount` 里。

## 二 · 怎么变成一份能用的（这是工程活，我来定）

**统一成「全部按拆股折算到同一天」**，和 2016–2021 那段现成的口径对齐：
1. 2021-03-26 以后的原始价：用我们的拆股表，凡是 K 线日期之后发生的拆股，都除掉。
2. 两段接缝（2021-03-26 前后）逐只核对：折算后前一天收盘和后一天开盘应该对得上，对不上的列出来。
3. **分红一律不折**（两段本来就都没折）。要「总回报」口径的，用日线的 `dividend_amount` 另算。
4. 只留你们要的「前 1,000~1,500 只」（每天按年初成交额排，名单用 `universe_1107/`），拼成 1 小时线（每天 7 根，09:30 起切）；边界两根换成日线的官方开盘价和收盘价，`warnings` 里写明。
5. 交付到 `intraday_1h_<日期>/`，格式和日线一样，一年一个文件。

**卡在哪**：全量分钟线不在我这里，在 Lin 那台机器 / 网盘上（2016 年起约 45GB）。所以要在那台机器上跑我写的处理脚本，跑完只把拼好的 1 小时线推上来（估计几百 MB）。**脚本等 Lin 回完第三节那一行清单就给。**

## 三 · Lin 只需要粘这一段（只读，30 秒，回我屏幕上打出来的那几十行）

```bash
# ★ 把下面这个路径改成分钟线所在的文件夹(就是里面有 2016、2017……这些年份子文件夹的那个),只改这一行
MIN_DIR="$HOME/美股历史数据/minute"

python3 - "$MIN_DIR" <<'PY'
import os, sys, re, gzip, collections
root = sys.argv[1]
if not os.path.isdir(root): print("★ 路径不存在:", root); sys.exit()
years = collections.defaultdict(lambda: [0, 0, None, None, set()])
for dp, dn, fn in os.walk(root):
    for f in fn:
        m = re.match(r"(\d{4})-(\d{2})-(\d{2})\.csv(\.gz)?$", f)
        if not m: continue
        y = years[m.group(1)]; p = os.path.join(dp, f)
        y[0] += 1; y[1] += os.path.getsize(p)
        d = f[:10]; y[2] = min(y[2] or d, d); y[3] = max(y[3] or d, d)
        if len(y[4]) < 2:
            with (gzip.open(p, "rt") if p.endswith(".gz") else open(p)) as fh: y[4].add(fh.readline().strip()[:60])
for k in sorted(years):
    n, s, a, b, h = years[k]
    print(f"{k}  {n:4d} 天  {s/1e9:6.2f} GB  {a} ~ {b}  表头: {' | '.join(sorted(h))}")
PY
```
