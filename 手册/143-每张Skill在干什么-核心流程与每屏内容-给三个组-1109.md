# 一、主卡 `xing-main` —— ★ 门卫（A 组）

## 1.1 它干什么（一句话）

```
★★★ **用户说一句话，它只做一个判断：这个人手里「缺哪一边」。**
★ 不是按「他想干什么」分，★★★ 是按「他给了什么、还差什么」分 —— 这是全卡最核心的一条。
```

## 1.2 核心流程（★ 四步）

```
① 先上**共用边界**（★★★ 边界在分流之前，不是之后）
② 看他给了什么 → ★★ 判断缺哪一边 → 分到七条路之一
③ 走那条路，按**统一三样模板**输出
④ 判错了有纠错出口；★ 他中途改主意是**常态，不是异常**
```

## 1.3 七条路（★★ 这张表就是分流的全部）

| 他给了什么 | 缺哪一边 | 路 | ★ 他会怎么说 | 落到哪 |
|---|---|---|---|---|
| **一只票** | 做法 | **A** | 「NVDA 现在怎么样」 | `xing-quote` |
| **一套标准** | 股票 | **B** | 「找突破整理区、量跟上来的」 | `xing-screener` |
| ★★★ **什么都没给** | ★ 先要「人」 | **C** | 「有什么能做的」 | `xing-screener`（★ 先走三问） |
| **票 + 做法都有**（有持仓） | — | **D** | 「我 180 买的，现在亏着」 | `xing-review` |
| 他要**自己定一套做法** | — | **E** | 「盯一下 NVDA 跌破 20 日线」/「找**所有**跌破的」 | `agent-builder` / `skill-builder` |
| 他要**一份正式研报** | — | **G** | 「给我出一份 NVDA 的公司研究报告」 | `equity-research` |
| 以上都不是 | — | **F** | 「什么是 RSI」「今天天气」 | 兜底 |

```
★★★ E 路的分流判据是**唯一一条机械判据**：**他说的里面有没有具体标的。**
  · 有标的（盯 NVDA）→ `agent-builder`（★ 盯一只）
  · 没标的（找所有跌破的）→ `skill-builder`（★★ 定一套规则）
★★ G 路是**唯一不套统一模板**的路，★★★ 触发条件很严：只在用户明确要一份研报时才走。
```

## 1.4 每屏长什么样（★★★ 四条主路一律这三样）

```
  ╔══════════════════════════════════════════════╗
  ║  ① **下一步该干啥**                           ║
  ║  ② **要你定哪几件**                           ║
  ║  ③ **为什么是这样**                           ║
  ╚══════════════════════════════════════════════╝
```

```
★★ 给出去的单位**不是「一段分析」**，是「**一个待定的事 + 做这个决定要的东西 + 它的来由**」。
★★★★★ 第③样「为什么」不是客套：
   ★ 没有它，前两样就变成**我们在替他做决定**；
   ★★★ 有了它，他**能自己判断要不要照做**。
→ ★★ A 组测的时候，**第③样缺了就是红牌**，不是小问题。
```

## 1.5 ★ A 组在使用中该盯什么

```
★★★ ① **分流判对没有** —— ★ 最常见的错是：用户给了票又给了做法（该走 D 复盘），
   却被分去了 A 报价。★★ 判据很简单：**他有没有持仓**。
★★ ② **三样齐不齐** —— ★ 尤其第③样「为什么」。
★★★ ③ **他中途改主意** —— ★ 卡里写明这是常态；★★ 如果系统表现得像「你怎么又变了」，就是错。
★ ④ **判错了能不能纠回来** —— ★★ 卡里有纠错出口，★★★ 测的时候要专门走一遍。
```

# 二、另外两张主干卡（A 组）

## 2.1 `xing-fundamental-analyst` —— ★ 基本面研究

```
★★★ 它的目标写得很硬：**让用户知道「自己该查什么」，而不是代替用户买卖。**

★ 核心流程（★★ 顺序不能颠倒）：
   ① **三项先决检查** → ② **四道底座**（顺序写死）→ ③ **七维研究视角**
   → ④ 按问题运行具体步骤 → ⑤ **离开前的质量门槛**

★★★★★ 两条最该盯的：
   · **七维视角「无合成总分」** —— ★ 不许把七个维度加权成一个分数（★★★ 这是红线）
   · **离开前的质量门槛** —— ★★ 答完要自检，★ 没过门槛不许交付
```

## 2.2 `xing-technical-analyst` —— ★★ 技术面通用能力

```
★★★ 它不是某位大师，★ 是「默认能回答所有技术面问题」的通用卡（周期、阶段、压力位⋯⋯）。

★ 核心流程：
   ① **六层结构**（从大到小看）→ ② **五类问题，五种答案形态**
   → ③ **状态只有六个**（★★ 不许自己发明第七个）
   → ④ **高层和低层打架的时候**怎么办 → ⑤ 答不了要**记下来**

★★★★★ 最该盯的一条：**权限是分层的** ——
   ★ 用户只是问问，和用户说了「我要做这笔单」，★★★ 系统能说的话**不一样**。
   ★★ 用户没表态之前就给买卖动作 → 红牌。
```

# 三、功能件 8 张（B 组）—— ★★ 同一个骨架

```
★★★★★ 这 8 张**结构完全一样**，★ 看懂一张就看懂八张：

   1 管什么 → 2 什么时候用 → 3 **不管什么，交给谁** → 4 这个场景属于哪一档
   → 5 **输出长什么样** → 6 这个 Skill 特有的禁令 → 7 共用边界
```

| 卡 | 管什么（大白话） | ★ 特别要盯的 |
|---|---|---|
| `xing-quote` | ★ 一只票现在怎么样 | ★★ 别越界给买卖建议 |
| `xing-screener` | ★ 按标准找票；★★ 用户什么都没给时**先走三问** | ★★★ 「三问」是必经步骤，跳过就是错 |
| `xing-review` | ★ 有持仓了，复盘这笔单 | ★★ 别变成「安慰」或「劝加仓」 |
| `xing-agent-builder` | ★ 盯**一只**票的条件（「NVDA 跌破 20 日线提醒我」） | ★★ 和 skill-builder 的分界：**有没有具体标的** |
| `xing-skill-builder` | ★ 定**一套规则**（「找所有跌破的」） | ★★★★★ **八张里最危险的一张** —— 卡里自己这么写的 |
| `equity-research` | ★ 一份正式研报（★ 唯一不套三样模板的） | ★★ 触发条件很严，别被轻易触发 |
| `risk-dashboard` | ★ 风险雷达：把风险变成可监测、可证伪的项 | ★★ 别过度量化 |
| `xing-discipline-coach` | ★★ 纪律陪练：交易前四问、退出契约、持仓三步复核 | ★★★ **不替用户交易** |

```
★★★ 第 3 节「**不管什么，交给谁**」是 B 组最该读的一节 ——
   ★ 它写明这张卡的边界在哪、越界了该转给谁。
★★★★★ B 组在使用中最该盯的一句：**「这张卡是不是在干别人的活？」**
```

# 四、大师卡 22 张（C 组）—— ★★★★★ 一个流程通用全部

```
★★★ 22 张的骨架**完全一样**（★ 实测核过），★★ 所以 C 组只要掌握这一个流程：

   ① **能力清单（匹配前先看）**  ← ★★★ 1109 新加的，路由靠它
   ② **这个 Skill 是干什么的**
   ③ **什么时候用**              ← ★★ 用户这样问就该触发它
   ④ **分析方法**                ← ★★★★★ 这一节是这张卡的**全部价值**
   ⑤ **输出要求**
   ⑥ **共用边界**
   ⑦ **严格且温暖的指导**（默认启用）
```

## 4.1 ★ 每屏长什么样

```
★★ 用户问一个问题 → ★ 系统用**这位大师的方法**去看 → ★★★ 答案里要有三样：
   · **这位大师的方法说什么**（★ 按「分析方法」那一节走）
   · **证据是什么**（★★ 哪几个数、哪段时间）
   · **这个方法在什么时候会失效**（★★★ 共用边界要求的「反方」）
★★★★★ 并且：**不扮演真实人物** —— ★ 是「用他的方法」，不是「他本人说」。
```

## 4.2 ★★ C 组在使用中该盯什么（★ 只有三件）

```
★★★ ① **方法有没有走样** —— ★ 比如威科夫那张，答案里有没有真的用「吸筹/派发」那套；
   ★★ 还是退回成一般的技术分析。
★★★ ② **该触发的时候触发了吗** —— ★ 1109 之前 19 张卡写的是「**必须点名大师才用**」，
   ★★★ 一个不知道威科夫是谁的用户**永远触发不到**。★ 现在改成「按需求触发 + 点名也用」，
   ★★ 这一轮要专门测：**用户不说名字，能不能被匹配到**。
★★★ ③ **有没有冒充本人** —— ★ 「巴菲特会说⋯⋯」是错的，★★ 「按巴菲特的方法看⋯⋯」才对。
```
