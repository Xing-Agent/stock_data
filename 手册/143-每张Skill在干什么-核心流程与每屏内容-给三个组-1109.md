# 一、主卡 `xing-main` —— ★ 门卫（A 组）

## 1.1 它干什么（一句话）

```
★★★ **用户说一句话，它只做一个判断：这个人手里「缺哪一边」。**
★ 不是按「他想干什么」分，★★★ 是按「他给了什么、还差什么」分 —— 这是全卡最核心的一条。
```

## 1.2 核心流程（★ 四步）

```
① 先上**共用边界**（★★★ 边界在分流之前，不是之后）
② 看他给了什么 → ★★ 判断缺哪一边 → 分到七条路之一
③ 走那条路，按**统一三样模板**输出
④ 判错了有纠错出口；★ 他中途改主意是**常态，不是异常**
```

## 1.3 七条路（★★ 这张表就是分流的全部）

| 他给了什么 | 缺哪一边 | 路 | ★ 他会怎么说 | 落到哪 |
|---|---|---|---|---|
| **一只票** | 做法 | **A** | 「NVDA 现在怎么样」 | `xing-quote` |
| **一套标准** | 股票 | **B** | 「找突破整理区、量跟上来的」 | `xing-screener` |
| ★★★ **什么都没给** | ★ 先要「人」 | **C** | 「有什么能做的」 | `xing-screener`（★ 先走三问） |
| **票 + 做法都有**（有持仓） | — | **D** | 「我 180 买的，现在亏着」 | `xing-review` |
| 他要**自己定一套做法** | — | **E** | 「盯一下 NVDA 跌破 20 日线」/「找**所有**跌破的」 | `agent-builder` / `skill-builder` |
| 他要**一份正式研报** | — | **G** | 「给我出一份 NVDA 的公司研究报告」 | `equity-research` |
| 以上都不是 | — | **F** | 「什么是 RSI」「今天天气」 | 兜底 |

```
★★★ E 路的分流判据是**唯一一条机械判据**：**他说的里面有没有具体标的。**
  · 有标的（盯 NVDA）→ `agent-builder`（★ 盯一只）
  · 没标的（找所有跌破的）→ `skill-builder`（★★ 定一套规则）
★★ G 路是**唯一不套统一模板**的路，★★★ 触发条件很严：只在用户明确要一份研报时才走。
```

## 1.4 每屏长什么样（★★★ 四条主路一律这三样）

```
  ╔══════════════════════════════════════════════╗
  ║  ① **下一步该干啥**                           ║
  ║  ② **要你定哪几件**                           ║
  ║  ③ **为什么是这样**                           ║
  ╚══════════════════════════════════════════════╝
```

```
★★ 给出去的单位**不是「一段分析」**，是「**一个待定的事 + 做这个决定要的东西 + 它的来由**」。
★★★★★ 第③样「为什么」不是客套：
   ★ 没有它，前两样就变成**我们在替他做决定**；
   ★★★ 有了它，他**能自己判断要不要照做**。
→ ★★ A 组测的时候，**第③样缺了就是红牌**，不是小问题。
```

## 1.5 ★ A 组在使用中该盯什么

```
★★★ ① **分流判对没有** —— ★ 最常见的错是：用户给了票又给了做法（该走 D 复盘），
   却被分去了 A 报价。★★ 判据很简单：**他有没有持仓**。
★★ ② **三样齐不齐** —— ★ 尤其第③样「为什么」。
★★★ ③ **他中途改主意** —— ★ 卡里写明这是常态；★★ 如果系统表现得像「你怎么又变了」，就是错。
★ ④ **判错了能不能纠回来** —— ★★ 卡里有纠错出口，★★★ 测的时候要专门走一遍。
```

## C · 大师卡通用流程（★★★ 22 张一个样 · 典型 1~2 屏）

```
 第 1 屏  ★★★ 能力匹配（用户不必说出大师名字）
          「这个突破是真是假？」→ 命中能力「量价结构」→ 威科夫那张

          ③ ★★★ 这个方法什么时候会失效（反方）

```

**★ 走一个例子：**

```
用户：「这票刚创新高，但我总觉得不对劲」
 第 1 屏  命中「量价结构」→ 威科夫
 第 2 屏  ① 方法：创新高但**成交量没跟上**，在威科夫体系里属于派发的迹象之一
```
