### 一、你们哪里测错了、问错了

**错误 1：用“一个月的实测结果”去评价中低频趋势/波段策略，样本量严重失真。** [行业里有人在用]
一个自然月只有约 21 个交易日。对于基于日线、小时线、15 分钟线做多的美股策略来说，一个月连一个完整的市场状态（Market Regime）都走不完——可能刚好赶上单边逼空，也可能刚好赶上财报季震荡。在华尔街，实盘/模拟盘跑 1 个月只用来做一件事：核对滑点、手续费、成交率与回测是否一致（Execution Audit），绝不能用来评价策略好坏或筛选挂件。评价策略必须拉回过去 10–15 年的历史数据（必须涵盖 2008 金融危机、2015–2016 震荡市、2020 熔断、2022 加息熊市）。

**错误 2：拿“满仓扛 50% 回撤的买入持有”去对比“单笔锁死 1R 的择时策略”，分母（风险暴露）完全不对等。** [书上原话/公开研究]
在 Van Tharp 的《通向财务自由之路》（Trade Your Way to Financial Freedom）以及对冲基金母基金（FoF）的尽调标准中，不看资金暴露度（Exposure）和下行风险的绝对收益对比是无效的。过去二十年标普 500 指数（SPY）确实大涨，但它代价是 2008 年最大回撤 -55.2%、2020 年一个月暴跌 -33.9%、2022 年回撤 -25.4%。而你们的策略单笔亏损定死、还有大盘开关，平均仓位暴露可能只有 30%–50%。拿 40% 仓位的低回撤策略去跟 100% 满仓高回撤的指数比绝对收益，就像拿家用轿车的油耗去跟 F1 赛车比极速。

**错误 3：问“普通人能不能照着做下来”时，混淆了“策略参数”与“人性承受极限”。** [我自己的建议]
交易员“拿不住”从来不是因为理解不了规则，而是因为两件事：浮亏回撤深度（痛感）和资金曲线不创新高的时间长度（绝望感）。此外，你们的目标写着“每一单不亏或亏很少”，这会诱导团队疯狂使用“推保本”挂件。在实盘中，过早推保本虽然能把胜率/平局率刷得很好看，但会把大趋势行情里的龙头股在正常回踩时全部洗出去，反而拉长资金曲线的水下时间，让人更“拿不住”。

**错误 4：“同样的票全买不动”这一行对照，存在严重的选股/前视偏差污染。** [行业里有人在用]
如果你们的主策略是趋势跟踪或阶段分析（比如 Stan Weinstein 的第二阶段突破），一只股票能进入你们的交易名单，本身就已经通过了趋势筛选。如果你拿“从回测第一天起买入并持有这批票”做对照，那是严重的前视偏差（未来函数）；如果你拿“触发买点时买入并死拿不卖”做对照，你测的其实是“不设止损的裸奔收益”，在美股个股财报暴雷或行业退潮时，这种对照毫无意义。

### 二、行业里真正在用的做法（针对你的 3 个核心问题）

**问题 1：评价有进有出的交易方法，行业用什么尺子与及格线？**

在华尔街多策略基金（如 Millennium、Point72 的股票多空与波段团队）以及 CTA/量化趋势团队中，评价一个有进有出的做多系统，绝不单独使用夏普比率（Sharpe Ratio）——因为夏普比率把“向上暴赚的波动”也当成惩罚项，对抓大趋势的策略极不公平 [书上原话/公开研究]（见 Jack Schwager《对冲基金奇才》与 Sortino 比率原始文献）。

行业里真正在用的是一套“风险调整收益 + 痛苦度 + 交易质量”组合尺子。结合你们“做多为主、单笔固定 1R 亏损、中短周期进场”的约束，及格线如下：

**问题 2：“拿不住”能不能量化？有没有公开研究？**

完全可以量化，而且有非常成熟的学术研究与机构风控数据。

学术与行业量化指标（测“痛苦面积”）： [书上原话/公开研究]

- 溃疡指数（Ulcer Index, UI）：Peter Martin 在 1989 年出版的《富达基金投资者指南》（The Investor's Guide to Fidelity Funds）中提出。他指出普通人不是按标准差感受风险的，而是按“每天盯着账户看它离最高点还差多少、且已经持续了多少天”来分泌胃酸的。UI 把每天的回撤百分比平方后再求平均开根号，直接把“深跌”和“阴跌不创新高”合并成一个痛苦数字。
- 湖泊比率（Lake Ratio）：Ed Seykota 与 Jack Schwager 推广的指标。把资金曲线画出来，水面（历史新高连线）与曲线之间蓄积的“水（回撤面积）”除以曲线下方的“陆地面积”。水越多，交易员淹死的概率越大。

关于“跌多少、熬多久会放弃”的公开研究与机构实证：

- 投资者行为差距研究（DALBAR QAIB 报告 & Morningstar《Mind the Gap》年度研究）：[书上原话/公开研究]
  连续二十多年的实证追踪表明，美股主动投资者与基金持有人的实际到手收益，平均每年比标的本身低 1.5% 到 2.2%。核心原因就是择时投降（Capitulation）——在连续回撤或横盘后割在底部，在创新高后追回。
- 机构资金（FoF / 外部出资人）的赎回阈值：[行业里有人在用]
  华尔街主经纪商（Prime Brokerage）和母基金行业有一个著名的“15% / 18 个月魔咒”：当一个交易团队回撤达到 10% 时进入观察名单；回撤达到 15%–20% 或 连续 12–18 个月净值不创新高时，超过 70% 的外部资金会触发赎回。
- 主观交易员与小团队的“心理熔断线”：[我自己的建议]
  你们的交易员单笔固定 1R 风险，他们放弃的触发点不是百分比，而是连续亏损的 R 数（Consecutive R-Drawdown）和盘中浮亏回吐。在我的管理经验里：
  - 哪怕胜率 45%、盈亏比 2.5:1 的神级系统，做 500 笔交易，数学上出现连续 8–10 笔止损的概率超过 80% [书上原话/公开研究]（概率论游程检验 / Van Tharp 统计）。
  - 绝大多数小团队在净值从高点回撤达到 10R–12R，或者连续 4–6 个月不创新高时，就会开始怀疑参数失效、私自关掉“大盘开关”或手动提前平仓——那一刻，策略在实质上就已经被放弃了。

行业里真正放在成绩单里的 4 行标准对照（缺一不可）： [行业里有人在用]

- 基准 A：SPY 买入持有（机会成本尺子）

### 三、能直接写成程序、能再测一遍的具体规则

为了让你们的量化/开发同事今天就能写进回测框架，下面给出完全基于你们现有数据约束（日线/1H/15m OHLCV + 财报日期 + 固定 1R 风险）的可编程计算规则与硬性淘汰门槛。

**规则集 1：计算公平的“日频盯市（MTM）核心指标”** [我自己的建议]

工程细节警告：必须用每日收盘盯市净值曲线（Daily Mark-to-Market Equity Curve，包含持仓浮盈浮亏）来算回撤，绝对不能只用“已平仓交易记录”算回撤——因为实盘中人是在浮亏最深的那天崩溃的。

```python
import numpy as np
import pandas as pd

def evaluate_strategy(daily_equity: pd.Series, daily_exposure: pd.Series, trade_r_multiples: list, rf_annual: float = 0.03):
"""
daily_equity: 每日收盘盯市净值序列 (起始为 1.0)
daily_exposure: 每日实际持仓市值 / 当日总净值 (0.0 ~ 1.0+)
trade_r_multiples: 每笔已平仓交易的最终 R 倍数列表 (例如 [-1.0, 2.5, 0.0, 4.1, ...])
"""
n_days = len(daily_equity)
years = n_days / 252.0

# 1. 基础收益与最大回撤
cagr = (daily_equity.iloc[-1] / daily_equity.iloc[0]) ** (1 / years) - 1
running_max = daily_equity.cummax()
drawdown = (daily_equity - running_max) / running_max # 负数序列
max_dd = abs(drawdown.min())
mar = cagr / max_dd if max_dd > 0 else np.inf

# 2. 溃疡指数 (Ulcer Index) 与 UPI (Martin Ratio)
dd_pct = drawdown * 100 # 转为百分比，如 -12.5
ulcer_index = np.sqrt(np.mean(dd_pct ** 2))
upi = ((cagr - rf_annual) * 100) / ulcer_index if ulcer_index > 0 else np.inf

# 3. 暴露度调整后年化收益 (解决牛市对比不公平问题)
avg_exposure = daily_exposure.mean()
exposure_adj_cagr = cagr / avg_exposure if avg_exposure > 0 else 0.0

# 4. 最长水下天数 (Max Time Underwater)
is_underwater = daily_equity < running_max
# 计算连续 True 的最大长度
underwater_streaks = is_underwater.groupby((~is_underwater).cumsum()).cumsum()
max_underwater_days = int(underwater_streaks.max())

# 5. Van Tharp 单笔期望值与上限为 100 的 SQN
r_arr = np.array(trade_r_multiples)
expectancy_r = np.mean(r_arr)
n_trades_capped = min(len(r_arr), 100)
sqn = np.sqrt(n_trades_capped) * (expectancy_r / np.std(r_arr, ddof=1)) if np.std(r_arr, ddof=1) > 0 else 0.0

return {
"CAGR": round(cagr, 4),
"MaxDD": round(max_dd, 4),
"MAR": round(mar, 2),
"UPI": round(upi, 2),
"Avg_Exposure": round(avg_exposure, 2),
"Exposure_Adj_CAGR": round(exposure_adj_cagr, 4),
"Max_Underwater_Days": max_underwater_days,
"Expectancy_R": round(expectancy_r, 3),
"SQN_100": round(sqn, 2)
}
```

**规则集 2：程序化模拟“拿不住（心理放弃率）”压力测试** [我自己的建议]

把“人会不会拿不住”写成一个滚动窗口生存检验器。假设任意一个普通交易员在历史上的任意一个交易日 $t$ 开始跟单，如果他在创新高之前触发了以下任意一条“人性投降线”，记为一次放弃事件（Abandonment Event）：

- 触发条件 A（痛感极限）：盯市净值回撤超过 15%（或累计亏损超过 12R）。
- 触发条件 B（绝望极限）：连续 150 个交易日（约 7 个自然月）账户净值未创出阶段新高。
- 触发条件 C（高频挫败极限）：连续出现 8 笔 亏损交易（每笔亏损 $\le -0.5R$）。

```python
def abandonment_stress_test(daily_equity: pd.Series, max_dd_limit: float = 0.15, max_stagnation_days: int = 150):
"""
模拟在历史任意一天入场跟单，有多少比例的起始点会在 1 年内触发“心态崩溃放弃线”
"""
n = len(daily_equity)
lookahead = 252 # 考察入场后 1 年内的体验
if n <= lookahead:
return None

quit_count = 0
total_starts = n - lookahead

for start in range(total_starts):
window = daily_equity.iloc[start : start + lookahead]
peak = window.cummax()
dd = (peak - window) / peak

# 条件 A：回撤超限
hit_dd = (dd > max_dd_limit).any()

# 条件 B：连续不创新高天数超限
uw = window < peak
max_uw = uw.groupby((~uw).cumsum()).cumsum().max()
hit_time = max_uw > max_stagnation_days

if hit_dd or hit_time:
quit_count += 1

survival_rate = 1.0 - (quit_count / total_starts)
return round(survival_rate, 4) # 及格线建议：>= 0.75 (即 75% 以上的入场时点不会触发心理崩溃)
```

### ③ 仓位怎么分、加不加仓

**1. 你们哪里测错了、问错了**

- 首仓永远小风险：第一笔开仓只用总资金 0.75% 的止损风险（通常对应 10%–15% 的名义仓位）。

**2. 行业里真正在用的做法与适用场景**

**3. 可直接写成程序的规则（仅用日线 OHLCV + 2000 股宽度）**

Pct_Above_MA200 = count(Close > SMA(Close, 200)) / 2000
Daily_Adv_Ratio = count(Close > Close[1]) / count(Close != Close[1])
Zweig_EMA10 = EMA(Daily_Adv_Ratio, 10) # 10日上涨家数占比EMA

# 2. 行业等权指数（按11个一级行业分别合成日线收盘价 Sector_Close[s]）

# 最终仓位乘数映射

Regime_Mult = 1.0 # 宽度脉冲期间，满额开放做多权限
elif Score == 3:
Regime_Mult = 1.0 # 全面牛市：单笔风险 = 1.0 * Base_Risk
elif Score == 2:
Regime_Mult = 0.5 # 震荡整理：单笔风险 = 0.5 * Base_Risk

Regime_Mult = 0.25 # 弱势预警：单笔风险 = 0.25 * Base_Risk，且仅允许 Sector_Green[s] == True 的行业开仓

# 2. 动作：将所有现有多单的移动止损（Trailing Stop）从原策略宽度收紧为 1.5 * ATR(14)，让市场自己把弱势股踢出去，保留真正抗跌的龙头。

- Regime_Mult 仅限制新开仓风险预算、不强平现有持仓并收紧 ATR 移动止损的做法：【行业里有人在用】。

### ⑥ 行情转跌后的减仓

**1. 哪里测错了或问错了**

[我自己的建议] 评估指标完全测错了（拿 Beta 风控当 Alpha 择时）： 你们去对比「几种卖法卖出的平均价格」，这是把减仓当成了「逃顶卖高点」。行情转跌时减仓，目的从来不是为了卖得比别人高，而是在市场进入 Regime Shift（状态切换）、个股相关性趋近于 1 的初期，强行把组合的净敞口（Net Exposure）和日内净值波动率砍下来。指数三次里两次涨回来是常态，你们付出的那两次「卖飞摩擦成本」，就是为了防第三次演变成 2020 年 3 月或 2022 年那种单边流动性危机。

[行业里有人在用] 账目核算维度问错了： 买不回来时，减仓的账不能按「少赚了多少钱（踏空幻觉）」来算，而要按「回撤调整后收益（Calmar Ratio / Ulcer Index）」来算——即减仓后组合最大回撤深度降低了多少、回撤期缩短了多少，以及在真正大跌时你手里保留的购买力让你多抓住了多少底部新仓。

**2. 行业里真正在用的做法**

[书上原话] 阶梯式总敞口管理（Progressive Exposure）： Mark Minervini 与 William O'Neil 体系的核心做法是减仓看大盘（Beta），买回看个股结构（Alpha）。大盘出现派发日密集或跌破 21/50 日均线进入「上升趋势受压」时，无条件把总仓位上限从 100% 砍到 50%；跌入「市场调整」时砍到 0%–25%。砍仓顺序是「砍弱留强」——优先清掉跌破成本线或浮盈最薄的弱势股，保留相对强度（RS）抗跌的领头羊。

[行业里有人在用] 波动率目标缩放（Volatility Targeting）： 量化与 CTA 团队不主观判断「转跌」，而是用基准指数过去 10–20 天的实现波动率反推组合敞口（目标波动率除以当前波动率）。大盘一旦放量下跌、ATR 飙升，系统自动按比例削减全组合头寸；等市场横盘、波动率回落，系统再自动把仓位加回来，完全不纠结「有没有卖在反弹高点」。

### ⑦ 怎么事先知道这次破位是真的

**1. 哪里测错了或问错了**

[行业里有人在用] 测试时间窗口切错了： 你们只测了 t=0（破位当天），漏测了 t+1 到 t+3（破位后 1–3 天的价格反应）。行业里几乎没人能在 t=0 猜中方向，大家区分真假破位，靠的是观察破位后的「无力反弹（Failed Reclaim）」。

**2. 行业里真正在用的做法**

[书上原话] 弹簧效应与弱势反抽（Spring vs. LPSY）： Richard Wyckoff 经典理论与 Victor Sperandeo 的 2B 法则指出，真假破位的分水岭在于破位后 1–3 天能否迅速收回支撑位。迅速放量收回叫「弹簧洗盘（Spring）」，反而是强多头信号；缩量反抽过不去原支撑位（支撑变阻力）并跌破破位 K 线低点，才是真破位。

**3. 能写成程序、能再测一遍的具体规则**

## 「最后一问:挂件怎么配」回答原文

这份实测报告非常精彩。如果我的量化研究员拿着这份报告来找我，我会直接给他发全额奖金。你们这一个月的测试，触及了量化交易里最反直觉、但也最真实的“丑陋真相”——很多书上教的、散户趋之若鹜的“高级技巧”，在带有右偏分布的美股多头策略里，全是拔苗助长的累赘。

在给具体配置前，我先以交易主管的视角，点评一下你们的测试（指出哪里错、行业怎么做）：

- 关于①（分批止盈推保本降低收益）：你们没测错，问得也没错。美股多头的利润来源是极度右偏的幂律分布（Power Law），即5%的交易贡献了95%的利润。分批止盈本质上是“切断右尾（Cut the right tail）”来换取胜率（心理安慰）。[行业在用] 机构的趋势跟踪策略极少设置硬性止盈目标，全靠跟踪止损（Trailing Stop）让利润奔跑。
- 关于②（小周期进场无效）：你们没测错。美股因为有隔夜休市，日内（1小时/15分钟）充满了开盘Gap（跳空）和机构算法造成的均值回归噪音。加密货币24小时交易，趋势连贯，所以小周期有效。[我的建议] 股票策略彻底放弃日内MTF（多时间框架）进场，只按日线信号在收盘前或次日开盘执行。
- 关于③（等权重跑赢各种复杂仓位管理）：极其精准。波动率倒数（风险平价）在个股上往往表现很差，因为它会惩罚那些“正在主升浪上、波动率开始放大”的超级牛股。[行业在用] 华尔街很多Long-Only（纯多头）基金的底仓就是最粗暴的“等资金分配”（Equal Dollar Sizing）。
- 关于⑥（跌破后等反弹再卖）：你们打碎了散户最大的心理幻觉。[书上原话] “沉没成本不是成本”。破位后立刻卖出和等反弹卖出的数学期望是一样的，但等待会让你承担未知的左尾风险（直接腰斩）。
- 关于⑦（用市场宽度判断破位真假）：你们触碰到了真正的宏观择时Alpha。单只股票的量价无法判断真假破位，但大盘的“宽度（Breadth）”可以。这是构建下面大盘开关的核心。

### 最后一问：挂件怎么配（大盘状态判定与策略矩阵）

作为个人投资者，美股做多策略的核心哲学应该是：在顺风局里重仓满载、在震荡局里吃短线小肉、在转弱时光速逃命、在深熊里耐心装死。

以下是可编程的大盘状态判定规则，以及对应的实战配置。

**1. 如何用程序判断大盘的四种情况？**

我们需要输入两个数据源：标普500指数ETF（SPY）的日线，以及罗素3000（或标普500）成分股的“市场宽度”（Breadth，定义为收盘价在50日均线上方的股票比例）。

- 大盘在涨（Uptrend）：
  - 代码规则：SPY_Close > SPY_SMA(50) 且 SPY_SMA(50) > SPY_SMA(200) 且 Breadth > 50%。
  - 逻辑：指数处于多头排列，且市场大部分股票都在涨。
- 大盘震荡（Choppy / Consolidation）：
  - 代码规则：SPY_Close > SPY_SMA(200) 且 （SPY_Close < SPY_SMA(50) 或 Breadth < 50%）。
  - 逻辑：长期趋势还在，但短期均线跌破，或者指数没跌但大部分个股已经涨不动了（赚了指数不赚钱）。
- 大盘刚转弱（Just Turned Weak）：
  - 代码规则：利用你们第⑦点的伟大发现！SPY_Close < SPY_SMA(200) 且 SPY 距离过去252天最高点跌幅 < 12% 且 Breadth < 30%。
  - 逻辑：刚刚跌破牛熊分界线，距离高点还不远，且发生大面积泥沙俱下（宽度极度萎缩），这是大崩盘的前兆。
- 大盘跌了很久（Prolonged Bear Market）：
  - 代码规则：SPY_Close < SPY_SMA(200) 且 SPY 距离过去252天最高点跌幅 >= 12% 且 （可选：VIX > 30 或 连续超过40天低于200日均线）。
  - 逻辑：已经处于深熊。

**2. 四种情况下的策略配置矩阵**

**状态一：大盘在涨（Uptrend） —— “利润收割期”**

这是你全年80%利润的来源，不要做任何限制收益的蠢事。

- 主策略：趋势跟踪 / 突破买入（如突破50日新高，或带量的杯柄形态突破）。[书上原话]
- 打开的挂件：
  - 按行业开关（Sector Filter）：只做强度排名前三的行业里的股票。[行业在用]
  - 大级别跟踪止损（Trailing Stop）：用ATR（如3倍ATR）或20日低点作为止损，死抱直到趋势终结。[我的建议]
- 关闭的挂件：
  - 分批止盈 / 推保本：绝对关掉！不要为了胜率去剪断那几只能翻倍的超级牛股的翅膀。[行业在用]
  - 小周期进场：关掉，纯日线级别操作，省时且过滤噪音。[我的建议]
- 仓位配置：满仓（100% Exposure）。“每只票一样大”（等权重配置，比如均分10等份，每只10%）。[基于你们的测试结论]

**状态二：大盘震荡（Choppy） —— “防守反击期”**

趋势策略在这个阶段会被反复打脸（Whipsaw），必须改变策略内核。

- 主策略：均值回归 / 回踩买入（如跌至上升趋势的50日均线且缩量，或者RSI超卖）。[行业在用]
- 打开的挂件：
  - 分批止盈 / 推保本：打开！因为震荡市里没有大趋势，赚了1-1.5倍风险立刻卖出一半，推保本。这里需要的是高胜率维持净值。[我的建议]
  - 转跌后立刻减仓：跌破关键支撑直接无脑砍，不等反弹。[基于你们的结论]
- 关闭的挂件：
  - 突破买入：震荡市的突破80%是假突破（Bull Trap）。[书上原话]
  - 被止损后再进：关掉，避免在震荡区间被来回割肉。[我的建议]
- 仓位配置：总仓位降至 40%-50%。单只股票的投入降为多头时期的一半。

**状态三：大盘刚转弱（Just Turned Weak） —— “光速逃命期”**

不要去猜底，活下来是最重要的。

- 主策略：空仓观望（Cash is a position）。或者仅持有极少数防御性行业（如公用事业、消费必需品）。[书上原话]
- 打开的挂件：
  - 收紧跟踪止损：把所有多头持仓的止损线强制上移，比如从3倍ATR缩紧到1.5倍ATR，或者收盘破10日线直接走人。[行业在用]
- 关闭的挂件：
  - 所有进场信号全部失效：主策略的买入模块硬核切断。[我的建议]
  - 做空挂件：关掉（如你们测的，做空是个亏钱买卖，不如直接拿着现金买短期国债吃利息）。[基于你们的结论]
- 仓位配置：只卖不买，随着持仓被止损，仓位自然滑落到 0% - 10%。坚决不允许任何形式的加仓或摊薄成本。

**状态四：大盘跌了很久（Prolonged Bear Market） —— “左侧试探期”**

市场泥沙俱下，但极度恐慌后会有暴力反弹（如你们在2008和2020年观察到的急跌快弹）。

- 主策略：极度超卖的均值回归（比如股价偏离200日均线极远，且VIX开始从高位回落的第一天）。[行业在用]
- 打开的挂件：
  - 按波动定大小（Volatility Sizing）：在这个阶段必须打开。熊市里单日波动极大（ATR飙升），如果还用固定的等额资金买入，实际承担的风险会翻倍。必须按 (账户总风险限额 / 当前极大的ATR) 来缩小股数。[行业在用]
  - 快速止盈：熊市多暴涨（Bear Market Rally），反弹到阻力位（如下降的20日均线）直接全平。[我的建议]
- 关闭的挂件：
  - 大盘开关（按行业看）：关掉。熊市末期，所有行业一起暴跌，此时看相对强弱没有意义，看绝对超卖才有效。[我的建议]
- 仓位配置：总仓位不超过 20%-30%。单笔风险定死在账户总资金的 0.5% 以内。
