## 三、两种口径（★★★ 打法单第八节明确要求分开，★ 不许只报一种）

### 口径① **股数不变** —— 事后重放（不重跑引擎）

```
★ 做法：对那 349 笔「reason = 止损」的单子，★★ 从**原止损离场日**起继续持有，
   ★★★ 用**同样的股数**，直到满足 `close < 过去 10 日最低价` 才卖（次日开盘成交）。
★ 窗口末仍未触发 → 按窗口最后一个交易日收盘结算，★★ 并**单独报这类笔数**。

★ 它故意**不改仓位** —— 因为改仓位会把两件事混在一起。
```

### 口径② **按新止损重新定仓位** —— 重跑引擎

```
★ 做法：`initial_stop.params.multiple` 跑三点 **2.0（原版）/ 2.5 / 3.0**。
★★★ 注意引擎的仓位公式：`by_risk = (权益 × 单笔风险) / (进场价 − 止损价) × 进场价`
   → ★ 止损放宽 **自动把仓位变小**。★★ 所以这一口径回答的是：
     「**放宽止损 + 自动减仓，整体净值是变好还是变坏**」。
★★★ 这和口径① 是**两个不同的问题** —— 两个都要报，谁也不许单独报。
```

## 四、判据（★★★ 跑前写死，出数时不许动）

| 判据 | 门槛 | 出处 / 理由 |
|---|---|---|
| ★★★ 逐日配对检验 | Newey-West 滞后 8，**\|t\| > 2.5** | ★ 本轮只产生 **1 组**配对（整套 vs 原版），不是多重检验 |

```
★★★ 预先写死的两种结论话术：
★ 情形一：口径①「少亏」且配对 |t| > 2.5，且口径② 三点同向、大单保留率 ≥ 85%
   → ★★ 写：「**放宽硬止损有实测支持**；硬止损应退回灾难保险的定位。」
★ 情形二：配对没过，或三点不同向，或大单保留率 < 85%
   → ★★ 写：「**测不出放宽止损更好。**」
   ★★★ 这时候**不许继续挪门槛去凑**（那就是「试了 K 种挑最好的一种」）；
     ★ 该动的是**止损的类型**（换成跟踪/形态止损），不是它的倍数。
★ 情形三：口径① 和口径② **方向相反**
   → ★★★ 这是**最可能**的一种（因为②自动减仓）。
     ★ 写：「不砍更赚（①），但放宽止损+自动减仓更差（②）
       → **问题在仓位公式和止损耦合，不在止损宽度本身**。」
     ★★ 这一条指向的是引擎的 sizing 设计，不是挂件。
```
