# 给主 chat · 技术面大师卡改动单 v0.7：二次回踩、截图读价、小形态库、两套计划 · 2026-11-20

**背景（大白话）**：《235》用 Lin 真实的 30 道看图题考了卡（v0.7 + v0.6），对照 Gemini：平 24、我们胜 1、Gemini 胜 4、分歧 1。Gemini 胜的地方集中在：扫完低点后等二次回踩、没数据时也能从图上读价位给计划、有形态知识、总是给多空两套计划。
**Lin 11-20 12:31 拍板：同意。**

**要干啥**：卡里加下面四处（都是默认值 / 经验，没有回测）。

## 1 · 扫完低点后等「二次回踩」（改计划表「扳机」和区间打法的「做多」）
- 支撑 / 箱底被扫（假跌破收回）之后，**第一腿反弹不追**。
- 两种进法任选：① 回踩到这一腿反弹的 0.5~0.618，出现「更高的低点」+ 长下影 / 吞没 → 进；② 收盘站上第一腿反弹的高点 → 进。
- 止损：扫单针尖再往外 0.5×ATR（不变）。做空镜像。
- 例子：第 20 题 QQQ 705 被扫后弹到 718，Gemini 的计划是「等回踩 708~712 不破」，我们当时直接想等扫 700，慢了一步。

## 2 · 取不到行情数据时，从用户截图读价位（改第五节「为什么是这些价位」、第八节）
- 个股、A 股、港股等取不到数据时，不要只说位置：从截图读出关键价位（前高前低、平台、均线带、图上标的支撑阻力），**标明「来自你的截图，未用行情数据核对」**，照样给带条件的计划。
- 读不清的价位写「图上看不清，约 ××」。

## 3 · 小形态库（新增一节，全部标「经验，没有统计」）
| 形态 | 怎么认 | 意味着 |
|---|---|---|
| 底部弹簧 + 收敛 → 爆发 | 支撑处先放量扫单针 → 缩量、波动越来越窄 → 放量突破 | 后面常是单边上涨；突破那根就是扳机 |
| 顶部镜像 | 阻力处三顶 / 插针 → 收敛 → 跌破 | 后面常是快速下跌 |
| 平顶 + 抬高的低点 | 上沿几次冲不过、下沿斜线越抬越高 | 向上突破是延续；**跌破斜线是失败形态，往往跌得急**（第 35 题 Lin 的例子） |
| 斜线被踩多次 | 第三、四次踩线 | 越踩越容易破（Lin 的经验，我们还没测） |

## 4 · 用户问「怎么做」时，至少给两套计划（改第一节格式说明）
- 主剧本方向一套 + 反方向一套（逆势的那套写明半仓 / 0.5 倍、目标只看到中轴或第一阻力），每套都有等待区、扳机、止损、两个目标。
- 不许只写「等」。
