# 42 · 「缺行记 0」三档对比 · 待 Lin 拍板(2026-11-05)

> **三秒版:Gemini 说业界做法就是「报表完整、但没有这一行 → 记 0」;Sloan 原文没写,但复现者普遍这么做。我们实测:打开这条规则,股东回报三项齐全从 31% → 85%,Sloan 应计原著版从 19% → 46%。我倾向打开,并加一道「分项加不到合计」的检查,把可能藏在「其他」里的情况标出来。**

---

## 一 · 要定的事(一句话)

一份 10-K / 10-Q 里,**整张表是完整的**(资产负债表有流动负债合计,或现金流量表有经营现金流),但**没有某一行**(应交所得税、短期借款、增发、分红、回购)—— 这一行记 0,还是算「缺」?

长期负债我们 11-03 已经按「记 0」处理了。这次是要不要推广到这五项。

---

## 二 · 三档并排(按 11-04 定的次序)

| 档 | 说法 | 出处的可靠程度 |
|---|---|---|
| **① 原著** | **Sloan(1996)原文没有写**缺失怎么处理 | ✅ Gemini 和我都认这一点 |
| **② Gemini(业界做法)** | 应计类(Sloan、Hribar & Collins 2002、Richardson 等 2005):缺的分项**记 0**,不剔除公司。股东回报类(Boudoukh 等 2007):现金流量表上没有这一行就是没发生,**记 0**。用 SEC XBRL 数据时,只要上一级合计(比如流动负债合计)报了,缺的分项记 0 也是通行做法。剔除公司会把「不借钱、不发股的健康公司」系统性地剔掉 | ⚠️ 它说这是「复现者的共识」,**没有给出原文页码**。不能当成原著规定,只能当行业惯例 |
| **③ 我们实测** | 见下表 | ✅ 实测 |

**实测(池子 2016–2025 年,共 19,750 个「公司 × 年份」,看上一财年)**

| 项 | 修之前(手册 40) | 补了科目、不记 0 | 补了科目、**记 0** |
|---|---|---|---|
| 应交所得税 | 0% | 47.2% | **76.8%** |
| 短期有息负债 | — | 56.6% | **77.1%** |
| 增发 | 31.4% | 70.0% | **88.9%** |
| 分红 | 50.7% | 53.7% | **86.4%** |
| 回购 | 61.6% | 63.4% | **87.2%** |
| **股东回报三项齐全** | 11.8% | 31.1% | **84.5%** |
| **Sloan 应计原著版能算**(连续两年都有:流动资产、流动负债、现金、短期负债、应交所得税、折旧) | 0% | 19.3% | **45.8%** |

说明:
- **增发从 31% 涨到 70%,不靠「记 0」**,靠的是把行权、股权激励发股、员工购股等几条「发股收到的钱」加起来。很多公司根本没有「发行普通股」这一行,只有「员工行权收到的钱」
- **Sloan 原著版打开规则后也只到 46%**,卡在两项别处的缺口:折旧(57%)和流动资产 / 流动负债(75%,银行保险天然没有)。这两项不是「记 0」能解决的

## 三 · 反方(Gemini 当的)和我们的对策

| 「记 0」可能错的地方 | 对策 |
|---|---|
| **金额小的被并进别的行**:比如应交所得税并进「其他应计负债」,实际不是 0 | 加检查:「各分项加起来」和「合计」差得多的,标 `zero_suspect = true` |
| **早年(2009–2012)用自定义科目名**,标准科目里找不到 | 同上检查能抓到一部分;另外记 0 的记录都标了规则名,可以按年份整段关掉 |
| **银行、保险**:资产负债表不分流动 / 非流动 | 已经排除:规则要求「流动负债合计」存在才记 0,银行保险自然不会被记 0 |
| **某一年突然从有数变成 0,同时「其他」那一行正好涨了这么多** | 同样标 `zero_suspect`(时间上的检查) |
