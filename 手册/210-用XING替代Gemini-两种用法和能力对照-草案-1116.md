## ★★★ 三秒版

```
★ 两种用法：
  A「随便问」：不用绑定，丢图、丢代码、问一句就答 —— 大师分析直接答，答法照 Sniper 那套（先结论→价位→纪律）。
  B「帮我盯」：绑定持仓和自己的规则 → 盘中提醒、到价提示、持仓管理、隔天复盘。
  A 用着用着想让我们盯，一键转成 B（把这次聊的价位和计划带过去）。
★ Gemini 那些具体本事，我们能做的分三档：
  现在就能做（美股日线）：先给结论、一票否决、等待区/止损/TP1/TP2、仓位按风险倒推、成本价计算、复盘手册、心得提炼成规则

  要补功能才能做：持仓绑定、到价提醒、盘中盯盘、隔天自动复盘
★ 我们比 Gemini 强、要保住的：数字有回测/出处、不附和、价位用数据算不靠读图。
★ 最大的缺口：Gemini 139 轮里 124 轮用了 15分钟/1小时/4小时 —— Lin 的打法离不开盘中周期，我们现在只有日线。
```

## 一 · 两种用法怎么分

| | A · 随便问 | B · 帮我盯 |
|---|---|---|
| 谁 | 偶尔来问的人；Lin 的朋友第一次来 | 天天交易、想要陪练的人（Lin 自己就是这种） |
| 要不要绑定 | 不用 | 要：持仓（品种、成本、数量）、自己的规则（档位 / Sniper 这种设定）、每笔愿亏多少 |
| 我们给什么 | 一次性回答：结论 → 关键价位 → 计划 → 纪律提醒 | 持续服务：到价提醒、盘中「该不该动」、持仓怎么管（平多少、推保本、加不加）、隔天复盘 |
| 怎么转 | 回答末尾一句：「要不要我帮你盯这几个价位？」→ 用户点了就带着这次的价位进入 B | — |

## 三 · 我的建议次序（七十的先做）

1. **A 类先做满**（只动大师卡，不用新数据）：第 1、2、3、4、5、6、11、12 项 —— 让「随便问」的回答达到 Gemini + Sniper 的水平，而且数字有根据。
2. **B 类的骨架**：持仓绑定 + 到价提醒 + 隔天复盘（第 9、10、14、15 项），先用日线收盘版。
3. **接分钟线**（第 7、8 项的确认部分）：数据在 Lin 那台机器上，取数单我来写。
4. 加密货币 / 资金费率（第 13 项）：要不要做，Lin 定。

## 三之二 · v2 补充（最近 90 轮）带来的两条

- **B 类流程不用从零设计**：Gemini 在 v2 第 19、70 轮已经替 Lin 写了两份工程规格（五步串行 + 一票否决；等待 → 进区 → 确认 → 持仓 → TP1 → 推保本的状态机）。我们拿来当 B 类骨架的起点，再把每一步的数换成我们回测过的。
- **「回踩要不要平」能算**：v2 第 80 轮的强弱四维（回踩深度、回踩用时、量能、均线）全部能用日线算，第一版就能放进 A 类回答。

## 七 · Lin 1117 11:23 提：初期怎么接 Sniper 的档位、用户怎么选（Claude 草案）

**倾向：第一版只上 Sniper 一套体系，按「能不能盯盘」分两档；用户进来答 4 个问题自动落档，之后随时能改。**

| 档 | 给谁 | 看什么周期 | 怎么陪 |
|---|---|---|---|
| 盯盘版 | 白天能看盘、做波段的 | 日线/4H 定方向，1H/15m 找扳机（Sniper 原样） | 到关键位置推送 + 盘中陪练 |
| 日线提醒版 | 上班族、一天看一两次 | 日线/4H 定方向，日线收盘确认 | 提前挂好提醒价，收盘后给计划 |

**入门 4 问**（落档 + 填个人参数）：① 一天能看几次盘 ② 每笔最多能亏多少钱 ③ 做不做空、用不用杠杆 ④ 连亏几笔要停手。

**为什么只上 Sniper**：它是唯一被真人（Lin）几个月实盘用过、Gemini 挂上就答得好的体系；其它模板（趋势跟踪、超卖反弹、长线）放第二批，等回测体检做完再上。
**依赖**：盯盘版要分钟线数据和推送；日线提醒版现在的日线引擎就能做 —— 所以日线提醒版可以先上。

**匹配 5 问**
1. 一天能看几次盘？（多次 → 1；一两次 → 2；一周一次 → 3；一月一次 → 4）
2. 一笔想拿多久？（几天 → 1/2；几周到几个月 → 3；几年 → 4）
3. 你更喜欢哪种票？（便宜 / 增长快 / 又便宜又增长 / 跌惨了翻身 / 不看公司只看走势）—— 决定基本面大师用哪一派
4. 每笔最多能亏多少钱？—— 填仓位参数
5. 做不做空、用不用杠杆、连亏几笔停手？—— 填纪律参数

1、2 两题定档；两题冲突时取更慢的那档（宁可少看盘）。3~5 题只填参数、不定档。用户随时能换档。
