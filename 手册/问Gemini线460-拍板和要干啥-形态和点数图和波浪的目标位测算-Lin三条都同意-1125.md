## 拍板

### 1. 技术面大师卡加形态测算目标,合成目标区
**形态测算表:**

| 形态 | 测算 | 向下 / 向上达成率(Bulkowski 第 2 版,待核) |
|---|---|---|
| 上升楔形(含顶压平变体) | 回到楔形起点;或最宽处高度,从跌破点量 1 倍 | 约 53%~63% / —(变体无统计) |
| 下降楔形 | 回到楔形起点 | — / 约 62% |
| 头肩顶 / 底 | 头到颈线的高度,从颈线量 1 倍 | 55%(量 0.75 倍时约 74%)/ 74% |
| 双顶 / 底 | 顶到中间低点的高度,量 1 倍 | 45%~58% / 66%~70% |
| 三重顶 / 底 | 同上 | 48%~51% / 64%~68% |
| 矩形箱体 | 箱体高度,量 1 倍 | 56% / 73%~76% |
| 旗形 / 三角旗 | 旗杆长度 × 0.5~0.618(1 倍偏激进) | 43%~47% / 54%~64% |
| 对称三角形 | 最宽处高度,量 1 倍 | 48% / 66% |
| 上升 / 下降三角形 | 最宽处高度,量 1 倍 | 下降三角 54% / 上升三角 64%~70% |
| 急拉后高位派发区 | 第一目标 = 急拉起涨点(把急拉全吐回去);再往下看点数图(第 2 条) | 无统计 |

- **第一目标取测算幅度的 75%~80%**,因为向下的达成率只有五成左右。另试 70% / 80% / 100%。
- **合成目标区:**
  - 测算位、结构位(前高前低、平台、密集区)、等距投射(第 3 条),彼此在 1 倍日线 ATR(或 2%)以内的合成一个区;另试 0.8 / 1.2 倍 ATR。
  - 测算位落在大前低下方不远处(< 1.5 倍 ATR)时,目标上移到前低上方一点。
  - 由近到远排 T1、T2;第三段交给移动止损。
- **到 T1 平 35%**(另试 25% / 50%),剩下的止损移到成本价。
- **卡里原盈亏比门槛先不动**(第一目标 ≥ 1.3 倍风险,加权 ≥ 2 倍)。另跑「到 T1 ≥ 1.5 / 1.8 倍风险才开仓」对比。
- **用户页面:** 显示「形态测算还剩多少空间」,注明是参考。

### 2. 点数图(Wyckoff P&F)先当实验模块,不上线
- **规则:**
  - 格值 = 0.5 倍 ATR(另试 0.4、0.6),3 格反转,按高低价画;
  - 从冲顶高潮那一列数到最后一次冲高失败那一列,得到列数 N;
  - 目标 = 基准价 − N × 格值 × 3,基准价取最高点和横盘中轴各算一个,得到一个区间。
- **周期:** 日线只用于横盘 > 2 个月的大箱子;4 小时用于横盘 ≥ 10 天的箱子。
- **为什么先不上:** 我实算 BTC 9-21 ~ 10-07(4 小时 ATR 1,059):
  - 格值 0.4 / 0.5 / 0.6 倍 ATR,列数 20 / 14 / 14;
  - 目标 5.7 万~6.5 万(实际最低 55,106),方向对,但格值一变就差 8,000 点;
  - 日线只画得出 1~4 列,目标 7.2 万~8.3 万,用不了;
  - Gemini 两边说的「日线点数图精准命中 5.6 万」是凑出来的。
- **上线条件:** 回测达成率不比形态测算差,而且不太晃,才并进目标区和用户页面。

### 3. 波浪:不自动数浪,只用两组比例
- **不写自动数浪**(千人千浪,事后会改)。
- **等距投射:**
  - ZigZag 拐点(拐点间最小 3 倍 ATR,另试 2.5、4);
  - 最近三个拐点是「高 → 低 → 更低的高」时,从反弹高点往下投射上一段跌幅的 1 倍、1.618 倍,并入目标区;做多时反过来。
- **按百分比投射,不按点数**(推断,要回测确认):
  - BTC 这笔:上一波 126,296 → 57,718 跌了 54%,按 0.618 倍的跌幅比例从 87,400 量,约 5.8 万,和前低 5.77 万重合;
  - 按点数量是 5.3 万(0.5 倍)或 4.5 万(0.618 倍),偏远。
  - 两种都跑。
- **反弹比例 0.382 / 0.5 / 0.618:** 和 459 第 1 条「收回 0.618 切转涨」是同一把尺子。
