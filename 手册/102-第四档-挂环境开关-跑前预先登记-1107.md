## 三、开关怎么定义（★★★ 跑前写死，不许事后调）

### 3.1 主轴：方向（这一档只用这一道）

```yaml
regime:
  rules:
    - type: index_above_ma          # ★ 引擎原生,无需覆盖层
      params: {symbol: SPY, ma: 200}
  flatten_when_off: false           # ★ 关闸只是不开新仓,不强制平掉已有仓
```

```
★ 出处:Brock, Lakonishok & LeBaron (1992) —— ★★ 200 日均线是**有文献出处的标准做法**,
   不是我们自己发明的阈值（红线①）。
★★★ 参数写死 SPY / 200 / flatten_when_off: false,**三个都不许调**。
★ 为什么选 `flatten_when_off: false`:挂开关的本意是「环境不对就不开新仓」,
   ★★ 强制平仓是另一个动作（止损），混进来就分不清是哪个起的作用。
```

### 3.2 副轴：波动（★★ 本档**不跑**，列在这里是为了说明为什么不跑）

```
★ Gemini 第 50 轮的判断:「20 日已实现波动 vs 过去一年中位数」**不是标准做法**,
   有结构性问题,而且「线下 × 低波动（阴跌）」这一格大概只占 5~8% → **严重缺样本**。
→ ★★★ 所以这一档**只上方向一道闸**。2×2 四格要等反锯齿规则（缓冲带 / 连续天数 /
   最短停留期）都定好、并且各格样本数点清之后,单独立一档。
★ 这是**现在就写下的放弃**,不是跑完发现不好看才砍掉的。
```

### 3.3 三点检验（红线②）

```
★ 200 日这个数虽然有出处,但仍按红线②跑相邻三点:**100 / 200 / 300 日**,
   ★★★ 报三点是否同向。
→ ★ 只有 200 好、100 和 300 都不好 → 那是**尖峰**,算挑出来的,不算站得住。
★★ 注意:1106 修过一个 bug —— 参数写在顶层会静默退回默认 200,
   ★★★ 所以这三档必须**逐字节比流水哈希**,确认三条真的不一样（《24》同类错已有先例）。
```

## 四、怎么比（★★★ 配对检验，规矩㊸v2）

```
★ 做法:
   1. 同一条策略、同一窗口、同一批信号,跑两条臂:【A 原样】【B 挂开关】
   2. 取两条臂的**每日组合收益序列**,逐日相减 → 得到一条「差值序列」
   3. 对差值序列做 **Newey-West 修正的 t 检验**（滞后期按持仓期定，≈8）
   4. ★★★ 配对没做完之前,一律写「**待配对检验**」——
      不许写「更好」,也不许写「分不出」。

★★ 为什么必须配对:两条臂各跑各的、再比两个均值,噪声会被放大 ——
   ★ 随机单次的标准差是 **0.0713**,而我们见过的最大「改进」只有 **0.052**。
→ ★★★ 不配对的话,真改进会被噪声埋掉（Gemini 清单第 7 条,唯一偏向「假不显著」的那条）。
```

## 五、预先写死：两种结果各对应什么话

```
★★★ 情形一:趋势/突破类（技-1、技-6）配对 t > 2.5 且为正,
          震荡类（技-14）符号相反或不显著
→ ★★ 写:「**挂环境开关对趋势类有实测支持**;震荡类不吃这道闸,符合预期。」
   ★ 这时候 Lin 1107 19:42 那句「那一档最好」**有实测支持**。

★★★ 情形二:三族配对 t 都 |t| < 2.5
→ ★★ 写:「**不是环境不重要,是这一道闸（SPY 200 日）对我们这批实现没作用。**」
   ★ 这时候该动的是**开关的定义**（换成有出处的别的闸）或**策略的实现**,
   ★★★ **不是继续加闸凑到显著** —— 那就是「试了 K 种挑最好的一种」（清单第 4 条）。

★★★ 情形三:关闸天数占比 < 5% 或 > 50%
→ ★ 这一档**整个作废重设**,不报任何 t 值。
   ★★ 理由:闸得太松等于没挂,闸得太紧等于换成了另一个策略 —— 两头都不是在测这件事。
```
