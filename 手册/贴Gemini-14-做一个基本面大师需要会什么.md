## 第 0 页 · 我们现在缺的到底是什么（★ 一句话）

```
★★ 我们**不缺**分析一家公司的底层能力 —— 那一块 V1 已经做了很多,
   35 个 SEC 指标(含 EBIT、长期负债、ROIC)全部 PIT 合格,行业代码、上市日期、业绩公布日都有。
★★★ 我们缺的是:**一个基本面大师该会什么** —— 这个我们从来没系统性问过。
```

**所以这一轮不是问「怎么算 ROIC」**（那个我们会算）。
是问：★★★ **一个顶级基本面分析师，收到用户那句话之后，脑子里按什么顺序走。**

### ★ 为什么不直接问「基本面分析包括哪些内容」

因为那会得到一份教科书目录 —— ★★ **教科书目录我们编不了码。**
我们要的是：**用户真实开口问的那五句话，每一句背后的分析流程。**

---

## 第 1 页 · 每个用例要它交的三样（★ 和技术面那份完全一致）

```
① **按什么顺序看** —— 第一步看什么、第二步看什么。★ 顺序本身就是知识
② **每一步能不能落成代码** —— 哪些算得出来,哪些只能靠人眼和经验
③ **★★★ 这一步凭什么知道(出处)**
```

### ★★★ 第三样决定我们编不编

```
说得出「凭什么」的  → 我们编码,进主体
说不出「凭什么」的  → ★ 挂第五档「外部模型回答·未经我们测试」,不编码
```

## 第 2 页 · 五个用例（★ 分五次问，一次一个）

```
① 「帮我看看这家公司怎么样」              ← 结构读表流程
★★★ ② 「这个价格贵不贵」                   ← 估值。★ 建议第一个问
③ 「它的护城河在哪、能维持多久」
④ 「财报出来了,该怎么看」                 ← 事件
⑤ 「我已经持有了,什么情况下该卖」
```

### 为什么建议 ② 先问

因为**估值是基本面里最容易含糊过去的一块**，也是最容易看出它在不在编的一块。
★★ 如果它在「贵不贵」上就只能给「要看行业」这种话，后面四个也别指望。

### ★ 第 ⑤ 个用例单独说一句

卖出是基本面派公认的弱项 —— ★★ **大部分书只教怎么买，不教怎么卖。**
所以这一问很可能会逼出一堆 `[你的推断]`。**那正是我们要知道的。**

## 第 3 页 · 粘贴模板（★ 五次都用这一套，只换中间那一段）

```
假设你是华尔街顶级的基本面分析大师。

我在搭一套系统,要把「基本面大师的分析能力」变成可编码的流程。
这一轮我不讨论任何回测成绩,★ 也请不要问我们测出来怎样。

────────────────────────────────
【这一次的用例】

用户对大师说:「【★ 从第 2 页五个用例里挑一个,原样填进来】」

请告诉我:一个顶级基本面大师,收到这句话之后,脑子里按什么顺序走。
────────────────────────────────

【回答规则 —— ★ 请严格遵守】

1. 请把你的分析流程拆成**有编号的步骤**。
   ★ 顺序很重要 —— 请说明为什么是这个顺序,而不是别的顺序。

2. ★★★ 每一步后面必须标三样:

   (A) 【要什么数据】—— ★ 具体到财报科目名。
       例:「IncomeBeforeTax + InterestExpense」,
       不要写「盈利质量」这种我没法取数的说法。
       ★★ 如果要用的科目在 SEC XBRL 里有多个标签,请把标签都列出来 ——
          我们踩过坑:只认一个标签会漏掉四成公司。

   (B) 【能不能落成代码】—— 只能选三个之一:
       [可计算]   —— 给得出明确的公式或判据
       [半可计算] —— 大体能算,但有一步要靠判断。★ 请说清是哪一步
       [只能靠人] —— 算不出来。★ 请直接承认,不要勉强给一个公式

   (C) 【凭什么】—— 出处,只能选这五个之一:
       [原文] —— 某本书/某篇论文里有,★ 必须给出书名作者 + 原文那句话
       [通行] —— 原著没写,但行业里普遍这么做
       [你的推断] —— 你自己补的
       [不确定]
       [有争议] —— ★ 业内两派打架。请把两派都说出来

   ★★★ 如果你拿不出原文那句话,就不许标 [原文],改标 [你的推断]。
   ★★★ 不许给我任何你估的数字范围。估的就标 [你的推断]。

3. ★★ 如果某一步根本没有公认做法,直接写「没有公认做法」。
   **不要替它补一个看起来合理的。**

4. ★★★ 这一轮有两条基本面特有的要求:

   (甲) ★★★ **时点问题**:你给的每一个数,请说明「**什么时候才真的能拿到**」。
        例:年报数字在财年结束后多久才公布?
        ★ 我们已经有精确到盘前/盘后的业绩公布日,所以请不要含糊。
        ★★ 凡是用了「事后才知道的数」的步骤,请自己标出来。

   (乙) ★★★ **行业差异**:你给的判据,哪些是**所有行业通用**的,
        哪些**换个行业就必须换口径**的?
        ★ 请把必须换口径的行业点名(银行?REIT?公用事业?铁路?)。

5. ★★★ 最后请单独回答两条:

   (丙) 这个用例里,**哪一步最容易被做错**?★ 新手和老手的差别在哪一步?
   (丁) ★★★ **这个流程在什么情况下会给出错的答案**?
        请给出具体情形。不要说「市场有风险」这种话。

6. ★ 不许在这一轮给我任何买卖方向建议,也不许推荐具体股票。

【我的数据边界 —— ★ 超出这个范围的做法请直接说"你们没有这个数据"】
  SEC XBRL 财务数据,35 个指标,全部 PIT 合格(含 EBIT · 长期负债 · ROIC)
  4 位 SIC 行业代码(297 只)· 上市日期(全量约 6,000 只)
  ★ 业绩公布日(292 只),精确到盘前/盘后 + 市场第一个能反应的交易日
  日线 OHLCV,2014-01 至 2025-12
  ★ 没有:分析师预期 / 管理层指引 / 电话会议文本 / 新闻 / 行业研报 /
         非上市同业数据 / 供应链明细 / 季度以外的频率
```

## 第 4 页 · 五次问完之后，再追加这一轮（★ 收口）

```
上面五个用例你都答完了。现在请回答四个收口问题。

(一) ★★★ 把五个用例的步骤合起来看,**哪些步骤是重复出现的**?
     ★ 那些重复出现的,是不是就是「基本面大师的核心能力」?请列出来。

(二) ★★★ 一个基本面大师的能力清单,**除了这五个用例覆盖到的,还缺什么**?
     ★ 我们是拿用户会开口问的话倒推的,所以一定有漏的。请补。

(三) ★★★ 在你标了 [只能靠人] 的步骤里,
     ★ 哪几步是「**再过几年也还是只能靠人**」,
       哪几步是「**现在算不出来,但原则上能算,只是没人做**」?
     ★★ 这两类请分开列。

(四) ★★★ **基本面和技术面冲突的时候怎么办?**
     ★ 具体问:基本面说好、技术面说坏,这种情况一个顶级分析师怎么处理?
     ★★ 请不要给「两者结合」这种套话 —— 请给**具体的处理顺序**:
        先看哪个?哪个有否决权?有没有「两个都不动手」的情形?

【回答规则】
★ 第 (三) 和 (四) 问请不要客气。我们要的是真实判断,不是让我们高兴的答案。
```

### 为什么第 (三) 问和技术面那份一样重要

★★★ 它直接决定**我们自己编多少、Gemini 兜多少**：

```
「再过几年也只能靠人」     → ★ 我们不编,老实挂第五档让它兜
「原则上能算,只是没人做」   → ★★★ 这是我们的机会,主体就在这里
```

### 为什么加了第 (四) 问

因为两个大师做完之后，**用户必然会同时问两个** —— ★★ 而冲突处理是我们现在完全空着的一块。
★ 这一问也是未来做融合策略的入口。

## 第 5 页 · 两条基本面特有的追问（★ 这两条我们是踩过坑才加的）

### 一 · 时点（第 4 条甲）

```
★ 我们实测过:真正的业绩公布日,中位数只比递交日**早 1 天,36% 是同一天**。
★★★ 真正要管的是「**盘后公布、第二天才能交易**」那一天。
→ 所以凡是它说「财报出来之后怎么样」,★ 必须追问「哪一天的收盘价才是能成交的」。
```

### 二 · 行业差异（第 4 条乙）

```
★ 我们实测过一次筛选方向**筛反了**:
   银行 11→0 ✅ (原著就要排)
   ★★★ 铁路 3→0 ❌ **纯 bug** —— 铁路正是质量复利最该选的
   ★★★ 公用事业留 82.3% ❌ **反了** —— 原著明说要排
→ 所以它给的任何筛选条件,★ 必须问清「哪些行业必须换口径、哪些必须直接排除」。
```

## 第 6 页 · 回来之后我们怎么处理（★ 不用你做，写在这里是为了让你知道为什么要这么问）

```
□ 1. 它标 [原文] 的 → ★ 去方法卡原文 grep。grep 不到的全降成「我们填的」
□ 2. 它标 [可计算] 的 → ★ 对着我们的 35 个指标逐条点。算不出的记「缺字段」
□ 3. 它给的 XBRL 标签 → ★★★ 全部去我们的数据里点一遍覆盖率。
      ★ 我们踩过的坑:`LongTermDebt` 只认了一个标签 `LongTermDebtNoncurrent`,
        补齐标签后覆盖从 140 只涨到 185 只,★★ 过「两项都要」闸的从 42.8% → 68.8%
□ 4. 它标 [有争议] 的 → ★★★ 这些最值钱 —— 两派打架说明那里有真东西
□ 5. 所有阈值抄成一张表 → ★ 看打不打架
□ 6. 凡提到某本书 / 某家公司 / 某个产品 → ★★★ 追问「哪一章、哪一年、哪个产品」
      答不出具体的 → 整条作废
```

**第 3 条是基本面独有的，而且是硬收益。** ★★ 它只要给对标签，我们的覆盖率就涨 ——
实测补标签后 **EBIT 177→216、长期负债 140→185、铁路 0/3 → 3/3 全回来了**。
