# ★ 以下是要贴给 Gemini 的正文

---

假设你是华尔街顶级的量化回测专家，同时熟悉学术实证文献和机构实践。

我们在重建回测池，有三件口径问题卡住了，它们直接决定我们现在跑出来的数能不能用。请逐条回答，并严格区分「有实证/有机构标准做法」和「你的推断」。

## ★ 一、退市股怎么结算（★★★ 影响我们 34.6% 的样本）

**我们的现状：**
- 池子 2,807 只，其中标记为已退市的 **972 只**（34.6%）
- 这 972 只里，**只有 13 只**我们有核实过的退市结算价（破产清算价、并购对价之类）
- 剩下 **959 只**，我们目前只能用「**最后一根 K 线的收盘价**」当结算价

**我们知道这是个偏差，而且方向对我们有利**：真正破产退市的股票，最后几天往往还在 0.3 美元上下交易，然后直接归零；用最后收盘价结算，等于假设我们在归零前卖掉了。所以我们的回测收益被**高估**。

**问题 1：**
- （a）机构在做历史回测时，**没有逐只核实退市原因**的情况下，标准做法是什么？是按 0 结算、按最后收盘价、按退市后 OTC 市场的价格，还是别的？请注明哪一种是有标准的（比如 CRSP 的做法）、哪一种只是惯例。
- （b）CRSP 的 delisting return 是怎么处理的？它对「因财务问题退市」和「因并购退市」是不是分开给值？如果是，那两类的典型 delisting return 大致是什么量级？**请只给你确实知道有出处的，不确定就说不确定。**
- （c）如果我们**只能二选一**（全按 0，或全按最后收盘价），你会选哪个？为什么？代价各是什么？
- （d）有没有一种**只用价格和成交额**就能大致分出「破产退市」和「并购退市」的办法？（比如退市前 20 天的累计跌幅、成交额是否放大）——如果有，请给判据；如果只是推断，请说明。

## ★ 二、「小盘池」怎么定义（★★ 我们现在的办法筛不出小盘）

**我们的现状：**
- 我们按 **当年年初回看 60 个交易日的日均成交额** 给每只股票排名，然后按排名分大/中/小盘
- 问题：**按这个口径，真小盘几乎不存在** —— 排名在 2000 名以后的，每年只有 0 到 186 只
- 而按市值分，我们池子里有 1,271 只是小盘
- 交叉对照发现：**2020 年有 719 只「市值小盘」落在成交额排名的「中盘」档里**
- 我们**没有历史股数**，所以没法按市值做时点分档（会前视偏差）

**问题 2：**
- （a）机构在做历史回测、**没有历史股数**的情况下，怎么定义「小盘池」？
- （b）成交额排名和市值排名作为「规模」的代理，业内更认哪一个？**有没有实证比较过两者？**
- （c）有没有**只用价格和成交额**就能近似市值分档的办法？（比如用价格水平本身、或者成交额的分布位置）
- （d）如果小盘这一档我们确实做不出来，**把它如实写成「我们的池子只覆盖成交额前列」**，这个取舍在机构实践里可接受吗？还是说它会让整套回测结论失效（因为很多技术面策略的效果本来就集中在小盘）？★ 这最后一句是我们最担心的。

## ★ 三、五个零件缺口有没有不改引擎的等价做法

我们的回测引擎有一条硬纪律：**引擎代码不许改**（为了保证历史结果可复现）。所以配置里只能用引擎已有的零件。下面五个是我们想做但引擎里没有的：

| 想做的 | 我们现在的替代 |
|---|---|
| **1. Clenow 动量分数**（90 天对数回归年化斜率 × R²，原书写明按此排序） | 用「相对强度对标普为正」当进场事件 |
| **2. 放量确认**（当日成交量 ≥ 50 日均量 × 1.5） | **没有替代，这一格空着** |
| **3. 「分数掉出前 20% 就离场」** | 没有，改用「跌破 100 日均线」 |
| **4. 按波动率倒数分配仓位** | 用固定单笔风险 1% |
| **5. 定期调仓**（Clenow 原书每周按分数重排） | 没有，只能事件触发进场 |

**问题 3：**
- （a）★★★ **最要紧的一条**：用「相对强度排名」代替「斜率 × R²」，两者选出来的股票差别有多大？**Clenow 用 R² 的目的是剔掉跳空暴涨的股票**——相对强度排名剔不掉。有没有人实证比较过这两种动量排序？请给出处。
- （b）如果没有实证，那么在**不能改引擎**的前提下，还有什么零件组合能近似「又涨得多、又涨得稳」？（我们有：相对强度、涨幅分位、ATR、布林带宽、肯特纳通道、各种均线、唐奇安通道、成交额、ADX）
- （c）**缺「放量确认」的后果有多大？** 我们的判断是：成绩会偏低（因为会多成交一批假突破）。你同不同意这个方向？业内有没有测过「突破策略加不加放量过滤」的差别？
- （d）**第 5 条（定期调仓 vs 事件触发）** 这个差别在动量策略上是大还是小？Clenow 那套的表现，有多少来自「定期重排」这个机制本身？

## ★ 四、顺手四件小的（★ 一次问完）

**问题 4：**
- （a）**窗口拼接**：我们的个股数据能回到 2009 年以前（1,093 只），但我们的**交易日历是用标普 500 ETF（SPY）的交易日生成的**，而我们手上的 SPY 只有 2014 年起。除了补 SPY 历史，还有别的生成交易日历的标准做法吗？
- （b）**摩擦分层**：我们按流动性分三档收成本（高流动 5bp / 中 15bp / 低 30bp）。这个分层和数值，和机构实践差多少？有没有更标准的做法（比如按成交额占比估冲击成本）？
- （c）**无风险利率口径**：我们有两条序列——3 个月期美债的**贴现口径**（FRED: DTB3）和**债券等价口径**（FRED: DGS3MO）。做股票策略回测的夏普比率和超额收益，业内用哪一条？我们倾向用 DGS3MO，因为贴现口径按 360 天和面值算、会系统性低于真实持有期收益率。这个理解对吗？
- （d）**相邻三点怎么判**：原著没给参数值时，我们的做法是跑相邻三个参数点（比如 20/40/55），并报「三点是否同向」。业内有没有更标准的参数稳健性检验做法？我们这个做法有什么盲点？
