# 测试单 · 「分界线破位后贴线整理」进场法 + 「到第二目标区后剩下仓位的去留」（2026-11-22，Lin 09:21 同意先测）

**一句话：Lin 11-20 夜和 Gemini 复盘时自己悟出一种进场法（《244》第一节第 1、5 条）：关键分界线被放量打穿后，价格贴着线外侧磨 3~6 根、不收回线内，就在这段尾巴进，止损放在试探分界线的针尖外。请用 1 小时数据测它，和卡里现在的「等回踩到等待区再进」比。测完我再决定写不写进卡。**

## 背景（大白话）
- 卡里现在的进场：价格回踩到等待区（0.382 / 0.5 / 0.618），出长下影或吞没才进。强行情里常常不给深回踩，就错过了。
- Lin 的说法：真破位之后，价格会「贴着线」慢慢磨，不回到原来的区间；假破位 1~2 根就被拉回去了。所以贴着线磨 3~6 根，就说明对手盘没力气了，可以进，而且止损很窄。
- 两个例子：TQQQ 1 小时（向上突破后贴线）、BTC 日线（向下跌破后贴线）。

## 规则（数字是默认值，可以扫一扫敏感度）
**分界线**：日线或 4 小时的平台上沿 / 下沿（卡里「平台」的定义），或 1 小时的 20 均线（布林中轨）。先只用平台，均线版本可选。
**进场（做空为例，做多反过来）**：
1. 一根放量（量 > 20 根均量 1.5 倍）的实体 K 线收盘跌破分界线至少 0.25×ATR。
2. 之后 3~6 根 1 小时线，每根收盘都在线下方，实体 < 0.5×ATR，没有一根收回线内。
3. 第 3 根起，满足 2 的那根收盘进场（只进一次）。
4. 硬止损：这几根里最高的那根影线高点再往上 0.5×ATR。
5. 有一根收盘回到线内 → 作废，不进。

**出场**：和卡里一样（第一目标 = 下一个平台 / 摆动低点，到了平 50%，止损推成本；第二目标 = 再下一个；最长 72 根）。

**第二目标区的去留（同一个「贴线」逻辑，第二组对照）**：到第二目标区时
- 出现长下影收回、之后 3 根不再创新低 → 剩下的全平；
- 实体收盘穿过目标区、之后贴线外侧走 → 剩下的拿着，跟踪止损放在贴线 K 线反向试探的针尖外 0.5×ATR；
- 对照：到第二目标全平（卡现在的做法）。
