# ★★★ 技术组 · 两件（★ 第一件最急）

## ★★★ 一 · 接 V1 那套数据工具（★ V2 第一版唯一的硬前提）

```
★★★ **要干啥:** 把 V1 产品里已经在用的那套数据工具,接到 V2 来。
★★ **先接这三个就能解锁第一屏:**
   ① `collect_fundamental_snapshot`   ← 单票的标准财务 + 派生指标
   ② `get_valuation_metrics`          ← 估值
   ③ `get_market_data`                ← 行情(★ 顺带解决下面第二件)
★ **其余的按需要再接**(一致预期 · 宏观序列 · SEC 原文检索 ·
  分部披露 · 事件日历 · 电话会 —— ★★ 正式研报那条路要用到)。
```

| | |
|---|---|
| **背景（大白话）** | ★ V2 的产品要在一只票出现时给用户**四项快照**：趋势状态 · 离观察线多远 · 最近一季增速 · 估值在它自己 5 年历史里的分位。★★ 前两项我们有；★★★ **后两项现在一项都算不出来** —— 因为 V2 用的是回测库，而那个库里**没有营收、没有净利润、没有 EPS**。<br>★★ 但 **V1 产品里有** —— ★ V1 的 `equity-research` 卡里原话：「**快照已提供标准财务、派生指标和一致性结果，直接复用。**」 |
| ★★★ **不做的后果** | ★★★ **用户问的第一只票，基本面那两行就是空的** —— ★ 而那是他第一屏就看得见的。★★ 我们只能写「这只票我们还没有财务数据」 |
| **验收** | ★ 随机抽 **10 只票**（★★ 含 NVDA / AAPL / MSFT），四项快照**每一项都有数**；★★★ 并抽 3 只和公开财报**核对一遍数**。 |
| ★★ **一条口径要守住** | ★★★ **这套数据只能用在产品展示，不能喂回测** —— ★ V1 自己写明「估值和一致预期**只有当前值，没有历史时点值**」。★★ 拿只有当前值的数去跑历史 = **偷看未来**。详见《共用边界》6.15 |
