## 三条跨文档的总规矩

```
★ 一 · 缺栏不许出厂;栏里写「说不清」可以出厂。          (《01》)
★ 二 · 能挡上线的只有两道门:保真度 + 笔数 ≥30。
       t 值不进门,进说明书。                            (《02》)
★ 三 · Gemini 的逻辑和做法大量采纳;
       它的出处、数字、法规引用一律当成未经核实。        (《03》《04》)
```

## 版本规则

- 每份文档文件名带版本号，文末有「版本记录」表。
- 改内容 → 版本号 +1，并在版本记录里写一行**改了什么**。
- 旧版不删，保留在 git 历史里。
