## 二、口径（★ 写死，跑完不许改）

| 项 | 怎么定 |
|---|---|
| 赛道 | **整张面板**：每个交易日，当天 `close` 有值的所有票 |
| ★★★ 退市 | **照算**（Brown 等 1992）—— ★ 退市前的收益计入，退市后权重自然再分配；**不事后剔掉** |
| 口径 | **全收益（分红再投）**，和策略侧同口径；分红走修好的 `probe/并池_1107/分红覆盖层_1107.py` |
| ★★★ 分红自证 | 数量型三个数必须**都非 0**（《130》3.2）：折算事件数 / 被折算票数 / 被折算格子数 |
| 滞后 | 权重用 t−1 日已知的信息；收益从 t−1 量到 t（★ 不重叠一天，规矩㉙） |
| 窗口 | A 2004-01-02~2014-12-31 · B 2015-01-01~2025-12-31（★ 和 84 条臂同窗口） |
| ★★★ 面板 | **修接缝版**，跑前先过 `probe/审计复核_1108/面板指纹_1108.py`（规矩 70）；退出码非 0 就停 |
| 成员下限 | 一天不足 **20 只** → 这一天不算（★ 不填 0，《108》#73 第二处错）；够格天数 < 60% → 整段不出数 |

## 三、判据（★ 跑前写死）

```

   X = 策略年化 − 赛道年化      （「在自己赛道里我们赢没赢」）
   Y = 赛道年化 − 标普全收益年化（「这个赛道整体落后标普多少」）
   Z = 策略年化 − 标普全收益年化（「整体输多少」）★ 已有，来自《130》第七节
```
