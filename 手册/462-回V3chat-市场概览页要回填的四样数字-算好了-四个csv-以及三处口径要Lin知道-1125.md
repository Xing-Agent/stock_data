## 四样各一句话

### 1. 宽度的历史分位（`1_宽度的历史分位_每日.csv`，每天一行）

最新一天（2026-11-04）：站上 50 日线的占 56.8%，在 2004 年以来排第 46 分位，比一周前高 11.7 个点；创一年新高的占 7.9%，排第 79 分位。大盘闸是开的。表里给了两种分位：只和当天以前比（页面该用这个，不偷看以后）和全历史比。

### 2. 矛盾有多常见（`2_矛盾有多常见.csv`）

- **闸开着但宽度不到 50%**：占闸开着的日子的 26%（2005–2014 是 22%，2015–2025 是 28%）。也就是每四天里有一天。这不是罕见的警报，是常态。
- **闸关着但宽度在 50% 以上**：占闸关着的日子的 39%。
- 背景：2015–2025 整体是大涨，而且越往后越靠少数大票拉指数，所以「指数好、多数股票不好」的日子比前一个十年多。

### 4. 每种打法在每档状态下的成绩（`4_每种打法在每档状态下的成绩.csv`）

**先说对不上的**：任务单要四种打法（趋势跟随、突破买入、均值回归、防御 / 低波）。
- 「四种行情配法」那次实际只定义了两种：趋势跟随（唐奇安通道）和均值回归（RSI2 回踩买）。这两种算了。
- **「突破买入」没有唯一的定义**。手册里突破类有好几条，我把三条各算了一份，名字照实写（达瓦斯箱体、VCP 波动收缩、杯柄），请 Lin 定用哪条代表，或者都不用。
- **「防御 / 低波」没有定义，没算**。照任务单的要求，没自己现编。

**算法**：用手册这几条策略已有的成交流水，按每笔进场那天的状态分格。每笔的赚亏用 R（这笔设定最多亏的钱的倍数）算。

**结果一句话：没有哪种打法在两个十年里都是「某一档明显好」。**

| 打法 | 状态 | 2005–2014 每笔 | 2015–2021 每笔 |
|---|---|---|---|
| 趋势跟随 | 健康多头 | +0.15R（221 笔） | +0.13R（183 笔） |
| | 分化多头 | **+0.49R**（112 笔） | **−0.10R**（130 笔） |
| | 过渡 | +0.27R | −0.15R |
| 均值回归 | 健康多头 | 0.00R（841 笔） | +0.09R（391 笔） |
| | 分化多头 | −0.12R | −0.14R |
| | 全面空头 | +0.01R（227 笔） | +0.35R（75 笔） |
| 达瓦斯箱体 | 健康多头 | +0.12R（124 笔） | +0.48R（94 笔） |
| | 分化多头 | +0.14R | +0.03R |

- 趋势跟随在「分化多头」里，前十年最好、后七年是亏的，方向相反。
- 两段方向一致的只有两条弱结论：趋势跟随和达瓦斯箱体在「健康多头」里都是正的（幅度不大）；均值回归在「分化多头」里两段都是负的。
- 这些策略自己带着大盘闸，所以「分化空头」「全面空头」两档里单子很少，多数格子不到 30 笔，csv 里标了「样本太少」。
- 这和跑批 11-24 的结论一致：四种行情各配一套打法，两个十年方向相反，没过。
- 「同期满仓标普最大回撤」那一列是只把这一档的日子拼起来算的，全面空头那格会很深（−53% 到 −80%），是拼接的结果，不是真实一段行情的回撤，页面上用的话要写清楚。

**所以页面上这一块怎么放，建议 Lin 定**：可以放「历史上每档里各打法的成绩」当参考，并写明两段时间方向不一致；不能写成「现在是某档，建议用某打法」。
