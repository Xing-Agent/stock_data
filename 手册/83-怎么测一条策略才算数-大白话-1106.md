# ★★★ 一 · 先说为什么要有这五步

## ★★ 一个今天真实发生的例子（★ 这比任何解释都清楚）

```
★ 我们本来有一把尺子,叫「赢随机」。想法很朴素:
   ★★ 「如果这条策略有用,它应该比**随机乱买**强。」
   → ★ 做法:在同样的行情里随机挑一样多的票、买一样多次,两边比。

★★★ 听起来没毛病。★★ 但它有一个地方错了:
   ★ **随机那一组,用的是策略自己的卖出规则。**
   ★★ 而我们的卖出规则是「亏到一定程度就砍,赚了就让它跑」——
   ★★★ 这套卖法**本身就赚钱**,不管你怎么买进来的。

★ 证据:★★ **随机乱买那一组,自己平均每笔赚 0.24 个风险单位。**
   → ★★★ **乱买不该稳定赚钱。** ★ 这就说明:赚的不是「买」,是「卖」。

→ ★★★ 所以那把尺子量的是**卖**,不是**买**。
  ★★ 我们拿它判了 21 条策略、写了好几份报告,★ 全都要改口。
```

### ★ 怎么做

```

```

```

   第 1 段最猛、第 10 段最弱 —— ★ 每一段都买一批，各自算后面赚了多少。

★★★ 两种结果，意思**完全不同**：

┌─ ★ **情况 A（真信号）**
│   第1段 **+3.2%**  ← 最猛
│   第2段 +2.6%
│   第3段 +2.1%
│      ⋮
│   第9段 −0.4%
│   第10段 **−1.1%** ← 最弱
│   → ★★★ **一段比一段少，排成了阶梯** →
│     ★★ 说明「涨得猛」这件事真的有用，★ 而且**越猛越有用**
│
└─ ★ **情况 B（挖出来的）**

    第2段 −0.2%
    第3段 +0.4%
    第4段 −0.8%      ← ★★ 往下全是乱的
    → ★★★ **只有最头上那一小撮赚钱，往下没规律** →

```

```
★★ 吃药的类比（★ 最直观）：

  · 只有「吃十片」那一组有效，一片两片三片都没反应 →
    ★★★ 那大概**不是药**，是那一组里**恰好有人自己好了**
```

## ★★★ 第三步 · 每天合成一个组合再算（★★ 五步里最关键的一步）

### ★ 它在问什么

```
★★ 「**这个结果,有多大可能只是运气？**」
```

### ★★★ 为什么这一步最关键（★ 用一个具体数字说）

```
★ 我们原来的算法是:**把每一笔当成一个独立的观测**。
★★★ 这是错的。为什么:

  ★ 假设某一天大盘暴涨 3%,★★ 而我们那天开了 10 笔仓。
  ★★★ 这 10 笔**会一起赚** —— 它们不是 10 个独立证据,
    ★ 本质上**只是「那一天」这一个证据**。

★★★ 后果:★★ 把 10 笔当 10 个独立证据,
   ★ 等于**凭空把证据量放大了 10 倍** → ★★★ 成绩会被**虚报好几倍**。
```

### ★ 怎么做

```
★ 把每天所有持仓合成**一个组合**,算出**这个组合每天赚亏百分之几**;
★★ 然后对这串**日收益**做检验,★★★ 并且做一个叫「自相关调整」的修正
   (★ 因为今天赚钱和明天赚钱之间往往有关联,不是完全独立的)。
```

### ★★ 我们现在的位置

```
🟡 **做了一半。**
★ 已经做的:★★ 按**进场那一天**把笔归堆 —— ★★★ 同一天进场的几笔先取平均,
  再对「天」做检验。★ 这比「每笔独立」已经好很多。
❌ 还没做的:★★ 「每天合成一个组合 + 自相关调整」这个完整版。
```

### ★ 这一步的出处档

```

  (自相关调整);★★ 另一条路是「按时间块重抽样」(**Politis & Romano 1994**)。
★★★ ⚠ 这三条我们**还没回原文核过**,目前记作「⑤档 外部模型说的，待核」。
```

# ★★★ 三 · 给用户看的指标，是**另外一套**（★ 别和上面五步混在一起）

```
★★★ 上面那五步,是**我们自己**判「这条策略到底有没有用」。
★★ 给用户看的,是另一回事 —— ★ 用户不关心显著性,他关心「我会赚会亏、会难受到什么程度」。

★★★ 行业给客户看的口径(★ Lin 1106 17:20 已经拍板采用):
   ★★ **一律按「这一笔让我的账户涨跌了百分之几」来算** ——
     ★ 不用 R(那是内部研发的语言),★★★ 也不用美元(美元会被时间顺序骗)。

★★ 为什么美元会骗人:
   ★ 同样是「冒账户 1% 的风险」,★★ 账户大的时候亏一笔,**美元数字就大**。
   ★★★ 所以我们真遇到过一条策略「按风险单位微赚、按美元亏 13.6 万」——
     ★ 两个数打架。★★ 换成百分比口径就不打架了。

★★★ 最核心的一个数叫 **利润因子**:
   ★ 赚的那些笔加起来 ÷ 亏的那些笔加起来。
```
