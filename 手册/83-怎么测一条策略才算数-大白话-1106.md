# ★★★ 一 · 先说为什么要有这五步

## ★★ 一个今天真实发生的例子（★ 这比任何解释都清楚）

```
★ 我们本来有一把尺子,叫「赢随机」。想法很朴素:
   ★★ 「如果这条策略有用,它应该比**随机乱买**强。」
   → ★ 做法:在同样的行情里随机挑一样多的票、买一样多次,两边比。

★★★ 听起来没毛病。★★ 但它有一个地方错了:
   ★ **随机那一组,用的是策略自己的卖出规则。**
   ★★ 而我们的卖出规则是「亏到一定程度就砍,赚了就让它跑」——
   ★★★ 这套卖法**本身就赚钱**,不管你怎么买进来的。

★ 证据:★★ **随机乱买那一组,自己平均每笔赚 0.24 个风险单位。**
   → ★★★ **乱买不该稳定赚钱。** ★ 这就说明:赚的不是「买」,是「卖」。

→ ★★★ 所以那把尺子量的是**卖**,不是**买**。
  ★★ 我们拿它判了 21 条策略、写了好几份报告,★ 全都要改口。
```

## ★★★ 这件事的教训（★ 一句话）

```
★★★ **一把尺子,必须先证明它量的是你想量的那件东西。**
★★ 五步里的每一步,都是在堵一个「尺子量错东西」的口子。
```

# ★★★ 二 · 五步，逐个说清

## ★★★ 第一步 · 固定拿几天，再和大盘比

### ★ 它在问什么

```
★★ 「**买进来这一下，到底挑得准不准？**」
```

### ★ 怎么做

```
★ 不管策略自己想什么时候卖 —— ★★ **一律按固定天数卖掉**(比如 5 天、10 天、20 天),
★★★ 然后减掉**同一段时间大盘涨了多少**。
→ ★ 剩下的那个差额,就是「这次买进来**比直接买大盘**好多少」。
```

### ★★★ 为什么不能跳

```
★★★ 因为只要让策略自己决定什么时候卖,★★ 你量到的就是**买和卖混在一起的结果** ——
  ★ 分不清功劳是谁的。
★★ 固定天数卖掉,等于**把卖的部分按住不动**,★★★ 剩下变化的只有「买」。
```

### ★★ 我们现在的位置

```
✅ **做了。** ★ 我们叫它「尺子 C」。
★★★ 结果(21 条策略 × 3 个天数窗口):
   · ★★★ **没有一条策略的「买」是明确有用的**
   · ★★ **7 个结果是明确有害的** —— ★ 也就是:
     **这些买点,比当天直接买大盘还差。**
   · ★ 最差的一条:20 天之后比大盘少赚 **1.148%**
★★ 唯一一个正面信号:有一条突破策略,★ 买进后**第 5 天**比大盘多赚 **0.6%**,
   ★★★ 但到第 20 天就变负了 → ★ 读法:**突破的优势只有一周左右,然后反转。**
```

### ★ 这一步的出处档

```
★★ ②档 行业通行 —— ★ Gemini 明说:「机构判一条进场信号有没有用,
  主流做法是:**固定持有期后跟基准比**、分档组合比较、多因子回归。
  ★★★ **不用随机进场对照。**」
```

## ★★★ 第二步 · 把信号从强到弱切十档

### ★ 它在问什么

```
★★ 「**信号越强，赚得越多吗？**」
```

### ★ 怎么做

```
★ 把信号强度排个序(比如「涨得最猛的 10%」「次猛的 10%」…一直到最弱的),
★★ 每一档各做成一个组合,★★★ 看收益是不是**一档一档往下递减**。
```

### ★★★ 为什么不能跳（★ 这一步最容易被忽略，但它抓的是最常见的假货）

```
★★★ 真信号应当**有剂量关系** —— ★ 就像药一样:吃得多该更有效。

★★ 假信号长什么样:★★★ **只有最强那一档赚钱,往下就乱七八糟。**
  ★ 那通常意味着:你不是找到了一条规律,
  ★★★ 而是**在历史里挖出了几只特别能涨的票**。

→ ★★ 一句话:★★★ **「有信号 vs 没信号」能骗人,「十档单调递减」很难骗人。**
```

### ★★ 我们现在的位置

```
❌ **没做。** ★ 这是我下一步要补的第一件。
```

### ★ 这一步的出处档

```
★★ ②档 行业通行 —— ★ Gemini 列的三种主流做法之一(「分档组合比较」)。
```

## ★★★ 第三步 · 每天合成一个组合再算（★★ 五步里最关键的一步）

### ★ 它在问什么

```
★★ 「**这个结果,有多大可能只是运气？**」
```

### ★★★ 为什么这一步最关键（★ 用一个具体数字说）

```
★ 我们原来的算法是:**把每一笔当成一个独立的观测**。
★★★ 这是错的。为什么:

  ★ 假设某一天大盘暴涨 3%,★★ 而我们那天开了 10 笔仓。
  ★★★ 这 10 笔**会一起赚** —— 它们不是 10 个独立证据,
    ★ 本质上**只是「那一天」这一个证据**。

★★★ 后果:★★ 把 10 笔当 10 个独立证据,
   ★ 等于**凭空把证据量放大了 10 倍** → ★★★ 成绩会被**虚报好几倍**。
```

### ★ 怎么做

```
★ 把每天所有持仓合成**一个组合**,算出**这个组合每天赚亏百分之几**;
★★ 然后对这串**日收益**做检验,★★★ 并且做一个叫「自相关调整」的修正
   (★ 因为今天赚钱和明天赚钱之间往往有关联,不是完全独立的)。
```

### ★★ 我们现在的位置

```
🟡 **做了一半。**
★ 已经做的:★★ 按**进场那一天**把笔归堆 —— ★★★ 同一天进场的几笔先取平均,
  再对「天」做检验。★ 这比「每笔独立」已经好很多。
❌ 还没做的:★★ 「每天合成一个组合 + 自相关调整」这个完整版。
```

### ★ 这一步的出处档

```
★★ ①档 学术 —— ★ Gemini 给的出处:**Fama 1998**、**Newey-West**
  (自相关调整);★★ 另一条路是「按时间块重抽样」(**Politis & Romano 1994**)。
★★★ ⚠ 这三条我们**还没回原文核过**,目前记作「⑤档 外部模型说的，待核」。
```

## ★★★ 第四步 · 参数铺成一张图，找「平地」而不是「山尖」

### ★ 它在问什么

```
★★ 「**这个参数是真的好，还是刚好蒙对了那一个数？**」
```

### ★ 怎么做

```
★ 把参数铺成一张网格(比如回看天数 10/20/30/40/50 × 止损 1/1.5/2/2.5/3 倍),
★★ 画成一张热力图(颜色深浅表示成绩好坏),
★★★ 然后**只用「周围一大片都还不错」的那个参数** ——
  ★ 不用那种「它自己特别好、旁边一步就塌」的参数。
```

### ★★★ 为什么不能跳

```
★★★ 「山尖」上的参数,几乎一定是**挖出来的**。
★ 道理很简单:★★ 真规律不会那么脆 ——
  ★★★ 如果「回看 20 天」赚钱、「19 天」和「21 天」都亏,
    ★ 那说明你找到的不是规律,是**这段历史的巧合**。
```

### ★★ 我们现在的位置

```
🟡 **只有一个简化版。** ★ 我们现在的做法叫「相邻三点」——
  ★★ 原著没给参数时,跑相邻三个值(比如 20/40/55),看**三个方向是否一致**。
★★★ Gemini 的评价:**太粗。**
→ ★ 我的处置:**相邻三点保留当底线**(★★ 它便宜、能挡住最明显的问题),
  ★★★ 重点策略**另加一张热力图**。
```

### ★ 这一步的出处档

```
★★ ②档 行业通行 —— ★ 热力图找平台:**Pardo 2008**;
★★★ 另加两个专门的过拟合指标:**PBO(回测过拟合概率,Bailey 等)**、
  **DSR(降级夏普)**。★ 同样**待核**。
```

## ★★★ 第五步 · 一堆结果里，挑掉蒙对的

### ★ 它在问什么

```
★★ 「**我跑了一百个检验,其中有几个是纯运气？**」
```

### ★★★ 为什么不能跳（★ 这一步我们今天已经吃到教训）

```
★ 今天我跑了 **21 条策略 × 3 个天数窗口 = 63 个检验**。
★★★ 纯靠运气,这 63 个里**大约会有 3 个看起来「显著」**。
★★ 实际结果:**正面显著 2 个 · 负面显著 7 个**。

→ ★★★ 所以两边的分量**完全不一样**:
   · ★★ 「买点有害」那 7 个 → **多于运气该给的 3 个** → ★ 这个结论**站得住**
   · ★★★ 「某条策略好」那 2 个 → **少于运气该给的 3 个** → ★ 这个**不算数**

★★ 换句话说:★★★ 我手上唯一一条「好消息」,很可能就是蒙的。
  ★ 要让它算数,必须**单独拿出来、事先说好只测它这一个**,再测一次。
```

### ★ 怎么做

```
★★ 正规做法有名字:**Reality Check(White 2000)** 和 **SPA 检验(Hansen 2005)**。
★ 它们干的事就是:★★ 把「跑了多少个检验」这件事算进去,
  ★★★ 然后告诉你「最好那条策略的成绩,扣掉挑选运气之后还剩多少」。
```

### ★★ 我们现在的位置

```
❌ **正规做法没做。** ★ 今天只是我**手算了一遍粗的**
  (「63 个检验、运气约给 3 个」那段)。
```

# ★★★ 三 · 给用户看的指标，是**另外一套**（★ 别和上面五步混在一起）

```
★★★ 上面那五步,是**我们自己**判「这条策略到底有没有用」。
★★ 给用户看的,是另一回事 —— ★ 用户不关心显著性,他关心「我会赚会亏、会难受到什么程度」。

★★★ 行业给客户看的口径(★ Lin 1106 17:20 已经拍板采用):
   ★★ **一律按「这一笔让我的账户涨跌了百分之几」来算** ——
     ★ 不用 R(那是内部研发的语言),★★★ 也不用美元(美元会被时间顺序骗)。

★★ 为什么美元会骗人:
   ★ 同样是「冒账户 1% 的风险」,★★ 账户大的时候亏一笔,**美元数字就大**。
   ★★★ 所以我们真遇到过一条策略「按风险单位微赚、按美元亏 13.6 万」——
     ★ 两个数打架。★★ 换成百分比口径就不打架了。

★★★ 最核心的一个数叫 **利润因子**:
   ★ 赚的那些笔加起来 ÷ 亏的那些笔加起来。
   ★★★ **小于 1 就是这条策略在亏钱。** ★★ 这一个数,比胜率和赢亏比都更难糊弄。
```

### ★★★ 用这个口径量出来的真实结果（★ 不好看，但这是真的）

| | 笔数 | ★★★ 利润因子 | 胜率 | 赢亏比 |
|---|---:|---:|---:|---:|
| ★★★ **买了不动（买入持有）** | 186 | ★★★ **5.816** | **67.2%** | **2.838** |
| **我们 65 条策略臂** | 186 ~ 10,405 | ★★ **中位 0.993**<br>最高 1.821 · 最低 0.545 | 29% ~ 62% | 0.63 ~ 3.86 |

```
★★★ **65 条里有 33 条小于 1(也就是在亏)。没有一条跑赢买了不动。**

★★ ⚠ 但有四件事让这个对比不完全公平,★ 我必须一起说:
  ① ★★ 买入持有只有 186 笔、每笔拿很久 —— ★★★ 利润因子**对持有期天生敏感**
    (笔少、每笔赢得大 → 数就高)
  ② ★★★ **我们的回测窗口里没有一次完整熊市**(2014–2025 一路涨)——
    ★ 买了不动在长牛里**本来就该赢**
  ③ ★★ 退市的股票我们按「最后一个收盘价」结算 ——
    ★★★ 这对**买入持有的高估更严重**(它一直拿到退市那天)
  ④ ★★★ **利润因子不看回撤** —— ★ 买了不动在 2020 年那次跌掉约 **34%**,
    ★★ 这个数里**完全看不见**。
    ★★★ 而我们策略的价值,本来就主要在「**少亏**」那一头,不在「多赚」。

→ ★★★ 所以准确说法只能是:
  **在这段长牛里、按这个口径,我们没有一条策略跑赢买了不动。**
  ★★ 而「换到有熊市的窗口会怎样」—— ★★★ **我们现在测不出来。**
  ★ 这件已经在办了:数据组说 ETF 能补到 2004 年起(含 2008 年那次熊市)。
```
