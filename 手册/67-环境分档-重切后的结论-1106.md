# ★★ 五 · 聚簇标准误 —— ★★★ 原来那套显著性判断整体作废

★ 「聚簇标准误是普通标准误的几倍」= 原来那套算法**把显著性虚增了多少倍**。

| 方法 | 旧切法 · 线上 | 旧切法 · 线下 | 新切法 |
|---|---|---|---|
| 技-12 康纳斯 | **×3.27** ← ★★★ 全表最大 | ×2.07 | ×3.19 |
| 技-5 VCP | ×1.65 | **×2.71** | ×1.89 |
| 技-10 海龟汤 | ×1.97 | ×2.37 | ×1.96 |
| 技-2 法伯 | ×2.34 | ×0.85 | ×2.13 |
| 技-6 达瓦斯 | ×2.12 | ×1.51 | ×1.82 |
| 技-13 TD 序列 | ×2.09 | ×0.72 | ×1.91 |
| 技-11 威科夫 | ×1.55 | ×2.09 | ×1.64 |
| 技-1 海龟 | ×1.36 | ×1.42 | ×1.39 |
| 技-3 温斯坦 | ×1.36 | ×0.90 | ×1.24 |
| 技-4 CANSLIM | ×1.24 | ×0.69 | ×1.28 |
| 技-14 布林带 | ×1.13 | ×0.91 | ×1.20 |

```
★★★ **结论:原来那套显著性判断(普通标准误)整体作废。**
★ 理由:上表 33 个格子里有 **28 个 > 1**,最多虚增到 **3.27 倍**(技-12 旧切法线上)。
★★ 换成聚簇标准误之后,原来被判成「赚/亏」的不少格子变成「和 0 分不开」——
   ★★★ 典型就是**技-5 的线下 +0.0417**:
   普通标准误 0.0565 → 聚簇标准误 **0.1527**,★★ 那个「正数」直接淹在噪声里。
```

> ★★ ⚠ 一条要标出来的（★ 否则写成「一律是几倍」就不准）：
> **有 5 个格子的倍数小于 1**（技-13 线下 ×0.72、技-4 ×0.69、技-2 ×0.85、技-3 ×0.90、技-14 ×0.91）。
> ★ 这不是算错 —— 聚簇标准误是从**簇间方差**算的，当簇内的交易彼此抵消、簇间均值反而很接近时，它可以比普通标准误小。
> ★★★ 所以准确的说法是：**「普通标准误整体不可信、方向上系统性低估（大多数格子虚增，最多 3.27 倍）」**，不是「一律大几倍」。
