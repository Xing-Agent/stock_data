## ★★★ Bug ② 加权均值配了不加权的标准误 → 那一栏的赚/亏标签不能当真

```
★ 大白话:`格(r, cl, w)` 里,**均值是加了权的**(`np.average(r, weights=w)`),
   ★★ 但 `聚簇SE` 和普通 SE **都在没加权的 r 上算**。
★★★ 所以「②新切法_按持有天数分摊」那一栏的「赚 / 亏 / 和0分不开」,
   是**「加权均值」对「不加权标准误」** —— 两个口径对不上,那一栏的标签不能当真。

★ 一眼能看出来的旁证(修之前):②新切法「线上」和「线下」两格的
   **笔数、簇数、聚簇 SE 完全一样**(技-14 两边都是 11,037 / 55 / 0.0373)——
   ★★ 因为它们本来就是同一堆交易,只是权重不同,而标准误根本没用权重。

★ 怎么修的(两条都做了):
   ① **标准误也按权重算**:每个簇内先算**该簇的加权均值**(权重 w),
      簇之间再算均值的标准误,**簇权重 = 该簇的 w 之和**;
      ★★ 权重和为 0 的簇(该簇完全不在这一档)**不算一个簇**。
      → 这样均值和标准误**同口径**。
   ② **加一道有效权重门槛**:某一格的**权重之和 < 5**(相当于不足 5 个「全程在该档」的交易)
      **不给赚/亏标签**,写「有效权重不足,只给数」。

★★★ 修完之后旁证消失了:技-14 ②新切法现在是
   线上 9,041 笔 / **51 簇** / 聚簇 SE **0.0531**,线下 9,041 笔 / **54 簇** / **0.0337** —— 两边不一样了。
★★ 实测:**没有一个格子命中「权重和 < 5」这道门槛**(最小的是技-4 线下 **38.42**,
   其次「其他」线下 37.92)—— ★ 门槛加上了,这一轮没触发,如实记下。
```
