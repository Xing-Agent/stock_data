# ★★★ ④ 「连着亏」这个数，界面上按天算还是按笔算？

## ★ 大白话：为什么会有两种算法

```
★★ 「这套做法历史上最长连着亏多少次」—— ★ 这句话有两种数法:

★★ **按笔数**:一笔交易一笔交易地数
   → 技-14 那条是 **连亏 61 笔**

★★★ **按天数**:**同一天平仓的算一次**
   → 同一条变成 **连亏 23 天**

★ 为什么差这么多:★★ 那 61 笔**挤在 23 天里** ——
   ★★★ 一天平好几笔是常事,所以按笔数会把同一天的痛苦**重复数好几遍**。
```

## ★★ 我倾向按天的理由

```
★★★ **因为人是按天看账户的。**
★ 一个人不会想「我连着亏了 61 笔」,★★ 他想的是
   「**我连着看了二十来天,账户一直在跌**」。
★★★ 所以按天那个数,才是他真正感受到的东西。
```

## ★ 要你定的

| | |
|---|---|
| ★★★ **我的倾向** | **界面上用「按天」**，★★ 但两个数都存着，说明书里都写 |
| ★ 为什么都存 | ★★ 问「连着亏几次你会放弃」→ 用按笔；★ 问「连着几天看到账户在跌你会放弃」→ 用按天。★★★ **问法不同，该用的数不同** |
| ★ 实测范围 | 按笔 **4 ~ 61 笔**（中位 14）· **按天 4 ~ 21 天**（中位 12） |

> ⬜ **同意：界面用按天，两个数都存**　⬜ 用按笔
