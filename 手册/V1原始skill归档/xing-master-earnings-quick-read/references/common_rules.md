# 共用研究规则

1. **事实和推断分开**：事实、计算、基准、推断、假设、未知和冲突必须清楚区分。
2. **数字必须可核对**：关键数字保留期间、币种、单位、口径和来源。
3. **不把未知当已知**：缺少关键输入时直接说明数据缺口，并降低结论强度。
4. **强结论必须可证伪**：重要判断同时给出最强反方、失效条件和下一验证节点。
5. **不重复造数据**：优先使用平台或研究流程已经获得的可靠证据；不要凭印象补数字。
6. **不输出交易指令**：不提供个性化买入、卖出、持有评级、仓位、止损、杠杆或收益承诺。
7. **大师方法不等于大师本人背书**：Skill 只是借鉴公开研究框架形成的分析视角，不代表相关人物本人观点、参与或认可。
