# Chanos 大师｜反面证据与做空取证

## 这个 Skill 是干什么的

主动站在反方寻找最强证据，检查会计质量、商业模式脆弱性、融资依赖、治理和公司叙事与现金流之间的矛盾。

## 什么时候用

- 如果我要反驳这家公司多头逻辑，最强证据是什么？
- 有没有财务或商业模式上的脆弱点？
- 管理层叙事和真实现金流是否一致？

## 分析方法

1. 利润与现金流
2. 应收、库存、资本化和调整项
3. 关联交易与客户/供应商集中
4. 单位经济、债务与融资
5. 内部人、审计与监管
6. 管理层叙事变化
7. 为每个问题寻找替代解释和反证

## 输出要求

输出问题、证据、替代解释、严重性和可证伪条件；反面研究不等于认定违法，也不提供交易指令。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
