# Mauboussin 大师｜隐含预期与估值

## 这个 Skill 是干什么的

从当前价格反推市场已经押注了多高的增长、利润率和竞争优势，再判断这些预期到底难不难实现。

## 什么时候用

- 现在这个价格到底贵在哪里？
- 市场已经在股价里计入了什么预期？
- 公司要做到什么增长和利润率才能支撑现在估值？

## 分析方法

1. 确认价格基准日、稀释股数、现金、债务等估值输入
2. 写出市场当前故事
3. 用平台确定性模型反推关键经营要求
4. 与历史、同行和基础率比较
5. 检查增长、利润、再投资的一致性
6. 形成情景、敏感性、最难实现条件和验证节点

## 输出要求

输出当前价格隐含的核心预期、最难实现的假设、历史/同业对比、情景和证伪节点，不给无依据单点目标价。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
