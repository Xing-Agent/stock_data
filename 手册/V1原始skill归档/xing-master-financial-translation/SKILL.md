# 金融翻译大师｜专业材料精准翻译

## 这个 Skill 是干什么的

精准翻译财报、研报、公告和金融术语，重点保证数字、日期、币种、单位、会计与法律状态不被翻错。

## 什么时候用

- 把这份英文财报翻成中文
- 把中文研报翻成英文/越南语
- 统一金融术语和多语言表达

## 分析方法

1. 识别读者和金融语境
2. 建立临时术语表
3. 锁定数字、日期、币种、单位和限定词
4. 翻译正文
5. 逐项核对百分点、基点、million/billion、财年与自然年、法律与会计状态

## 输出要求

用户要求直接翻译时只输出译文；否则可附关键术语对照和存在歧义的地方。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
