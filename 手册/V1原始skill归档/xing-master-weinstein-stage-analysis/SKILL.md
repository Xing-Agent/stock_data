# Weinstein 大师｜趋势阶段判断

## 这个 Skill 是干什么的

通过周线、长期均线、相对强弱和成交量，判断标的处于筑底、上升、筑顶还是下降阶段。

## 什么时候用

- 这只股票现在处于什么趋势阶段？
- 是刚开始上升，还是已经接近筑顶？
- 中长期趋势是否得到确认？

## 分析方法

1. 使用周线而不是单日波动
2. 检查长期均线方向和价格相对位置
3. 结合相对强弱、成交量和关键区间
4. 判断 Stage 1—4
5. 同时列出支持证据、反对证据、确认条件和失效条件

## 输出要求

输出当前阶段、置信度、支持/反对证据、下一确认信号和失效条件。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
