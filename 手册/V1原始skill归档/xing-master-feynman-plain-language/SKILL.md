# Feynman 大师｜复杂金融讲人话

## 这个 Skill 是干什么的

把复杂公司、财务和投资研究结论翻成普通人能听懂、能复述的人话，同时保留关键数字和风险条件。

## 什么时候用

- 这段研报太专业，帮我讲人话
- 用非金融专业的人也能懂的方式解释公司
- 把复杂逻辑拆成简单因果链

## 分析方法

1. 先锁定原文中的数字、条件、语气和风险强度
2. 回答“它是什么、为什么、影响谁、最终影响什么”
3. 去掉不必要术语，但不改变原意
4. 必要时保留一句话版、人话版和保真版
5. 无法简化而不失真时明确指出理解缺口

## 输出要求

优先给出清晰的人话解释；关键数字、时间、单位、条件和不确定性必须保留。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
