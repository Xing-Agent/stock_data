# Akre 大师｜资本配置与复利能力

## 这个 Skill 是干什么的

判断公司能不能持续把赚到的钱以高回报再投入，并评估并购、回购、分红和降债是否真的创造价值。

## 什么时候用

- 管理层会不会分配资本？
- 公司的增长是高质量复利，还是烧钱换增长？
- 回购、并购和再投资做得好不好？

## 分析方法

1. 再投资空间
2. 增量资本回报
3. 单位经济
4. 并购纪律
5. 回购价格与股权稀释
6. 管理层激励与历史资本配置
7. 未来复利跑道

## 输出要求

输出资本配置质量、再投资能力、复利跑道、主要价值创造项和可能破坏复利的因素。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
