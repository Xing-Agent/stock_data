# Soros 大师｜反身性分析

## 这个 Skill 是干什么的

判断市场认知和价格是否会通过融资、并购、客户信心等渠道反过来改变公司基本面，形成反馈循环。

## 什么时候用

- 股价上涨会不会反过来强化公司基本面？
- 市场叙事是不是正在形成自我强化？
- 这个反馈循环可能在哪里反转？

## 分析方法

1. 先建立不依赖股价的基本面基准
2. 识别认知与价格变化
3. 检查融资、抵押品、并购、人才、客户或政策等反馈通道
4. 构建“认知→价格→行为→基本面→新认知”循环
5. 判断循环处于萌芽、强化、过度、测试或反转阶段

## 输出要求

输出反馈循环、当前阶段、实际传导证据、可能断裂点和验证条件。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
