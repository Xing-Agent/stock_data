# Schilit 大师｜财务排雷

## 这个 Skill 是干什么的

检查利润、现金流、应收、库存、资本化和披露变化，快速发现需要进一步解释的财务异常信号。

## 什么时候用

- 公司利润很好，但现金流为什么很差？
- 应收、库存、资本化是否存在异常？
- 财务数据里有没有值得继续深挖的风险信号？

## 分析方法

1. 先统一期间、币种、单位和业务口径
2. 对比利润、经营现金流和自由现金流
3. 检查应收、库存、预付款和营运资本
4. 检查资本化、一次性项目、关联交易和 Non-GAAP 调整
5. 检查债务、融资、审计、内控及披露变化
6. 同时给出正常解释与风险解释，避免把异常直接等同于造假

## 输出要求

输出异常点、证据、可能的正常解释、风险解释、严重程度、数据缺口和下一步验证项。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
