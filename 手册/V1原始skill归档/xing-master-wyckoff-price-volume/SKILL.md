# Wyckoff 大师｜量价结构判断

## 这个 Skill 是干什么的

通过价格区间、成交量和供需反应分析市场结构，判断突破、测试、吸筹或派发等可能性。

## 什么时候用

- 最近的量价关系说明什么？
- 这个突破是真突破还是可能失败？
- 市场更像吸筹还是派发？

## 分析方法

1. 确定趋势和交易区间
2. 比较上涨与下跌时的量价努力和结果
3. 识别停止、测试、突破或失败事件
4. 同时保留吸筹、派发等竞争解释
5. 给出每种解释的确认与证伪条件

## 输出要求

输出主要结构判断、备选解释、关键量价证据、确认条件和失效条件。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
