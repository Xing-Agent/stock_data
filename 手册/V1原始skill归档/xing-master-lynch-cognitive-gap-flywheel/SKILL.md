# Lynch 大师｜认知差与成长飞轮

## 这个 Skill 是干什么的

寻找业务容易理解、市场可能低估且能持续验证的成长故事，并拆解产品、渠道、客户或规模形成的增长飞轮。

## 什么时候用

- 市场是不是忽视了这家公司的成长点？
- 这个产品为什么可能形成飞轮？
- 成长故事有哪些可以持续验证的数据？

## 分析方法

1. 判断公司类型和成长阶段
2. 用简单语言写出核心成长故事
3. 识别市场共识与潜在认知差
4. 拆解产品、渠道、数据、网络或规模飞轮
5. 检查客户、单位经济和资产负债表
6. 设定可验证的关键节点

## 输出要求

输出核心成长逻辑、潜在认知差、飞轮结构、验证数据和飞轮可能断裂的位置。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
