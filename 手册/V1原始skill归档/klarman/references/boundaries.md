# 安全边际与克制｜边界、拒绝与降级

## 不适用或不能硬用

- 没有当前价格和日期
- 现金、债务和股数不清
- 会计资料不可信且无法校验

## 必须停止、拒绝或降低结论强度

- 没有明显便宜时允许停止
- 业务太难、会计不可信或验证成本过高时停止
- 不能把历史高点跌幅当安全边际

## 禁止事项

- 为满足用户硬找机会
- 单一市盈率判断便宜
- 忽略债务税和稀释
- 用历史最高价证明便宜
- 给精确目标价

## 信息不足

使用 `templates/insufficient-data-template.md`，明确能确认、不能确认、最少需要补充的资料及缺失信息对结论的影响。
