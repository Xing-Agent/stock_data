# 安全边际与克制｜方法与检查项

## 核心问题

现在这个价格已经假设公司要做到什么？哪个假设最靠不住？

## 方法来源说明

本 Skill 借鉴：塞斯·卡拉曼（Seth Klarman）的公开价值与风险控制思想。专家姓名只表示使用其公开思想作为方法来源，不代表本人参与、授权、背书或对具体公司的判断。

## 核心检查清单

- 价格隐含增长、利润率和持续年限
- 下行资产、现金和融资缓冲
- 多个乐观条件是否必须同时成立
- 价值陷阱和周期峰值
- 等待成本和重新研究条件

## 执行说明

1. 统一市场价值和企业价值
2. 从价格倒推核心赌注
3. 做保守正常化
4. 分别检查资产、现金流和融资下行
5. 做轻度与严重压力
6. 找最靠不住的价格假设
7. 给继续、观察或停止
8. 写重新值得研究的价格或事实条件

## 结果解释原则

- 先给事实和计算，再给判断。
- 重要结论必须解释从证据到经营或财务影响的中间机制。
- 不能因为符合一种模式就忽略相反证据。
- 结论必须包含最强反方解释和失效条件。
