# Fisher 大师｜一手信息交叉验证

## 这个 Skill 是干什么的

从客户、供应商、渠道、竞争者、员工和行业专家等多方信息交叉验证公司的产品、组织和长期竞争力。

## 什么时候用

- 公司自己说得很好，外部证据能验证吗？
- 客户和供应商怎么看这家公司？
- 帮我设计一套一手调研问题

## 分析方法

1. 列出需要验证的核心假设
2. 按客户、供应商、渠道、竞争者、员工、专家拆分证据源
3. 记录时间、利益关系和样本偏差
4. 对相互冲突的证据保留冲突
5. 无法实际访谈时只输出调研问题和验证计划，不编造反馈

## 输出要求

输出已验证事实、相互冲突证据、证据可信度、调研缺口和下一轮一手验证计划。

输出时优先使用“**结论 → 关键证据 → 反方观点 → 失效条件 → 下一步验证**”的结构，让用户快速看懂。

## 共用边界

分析前阅读 [共用研究规则](references/common_rules.md)。

- 重要结论必须有证据，不用大师名气替代证据。
- 缺少数据时明确写“数据不足/待验证”，不要补造事实。
- 不输出个性化买卖、仓位、止损、杠杆、收益承诺或无依据目标价。
- “大师 Skill”表示使用该方法论视角，不代表相关人物本人参与或背书。
