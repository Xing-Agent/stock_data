## ★★★ 三秒版

```
★★★ 这一版**不是去证明它好**,是去**找出它哪儿不对**。
★★ 四层人一起找,每层问的是**不同的一个问题**:
   ① 团队装上用  → 「代码能不能给出我们说的那种结果?」
   ② 运营人工    → 「流程顺不顺、话说得对不对?」
   ③ 机器批量    → 「量大了会不会炸、会不会前后矛盾?」
   ④ 拿 Gemini 当第二个意见 → 「同一个问题,两边答得一样吗?」
★★★ 前三层找的是 **bug**;第四层找的是**我们可能根本不知道自己错了的地方**。
★ 判「通过」的标准写在每一节里 —— ★★ **没有标准的,这一轮就不测**。
```

### ★ 一句话分工判据（★★ 以后照这条分，不用再讨论）

```
★★★ 一件事**有验收条件** → 它是**工程的**,团队测。
★★★ 一件事要**一句人写的话** → 它是**策略的**,Lin 判。
```

# ★★ 第一层 · 团队装上 skill 自己用

| | |
|---|---|
| **问的问题** | ★ 「现在的代码，能不能给出我们在说明书里描述的那种结果？」 |
| **谁** | ★ 所有人（运营、技术、产品），★★ 各自装上 skill 真用 |
| **怎么算发现了问题** | ★★ 三种都算：① 它答不出来 ② 它答了但和说明书写的不一样 ③ 它答得对但**话说得让人看不懂** |

★ **反馈怎么写**（★★ 三行就够，不用写报告）：

```
问的是:  <你输入的原话>
期望:    <说明书上写的,或你觉得应该是什么>
实际:    <它给的原话>
```

★★★ **一条硬要求**：★ 反馈里**必须有「它给的原话」** —— ★★ 转述会把问题改掉，我们就查不到根。

# ★★ 第二层 · 运营人工 + 机器

| | |
|---|---|
| **问的问题** | ★ 「从用户第一屏到拿到结果，这条路顺不顺？每句话说得对不对？」 |
| **谁** | ★ 运营 |
| **主要看** | ① 流程有没有断头路 ② 措辞（★★★ 尤其「代价在前」有没有真的在前）③ 空数据的时候它怎么说 |
| ★★★ **怎么算通过** | ★★ **七把尺子**（运营那份单子里的七条），★ 每条都要有一个明确的「过 / 不过」 |

★★★ **这一层最容易漏的一件**：

```
★ 大家会去测「有数据的时候对不对」,★★★ 但**最该测的是没数据的时候**:
   · 这只票我们没有财务数据 → 它说了吗?还是留白?
   · 这一格算不出来 → 它写「算不出来 + 缺什么」了吗?还是给了个近似值?
   · 笔数不够 30 → 它说「笔数不够」了吗?还是照样给了个结论?
★★ 这三种情况**正是我们和别人最不一样的地方** —— ★★★ 如果这儿露了,整套「不冒充确定性」就是空话。
```

# ★★ 第三层 · 机器批量（★ 测试军团）

| | |
|---|---|
| **问的问题** | ★ 「量大了会不会炸？同一个问题问两次，答得一样吗？」 |
| **谁** | ★ 技术 + 我 |
| ★★★ **怎么算通过** | ★ 下面四条，**全部要有数** |

```
★ ① **不炸**:批量跑完,错误率 < 1%,★★ 而且每一个错误都能指回一行代码
★ ② **不自相矛盾**:同一只票、同一天,★★★ 问两次给的**结论方向必须一致**
     (★ 措辞可以不同,★★ 但「该不该买」不许一次说能一次说不能)
★ ③ **不越界**:★★★ 任何一句话里**不许出现我们没算过的数** ——
     ★ 自动扫一遍输出里的数字,★★ 每个都要能指回一份结果文件
★ ④ **空值不装饰**:★★★ 数据缺的时候,输出里**不许出现具体数字** ——
     ★ 这一条用机器扫最合适,人看会漏
```

★★ **③ 和 ④ 是这一层真正的价值** —— ★★★ 这两件人工测不出来（★ 一屏一屏看，谁也看不出哪个数是编的）。

## ★★★ 这一层最要紧的一件：先说清「什么叫不一样」

```
★★ 不先定这个,★★★ 两边措辞一不同就全标成「有问题」—— 看都看不完。
```

★ **所以本轮只对「事实型」问题做对照**（★★ 判断型留到 V3）：

| | ★ 问什么 | ★★ 例子 | ★★★ 不一样算不算 bug |
|---|---|---|---|
| ✅ **事实型** | 原著怎么规定的 · 这个指标怎么算 · 这家公司这个数是多少 | 「海龟 System 1 的入场是多少日通道？」 | ★★★ **算** —— ★ 有唯一答案，不一样就是有一边错了 |
| ❌ **判断型** | 这只票现在该不该买 · 这个环境适合哪条策略 | 「现在该买 NVDA 吗？」 | ★★ **不算** —— ★★★ 两边必然不一样，而且**谁对没有标准答案** |

★ **我的倾向：本轮只做事实型**（★★ 理由：判断型的不一样**不构成 bug，只构成分歧**；★★★ 而这周要找的是 bug）。
★★ ⬜ **Lin 如果要把判断型也放进来，在这里改一行**，我再补一套判据。

## ★★ 怎么做（三步）

```
★ ① 同一个问题,**同时**问我们的技术大师 / 基本面大师,和 Gemini
★ ② 两边答案并排,★★ 只标三种:**一致 / 不一致 / 一边答不出**
```
