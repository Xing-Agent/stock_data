# 526 · Gemini 回复与判断 · 做空还缺的四样怎么写成规则(2026-11-28)

> 这次的四样都要用美股的 4 小时和 1 小时数据去验,我这边只有 BTC 日线,验不了。下面「我核」只核了 Gemini 的算术、引用来源和前后是否矛盾,实测全部交给主 chat。

## 一、三秒版
**两个窗口都说:**
- **背离:** 救不了美股做空,只能当过滤条件用。默认用 MACD 柱。
- **最可能把美股做空扭过来的:** 两边意见不一样。
  - A 说是「下面有没有支撑挡着」:美股跌破后,下面不远处往往就是前低、50 日线或成交密集区,空单刚进场就撞上买盘。
  - B 说是「无量弱反抽」:美股的假跌破很多,跌破之后反抽要是放量,就是机构在回补。
- **所以主 chat 先测这两样,** 背离和出场放后面。

## 二、两边一致的
1. **背离(第 1–4 题)**
   - **默认用 MACD 柱(12, 26, 9):** 第二个顶的柱子不超过第一个顶的 0.65 倍(A)或 0.7 倍(B)。两个顶之间,柱子要跌到零轴下面(B 的硬条件;A 是跌到零下,或缩到第一个顶的 20% 以内)。
   - **两个顶怎么选:**
     - 用左右各 3 根确认过的波段高点;
     - 两个顶隔 8~10 根 K 线以上、50~60 根以内;
     - 中间至少回落 1.5 倍 ATR。
   - **4 小时和日线听谁的:** 听日线的(Elder 三重滤网)。日线没背离、4 小时有背离,不许空;要等 4 小时跌破颈线,这和你原来的规矩一致。
   - **最常见的失效:** 强趋势里连续背离 3~4 次,价格照样往上走。
2. **无量弱反抽(第 5–7 题)**
   - **「无量」看相对量:** 反抽这几根 K 线的平均量,除以一个基准量。
     - **A:** 基准取「跌破那段的均量」和「前 20 根均量」里较小的那个,门槛是美股大盘 0.75、个股 0.65、加密 0.60。
     - **B:** 先要求跌破那根是放量的(≥1.3 倍 20 根均量),再要求反抽均量 ≤0.65 倍 20 根均量,而且反抽里最大的那根量小于跌破那根的 0.8 倍。
   - **美股不能直接比绝对量:** 美股开盘和收盘的量是中午的 2.5~4 倍,所以要拿「这个时段的量」和「过去 20 天同一时段的平均量」比(同时段相对量)。加密可以直接比。B 补了一条:周末量本来就少,门槛要收紧到 0.5。
   - **「弱」还看三样:**
     - 反抽收回的跌幅不超过 0.5(超过 0.618 就不当弱反抽);
     - 反抽用的 K 线根数比下跌时多(A 要 ≥1.0 倍,B 要 ≥1.5 倍);
     - 不能有大阳线(A:实体不超过 1.2 倍 ATR),或者碰到阻力时出长上影线(B:上影线 ≥ 整根 K 线的一半)。
3. **下方支撑(第 8–10 题)**
   - **什么算一层支撑:** 没被收盘跌破的波段前低、过去 60 天成交最密集的前 15% 价位、日线 50 / 100(或 120)/ 200 日线。
     - A 补充:只有向上或走平的均线才算支撑。
     - B 补充:整数关口只对指数和 BTC 算。
   - **几个价位挨多近算同一层:** A 是 0.4 倍日线 ATR,B 是 0.5 倍 4 小时 ATR。
   - **有支撑怎么办:**
     - 第一层支撑离得太近(B:进场到第一层支撑的距离不到止损距离的 1.2 倍),就不做。
     - 不太近的,照样做,但第一目标放在支撑上方 0.2 倍 ATR。
     - A 多一条:2R 之内有 2 层以上支撑,也不做(R = 进场价到止损价的距离)。
   - **「测三次、第四次易破」:** 两边都说,要每次反弹的高点越来越低(下降三角形)才成立。如果反弹高点在抬高,说明买盘还在补,反而不容易破。
4. **阴跌贯穿还是双底(第 11–12 题)**
   - **会贯穿,继续拿着:** 接近前低时是连续小阴线、几乎没有下影线、收在最低价附近,中间没有像样的反弹阳线,量也不大。
   - **会撑住做双底,先平:** 一根大阴线砸到前低、拉出长下影线(下影线超过一半),量是平时的 2 倍以上(恐慌盘出完了)。
   - **你的 75% / 12.5% / 12.5% 分法:**
     - 道理:大部分利润在前低就落袋,剩下的单子止损推到成本,等于白拿一张彩票。专门对付美股「跌到前低就 V 转」。
     - 代价:碰上一路大跌,比五五分少赚三到四成。
     - A 的折中建议:美股 75 / 25,加密 50 / 30 / 20。

## 三、我核(只核算术、出处、前后矛盾;实测交给主 chat)
- **A 的分批算术对:**
  - 50 / 50:0.5×1.5R + 0.5×6R = 3.75R;
  - 75 / 12.5 / 12.5:0.75×1.5R + 0.125×3R + 0.125×6R = 2.25R;
  - 少赚 40%。前提是第一目标 1.5R、第二目标 3R、尾仓吃到 6R,这些都是它假设的。
- **B 有一处拿错了我们的数:** 它说「你们回测这套体系单笔平均赚 0.6R」,所以前低先平 75% 合适。其实 0.6R 只是 BTC、ETH 那 18 笔的数,美股是每笔都亏。这条理由在美股上不成立。
- **「测三次、第四次易破」的出处两边说法不一:** A 说有原著出处(Wyckoff、Edwards & Magee);B 说是经验法则,而且大势向上时正好相反。我倾向 B 的说法:两边都要加「反弹高点递减」才成立,说明单看次数靠不住。
- **引用来源都对得上:** RSI 是 Wilder,MACD 是 Appel,MACD 柱背离要先穿零轴是 Elder,OBV 是 Granville,Market Profile 是 Steidlmayer,三重滤网是 Elder。
- **两边都标了「推演」的数,不当依据:**
  - 「美股假破位短命空单能拦掉 70% 以上」(A);
  - 「能过滤 70% 的机构洗盘假跌破」(B);
  - 「强牛市里单靠背离做空,胜率低于 35%」(B);
  - 「震荡市里分三批的夏普更高、单边市少赚 25%~35%」(B)。
- **我这边验不了的:** 支撑过滤、无量反抽在美股上到底能挡掉多少亏损单,要用美股 4 小时、1 小时数据,只能主 chat 跑。

## 四、要 Lin 定的(4 条)

我的倾向:同意。

**【2 / 4】下方支撑:用 A 窗口的版本,B 的当对照**
- **数支撑:** 从进场价往下看到 2R(另试 1.5R、2.5R)。下面这些算一层支撑:
  - 没被收盘跌破的日线和 4 小时波段前低;
  - 过去 60 天成交最密集的前 15% 价位;
  - 向上或走平的 50 / 120 / 200 日线。
- **合并:** 几个价位相距 0.4 倍日线 ATR 以内,算同一层(另试 0.25、0.6)。
- **不做:** 1.2R 之内有支撑(另试 1.0R、1.5R),或者 2R 之内有 2 层以上支撑。这就是你说的「下面三个底撑着,跌不下去」。
- **照做,但改第一目标:** 只在 1.2R 到 2R 之间有 1 层支撑时,第一目标放到这层支撑上方 0.2 倍日线 ATR(另试 0.1、0.3)。
- **对照(B 版):** 只看第一层支撑,进场到它的距离不到止损距离的 1.2 倍就不做;往下看 3 倍日线 ATR;合并半径 0.5 倍 4 小时 ATR;整数关口只对指数和 BTC 算。

我的倾向:同意。

**【3 / 4】无量弱反抽:量用 B 窗口的写法,「弱」三样都加**
- **量:**
  - 跌破那根要放量,≥1.3 倍 20 根均量;
  - 反抽这几根的平均量 ≤0.65 倍 20 根均量(另试 0.5、0.8);
  - 反抽里最大那根的量,小于跌破那根的 0.8 倍。
  - 美股改用同时段相对量(和过去 20 天同一时段比),门槛一样;加密周末另试 0.5。
  - 对照:A 窗口的分品种门槛(大盘 0.75、个股 0.65、加密 0.60)。
- **弱:**
  - 反抽收回的跌幅 ≤0.5(另试 0.382、0.618);
  - 反抽用的 K 线根数 ≥ 下跌根数的 1.0 倍(另试 1.5、0.8);
  - 反抽中没有实体超过 1.2 倍 4 小时 ATR 的阳线(另试 1.0、1.5)。
- 个股做空,财报前后 3 天不做(B 提的)。

**【4 / 4】背离当过滤用,出场保留你的分法,另加「贯穿就拿着」的判断**
- **背离:**
  - 默认用 MACD 柱:第二个顶的柱子 ≤ 第一个顶的 0.65 倍(另试 0.5、0.75),两个顶之间柱子要穿过零轴。
  - 两个顶:左右各 3 根确认;隔 8~60 根;中间回落 ≥1.5 倍 ATR。
  - 只听日线:日线没背离,光有 4 小时背离,不许空。
  - 只用在「有顶部形态」的单子上,作为右侧空的必要条件。这正是你的规矩:有形态又有背离才空,只有背离、没有形态不空。
- **出场:**
  - 默认照你的 75% / 12.5% / 12.5%。
  - 到了前低附近,如果判成「阴跌贯穿」(最近 5 根里 4 根收阴、没有超过 0.8 倍 ATR 的反弹阳线、下影线短于整根的 35%),这 75% 先不平,继续拿着。
  - 如果出现「长下影线超过一半 + 量 ≥2 倍」,立刻在前低平。
  - 对照:加密另测 50 / 30 / 20。
