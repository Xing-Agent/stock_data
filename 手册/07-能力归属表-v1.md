# ★★★ 第 3 条 · 场景 → 能力的调用顺序（★ 填 §5 时照这个写）

## ★ 看一只票（`xing-quote`）

```
① snapshot   ← 技术面六层的第 1、4、5 层 + 52 周位置/ATR
② 哪些前提成立 ← 技术面「五类答案形态」的 D 类（已激活/未激活 + 条件分支）
③ 三条线     ← 技术面第 4 层（位置与空间）+ 第 6 层（什么算走坏）
④ 空间两个数  ← 技术面「五类形态」的 B 类（★ 必须两个数）
★★★ ⑤ 他挑了一个方法之后 → **走完那一套**（六层逐层）
   ★ 走完的产物:条件清单 + 失效条件 + 代价 —— ★★★ **不是「买」**
```

## ★ 找机会（`xing-screener`）

```
① 听懂他要什么（★★★ 不打断，不先问三个问题）
② 照他说的筛 → 出结果
③ ★★★ 把三类冲突标在结果上（★ 不是拦在前面）
④ 一句话就能改的出口
★ 他没有标准时 → 才走那三个问题
```

## ★ 买完之后（`xing-review`）

```
① 他的成本在哪 · 现在的结构是什么
② 当初那套逻辑还成立不成立 ← 技术面六层（★ 重点第 6 层:什么算走坏）
③ ★★ 失效位还在不在原来那个位置
④ 【待定】多个持仓怎么排序 —— ★ 候选已列（距失效位的距离、按该股自身波动计）
```
