二、 回撤与扩展如何“配合定目标”？

经典招式：内部回撤反延（External Retracement）与三点扩展（Projection）的共振。

二、 依据打架时的“硬核优先级”

[量化推荐] 优先级排序（从高到低，1 为最高）：

🥇 绝对第一顺位：真实历史资金遗留 —— 成交密集区 (Volume Profile) 与 前高/前低 (Swing Nodes)

理由：斐波那契和波浪是数学计算，只有人相信时才有效。但成交密集区（VPVR 的 POC 或高成交量节点 HVN）代表着真实的套牢盘和获利盘筹码。如果一个漂亮的 1.618 斐波那契扩展位上方刚好遇到了半年前形成的海量套牢筹码峰，1.618 会被直接砸穿失效。一切抽象测算必须向真实的资金墙让路。

🥈 第二顺位：机构算法常数 —— 1.0 等距测算 (AB=CD 或 A浪=C浪)

理由：华尔街大量趋势跟随算法（CTA）和套利机器人的硬编码离场逻辑中，包含 1.0 倍等距运动。它的到达率远高于主观猜测的 1.618。

🥉 第三顺位：结构共振 —— 斐波那契簇 (Fib Clusters) 与 波浪特定比例

理由：当多个维度的计算（如周线 0.618 回撤 + 日线 1.272 扩展 + 波浪浪 3 的 1.618）巧合地指向同一个狭窄价格区间时，会引发场内技术派和程序化策略的共识性踩踏平仓。

🏅 最低顺位：形态的 100% 垂直高度量度

理由：如第 1 题所述，除了箱体和头肩形态，诸如旗形、楔形等形态的 100% 高度到达率在量化回测中往往表现最差（不足 50%）。它只能作为补充参考，绝不能当做唯一的离场依据。

def generate_pattern_plan(df, pattern_type, pivots, k_multiplier, is_log_scale=False):
    # 1. 计算形态高度 H（高波动或跨度大于6个月强制对数化）
    p_high = max(pivots['highs'])
    p_low = min(pivots['lows'])
    atr_14 = df['ATR_14'].iloc[-1]
    vol_ma20 = df['Volume'].rolling(20).mean().iloc[-1]
    
    # 2. 突破激活条件（Trigger）：收盘有效站稳阻力 + 0.25 ATR，且量能放大
    resistance = pivots['neckline_or_resistance']
    close_today = df['Close'].iloc[-1]
    vol_today = df['Volume'].iloc[-1]
    
    is_triggered = (close_today > resistance + 0.25 * atr_14) and (vol_today > 1.3 * vol_ma20)
    if not is_triggered:
        return None  # 未触发，保持空仓观察

    # 3. 计算分级目标位 T1, T2 与止损位 SL
    if is_log_scale or ((p_high - p_low) / p_low > 0.25):
        ratio = p_high / p_low
        t1 = close_today * (ratio ** k_multiplier)   # 保守第一目标（如 k=0.70）
        t2 = close_today * (ratio ** 1.00)           # 经典全幅目标
    else:
        height = p_high - p_low
        t1 = close_today + k_multiplier * height
        t2 = close_today + 1.00 * height

    # 止损位：取形态内最后一个抬高低点下方 1.0 ATR，与突破点下方 2.0 ATR 的较紧者
    sl = max(pivots['last_higher_low'] - 1.0 * atr_14, close_today - 2.0 * atr_14)
    
    return {"entry": close_today, "T1": t1, "T2": t2, "SL": sl, "ATR": atr_14}

四、 深度剖析：「横得越久、突破后走得越远」到底靠不靠谱？

这是个人投资者最常问的问题。根据 Bulkowski 跨度 30 年的美股大样本回归以及 2005–2025 量化回测，这句话不能一概而论，它在统计上呈现一条非单调的“倒 U 型曲线（Inverted-U Curve）”，且完全取决于形态属性：

场景一：中继整理形态（旗形、三角旗、窄幅楔形）—— 完全不靠谱，甚至是强负相关！

统计事实：旗形横盘 5–12 个交易日突破后的平均涨幅最高；一旦横盘超过 15–20 个交易日，突破后的平均涨幅大幅缩水，而跌破失败率飙升至 50% 以上。

底层机理：中继形态依赖的是原有趋势的惯性动量（Momentum）。横盘时间过长，意味着追涨资金热情冷却、早期获利盘不断派发，原有的动量因子已经衰减殆尽。

场景二：大型底部反转形态（箱体底、头肩底、双底、杯柄）—— 在合理区间内高度靠谱！

统计事实：一个筑底 4 至 9 个月 的头肩底或杯柄形态，突破后的平均涨幅显著高于只筑底 3 至 4 周 的小型底部，且跌破颈线的失败率低得多。

底层机理：底部横盘的核心功能是筹码结构重塑（Chip Redistribution）——把前期高位套牢的恐慌盘（Weak Hands）洗出，让中长线机构资金（Strong Hands）在低位完成充分吸筹。横盘时间足够长，上方阻力的套牢盘就越轻，突破后的抛压自然越小。

场景三：超长周期“死水盘整”（横盘超过 1.5–2 年的个股）—— 边际效益递减甚至失效！

统计事实：在美股 2005–2025 样本中，横盘超过 18–24 个月才突破的股票，其超额收益并不比 6–9 个月底部更高，反而混杂了大量流动性枯竭的“僵尸股”。

底层机理：如果一家公司在长达两年的时间里都无法吸引资金突破，说明其行业逻辑或基本面存在硬伤。此时必须叠加相对强度指标（RS Rating 排名前 20%）过滤，只做有基本面或板块催化配合的长底突破。
