# ★ 要你做的：在存着原始资料那台电脑上跑这一条

```bash
# ★ 在家目录下全盘找这 14 张方法卡(含压缩包里的)
find ~ -type f \( -name "技-*.md" -o -name "状-*.md" -o -name "基-*.md" \) 2>/dev/null | head -60

# ★★ 如果上面没找到，再找装着它们的包
find ~ -type f \( -name "*.zip" -o -name "*.tar.gz" \) 2>/dev/null \
  -exec sh -c 'case "$1" in *.zip) unzip -l "$1" 2>/dev/null | grep -l "技-1" >/dev/null && echo "命中: $1";; esac' _ {} \;

# ★★★ 再不行，按内容找（★ 方法卡里一定有「谁不该用」这四个字）
grep -rl "谁不该用" ~ --include=*.md 2>/dev/null | head -30
```

★★ 找到之后推到 GitHub（★ 老规矩）：

```bash
cd <stock_data 仓库目录>
mkdir -p METHOD_LIBRARY
cp <找到的那些 md 的目录>/*.md METHOD_LIBRARY/
# ★★★ 推之前先核一下张数和校验值，免得推进来一份不全的
```
