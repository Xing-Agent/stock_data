```

★★★★★ 为什么用「靠什么赚钱」当内层：

      ★★★★★ 他会说「**我想做趋势**」或「**我想抄底**」。

★★ 出处分档：★★★★★ **外层「派」是 ①档**（台账原有列）；
   ★★★ **内层「机制」是 ③档 —— 我从每条的「一句话」归的，不是原著给的分类。**
   ★ 如果 Gemini 或原著给出不同的分法，以它为准（★★《165》问题 5(c) 正在问这件事）。
```

## 二、★★★ 两条必须写明的（★ 否则这张表会被用错）

### ① ★★★★★ 「抄弱」拆成两格，不是一格

```
★★★ 因为这两格的环境前提**是相反的**：
   · **震荡里抄**（技-10 技-11 技-13）→ 要**没有方向**的市场
   · **上升趋势里抄回调**（技-12 技-14）→ 要**向上的大方向**

★★★★★ 实际后果：**这两格不能放一起比。**
   ★ 2020 年 3 月单边下跌：两格都废
   ★★ 2021 年慢牛：★★★ 回调格是旺季，震荡格几乎没信号
→ ★★ 混在一类里比出来的，是「**过去十一年哪种环境多**」，不是哪条策略好。
```

### ② 🟡 ★★★ 融-1 的卡名是错的（★ 待改）

```
★ 卡名叫「**震荡类**融合策略」，
★★★★★ 但它的一句话写的是「**大趋势向上时**，买短期跌过头的；回到 5 日均线之上就走」
   —— ★★★ 那是**上升趋势抄回调**，**不是震荡**。
★★ 而且它的「什么时候用」那一格**是空的**，★ 所以卡名成了唯一线索 → 会误导。

★★★ 它真正的同类是 **技-12 康纳斯**（★ 卡自己也这么写：
   「和技-12 的区别：技-12 没有大盘闸、没有时间止损；本条两样都有」），
   ★★★★★ 而技-12 的环境前提恰恰是「**温和上涨**」。
→ ★★ 建议：卡名改「**回调类**」，并把空着的「什么时候用」补上。★★★ 待 Lin 拍。
```

## 三、★★ 「震荡」为什么不列为类型

```
★★★ 「追强 / 抄弱」说的是**靠什么赚钱**（★ 策略的性质）；
★★★ 「震荡 / 上涨」说的是**什么市场里才管用**（★ 环境的性质）。
★★★★★ 两件事是**配对**的，不是并列的 ——
   ★ 把震荡列成类型，会让同一条策略同时落两格（★★ 技-14 就是「震荡 **或** 上升回调」）。
→ ★★★ 所以：**震荡写进每条的「什么时候用」那一格，不进分类。**
```
