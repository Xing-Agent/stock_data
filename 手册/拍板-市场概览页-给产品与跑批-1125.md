# 拍板 + 要干啥 · 市场概览页「大盘现在什么样」(2026-11-25)

> 依据:《Gemini原文回答-市场概览页与环境配打法-1125.md》《Gemini回复与判断-市场概览页与环境配打法-1125.md》。Lin 11-25 17:06–17:10 四条都同意。
> 读者:做样张的人(产品)+ 跑批 chat(算数)。

## 一句话
**页面四段不变:大盘状态 → 行业强弱 → 核心股票 → 顺手打法。第一屏把「指数闸」和「宽度」并排摆,不合成分数;宽度加历史分位,有矛盾时用一句大白话点出来。「顺手打法」放最后,只当历史参考,数字全部用我们自己的回测。**

## 拍板(4 条)

### 1. 第一屏:指数闸 | 宽度 并排
- **左栏:** 大盘闸。行业惯例版(标普在 200 日线上方,且 200 日线比 20 天前高)和温斯坦周线版并排。
- **右栏:** 宽度。站上 50 日线的比例、创一年新高的比例。每个数后面跟:2004 年以来的历史分位、比上周的变化。
  - 例:「42%(2004 年以来 28% 分位,比上周 ↓6%)」
- **一红一绿时自动加一句:** 例:「指数在涨,但多数股票没跟上;这种情况 2004 年以来约占 X% 的日子。」
- **顶上状态标签(四档):**

  | 标签 | 条件 |
  |---|---|
  | 健康多头 | 标普 > 200 日线,宽度 > 60% |
  | 分化多头 | 标普 > 200 日线,宽度 < 40% |
  | 分化空头 | 标普 < 200 日线,宽度 > 50% |
  | 全面空头 | 标普 < 200 日线,宽度 < 30% |
  | 其余 | 显示「过渡」 |

  门槛是行业惯例,要用 2004 年起的数据核一下每档占多少天。
- **不违反约束:** 不出合成分数,矛盾照样摆在明面上。
- **注意:** 「站上 50 日线比例」在这里只当健康度展示。按《拍板-三步走认顶改写》,它不用来认大顶。

### 2. 「顺手打法」:防止被当成胜率保证
- **每种打法同时摆四样:**
  - 当前这种状态历史上出现过几次、平均持续多久;
  - 这种打法在这种状态下的胜率和盈亏比;
  - 最大连亏次数和最大回撤;
  - 2005–2014 和 2015–2025 两段成绩的差别。
- **第一屏一行对比,** 例:「同类状态 2004 年以来出现 X 次:趋势跟随历史上赚钱的概率 68%,均值回归 44%。」详细回测默认折叠。
- **大盘闸关着时,标题自动换成「防守模式」,** 写明:「进攻型打法在这种状态下历史上都变差;防御类只是跌得比大盘少。」
- **数字来源:** Gemini 的「环境 × 打法 × 标的」表只当假设起点(见判断文件第四节)。页面上的数字一律来自我们自己的回测,等跑批 chat 的「四种行情配法」。

### 3. 行业强弱、核心股票
- **行业:**
  - 用 11 个 SPDR 行业 ETF:XLK、XLF、XLV、XLY、XLP、XLE、XLI、XLB、XLU、XLRE、XLC;
  - 默认按「过去 1 个月比标普多涨(少跌)多少」排序,可切到 3 个月;
  - 每个行业旁标「行业内站上 50 日线的比例」。
- **核心股票:** 先用标普 100。「市值前 100 ∪ 20 日成交额前 100」留第二版。
- **涨跌榜:** 默认当天前 5 / 后 5,可切 20 日。每只票打一个标签:
  - 财报日;
  - 趋势延续(创 52 周新高);
  - 超跌反弹(还在 200 日线下);
  - 无明显消息。
  - 没有财报日历就先不打「财报日」。

### 4. 页面顺序不挪
- **保持:** 大盘状态 → 行业强弱 → 核心股票 → 顺手打法 → 底部入口「今天的行情对我的持仓和策略有什么影响?」。
- **理由:** 打法放第 2 位,用户第一眼就看到「该怎么打」,容易当成建议;放最后更像历史参考。

## 要干啥

**跑批 chat:**
1. 用全池宽度日序列(2004 年起),算站上 50 日线比例和创一年新高比例的历史分位,以及每天比上周的变化。
2. 按第 1 条四档,统计 2004 年以来每档占多少天、平均持续多久,以及「一红一绿」的日子占比。
3. 11 个行业 ETF 的 1 个月 / 3 个月相对标普强弱。行业内宽度:按 GICS 行业分组算站上 50 日线比例。
4. 「四种行情配法」出来后,按四档状态回填第 2 条的四样数字;两段时期分开报。

**产品(样张):**
1. 第一屏按第 1 条改成左右两栏加状态标签。
2. 打法段按第 2 条:一行对比 + 折叠详情;闸关时换「防守模式」。
3. 行业段、核心股票段按第 3 条;涨跌榜加标签位。
4. 顺序按第 4 条。

**数据要找:**
- 标普 100 成分股名单;
- 按 GICS 分组的成分股;
- 财报日历(没有就先跳过);
- NYSE 新高新低家数 / 涨跌家数(和「三步走」第 2 条共用,没有先跳过)。

## 学业内的 5 点(给做样张的人参考)
1. **Finviz:** 指数和宽度红绿条并排,不打分。
2. **IBD / MarketSmith:** 顶上一个客观状态词,下面用客观数字撑住。
3. **Koyfin:** 大盘 / 等权 / 小盘(SPY / RSP / IWM)并排;行业表 1 天 / 1 周 / 1 月 / 年初至今一键切。
4. **Bloomberg IMAP:** 拆解今天的涨跌是几只巨头拉的,还是普涨。
5. **Robinhood:** 一句话说清今天为什么涨跌,留白克制。
