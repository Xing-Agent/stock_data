# 改动单 v0.8 · 上涨行情里的顶部空单：中轴先平一部分，剩下拿着（Lin 11-20 12:35 定）

**一句话**：上涨里不是不做空，出现非常好的顶部机会就从尝试开始。到中轴**先平一部分**，不是全走；剩下的空单拿着看走势。

## 改哪里
v0.5「震荡/上涨里做空（少做）」那一行，原写法是「小仓（半仓），目标只看中轴」。改成下面这张：

| 项 | 新写法 |
|---|---|
| 条件（两个都要） | ① 顶部派发形态（横三顶 / 一个顶比一个弱 / 背离，见 v0.4）② 加一次假突破（冲过前高又收回） |
| 仓位 | 比同样条件的多单**减半**（仓位倍数 0.5×），当作「尝试」 |
| 中轴 | 到区间中轴**先平一部分**（按 v0.6 逆势单 TP1 平 75%），止损移到成本 |
| 剩下的 | 拿着，看走势；止损在成本，直到结构破了（重新站回假突破那个高点之上）或到下一目标 |
| 话术 | 「上涨里做空是尝试，不是主打；没有统计支持」照旧写 |

## 删掉
- 「目标只看中轴，到了就走」→ 删。
