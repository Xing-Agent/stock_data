## 一、粘贴这一段（★ 不需要 API key，走 FRED 的 CSV 下载口）

```bash
mkdir -p ~/fred_1110 && cd ~/fred_1110

# ★★ 五个序列（★ 括号里是 Gemini 给的用途）
for S in \
  NAPM        `# ISM 制造业 PMI —— 增长` \
  PAYEMS      `# 非农就业总人数 —— 增长` \
  PCEPILFE    `# 核心 PCE 物价指数 —— 通胀` \
  NFCI        `# 芝加哥联储金融状况指数（周度）—— 流动性` \
  BAMLH0A0HYM2 `# ICE BofA 高收益债期权调整利差 —— 信用（★★★★★ 授权要查）` \
  T10Y2Y      `# 10年减2年国债利差 —— 利率曲线` \
  DGS10 DGS2  `# 10年/2年国债收益率（★ 备用，自己也能算利差）` \
  T10YIE      `# 10年盈亏平衡通胀率 —— 市场定价那一栏要用` \
  ; do
  case "$S" in \#*|'`'*) continue;; esac
  echo "=== 取 $S ==="
  curl -sS -L -o "$S.csv" \
    "https://fred.stlouisfed.org/graph/fredgraph.csv?id=$S" \
    && head -2 "$S.csv" && tail -1 "$S.csv" && wc -l < "$S.csv"
done

echo; echo "=== 汇总 ==="
ls -la ~/fred_1110/*.csv | awk '{print $5"  "$9}'
```

**★★ 如果上面那段的注释写法在你的 shell 里报错，用这个更简单的：**


## 二、★★★★★ 顺手查授权（★ 这条比取数更要紧）

```bash
# ★★ FRED 每个序列页面底部都写着版权和使用条款
for S in BAMLH0A0HYM2 NFCI T10Y2Y T10YIE; do
  echo "########## $S ##########"
  curl -sS -L "https://fred.stlouisfed.org/series/$S" \
    | grep -oiE "(copyright|terms of use|not be redistributed|permission|courtesy of|source:)[^<]{0,200}" \
    | head -6
  echo
done
```

```
★★★ 我要从这里看什么：
   ★★★★★ **`BAMLH0A0HYM2`（ICE 高收益债利差）能不能展示给用户** ——
      ★ Gemini 说它「在 FRED 上有转载限制」。
      ★★ 如果不能展示，我们有两条退路：
        ① 只在**内部**用它判状态，★ 界面上只说「信用环境偏紧 / 偏松」**不给数**
        ② 换一个可商用的替代序列（★★ 到时候再找）
```

## 三、我拿到数据之后会做什么（★ 你不用管）

```
★★ 按《160》第二节那张表建「**宏观状态层**」五步：
   1 增长 —— ISM PMI、非农：**近 3 个月均值减前 3 个月均值**；
     ★ 门槛：正 = 扩张；**PMI < 50 且在降 = 衰退确认**（★★ 50 是 ISM 官方荣枯线）
   2 通胀 —— 核心 PCE 环比**近 3 个月年化**；★ 门槛 **> 2% 超标**（★★ 美联储目标）
   3 流动性 —— NFCI 最新值；★ **> 0 收紧，< 0 宽松**（★★ 指数以 0 为平均）
   4 信用 —— 高收益债利差（★★★ Gemini 那一栏文字被截断，我按常规做法补：**绝对水平 + 变化速度**）
   5 利率曲线 —— 10 年减 2 年：**倒挂 / 解除倒挂**

★★★★★ 三条我会写死的边界：
   · 门槛凡是 Gemini 给的（★ 不是官方定义的），**跑相邻三点**，卡上标「行业做法，不是原著」
   · **这一层和「打法可用度」那一层分开显示**，★★ 不许合成一个数
   · ★★★ 「**衰退确认**」这类词**不许单独出现** —— 必须带日期和数据来源
```

## 附 · 为什么要加这两样（★ Gemini 原话，留着当依据）

```
★★★★★ 「**股市大跌但信用利差没爆**（比如 2018 年圣诞节）和
   **股市大跌、信用利差也快速走阔**是两回事，★★★ **后者才是系统性风险。**」

★★ 而我们现在那张面板**分不出这两种** —— ★★★ 它只看价格和广度。
★ 这也是 Gemini 批评里我认为最站得住的一条：
   「★★★★★ **只有「果」没有「因」** —— 分不清这场雨是流动性枯竭（2020）、
     通胀失控（2022），还是信用违约。」
```
