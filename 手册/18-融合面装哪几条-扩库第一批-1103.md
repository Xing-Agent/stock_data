# 一 · 融合面

## 1.1 ★★★ 修法次序(这一节是我的裁定,和 Gemini 不同)

| | Gemini 的诊断 | ★ 我们的实测 |
|---|---|---|
| 0 笔的原因 | 四道闸各留最好的 10%,一乘 = 0.2 只 | ★★★ **数对上了(实测 0.17),机制错了** |
| 真正的机制 | — | ★★★ **「算不出」,不是「分低」** —— 第一道闸 **91%** 的票·日根本评估不了 |
| 代码级根因 | — | `ops_q57_1030.py:218-241` 的 `roic_consecutive` 要 **t / t−4季 / t−8季 三个点全算得出**,★ 缺任何一期 → 整只票整段判 False;★★ 老库财务最早 2015、研发池 2018 起 |

★★★ 所以次序是:

```
★★★ 第 1 步 · 在新扩池库上重算(★ 新库历史到 2009,正好治这个)  ← 在跑
★   第 2 步 · 还不够,再上方案 B
★★★ 绝不先上方案 B
```

★★ 理由一句话:**先上方案 B,等于把一个数据问题包装成一个策略决定** ——
★ 而且那之后我们再也分不清「改好了」是因为选池方式变了,还是因为数据变全了。

## 1.2 方案 B 的形状(等第 1 步之后才可能用)

```
★ 一个最核心的指标按**排名**定池子(比如前 15%)
★ 另外三道只用来**剔除最差的**,没有赞成权
★★★ 这正是我们允许的「一边否决」,不碰红线
```

★★ **要守住的一条**:那三道否决闸的门槛,**原著有数就用原著的数**;
★ 原著没有的,标「我们填的」并按红线②跑**相邻三个点**。
★★★ Gemini 举的「剔除负债率最差的 20%」这类放宽,**不能直接拿来用**。

### ★ 两种明确不做的修法

| 方案 | 为什么不做 |
|---|---|
| ❌ **名次相加**(四个指标各排名,名次加起来取前 100) | ★★ Gemini 说这是「格林布拉特原著」—— ★★★ 但格林布拉特只把**他自己的两个指标**名次相加。把我们四个指标的名次加起来,**是我们自己定的等权合成** |
| ❌ **四道满足三道就行**(过了记 1,总数 ≥3 入池) | ★★★ 同样是我们自己合成的分数。★ 例外:**原著本身就这么定义的**(F-Score 就是),那是复原不是合成 |

## 1.4 ★★★ 排雷否决闸 —— 和融合面方向相反,必须一起看

| # | 闸 | 公式 | 阈值 | 出处 | ★ 判定 |
|---|---|---|---|---|---|
| 1 | 利息覆盖不足 | EBIT ÷ 利息费用 | **< 1** | Asquith 等 1994 | ✅ 可用。★★ 但原论文用「<1」是**挑研究样本**,不是当否决规则 —— ★ 出处要写准 |
| 2 | 利润和现金流背离 | (净利润 − 经营现金流) ÷ 总资产 | ★ 原著:**截面最高 10%** | Sloan 1996 | ✅ **用原著的排名法**。★ Gemini 补的静态线 0.10 不用 |
| 3 | 应收涨得比收入快 | (应收÷收入) 今年 ÷ 去年 | ★★★ **没有公开阈值** | Beneish 1999 | 🔧 ★ 原著里造假样本均值 1.465、正常 1.031 → **跑 1.3 / 1.4 / 1.5 三个点** |
| 4 | 存货涨得比收入快 | 存货增速 − 收入增速 | ★ 原著 > 0 | Lev & Thiagarajan 1993 | 🔧 ★★ 原著里它只是**负面信号**,不是否决线。★ 用 0.20 就要标「我们填的」+ 跑三点 |
| 5 | 有形净资产 ≤ 0 | 股东权益 − 商誉和无形 | ≤ 0 | Graham & Dodd 1934 | ⚠ ★★ **先不装** —— ★ 发债回购的好公司(麦当劳、星巴克)和靠并购做大的医药龙头会被一刀切掉 |
| 6 | 破产概率 | Zmijewski 三项比率 | > 50% | Zmijewski 1984 | ✅ 可用。★★★ 但 Gemini **写错了一处**:原公式是**总负债**÷总资产,它写成了总**债务** —— ★ 按原公式 |

### ★★★ 这一节最要紧的一句

```
★★ 6 道全装,按它估的比例加起来要剔掉**三四成**的票。
★★★ 而融合面的毛病正是「池子太小」—— **两件事方向相反。**

★ 所以上之前必须先做一件事:
  **每道单独剔多少、合起来剔多少 —— 只数个数,不看收益。**
★★ 不许两件事各自上,然后撞在一起。
```

★ 建议的默认组合:**第 1、2、6 道**(原著有数)+ Beneish M-Score(★ 等追问结果)。

★★★ 另外:**Gemini 漏了一个现成的、原著自己定义的总分 —— Beneish M-Score。**
★ 它有固定公式、固定门槛,8 个指标我们都抓得到。★★ 按新规矩「原著定义的打分照原样复原」是允许的,

# 二 · 扩库第一批:五条

★ 共同点:**公式干净 · 我们数据全够 · 不等任何人 · 都有论文出处**。
★★ 全部落第 ⑤ 档,★★★ 出处要我们自己 grep 原文核过才能升档。

## 2.1 ★★★ 五条是什么(大白话 + 投资逻辑)

### ① Novy-Marx 毛利质量 · JFE 2013

```
算什么:毛利 ÷ 总资产,取池内前 20%
```

★ **大白话**:看「这家公司手上每一块钱的家当,一年能挣出多少**毛**利」。

★★ **为什么用毛利不用净利润** —— 这是这条策略的全部精髓:
毛利在损益表**最上面一行**,是被会计手法动过最少的一个数。★ 净利润要往下走过折旧、减值、
一次性损益、税 —— ★★★ 每一道都能被调。所以毛利是「赚钱效率」最干净的代理。

★ **投资逻辑**:便宜的好公司很难找;但「赚钱效率高」这件事本身就带超额,
★★ 而且它和「便宜」几乎不相关 —— ★★★ **所以它能和价值策略叠加,而不是替代**。

### ② Ball 等 现金经营利润 · JFE 2016

```
算什么:(营业利润 − 应计项) ÷ 总资产
```

★ **大白话**:把「账上记了、但钱还没进来」的那部分从利润里**扣掉**,剩下的才算。

★★ **应计项**是什么:利润和现金流的差额。★ 应收账款涨了一大截、存货堆起来了 ——
利润表很好看,但钱没收到。

★ **投资逻辑**:这是 ① 的升级版 —— ★★ 同样是赚钱效率,**但只认收到现金的那部分**。
★★★ 它背后站着 Sloan 1996 那个发现(应计高的股票后面会跌),★ 这条策略是把那个发现装到**正面筛选**里。

### ③ Hou-Xue-Zhang 资产扩张 · RFS 2015

```
算什么:总资产增速最低的 10%        ★ 公式最简单的一条 —— 就一个同比
```

★ **大白话**:买那些「**今年没怎么扩张**」的公司。

★★ 听起来反直觉 —— 不扩张不就是不成长吗?★★★ **投资逻辑恰恰在这里**:
公司管理层在股价高、钱便宜的时候,倾向于大举投资和并购(★ 「帝国构建者」)——
而那笔钱的回报通常很差。★★ 反过来,收缩或不扩张的公司,往往是在被市场冷落的时候。

★ **证据强度**:这是 q 因子模型的核心一块,★★ 学术支持最扎实的几条之一。

### ④ Richardson 等 净经营资产 · JAE 2005

```
算什么:ΔNOA(净经营资产变动)最低的 10%
```

★ **大白话**:和 ③ 是近亲,但看得更细 —— ★★ 只看「**经营用的**那部分家当」涨了多少,
把融资那部分(现金、债务)剔出去。

★ **投资逻辑**:经营资产涨得快,往往意味着利润里有很大一块是「**记在账上的**」而不是收到的现金。
★★★ 它是 Sloan 应计异象的**资产负债表版本** —— ② 从利润表看,④ 从资产负债表看同一件事。

### ⑤ O'Shaughnessy 趋势价值 · 《What Works on Wall Street》第 23 章

```
算什么:6 个估值指标综合,选最便宜的 10%
        → 再在这 10% 里买 6 个月动量**前 25 只**,等权
```

★ **大白话**:★★★ **先用便宜筛出一个池子,再在池子里买涨得最好的。**

★ **投资逻辑**:纯便宜股里有大量「便宜是因为**真的不行**」的价值陷阱。
★★ 用动量当第二道,相当于**让市场先替你投一次票** —— 便宜、而且已经开始有人买了。

★★★ **这一条对我们有三重好处**:
1. ★★ 它是**两段漏斗**,正是我们允许的融合形状
2. ★★★ 而且**原著自己就是这么写的** —— ★ 不是我们组合的,归属能标原著
3. ★ 6 指标综合是**原著定义的打分**,按新规矩可以照原样复原

★ **两处要核**:Gemini 说第 4 版是 2006 年(★★ 我们印象是 **2011** 年,「趋势价值」也是第 4 版才有);
★★★ 「年化超过 21%」是**书里的说法,不能当我们的预期写**。
