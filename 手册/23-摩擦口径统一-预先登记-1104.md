## 二 · ★★★ 影响面:跑之前算出来的(42 条链实测)

★ 方法:读考卷那一轮的流水(`probe/exam_run_1102/ledgers_1102/`),
★★ 用**名义金额加权**(`notional_in + notional_out`),不是笔数加权,
★ 按每笔自己的 `liquidity_tier` 重算三档下的摩擦,得到倍数。

### 2.1 ★★ 总览

| | 摩擦倍数(中位) |
|---|---:|
| **策略**(REAL) | **2.55×** |
| ★★★ **随机对照组**(CTRL) | ★★★ **3.12×** |
| | ★★ **39 条 / 42 条,对照组涨得更多** |

### 2.2 ★ 为什么(一个实例,技-5 XING 版)

| | 高流动性 | 中流动性 | 低流动性 |
|---|---:|---:|---:|
| **策略持仓** | ★ **62.3%** | 25.5% | 12.2% |
| **随机进场** | 37.0% | 35.6% | ★ **27.4%** |

★★★ **策略选的票流动性明显更好。** ★ 而三档摩擦就是按流动性罚钱 —— ★★ 所以随机进场被罚得更重。

### 2.3 ★★ 三个例外(已登记,要单独看)

| 链 | 策略倍数 | 对照倍数 |
|---|---:|---:|
| 技-11 · 行业版(后人量化版 Spring) | **3.97×** | 3.17× |
| 技-11 · ★旧实现(一日合并版) | **3.97×** | 3.17× |
| 技-11 · 行业版(下刺 0.15~0.80ATR) | **3.97×** | 3.17× |

★★★ 这一族(技-11)的**持仓流动性比随机进场还差** —— ★ 所以统一摩擦对它是**双重打击**。
★★ 跑完要单独看这三条,★★★ 并且在说明书里写明:**这一族挑的是流动性差的票**。

### 2.4 ★ 绝对影响有多大(一个实例)

```

  现在:摩擦总额 $218,465   净盈亏 $8,238
  ★★★ 三档之后(2.13× 粗估):摩擦约 $465,000,增加约 $246,500
  ★★★ 也就是说 —— 这条链会从「赚 $8,238」变成「亏约 $238,000」。

★★ **所以绝对成绩会明显变差,这一点要提前跟团队说清**,★ 不然看到结果会以为出了 bug。

### 4.1 ★★★ 连带影响一:`buy_and_hold` 是我们的 sanity check

★★ 查出来的(`engine/bench_run_1029.py:160-205`):★★★ **它不只是锚点,它是「能认出自己坏了」那个检查点(硬纪律第 11 条)**。

```
★ 它的逻辑:从不空仓 → 环境过滤一条规则都没有 → 闸门全程开着
  → ★★ 同敞口口径下「择时贡献」必须**恒等于 0**、加法恒等式残差必须**恒等于 0**
★★★ 原话:「**它不通过,这一轮的所有择时/选股拆分数字全部作废**」
★ 为什么要有它:之前出过三次「静默失效」(exit.rules 没被执行 / ranking 被忽略 /

★★★ **改了摩擦会不会把它弄坏?——我的判断:不会,但有一个数会变。**

| 检查项 | ★ 会不会受影响 | 为什么 |
|---|---|---|
| 闸门全程开着(关闸天数 = 0) | ❌ 不受影响 | ★ 和摩擦无关 |
| ★ 择时贡献恒等于 0(**同敞口口径**) | ❌ 不受影响 | ★★ 同敞口口径会把敞口差归一化掉 |
| 加法恒等式残差恒等于 0 | ❌ 不受影响 | ★ 同上 |
| 静态基准与动态开关基准逐日相同 | ❌ 不受影响 | ★ 那是基准之间的比较,和这条链自己的摩擦无关 |
| ★★★ **原文口径下的差额** | ✅ **会变大** | ★★ 文件自己写了:那个差额 = Ē(实测 **0.981**,★ 「**因为有零头现金和摩擦**」)和 1.0 的敞口差 —— ★★★ 摩擦变多 → Ē 变小 → **差额变大** |

★★★ **所以要提前写明**:跑完之后看到「原文口径差额变大」,★★ **那是预期的,不是 bug**。
