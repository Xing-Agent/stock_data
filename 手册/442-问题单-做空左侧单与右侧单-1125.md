# 442 · 给 Gemini 的问题单：做空的左侧单和右侧单（先给 Lin 过目）

**背景一句话**：我们在做一套照 Wyckoff / Sniper 体系的做空规则。Lin 的理解是做空分两种单：

- **左侧单**：价格还没跌破核心位置，看顶部的派发形态就先空。
- **右侧单**：跌破核心位置之后，等反弹回来确认「没过」，再接着空。**不是跌破当时追空。**

我们自己拿过去的数据试过几种写法，结果都不好（见最后一节）。想请你照原著和行业通行做法，把这两种单说清楚。**每一条请标明出处：是哪本原著 / 哪位作者说的，还是行业惯例，还是你自己的推断。没有出处的数请直接说「原著没给」。**

## 一 · 左侧单（没破位，看派发形态先空）

1. Wyckoff 派发结构里，哪几个位置是原著认可的左侧做空点？（比如 UT、UTAD、LPSY）各自的认定条件是什么？
2. 每个位置的进场扳机是什么（哪根 K 线、什么量价）？止损放哪？
3. 原著或行业有没有说哪个位置成功率高、哪个低？有没有说仓位该怎么分（比如左侧先小仓）？
4. 怎么区分「派发」和「上涨中途的再吸筹」？原著给的判别点有哪些？这是我们左侧单最大的坑：认错了就是空在上涨中继。
5. 左侧单要不要求大周期先有条件（比如月线、周线已经出过顶部信号）？

## 二 · 右侧单（破位后，反弹没过再空）

1. 「反弹确认没过」原著怎么定义？反弹到哪算到位（原支撑位下沿、破位 K 线的一半、还是别的）？
2. 「没过」的扳机是什么：反弹量缩、出现上影线、收盘收回破位价以下，还是别的？要等几根 K 线？
3. 止损放哪（反弹高点上方、还是原支撑位上方）？
4. 如果破位后根本不反弹、直接跌走，原著怎么说：放弃，还是有别的进法？
5. 第一次反弹没过、第二次反弹没过，原著或行业有没有说哪一次更好？
6. 反弹如果收回到核心位置上方（假跌破），原著怎么处理：马上撤，还是反手？

## 三 · 两种单的共用问题

1. 「核心位置」原著怎么定？Lin 的做法是几样叠加（趋势线、前一段的压制、均线或区间中轴、0.382 / 0.5 / 0.618、缺口、小周期形态），叠得越多越重。原著或行业有没有类似的「叠加」说法？有没有说哪几样最重要？
2. 目标位怎么定？什么情况下提前走？
3. 大指数（标普、纳指）、行业 ETF（SOXX）、个股、BTC，做空规则要不要分开？行业通常怎么分？
4. 牛市里的回调和真正转熊，做空规则有什么不同？行业有没有「牛市里不做空 / 只做右侧」这类通行规矩？

## 四 · 三种开法怎么配合（Lin 11-25 补充）

Lin 的实际做法不是只有一种开法，而是下面几种配合着用：

- **开法 A · 跌破当时追空**：可以做，但空头里跌破之后常有一次反抽确认，追进去的单子要扛这一下。
- **开法 B · 左侧先空，跌破后右侧加仓**：跌下去之后如果看到要反弹确认了，**先平掉一部分，甚至全平**；等反弹确认没过，再在那个位置重新开。
- **开法 C · 跌破不追，只等反弹没过再空**：问题是**不是每一次跌破都会有反弹**，等不到就错过了。

请回答：

1. 原著或行业对这三种开法各自怎么说？有没有通行的配合方式（比如跌破当时先开一部分、留一部分等反抽）？仓位一般怎么分？
2. 开法 B 里「看到要反弹确认了」靠什么判断（跌到哪、出现什么量价）？平一部分还是全平，原著或行业有没有说法？
3. 跌破之后「会反抽」和「不反抽直接走」，事前有没有办法区分（比如破位那根 K 线的量、破位的幅度、大周期所处的阶段）？
4. 有没有公开的统计：跌破关键支撑之后，出现反抽确认的比例大概是多少？（有的话请给出处；没有就说没有）

## 五 · 我们自己试过的（给你参考，不用评价数字）

| 写法 | 结果 |
|---|---|
| 跌破后直接追空 | 24 个品种合计不赚，只有 BTC、ETH 是正的 |
| 大指数「第 1 次跌破就空」 | 标普、纳指、道指全亏 |
| 大指数「第 2 次跌破才空」 | 纳指小赚，道指打平，标普亏；样本只有个位数 |
| 美股「四步做空」（跌破 → 反弹 → 没过 → 空）试了三轮 | 三轮都亏 |
| 压力位「假突破后收回」再空 | BTC、ETH 是正的（样本小）；SOXX 是亏的 |

我们怀疑问题出在两处：一是「核心位置」我们只用了单一因素，没有叠加；二是「反弹没过」的认定写得太粗。请你重点看这两处原著是怎么写的。
