# 376 · 「先挑票、再技术面进出场、再分仓位」连起来试的结果（2026-11-22）

**一句话：2015–2025 这十一年，把动量和营收增长都排在前面的票挑出来、买了拿着不动，每年赚 13.5%，比不挑（8.1%）高出一截；在这些挑中的票上再用技术面策略做进出，五条里没有一条比「拿着」赚得多，多数还把挑票的好处丢掉了。「大盘关了就全卖、开了再买回」把收益砍掉一半多，最惨跌幅却没有变浅。也就是说，这十一年的收益主要来自「挑对票并拿住」，和你昨晚说的一致。**

> 只有一段时间，而且是美股最强的十一年。营收数据撑不起更早的十年，所以 2008 年那种行情下这套结论成不成立，这次答不了。
> 挑票的规则是我自己起的第一版，不是原著，也不是你定的。先看方向。

## 怎么测的

- **范围**：研发池里每天成交 1000 万美元以上的票，每天约 900 只。含分红。2015-01-02 到 2025-12-31。
- **挑票**（门槛各跑相邻三档）：
  - 动量：过去 12 个月的涨幅（跳过最近 1 个月）排前 20%。每天约 175 只。
  - 增长：最近四个季度营收合计比一年前高，增速排前 30%。财报公布后第二个交易日才算数。每天约 200 只。
  - 两样都中：每天约 56 只。
- **进出场**：5 条已有的技术面策略原样用，只限制它们能挑的票。
- **仓位**：每笔按「打到止损亏账户 0.5%」定大小，单票最多 20%，不加仓。
- **新加的一把尺子**：「每跌一分赚几分」= 每年赚 ÷ 最惨跌幅。数越大越好。这是照你说的，不拿「纳指拿着不动」当及格线，改看承担每一分回撤换来多少收益。

## 结果一：挑票本身有用（买了拿着不动）

| 挑哪些票 | 每年赚 | 最惨跌掉 | 每跌一分赚几分 | 最差一年 | 最赚的 5 只占总利润 |
|---|---:|---:|---:|---:|---:|
| 不挑（整个流动性池） | 8.06% | −38.7% | 0.21 | −22.9% | 14% |
| 只看动量前 20% | 10.33% | −37.0% | 0.28 | −28.7% | 45% |
| 只看增长前 30% | 8.90% | −40.9% | 0.22 | −26.0% | 58% |
| **动量前 20% + 增长前 30%** | **13.50%** | −45.1% | 0.30 | −36.0% | 85% |
| 松一档（动量 30% + 增长 40%） | 11.97% | −38.9% | 0.31 | −30.1% | 72% |
| 紧一档（动量 10% + 增长 20%） | 15.00% | −53.0% | 0.28 | −46.2% | 99% |
| *对照：标普 500* | *13.47%* | *−33.7%* | *0.40* | | |

- 三档门槛方向一致：**挑得越严，赚得越多，跌得也越深。**
- 「每跌一分赚几分」从 0.21 提到 0.30 左右，三档差不多。
- **利润极度集中**：两样都中的那一档，904 只票里最赚的 5 只贡献了 85% 的利润；紧一档是 99%。也就是说，这个收益靠的是押中了极少数大牛股并且一直没卖。
- 动量单独用就有效，增长单独用几乎没用（8.9% 对 8.1%），两样叠起来最好。

## 结果二：在挑中的票上做技术面进出，没有加分

每条策略四种范围并排（每年赚 / 最惨跌掉 / 每跌一分赚几分）：

| 策略 | 原样（不挑票） | 只加动量 | 只加增长 | 两样都加 | 两样都加 + 按风险定仓位 |
|---|---|---|---|---|---|
| 趋势跟踪 | 4.9% / −22% / 0.22 | 8.5% / −25% / 0.34 | 6.3% / −24% / 0.26 | 4.8% / −21% / 0.23 | 7.8% / −25% / 0.31 |
| 海龟（技-1） | 6.0% / −49% / 0.12 | 1.8% / −57% / 0.03 | −5.7% / −69% | −7.5% / −76% | 1.6% / −61% / 0.03 |
| 阶段分析（技-3） | 8.8% / −23% / 0.38 | 4.3% / −34% / 0.13 | 6.6% / −32% / 0.21 | 5.3% / −35% / 0.15 | 8.7% / −33% / 0.26 |
| 突破买入（技-4） | 2.4% / −38% / 0.06 | 3.9% / −29% / 0.13 | 1.5% / −30% / 0.05 | 2.0% / −20% / 0.10 | 2.3% / −26% / 0.09 |
| 技-6 | 5.9% / −27% / 0.22 | 4.0% / −26% / 0.15 | 2.2% / −45% / 0.05 | 7.0% / −30% / 0.23 | 10.3% / −37% / 0.28 |
| *对照：同样的票拿着不动* | *8.1% / −39% / 0.21* | *10.3% / −37% / 0.28* | *8.9% / −41% / 0.22* | *13.5% / −45% / 0.30* | |

- **「两样都加」那一列，5 条策略每年赚 −7.5% 到 7.0%，同样的票拿着不动是 13.5%。** 没有一条赢。
- 换成「每跌一分赚几分」这把更公平的尺子：拿着不动是 0.30；5 条里最好的是趋势跟踪加动量的 0.34 和阶段分析原样的 0.38，其余都低于 0.30。**也就是最好的情况下打平，多数情况下更差。**
- 加了挑票以后，5 条策略里只有趋势跟踪加动量是三档门槛都变好的。海龟和阶段分析加了挑票反而变差：它们本来靠在很多票里撒网抓少数大行情，把范围收窄以后，网里的鱼少了。
- 换门槛，「两样都加」那一列很不稳：技-6 是 7.0%，松一档 1.2%，紧一档 1.5%。

## 结果三：按风险定仓位，有一点帮助，但主要是因为仓位更满了

「两样都加」对「两样都加 + 按风险定仓位」，5 条策略：

- 每年赚：5 条都提高了（4.8→7.8、−7.5→1.6、5.3→8.7、2.0→2.3、7.0→10.3）。
- 每跌一分赚几分：4 条提高，1 条略降。
- 但平均仓位也从 27%–92% 变成 16%–90%，其中三条明显更满（27→36、73→90、67→87）。**多赚的那部分，大半是因为钱用得更足，不是因为分得更聪明。**

## 结果四：「大盘关了就全卖、开了再买回」在这十一年是亏的

你昨晚说的做法是「选中了拿着，中间根据市场环境减仓、再加仓」。我先试了最简单的一版：挑中的票拿着，大盘开关关了就全卖，开了再买回。

| 挑中的票（动量 20% + 增长 30%） | 每年赚 | 最惨跌掉 | 每跌一分赚几分 | 最长多少天不创新高 |
|---|---:|---:|---:|---:|
| 拿着不动 | 13.50% | −45.1% | 0.30 | 732 |
| 行业版开关，关了全卖 | 5.85% | −49.6% | 0.12 | 1,226 |
| Faber 月线，关了全卖 | 5.07% | −58.4% | 0.09 | 1,229 |
| 温斯坦周线，关了全卖 | 4.88% | −50.5% | 0.10 | 1,229 |
| 任何一种开关，只是不开新仓 | 13.5% 上下 | −45.1% | 0.30 | 约 730 |

- **三种开关，全卖再买回，每年赚都砍掉一半多，最惨跌幅没有变浅，反而更深。** 松一档的范围、整个流动性池上结果一样。
- 原因和这两天所有测试是同一个：这十一年大盘每次转弱之后多数是很快涨回来，卖在低点、买回在高点。
- 「只是不开新仓」对拿着不动没有影响，因为它本来就不卖。
- 这**不等于**「按环境减仓」没用。我只试了最粗的一版（全卖、全买回，只看标普和均线）。你说的是在对的点减一部分、再加回来，那个要另写规则。而且这十一年里没有 2008 年那种跌得久的熊市，大盘开关最有用的场合没出现。

## 我的读法

1. **你昨晚说的是对的，数据支持**：这十一年，最好的做法就是挑中强的票拿住。技术面的进出场、大盘开关，在这段行情里都是在往下减收益。
2. **所以技术面这些零件的价值不在「多赚」，而在「拿得住」**。拿着不动那一行，最惨要扛 45% 的回撤、最差一年亏 36%、两年不创新高。几乎没有人能扛下来。趋势跟踪加动量那一格每年赚 8.5%、最惨跌 25%，是一个普通人更可能照着做下来的版本。这才是它该被拿来比的方式。
3. **挑票这一环比我们之前花的力气该得的多。** 这一个月大部分测试花在进场、止损、仓位、开关上，这些都是零点几个 R 的事；挑不挑票是每年 8% 和 13.5% 的事。
4. **但挑票的收益靠极少数票**：最赚的 5 只占 85%。漏掉它们中的一两只，或者中途被震出去，结果就完全不同。这也解释了为什么在这些票上做进出会变差：进进出出最容易丢的就是那几只。

## 要打的折

- **只有一段时间，而且是最强的一段。** 更早的十年没有营收数据。动量那一半可以单独在 2005–2014 上跑，我接着做。
- 挑票规则是我起的。流动性池里约三成的票没有营收增速数据，被「增长」条件直接筛掉了，不是因为增长慢。
- 研发池里约三成是后来退市的票，所以「拿着不动」那一行已经包含了拿到退市的情况，这一点没有偏好看。
- 没有扣除持仓集中带来的现实问题：904 只票等权重买入、拿到底，实际操作不了。这一行是「挑票这件事本身值多少」的度量，不是一个能照做的策略。
- 一次跑了 5 条策略 × 11 种范围。我只报了三档门槛方向一致的结论，单个格子的好数字（比如技-6 加仓位的 10.3%）不当结论。

## 接下来（我的建议，等你定）

1. **把挑票这一环做扎实**：这是产品里选股卡和基本面大师该讲的东西。先在 2005–2014 上验动量那一半；再试你说的「流动性好、增长快」的其他写法（利润增速、毛利率变化）。
2. **「按环境减一部分、再加回来」写成具体规则再测**：减多少、看什么减、看什么加回。这个我想先听你说你实际是怎么做的，或者放进《369》让 Gemini 给一版。
3. **产品上的说法**：技术面大师帮用户的是「怎么拿得住、最坏亏多少」，不是「怎么多赚」。这句我建议写进「这版新在哪」。
