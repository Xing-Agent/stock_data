# 154 · 交易体系标准化：把大师模块组装成「一套体系」（草案 v0，2026-11-10）

> 起因：Lin 1110 19:07 ——「我这么用 Gemini 特别好使，是因为它了解我的交易习惯。但很多朋友、师弟师妹不行，他们多是听师傅的、按师傅那套走。如果能把我们的大师模块用简单的方法组装成一套体系让大家用，就往前进一步。」
> 参考：Lin 的 Price Action Sniper 设定（`手册/参考-Lin交易系统/`）；D 类对账（《152》）。

## ★★★ 三秒版

```
★ 发现：同一个 Gemini，挂上 Lin 的体系设定 → 能直接执行的作战计划；不挂 → 一份空话。值钱的是体系，不是模型。
★ 产品：不卖「一套体系」，卖「把体系装起来的那个框」——
   6 个固定格子（周期 · 入场 · 一票否决 · 仓位 · 出场 · 加仓），每个格子从大师模块里挑零件填。
★ 三种人：
   师傅（像 Lin）—— 把自己的打法装成一套体系，发布出去；
   学员（师弟师妹）—— 一键套用师傅的体系，只改几个跟自己有关的数（每笔亏多少、能不能做空）；
   新手 —— 回答 5 个问题，系统给他配一套默认体系。
★ 我们独有的一步：每套体系发布前，拿 2010~2025 的历史数据跑一遍，告诉用户一年开几单、最长连亏几次、最深回撤多少。
★ 之后用户问「这几个票怎么做」，回答就按他那一套的 6 个格子给 —— 就像 Lin 今天拿到的那份。
```

## 一 · 6 个格子（体系的标准骨架）

| 格子 | 管什么 | Lin 的 Sniper 填的 | 零件从哪来（我们已有的大师模块） |
|---|---|---|---|
| ① 周期与风格 | 看什么周期、拿多久 | 波段；日线 / 4 小时定方向，1 小时 / 15 分钟找确认 | 用户问卷（人×策略五问） |
| ② 看什么入场 | 找什么样的机会 | 结构 + 流动性：假突破收回、二次回踩不破、顶底转换位、斐波那契 0.5~0.618 | 方法库各卡：海龟突破、VCP、康纳斯超卖、温斯坦阶段、威科夫 |
| ③ 一票否决 | 什么情况坚决不做 | 价格在区间 35%~65% 不做；不接飞刀；盈亏比 < 1:2 不做；一个结构只开一枪 | 各卡的「什么时候别用」；大盘环境过滤；财报前不做 |
| ④ 仓位 | 一笔下多少 | 每笔固定亏多少钱，反推股数；止损 = 结构极值外 + 0.5 ATR | 仓位计算（C4 那道题的「按风险算仓位上限」） |
| ⑤ 出场 | 怎么走 | 第一目标平 40~50%，剩下的止损挪到成本 | 各卡的止损 / 止盈 / 移动止损（吊灯、均线、N 日低点） |
| ⑥ 加仓 | 赚了加不加 | 5:3:2 正金字塔；没推保本不许加；每次加仓后整体止损跟上 | 海龟的加仓规则；或「不加仓」 |

## 二 · 用户怎么拿到自己那一套

1. **选来源**：跟一个师傅的体系（如 Sniper）／从模板里挑一套／回答问题让系统配。
2. **只改几个自己的数**：每笔最多亏多少钱、能不能做空、一天能看几次盘、连亏几次要停手。
3. **看历史体检**：一年大概几单、胜率、利润因子、最长连亏、最深回撤（和满仓标普比）、时间段说清楚（《Lin 1110 要求》）。
4. **日常使用**：问任何票 → 先过③一票否决（不该做就直接说「现在不动，设提醒价 X / Y」）→ 再按②⑤④给计划。

## 三 · 先做几个模板（示意，待和 Lin 商量）

| 模板 | 适合谁 | 骨架要点 |
|---|---|---|
| Sniper（Lin） | 有经验、喜欢波段、能看盘 | 见第一节 |
| 趋势跟踪（海龟 / 温斯坦） | 没时间盯盘、能忍长连亏 | 周线/日线；突破或阶段二入场；大盘差不做；移动止损；可金字塔 |
| 超卖反弹（康纳斯） | 喜欢高胜率、小赚快走 | 日线；在 200 日线上方的超卖入场；持 2~5 天；不加仓 |
| 长线（法伯 / 均线择时） | 上班族、一个月看一次 | 月度检查；在 10 个月线上方持有、下方离场 |

## 四 · 我们现在做不到 / 要定的（细节放这里，逐条和 Lin 商量）

1. **体系从哪来**：只由我们出模板？还是允许师傅自己写体系、发布给学员？（Claude 倾向：两者都要，师傅发布是增长的来源）
2. **措辞边界**：给「如果……就……」的计划，不给「现在买」的指令。
3. **做空**：引擎只做多；Sniper 有一整套空单 SOP。
4. **小时线 / 分钟线**：Sniper 用 4H / 1H / 15m 找确认，我们目前只有日线（分钟线数据在 Lin 另一台机器上）。
5. **结构类概念要先写成能算的定义**：假突破、二次回踩、顶底转换、区间 35%~65% —— 写不成公式的，就没法回测、也没法保证每次判断一样。
6. **历史体检的口径**：每套体系发布前必须跑过回测吗？跑不过的怎么办？
