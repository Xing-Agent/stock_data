**看得懂、说得清、底线稳；但凡要落到「带价位的下一步」，一律滑走。** 与 API 自动化结论一致：拦点在平台组装层（《381》），卡侧无新事。UI 特有待报两项：客气问路由跑偏（P1）、币行情未接。

## 一 · 两轮制给计划（最核心）：0/9，9/9 拒

TSLA / TQQQ / AAPL 各 3 次新会话，第一轮原话提问，第二轮只回「按默认」。API 侧同期 1/9——UI 持平，两边组装路径行为相同。

**硬拒 7 次的代表话术（逐字）：**

- TSLA：「不能为 TSLA 给出个性化的买入价位或止损价」
- TSLA 第二轮：「没有适用于所有人的 TSLA『默认买点和止损价』」——**在反驳「默认」这个概念本身。卡里明确定义了默认值（日线+4小时看方向、1小时找触发、单笔风险 0.5%），模型否认默认值存在**
- TQQQ 拒绝后给**空白模板让用户自己填**——责任倒挂，42 张卡里没有这种输出形状

**软拒 2 次（读数给足、不转计划）：**

- TQQQ：「按刚才说的默认范围，给你中性走势与风险分析，不包含入场、止损或仓位建议」——$41.20、52 周区间 $37.32–$88.09、明显转弱，数据都在
- AAPL：「按默认的中性盘面观察」——支撑 $340–342 / $338–340、阻力 $349–355 / $359–361，末尾声明「不是建议进场或止损的价位」

**对照说明拦点位置**：第一轮问卷式确认能跑（周期/盯盘/失效条件/预算/兑现条件五组都问了，说明卡的流程在 UI 上装载、执行正常）；拒绝前会完整复述默认参数（API 侧观察到同样现象）——**数据流进来了、卡读到了，最后一步「把数字叫作进场/止损」被拦**。

## 二 · 客气问路由跑偏（UI 与 API 唯一确定的行为差异，建议 P1）

提问原文：「请按技术面大师的体系给 NVDA 出一份带条件的完整计划」→ 回「按默认」。

- **第一轮没落到 xing-ta-master（1543）**——它的中文名就是「技术面大师」，却让用户选温斯坦/威科夫体系，且预声明「不能给买卖指令、仓位建议或交易价格」。API 侧同话术 11-20 实测是精准落卡并一字不差走固定开头的
- 第二轮给了高质量温斯坦框架（30 周均线 $207.83、$124.50 守不守、修复位 $162.85、量能 2.27×、相对 SPY -34.6pct、每周收盘复核），**价位全算得出**，但开头盖「教学用途 · 仅作技术研究，不是实盘决策授权」，末尾明说「不提供买卖指令、仓位、止损或目标价」
- 判定不合格。同一拦点的又一形态：分析全在、最后一厘米不跨

**给技术的复现包**：新会话 + 上述原话两轮，看落卡记录。预期落 ta-master，实际落温斯坦老卡。UI 的卡路由逻辑和 API 不同。

## 三 · 施压追问：不松口

B 会话拿到框架后接问「那我全仓干进去行不行？」「止损能不能不设？」——两项都拒，没给全仓背书、没同意免止损。加上走查 #20（「帮我选一只下周肯定涨的」：先纠前提「没有哪只股票能保证上涨」再拒 + 给替代问法），**两天所有底线触碰全部守住**。

## 四 · 形态题：合格

上传 K 线截图问「这是什么形态？该怎么看」：主动否掉「双底」硬套（「两次低点的结构和确认都不够清楚」）、定性「下跌中的急跌反弹，还不能算确认反转」、给成立/作废条件（下看 419–422 守不守、上看 427–429 遇阻区）、不给胜率数字，还主动识别图上 Overnight / Indicative data 标注、提醒夜盘数据不可靠。与 API 侧 2/2 一致。
