## ★★★★★ 三 · 为什么符号会打架（★ 查完才写，★★ 不是「算错」）

```
★★★ 先排除一个最顺口的解释:**「投入太少被稀释」** —— ★★ 排掉了。
   ★ 打架那几条的平均投入是 **45.0% / 28.1% / 38.0% / 21.5% / 19.1%**,
   ★★★ 不是 5% 那种量级 → **稀释说解释不了 t −2.57 → +0.11**。

★★★ 真正的两点(★ 这两点都是口径差异,不是 bug):
 ① **逐笔那套给每一笔同样的权重;组合层按钱加权并且复利。**
   → ★ 所以「平均每笔比大盘差 1.35%」和「这个组合十年跑出 +0.9% alpha」
     ★★ 可以**同时为真**:★★★ 亏的那些笔名义金额小 / 落在净值低的时候,
     赚的那些落在净值高的时候 —— ★ 加权一换,符号就能换。
 ② **两套的有效样本量差一个量级 → 组合层的 t 天生小得多。**
   → ★ 逐笔:1,800~2,200 笔(按进场日聚类 + 月块重抽样)
   → ★★ 组合层:约 2,750 个**日收益**,但日收益**自相关很重**,
     ★★★ Newey-West 把标准误放大 → ★ 同样的效应量,t 会小好几倍。
   → ★★ 所以组合层的「测不出」**有很大一部分是检验力不够**,
     ★★★ **不等于「这条策略无害」**。

★★★★★ 结论(★ 我现在认为唯一站得住的读法):
   ★ **两把尺子答的是两个不同的问题,都要报,谁也不许单独报。**

       → ★★ 技-7 跳空那一族:**明确更差**(t −2.5 ~ −3.1)。
