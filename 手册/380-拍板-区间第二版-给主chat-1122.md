## 一句话
第一版亏,是规则挑反了单,不是参数没调好:「24 根极值」不是人画的箱子;冲破时放量挑出的是真突破;箱高上限和止损下限把最好的单砍了。**第二版先拆到四个骨架,看扣成本前能不能转正,再把条件一条条加回去。** 产品上先做「位置 + 条件体检」,不直接喊空。

## 拍板(Lin 11-22 11:22–13:13 全部同意)

**【区 1】第二版:先拆到骨架,再一条条加回**
- **骨架(四样):**
  1. **箱子用 1 小时摆动高低点画**(左右各 3 根):24~96 根里 ≥ 2 个高点 + 2 个低点;两个高点隔 ≥ 6 根、价差 ≤ 0.35 倍 ATR(1H);箱顶 = 高点均值,箱底 = 低点均值。还要过「上下交替检验」,排除斜着走的通道。
  2. **箱顶碰上大周期阻力**(±0.5 倍 ATR(1H) 以内):前一天 / 前 3 天高点;或 4 小时(用 1 小时合成)60 根内的摆动高点;或日线 20 / 50 / 200 均线压在上面。
  3. **扳机:第二次冲不过前高。** 第一次高点 H1 回落 ≥ 0.35 倍 ATR(1H) 到 L1;1~4 小时内第二次冲到 H2 < H1;15 分钟阴线收盘跌破 L1 就空。
  4. **止损 = max(H1, H2) + 0.12 倍 ATR(1H)。**
- **加回去测(每次加一条,报帮了还是害了):**
  - RSI 背离(第二次碰顶 RSI 低 ≥ 3)/ 1 小时 RSI ≥ 62;
  - 冲顶缩量(< 0.85 倍)/ 反转阴线放量(≥ 1.2 倍);
  - 资金费率 ≤ −0.01% 不空;
  - 只在伦敦盘(UTC 7–11 点)、纽约盘(UTC 13–17 点);周末做 / 不做;
  - 日线 RSI ≤ 32 或 3 天跌 ≥ 10% 不空;
  - ATR 异常 1.8 倍;
  - 同一箱顶 1 次 / 2 次;
  - 到中轴推保本 / 不推(到 1R 平一半、止损只挪到 −0.3R)。
- **并排比:**
  - **三种箱子:** 摆动点聚类 / 近似成交密集区(70% 价值区)/ 前一天高低点 + 亚洲盘高低点。
  - **三种扳机:** 第二次冲不过 / 到位不破、连续上影(止损 = 箱顶 + 0.25 倍 ATR(1H))/ 两步确认(冲破收回后 1~3 根内再跌破那根的最低点)。
  - 第一版留着当对照。
- **日线下跌时:** 不在 1 小时小箱子顶上空;改测「反抽到 4 小时 / 日线阻力再空」。
- **成本两种都报:**
  - 吃单价(来回 0.10% + 止损滑点);
  - 挂单价:触发后挂在 收盘价 + 0.25 ×(止损 − 收盘价),30 分钟不成交就撤,按挂单费 0.02% 算;没成交的不算。

**【区 2】样本:先改规则,再加币,不降门槛**
- 先让 BTC、ETH 单品种自然多出手,目标每年 ≥ 100 笔。
- 骨架版扣成本前转正后,再加 SOL、BNB 等 4~6 个主流币;同一小时几个币同时出的信号,合并成一次算。
- 单品种 ≥ 300 笔的门槛不降。

**【区 3】Lin 给 10~20 笔自己的手动区间顶底单**
- 每笔要:品种、时间(到小时)、进场、止损、出场、一句话理由。亏的也要。
- 拿到后逐笔对照规则:
  - 规则抓到几笔、漏几笔、漏在哪一步;
  - Lin 没做、规则做了的单,结果怎么样。

**【区 4】产品先做「位置 + 条件体检」,不直接喊空**
- **系统负责:**
  - 标箱体和大周期阻力;
  - 到顶时列出:位置分、背离、缩量、资金费拥挤度、日线逆风警告;
  - 算好仓位、止损、杠杆上限。
- **扳机:** 用户自己按;系统只说现在满足了哪几条。
- **机械「现在空」信号:** 过了上线门槛(≥ 300 笔、每笔 ≥ +0.15R)才开。
- **复盘:** 给用户看「在系统标的好位置开单」vs「在悬空位置开单」的盈亏差。
