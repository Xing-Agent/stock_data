# 第 2 屏 · 这件事为什么难（★★★ 这一屏最重要）

```
★ 难的不是算不出来。
★★★ 难的是:**算出来的东西和编出来的东西，在屏幕上长得一模一样。**
```

## ★ 一个真实的例子

我们本来要做一步估值：`公司值多少钱 = 每年赚的钱 ÷ 一个折扣率`。

```
★ 那个折扣率，我们的数据库里**当时没有**。
★★ 如果随手填一个 9% 进去，界面上会显示:
      「这家公司的公允价值是 **1,240 亿美元**」
★★★ 一个精确到个位、看起来**和真算出来的一模一样**的数字。
★ 而用户没有任何办法知道:那里面有一个我们随手填的 9%。
```

★★★ **这不是「不准」的问题，是「看不出来不准」的问题。**

★★ 比「这只票很有潜力」危险得多 —— ★ 因为后者用户知道那是看法，★★★ **前者长得像事实**。

→ ★ 所以我们**把那一步整步停用了**，没有编一个数填进去。

# 第 3 屏 · 我们只有一条规矩

```
★★★ **算得出来的可以给，猜出来的不能给。**
★★ 猜出来的也可以给 —— ★★★ 但**必须让人看出来那是猜的**。
```

★ 整套系统剩下的全部东西，都是为了**对我们自己**执行这一条。

## ★★ 落地的样子：每一句话都带一个「出处等级」

| 档 | 这句话从哪来 | ★ 用户看到什么 |
|---|---|---|
| **①** | **原著** —— 书里原文查得到 | 「O'Neil 原文：7~8% 止损」 |
| **②** | **行业改进** —— 通行做法，★★ **而且我们自己跑过** | 「行业通行，我们验证过」 |
| **③** | **XING 修正版** —— 我们回测之后改的 | 「我们改的，原因是…」 |
| **④** | **用户自己的** —— 他自己调的 | 「你设的」 |
| ★★★ **⑤** | **外部模型回答 · 未经我们测试** | ★ 「未验证」 |

★★★ **第 ⑤ 档是外部模型的默认落点。** 要往上爬只有两条路：

```
★ 在原著里**查得到原句**        → 爬到 ①
★★ 我们**自己跑出来并验证**      → 爬到 ②
★★★ **它自己说自己是原文，不算。**
```

# 第 4 屏 · 我们造了两个「大师」

★ 大师 = 一份给 AI 的行为说明书：**它会什么、不会什么、哪些话不许说**。

| 大师 | 它干什么 | 规模 |
|---|---|---|
| ★★ **技术面大师** | 看图、看形态、看量价 —— ★ 海龟、康纳斯、威科夫那一路 | 298 行 |
| ★★★ **基本面大师** | 看财报 —— ★ 质量、成长、估值、分红那一路 | **664 行** |

★ 另外还有 6 张辅助卡（入口路由 · 筛选器 · 报价 · 复盘 · 两个构建器）。

## ★★★ 它们**不是**什么

```
❌ 不是「给你一个买入建议」—— ★ 它给的是「按**你选的那套体系**，这只票符合几条」
❌ 不是「我们的看法」—— ★★ 每一条都要能指回一个出处等级
❌ 不是无所不知 —— ★★★ 卡里专门有一节写「**我们没有哪些数据，所以这件事做不了**」
```

## ★★ 一条我们今天才立的纪律

```
★★★ **任何「我们没有 X」的声明，必须附上「我在哪里查过」。**
★ 为什么:实测发现卡里有 **2 条**「我们没有」是**写错的**(东西就在仓库里),
  ★★ 还有 **8 条是「有一半」**。
★★★ 而「有一半」被写成「没有」，后果和写错一样严重 ——
   ★ 用户问到那一半，卡照样拒答。**等于我们自己把功能关掉了。**
```

# 第 5 屏 · 大师背后那条线（★ 共用边界）

★ 两个大师共用一份「不许越过的线」（194 行）。★★ 里面最要紧的两条：

## ★★★ 一 · 拒答的六类

★ 大师**必须拒答**的六类问题（★★ 涉及个人财务处境、法律税务、确定性承诺那一类）。

## ★★★ 二 · 「不能做，必须给出口」

```

★★★ **说不了什么，就必须说清能说什么。**

★★ 举个我们写进去的例子:
   ❌ 「平台会在到价时提醒你」—— ★ 而条件引擎还没做
   ✅ 「你自己定个日子回来看」
   ★★★ 原话是:「平台不能提醒，而文案里写了『会提醒你』——
      **那是平台在骗他**。」
```

# 第 6 屏 · 一条策略要怎样才算「能出厂」

★ 每条策略出厂前要交一张**说明书**，★★ 规格书定了**十二格**。

| 几格 | 格子 | ★ 必填 |
|---|---|---|
| 1 · 2 | 这是哪个版本 · **规则逐条的出处** | ★ 是 |
| 3 · 4 | 要什么市场环境 · 要什么样的股票 | |
| ★★ 5 | **这个条件在这些年里成立了多久 · 哪几年完全不成立** | ★ 是 |
| 6 · 7 | 牛熊横盘分层 · 条件成立时的收益 | |
| 8 | 两条基准线（★ 和随机进场比 · 和大盘比） | |
| ★★★ 9 | **代价 —— 最大一次亏多少美元 · 最长连亏几次** | ★ 是 |
| 10 · 11 | 明确不适用什么 · 这个数字结实不结实 | |
| ★★★ 12 | **样本外** | ★ 是 |

## ★★★ 第 9 格为什么一定要用美元

```
★ 百分比零售端读不出痛感。
★★ 「最大回撤 18%」和「**这一笔亏了 1,800 美元**」是两种东西。
★★★ **代价这一格必须让人疼一下。**
```

## ★★ 第 5 格为什么是必填

```
★ 如果一条策略只在 2020–2021 那两年成立，★★ 那它的多年平均成绩**没有意义** ——
★★★ 用户买的是「**它现在还成立吗**」。
```

# 第 7 屏 · 我们怎么防自己作弊（★★★ 这一屏是核心）

★ 最容易骗人的不是外人，**是我们自己** —— ★★ 因为我们想要好结果。

## ★★★ 三道卡口（机器自动查，不靠人自觉）

```
★ 第一道 · **两道门**      —— ① 保真度:和原著一致吗  ② 统计:这个数结实吗
★★ 第二道 · **标准答案集**  —— 10 条策略链的结果**冻起来**。
     ★★★ 以后改任何代码，这 10 条的数字**必须一个字不差**;
        ★ 变了就必须说出是哪一处改动造成的 —— **说不出来就是你改坏了东西而不知道**。
★★★ 第三道 · **出处 grep**  —— ★ 不查「出处栏填了没」，
     ★★★ 查「**这个数在原著原文里真的搜得到吗**」。
```

★ 另外还有 **16 道**自动体检（恒定输出检测、阈值 vs 分布、静默截断、缺省值不许表态…）。

## ★★★ 考卷 —— 我们给自己出的期末考

```
★ 我们所有策略，都在同一批股票上反复测过很多轮。
★★ 问题:★★★ **那些结果我们全看过了，不能再当考试用** ——
   ★ 看过答案的卷子，考多少分都不算。

★★★ 所以我们另外准备了一份考卷:**1,026 只我们从来没碰过的美股**。
   ★ 门槛先锁死、名单先锁死(SHA-256)、代码先冻结(指纹 `ea289aba…`)，
   ★★ 然后才开考。
★★★ **这份考卷只能考一次。** 考完发现问题，修好的版本**不能再拿同一份考卷考**。
```

★★ 就是因为这条规矩，今天上午那次开考**作废重来了一遍** —— ★ 我们发现数据有修正没拉下来，★★★ 宁可重跑 5 小时，也不要一个不干净的分数。

# 第 8 屏 · 我们怎么用外部模型（Gemini）

★ 我们大量用外部模型查原著、要做法。★★ 但有一套**严格的流程**，因为踩过坑。

## ★★★ 四轮分离（★ 顺序不许乱）

```
第一轮 · 只要**原文**              ——「这本书原话怎么说」
第二轮 · 只要**使用条件**          ——「什么情况下该用」
第三轮 · **盲审我们的实现**        ——「我们这样写，和原著一致吗」
第四轮 · 看过成绩之后**要解释**     ——「为什么这个结果是这样」

★★★ **前三轮，一个回测数字都不给它。**
★ 为什么:给了数字，它会围着那个数字编一套解释 ——
  ★★ 而我们要的是**它在不知道答案时的判断**。
```

## ★★★ 为什么要这么严 —— 一件真事

★ 我们追问它那些「权威数字」的出处，它自己承认：

> 「我存在**将大量工程经验参数与个人主观调优值包装在权威来源下**的严重问题」

```
★★ 实测:它给的全部数字里，★★★ **拿得出确切原句的只有 2 条**
   (O'Neil 的 7~8% 止损 · Paul Tudor Jones 的 200 日线)。
★★★ 另有 **6 条引文它承认是伪造的**。
```

★★ **所以我们定了一条**：

```
★★★ **外部模型推荐 ≠ 可以上线。** 必须「我们自己跑过并验证」。
★ 跑之前，它说的话只是第 ⑤ 档「未经我们测试」。
```

★★ 而且凡是卡里引用的结论，**原文必须归档进仓库查得到** —— ★ 不能只存在于某次聊天里。
