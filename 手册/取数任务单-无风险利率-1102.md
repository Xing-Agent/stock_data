# 取数任务单 · 无风险利率（★ 量极小，几十 KB）

> **三秒版：** 我们缺一样东西 —— **美国国债收益率**。
> ★ 缺了它，基本面大师卡里有**两步是停用的**（算估值、判护城河）。
> ★★ 这份数据**公开免费**，一个请求就能拿全历史。
> ★★★ 策略组这边取不了（FRED 不在我们会话的出网白名单上，curl 返回 403）。

---

## ★ 为什么要这个（★★ 大白话）

```
★ 有一种估值做法:**公司值多少钱 = 它每年能赚的钱 ÷ 一个折扣率**。
★★ 那个折扣率的第一项就是「无风险利率」= 国债利率。
★★★ 同一家公司每年赚 1 亿:折扣率 8% → 值 12.5 亿;12% → 值 8.3 亿
   —— ★ **同样的利润,估值差 50%**,全部差别来自这一个数。
★★★ 所以我们**没有编一个数填进去**,★ 而是把那两步整步停用了。
   ★★ 拿到利率之后,**这两步立刻就能开**。
```

## ★ 怎么取（★★ 三种路，哪条通走哪条）

### ★★★ 路一 · 直接下 CSV（最简单，不需要 API key）

```bash
mkdir -p rates_1102 && cd rates_1102
for id in DGS10 DGS3MO DGS2 DGS30; do
  curl -sS --max-time 60 \
    "https://fred.stlouisfed.org/graph/fredgraph.csv?id=$id" \
    -o "$id.csv"
  echo "$id → $(wc -l < $id.csv) 行"
done
head -3 DGS10.csv && tail -2 DGS10.csv
```

### ★★ 路二 · 美国财政部官网（★ 如果 FRED 也被挡）

```bash
# 每日国债收益率曲线,一年一个文件
for y in $(seq 2004 2026); do
  curl -sS --max-time 60 \
    "https://home.treasury.gov/resource-center/data-chart-center/interest-rates/daily-treasury-rates.csv/$y/all?type=daily_treasury_yield_curve&field_tdr_date_value=$y&page&_format=csv" \
    -o "treasury_$y.csv"
  echo "$y → $(wc -l < treasury_$y.csv) 行"
done
```

## ★★ 要什么口径（★ 这几条请照着做）

```
★★★ 一 · 范围:**2004-01-01 ~ 今天**(★ 和我们的行情同起点)
★★ 二 · 频率:**每个交易日一行**(★ FRED 的 DGS 系列本来就是日频)
★★★ 三 · **缺值不要填** —— ★ 美国假日那天是空的,★★ 原样保留空值。
   ★★★ 不要用前一天的数补上 —— ★ 那会让「某天有利率」这件事变成假的。
★★ 四 · 单位:**百分数原样保留**(★ 比如 `2.27` 就是 2.27%,不要除以 100)
★ 五 · 推到 `Xing-Agent/stock_data`,建议放 `probe/rates_1102/`
```

## ★ 红线（★★ 这份只有一条）

```
★★★ **缺值不许填补。** ★ 假日、停市日那天就是没有数据。
★★ 用前一天的数补上看起来很合理,★★★ 但那会让「我们知道那天的利率」变成一句假话 ——
   ★ 而我们整套规矩的根就是「**算得出来的可以给,猜出来的不能给**」。
★★ 要补,是我们在用的时候决定怎么补、并写明补法,★★★ **不是在取数这一步悄悄补掉。**
```
