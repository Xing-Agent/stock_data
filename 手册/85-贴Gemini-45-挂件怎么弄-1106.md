## ★★★ 一、我们在做什么

我们有一个经典方法库（技术面 14 张卡、基本面 23 张卡）和一套日线回测引擎。
现在想做一件事，我们内部叫「**主装备 + 挂件**」：

```
★ 主装备 = 一条完整的策略（比如海龟趋势跟随、达瓦斯箱体突破、布林带均值回归）
★★ 挂件  = **可以独立装卸的小部件**，装在主策略上改善它的某一项表现
   · 止盈类：什么时候收一半、什么时候全出
   · 止损类：初始止损放哪、什么时候往上移、移多少
   · 筛选类：在主策略的选股池之上再加一道过滤
   · 加仓类：顺势加仓的条件和份量
★★★ 关键要求：**每个挂件各自独立**，可以挂在不同的主策略上，
  并且能**单独测出它带来的变化**。
```

## ★★★ 二、我们引擎现在有什么（★ 实测列出来的，不是凭记忆）

**出场与止损机制（撮合层已实现）：**
```
· close_below_trailing_stop   移动止损（★ 有「只许上移」的铁律）
· chandelier                  吊灯止损（最高价回撤 N 倍 ATR）
· lowest_low_trail            跌破近 N 日最低价
· ema_trail                   跌破均线
· staged                      多级（保本 → 吊灯 → 均线，可组合）
· breakeven / breakeven_after_r / move_stop_to_breakeven   赚到 N 倍风险后把止损移到成本
· profit_target_r             到 N 倍风险全额止盈
· time_stop_days              持有满 N 天离场
· max_stop_distance_pct       止损距离上限
· hold_initial_stop           不移动止损
· exit_unconditional          无条件平仓
```

**仓位机制：**
```
· risk_fraction    按「这一笔最多亏账户的 x%」反推股数（★ 我们现在用的）
· fixed_fraction   固定占账户 x%
· equal_all        在可用现金里均分
· max_positions    同时最多持几只
· max_weight       单只上限
```

**选股池过滤（我们刚补了一批，engine 没改，用进程内覆盖层）：**
```
★ 原有：均线排列 · 涨幅分位 · 相对强度 · 历史波动率上限 · 成交额排名
  · Altman Z'' 排雷 · 自由现金流收益率 · Piotroski F-Score · Sloan 应计项
★★ 今天新补：市盈率分位 · 市净率 · EV/EBIT · 资本回报率(ROC) · 股息率
  · 净流动资产(Net-Net) · 稳态 EBIT ÷ 企业价值 · 利息覆盖
```

### 问题 1 —— 业内到底有哪些标准挂件？

请按下面四类，**各列出一份清单**，每条都给这三样：

| | 要什么 |
|---|---|
| ① **可计算的定义** | ★ 具体到指标和参数（★★ 原著给了数的照原著，没给的请说「惯例」） |
| ② **出处** | ★ 作者 + 年份 + 书名或期刊；★★★ 没有出处就直接说「这是我的推断」 |
| ③ **有没有独立实证** | ★ 有人专门测过这个部件本身吗？还是只是行业习惯？ |

**四类：**
1. **止盈类** —— 什么时候收、收多少
2. **止损类** —— 初始止损怎么定、什么时候往上移、移多少
3. **筛选类** —— 在策略的选股池之上再加的过滤
4. **加仓类** —— 顺势加仓的条件和份量

★★ 请**按「业内实际用得多不多」排序**，不要按教科书目录排。

### 问题 2 —— 哪个挂件配哪类策略？

我们把策略分成三类：**突破类**、**震荡（均值回归）类**、**大波段（趋势跟随）类**。

- （a）★★★ 这三类**各自最该配哪 2~3 个挂件**？请说明为什么。
- （b）★★ 有没有「这个挂件配到那类策略上会**反而更差**」的已知组合？
  ★ 请举例，并说明机制。
- （c）我们今天实测到一个现象，请你判断这个理解对不对：
  ★★★ **我们的出场比进场值钱** ——
  用「只量进场」的尺子（固定持有 5/10/20 天后减同期指数），
  我们 21 条策略臂里**没有一条的进场是正显著的**，**7 个是负显著的**；
  但按「利润因子」看，有一条臂到 1.543，而**它的进场是测不出的**。
  → ★ 我们的解读：**赚的那部分来自出场和仓位，不是来自选股和择时。**
  **这个解读站得住吗？如果站得住，挂件应该优先做哪一类？**

### 问题 3 —— ★★★ 怎么**单独测**一个挂件？（★ 这一问最要紧）

我们遇到一个方法论上的难题，请你帮我们定做法：

```
★★★ 我们原来有一把判据尺子叫「赢随机」：
   在同样的行情里随机挑一样多的票、买一样多次，两边比每笔赚多少。
★★ 今天查明：★★★ **那把尺子的随机组沿用了策略自己的出场规则** →
   所以它量的主要是**出场**，不是进场。
   ★ 证据：随机乱买那一组自己平均每笔赚 0.24 个风险单位 —— **乱买不该稳定赚钱**。

★★★ 而挂件改的恰恰就是**出场**。
→ ★★ 所以如果我们用那把尺子去测挂件，★★★ **它会自己证明自己** —— 这不行。
```

**问题：**
- （a）★★★ **测一个止盈/止损挂件，正确的判据是什么？**
  请给**具体算法**（我们能改怎么算，但不能改引擎怎么撮合）。
- （b）★★ 一个挂件的效果应该看哪几个数？我们的猜测是：
  **最大回撤**、**回本时间**、**最长连亏**、**利润因子**——
  ★ 而**不是**总收益。这个理解对吗？漏了什么？
- （c）★★★ **一个挂件带来的改善，要多大才算「真的有效」而不是噪声？**
  我们现在的做法是：|改善| > 2 × √(两边标准误²之和)。
  ★ 但我们知道这个标准误算错了方向（同一天进场的几笔不独立、收益分布肥尾）。
  **请给一个更合适的显著性做法。**
- （d）**单测 vs 组合测**：我们计划「一个挂件挂一条策略」逐个单测。
  ★★ 但如果挂件之间有交互，单测结果加起来就不等于一起装的效果。
  ★★★ **业内怎么处理这个问题？**（部分因子设计？逐步加装？）
