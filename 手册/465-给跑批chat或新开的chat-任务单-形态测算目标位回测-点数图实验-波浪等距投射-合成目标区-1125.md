## 要做的五件

1. **形态测算**：每个形态跌破（或突破）之后，走到测算位的 100% / 80% / 75% 的比例各是多少；走到之前先打到止损的比例是多少。和拍板表里 Bulkowski 的数并排（那些数是 Gemini 转述的，没核过，以我们跑出来的为准）。
2. **点数图实验**：历史上的派发区、吸筹区各算一遍，格值 0.4 / 0.5 / 0.6 倍 ATR 三种，报达成率和实际落点差多少。
3. **波浪等距投射**：ZigZag 拐点（拐点间最小 3 倍 ATR，另试 2.5、4）；百分比和点数两种量法，1 倍和 1.618 倍，各报达成率。不写自动数浪。
4. **合成目标区 + 到 T1 平 35%**：对照组是卡里现在的「第一目标平一半 + 止损移到成本」。另跑「到 T1 至少 1.5 / 1.8 倍风险才开仓」。
5. **BTC 2026-09-21 那一笔单列**：每种方法给出的目标位是多少、实际打到没有、哪天打到的。
