## 二、★★★ 我们已经知道的事实（★ 必须一起给它，否则它会给我们已经试过的东西）

```

   · 比「不装挂件」更好的：**0 / 32**

   → ★★★ 而且止损实测是 **−1.14R** 而不是设计的 −1.00R（跳空穿价 + 滑点）。
```

## 三、要问的（★ 分三组，每条都要「出处 · 可计算步骤 · 属于 (a) 还是 (b)」三样）

### 3.1 第一组 · 进场侧挂件（★★ 属于「三十」，★ 框架定了再做）

```
请逐条回答，每条给：① 出处（谁、哪本/哪篇） ② 可计算的步骤（我们要能写成代码）
③ 只有日线时的等价做法 ④ 它主要想解决什么问题

Q1  **VCP（波动收缩形态）**：怎么用日线判定「收缩」？收缩几段算成立？
    每段的幅度和成交量各要满足什么？突破点怎么定？
Q2  **假跌破（甩盘/空头陷阱）之后的二次确认**：
    怎么判定「这次跌破是假的」？二次确认要等几根K线、要满足什么条件？
    ★ 如果原做法依赖盘中，请给日线版本。
Q3  **左侧单与右侧单的结合**：
    右侧（突破确认后买）我们已经有了。左侧（在突破之前、在支撑处买）
    在趋势跟随宿主上怎么加而**不破坏趋势跟随的本质**？
    两者怎么分配仓位？各自的失效条件是什么？
Q4  **多顶/多底突破形态**：几个顶、几个底算成立？顶底之间的时间和幅度有要求吗？
    这类形态和单纯的 N 日新高突破，统计上差别在哪？
Q5  如果上面这些**在「日线 + 一天一撮合」里做不出来**，请直接标 **(b)**
    并说清它需要什么粒度的撮合，不要勉强给一个等价品。
```

### 3.2 第二组 · 离场侧（★★★★★ Q10/Q11 属于「七十」，★ 先问这两条）

```
Q6  **突破失败**：突破之后多少根K线内、回落到什么位置，算「这次突破失败了」？
    判定成立之后是全部离场还是部分？
Q7  **顶部形态成形**：涨了一段之后进入震荡 —— 怎么用日线判定「这是顶部而不是中继」？
    要看震荡的幅度、几个顶底、量能怎么变？
Q8  **背离止盈**：哪些背离值得用（价量、动量指标）？
    怎么量化「背离成立」？★ 注意我们不做合成分数，所以请给**单独的条件**，不要加权。
Q9  **分批止盈**：
    「在第二个顶就先走掉大部分」——这个「大部分」行业里通常是多少比例？
    分几批？每批的触发条件分别是什么？
    ★★★ 我们引擎有一个硬限制：**同一只票不许同时持有两笔**。
      请在这个限制下给做法（或者明说这个限制让分批止盈做不了）。
Q10 **硬止损该不该放宽**：
    我们的实测是硬止损平均 5.8 天就把单子砍掉、合计亏掉 401.9 万，
    而「跌破均线」那道门平均活 29.9 天、合计赚 446.1 万。
    → 在趋势跟随宿主上，硬止损和「形态/均线离场」应该怎么分工？
      硬止损是不是应该放宽到只做「灾难保险」（比如 2R 以上）？
    ★ 请给出处，不要只给你的判断。
Q11 **−1.14R 这个缺口**：止损实测比设计多亏 14%（跳空穿价 + 滑点）。
    行业里怎么处理「开盘跳空直接穿过止损价」？有没有标准做法？
```
