# 基本面大师卡 · 改动单 v0.3（2026-11-22，来自《245》重考）

**一句话：FTDR 在 v0.2 下还是被判「不算」—— 它的商誉 + 无形资产占总资产 61%，不是回购造成的，但现金流是真的（5 年自由现金流 / 净利润 1.22），Gemini 判半算。把「商誉虚胖」从一票否决改成两档。以 Gemini 为基准，不涉及策略取舍。**

## 改第四节「商誉虚胖」那条
原（v0.1 后）：商誉 + 无形资产占总资产 > 40%，或者最近 3 年有大额商誉减值 → 一票否决；回购造成的不算。
改为：
> **商誉虚胖**（分两档）：
> - **否决**：商誉 + 无形资产占总资产 > 40%，**并且**下面任一条成立：最近 3 年有大额商誉减值；5 年累计自由现金流 / 5 年累计净利润 < 0.8。
> - **黄灯（不否决，写进风险）**：占比 > 40%，但没有减值、现金流也撑得住 → 写「商誉占比高（××%），主要来自 ××（拆分 / 收购）；目前没有减值迹象、利润有现金流撑着；一旦出现大额减值，这条就变成否决。」
> - 只看「商誉 / 净资产」或「有形净资产为负」仍然不算命中（回购造成的会计假警报，例 KO）。
