## 二 · ★★★ O'Shaughnessy:年代错了,但规则是对的

### 2.1 年代

| | |
|---|---|
| ★ Gemini 说 | 《What Works on Wall Street》**第 4 版,2006 年** |
| ★★★ 实际 | **第 4 版:2011 年 10 月 24 日出版**(McGraw-Hill,版权页 ©2012) |
| ★ 我们原来的印象 | 2011 —— ★★ **我们对,它错**;2005/2006 那个是**第 3 版** |

★★ 这一处和「趋势价值是第 4 版才有」是连着的:★ 如果按它说的 2006,那就对应第 3 版,
★★★ 而趋势价值在第 3 版里没有 —— **年代错会让归属标错一整个版本。**

### 2.2 ★★ 规则(比 Gemini 给的更细,★ 但来源是二手)

★★★ **来源说明必须写清**:下面这套规则来自一个公开的策略说明页(quant-investing),
★★ **不是原书**。★ 所以它的档位是「★ 二手公开描述」,★★★ 要升到原著档,得有人拿着第 4 版核一遍。

```
★ 池子:市值 > $200M(原著回测里按通胀调整过)

★★★ 估值那一段 = Value Composite Two(VC2),**六个比率**:
     市净率 P/B · 市销率 P/S · EBITDA/EV · 市现率 P/CF ·
     市盈率 P/E · ★ 股东收益率(股息率 + 回购比例)

★★ 打分方式:每个比率各自排名 → 名次**加总** → 总分再排名 →
   分成 1(最便宜)到 100 的百分位
   ★★★ 这是**原著自己定义的打分** —— 按我们的新规矩,照原样复原是允许的

★ 取最便宜的 **10%**
★ 然后按 **6 个月**价格涨幅从高到低排,买**前 25 只**(★ 原著也给了 50 只版本,25 只是头条结果)
★ 再平衡:原著回测是 12 个月度组合各持一年再平均;★★ 通行实现是**年度再平衡**
```

### 2.3 ★★★ 两件对我们很要紧的发现

```
★★★ ① 六个比率里有 **EBITDA/EV** —— 而 EBITDA 正好是我们的弱项。
     ★ 实测过:EV/EBITDA 可算的票·日只有 31.1%,
       而 EV/EBIT 有 53.3% —— ★★ 差的就是「折旧摊销」那一项。
     ★★★ 所以这一条落 config 时会撞上一个选择:
        · 降配成 5 个比率 → ★ 那就**不是原著的 VC2** 了,必须标「我们的减配版」
        · 等折旧摊销的覆盖率上去 → ★★ 而《20》里折旧实测 71.9%,可能够用,要实测
        ★ 两条路都行,但**不许悄悄只用 5 个还叫 VC2**。

★★★ ② 六个比率里有 **股东收益率(股息 + 回购)** ——
     ★ 这和我们的「基-12 回购筛选」以及 Gemini 给的「总股东收益率」**重叠**。
     ★★ 所以这三样不是三条独立策略,★★★ 落 config 时要在说明书里互相指认,
        **不许让用户以为自己分散到了三条不相关的策略上。**
```

## 三 · ★★★ 最要紧的那个发现:分位一条都没核到

★★ 这是这次核实里**最该记住**的一条,因为它影响全部五条:

| 方法 | ★ Gemini 给的分位 | ★★★ 核实结果 |
|---|---|---|
| ① 毛利质量 | 「取**前 20%**」 | ★★★ **摘要里没有**。★ 全文要订阅,未核到 |
| ② 现金经营利润 | (未给具体分位) | — |
| ③ 资产扩张 | 「总资产增速**最低的 10%**」 | ★★★ **摘要里没有**。★★ 而且 RFS 那篇是**因子模型**论文,它的投资因子是用排序组合构造的,★ 摘要没说用几分位 —— ★★★ 「最低 10%」**在摘要里找不到依据** |
| ④ 净经营资产 | 「ΔNOA **最低的 10%**」 | ★★★ **摘要里没有**。★ 未核到 |
| ⑤ 趋势价值 | 「最便宜 **10%** → 前 **25** 只」 | ⚠ ★★ 二手来源**支持**这两个数(10% / 25 只),★★★ 但不是原书,**档位只能到「二手公开描述」** |

### ★★★ 所以落 config 的规矩(现在定,不许跑完再改)

```
★★★ ①③④ 的分位一律标「**我们填的**」,不标原著。
★★  并且按红线② 跑**相邻三个点**(例如 10% / 15% / 20%),
    ★ 考核标准是**三点同向稳健**,不是挑最好的那一点。
★★★ ⑤ 的 10% 和 25 只标「**二手公开描述**」——
    ★ 有人拿到第 4 版核过,再升到原著档。
★   ② 没给分位,★★ 那就按①的同一套处理:自己定三点,标「我们填的」。
```

★★ **一句大白话**:★★★ 这四篇论文**证明了「这个因子有效」,没有告诉我们「该取前百分之几」**。
★ 前者是原著,后者是我们的工程选择 —— **两件事不许混成一句话写进说明书。**

## 四 · ★★ 这次核实对「怎么用 Gemini」的两条反馈

```
★★★ ① 它在**学术论文**上可靠(四篇卷期页全对),
     ★★ 在**投资书籍和行业做法**上不可靠(年代错、作者错、方法混淆)。
     → ★ 以后问出处,**分开问**:论文归一类,书和行业做法归另一类,后者一律要我们自己核。

★★★ ② 它给「分位」的时候,**从来不说那是它填的**。
     ★ 这一轮五条里有四条的分位,摘要里根本找不到依据。
     → ★★ 以后问策略规则,要**显式加一句**:
       「★★★ 请把『原著写明的数』和『你补的数』分成两栏列,补的那一栏注明你的依据」。
       ★ 这一条已记进《03 Gemini 使用协议》的待办。
```
