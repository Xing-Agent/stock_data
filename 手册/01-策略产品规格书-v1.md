# 策略产品规格书 v1

> 版本：v1 · 2026-10-31 · 维护：策略组
> 用途：**一条策略 = 一个产品。所有策略产品用同一张规格表。**
> 升级规则：改了这份就把版本号 +1，并在文末「版本记录」写一行改了什么。

---

## 第 0 节 · 两条总规矩

```
★ 规矩一:**缺栏不许出厂;栏里写「说不清」可以出厂。**
★ 规矩二:三样东西不许出现 ——
   ① 任何对未来的预测
   ② 任何买卖方向建议
   ③ 任何我们自己合成的综合评分
```

**规矩一的意思：** 我们不靠「成绩好不好」挡产品，靠「说清楚了没有」挡产品。
一条成绩平平但每格都如实填满的策略，可以出厂；一条成绩很好但第 9 格空着的，不行。

## 第 1 节 · 规格表十二格

| # | 格 | 不许留空 | 说明 |
|---|---|---|---|
| 1 | **这是哪一档** | ★ 是 | 五档见第 2 节 |
| 2 | **规则逐条的出处** | ★ 是 | 哪条是原著的、哪条是我们填的。**这一格就是「门一·保真度」** |
| 3 | 要什么市场环境 | | 每条标出处等级 |
| 4 | 要什么样的股票 | | 市值 / 流动性 / 波动 / 行业 |
| 5 | **这个条件在十二年里成立了多久 · 哪几年完全不成立** | ★ 是 | 我们自己加的一格，见第 3 节 |
| 6 | 分层表现：牛市 / 熊市 / 横盘 | | |
| 7 | **条件成立时的收益** | | ★ 不是全期平均 |
| 8 | 两条基准线 | | ① 和同环境随机进场比 ② 和同等仓位大盘比 |
| 9 | **代价** | ★ 是 | 最大一次亏多少**美元** · 最长连亏几次 · 最长多久不赚钱 |
| 10 | 明确不适用什么 | | |
| 11 | **这个历史数字结实不结实** | | t 值 / 两段一致性。★ 可以写「样本不够，说不清」 |
| 12 | **样本外** | ★ 是 | ★ 新增，见第 4 节 |

### 第 9 格为什么要用美元而不是百分比

百分比零售端读不出痛感。「最大回撤 18%」和「这一笔亏了 1,800 美元」是两种东西。
**代价这一格必须让人疼一下。**

### 第 11 格为什么可以写「说不清」

因为 `t ≥ 3.0` **不是上线门槛**，它是说明书里的一格。详见《02-测试方法手册》第 1 节。

## 第 2 节 · 五档出处

```
① 原著                        —— 原文 grep 得到
② 行业改进                    —— 原著没有,行业通行,★ 且我们做过简单验证
③ XING 修正版                 —— 我们改的
④ 用户自己的                  —— 用户在平台上自己调的
⑤ 外部模型回答·未经我们测试   —— ★ Gemini 说的,必须标注
```

### ★ 第 ③ 档只许装两类改动

```
✅ 修实现错误       —— 我们写错了,改对
✅ 补缺失机制       —— 原著有、我们没实现。★ 必须全矩阵同步装,严禁选择性补
❌ 为了让成绩变好而调参数      ← 100% 过拟合,没有辩解空间
❌ 换基准 / 换样本区间         ← 重大违规
```

### ★ 第 ⑤ 档必须标注

Gemini 给的东西**默认落第 ⑤ 档**。要往上爬，只能靠在方法卡原文里 grep 得到（→ ①）
或者我们自己跑出来（→ ②）。**它自己说自己是原文，不算。**
详见《03-Gemini 使用协议》第 3 节第一道。

### ★ 原著版不许用我们填的东西凑完整

原著没规定的地方，原著版那一档就写「原著没规定」。
**不许拿我们的默认值填进去，然后整档标成「原著」。**

## 第 3 节 · 第 5 格（条件成立了多久）—— 这一格是我们自己加的

**理由：** 一条策略写着「要指数在 200 日均线上方才开仓」，听起来很合理。
但如果这个条件在十二年里只成立过 8% 的时间，那它实际上是一条**几乎不开仓的策略** ——
而第 7 格的「条件成立时的收益」会很好看，因为样本极少。

**实测的真例：** 有一条链三道闸的交集只剩**每天 0.17 只**可选，而槽位有 8 个 →
它跑完全程只成交 **1 笔**。另一条 **0 笔**。
如果没有第 5 格，用户看到的会是「暂无数据」，而不是「这条策略几乎不开仓」。

**所以第 5 格和第 7 格必须同屏。** 单看第 7 格会骗人。

## 第 4 节 · 第 12 格（样本外）—— ★ 新增，两行

```
第一行:「**本策略未经历史样本外验证。**」
第二行:「**自 2026-10-31 起进入纸面模拟,实时样本外成绩累积中。**」
```

### 为什么第一行必须这么写

实测：我们**没有任何干净的留出池**。

```
时间维度:2022–25 已经反复看过          → 污染
股票维度:0 只候选是没碰过的,落到 20% 哈希切分后
         ★ 49/49 = 100% 都已经跑过      → 污染
```

**这不是可以含糊过去的一格。** 写「已通过样本外检验」是假话；
留空违反「缺栏不许出厂」。所以如实写第一行。

### 第二行是唯一的出路

```
过去的数据我们都看过了,但未来的数据我们还没看过。
→ ★ 从冻结日起的行情,是我们唯一一份真正样本外的数据。
```

**第二行会随时间变得越来越有分量**，而且它是我们唯一能给用户的「不是回测」的数字。
下一批策略**一开始就锁死最后两年**，不要再重复这个错。

## 第 5 节 · 两层（不是三层）

```
咨询层  —— 大师。同样的问题,不同用户给的条件不一样,输出也不一样
策略层  —— 会自己往下跑的东西
            ★ 融合是策略的一种(复杂策略),不是单独一层
```

### 边界：**这个输出会不会自己往下跑**

```
会自己往下跑  → 策略层
不会          → 咨询层
```

**物理位置：用户按下「保存」把它变成自己的 agent 那一下。**
保存之前 = 咨询（不给具体点位）；保存之后 = 策略（给）。

### 为什么融合不是单独一层

因为它**同样的输入会给同样的输出** —— 这正是策略层的判别准则。
融合只是规则更多的策略，不是另一类东西。

---

## 第 6 节 · 两个大师入口（先做 2 个）

```
① 技术面大师    ← 突破 / 震荡 / swing 全部归这一个
② 基本面大师
★ 融合大师先放一放
```

**主体是我们自己可编码的。** Gemini 只兜那 20% 我们覆盖不了的，**且必须标第 ⑤ 档**。

**咨询层是 skill → 策略组做。**

---

## 第 7 节 · 对外说话

```
❌ 「这些方法已经失效」
✅ 「这些方法在我们的实现上没有通过检验」
```

**凡对外说某方法「失效」，必须先过门一（保真度）。**
实测乙类不一致 55 处，其中 7 条疑似是我们自己的实现错误 —— 那 7 条说「失效」说的是我们自己。

**Gemini 给的法规引用一律不能直接对外**（已核出注水）。法规的事走律师。
