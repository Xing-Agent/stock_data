# ★★★ 一 · 先说清楚：这个测试在比什么

## ★★ 1 · 我们和 Gemini 不是同一类东西（★ 这一点要先认）

```
★★★ **Gemini 的优势是真的,不要假装它不存在:**
   · ★ 它读过的书比我们多
   · ★★ 它答得顺、答得全、答得快
   · ★★★ 它什么题都能答 —— 我们有一半题会说「我们没验过」

★★★ **我们的优势只有一条,但是硬的:**
   ★ 我们卡上**每一句话都有档位**:
      · **①a** = 原著原话,我们核过原文了
      · **①b** = 原著意思,但只是手册转述,★★ 没见原文
      · **②** = 行业通行做法,★★★ **必须带出处**
      · **③** = 我们自己的
   ★★★ 而 Gemini 给的是**一锅粥** —— ★ 原著说的、行业说的、它自己编的,
      ★★ 混在一段流畅的话里,★★★ **你看不出哪句能信**。

→ ★★★ 所以这个测试的真正问题是:
   **「一锅粥」和「分了档但有一半格子写着『我们不知道』」,哪个对用户更有用?**
   ★★ 这个问题测完才有答案。★ 我现在不知道。
```

## ★★★ 2 · 所以要防一件事：我们给自己打高分

```
★★★ **这是整个方案里最要紧的一条设计。**

★ 为什么会打高分:★★ 我们自己的答案长什么样,我们一眼就认得出 ——
   · ★ 我们爱用「★」标重点
   · ★★ 我们爱写「待核」「我们没验过」
   · ★★★ 我们爱写档位标记(①a/②/③)
→ ★★ 打分的人只要看一眼就知道哪张是自己家的,★★★ **然后手就软了**。

★★★ **办法:洗牌(第三节详细说)。**
   ★ 两份答案都按同一个模板重写一遍,★★ 去掉所有能认出来的痕迹,
   ★★★ 随机编成 A/B,★ **对照表只有 Lin 一个人有**。
   ★★ 打分的人(运营)**不知道哪个是哪个**。

★★★ ⚠ 但要说清这个办法的**弱点**:
   ★ 洗牌去不掉**内容本身的指纹** —— ★★ 比如一张卡写「我们这条没验过」,
   ★★★ 那就是我们,Gemini 不会这么说。
   → ★★ 所以洗牌**只能降低偏差,不能消除**。★★★ 这一点在结论里要如实写。
   → ★ 补救:**第四节的五个维度全部写成可核的判据**(★★ 比如「出处能不能查到」
     是去查、不是去感觉),★★★ 判据越硬,认出来也没法偏。
```
