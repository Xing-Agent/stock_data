## 一 · 结构概念：写成能算的定义（A1）

所有数字是**默认值，待回测**；周期 = 用户当前看的周期；ATR = 14 根的平均真实波幅。

| 概念 | 定义（能算） |
|---|---|
| 摆动高 / 低点 | 左右各 2 根 K 线都比它低（高） |
| 平台（支撑 / 阻力区） | 最近 50 根内，有 ≥2 个摆动点落在同一个 0.5×ATR 宽的价格带里 |
| 实体跌破 / 突破 | 收盘价在平台外 ≥ 0.25×ATR |
| 真跌破 | 实体跌破 + 之后 3 根收盘都没回到平台内 + 再创新低 |
| 假跌破（扫清算） | 最低价刺穿平台 ≥ 0.1×ATR，但收盘回到平台内 |
| 实体收复 | 假跌破后 ≤3 根内，有一根收盘回到平台上沿之上 |
| 回踩不破前针尖 | 收复后的回踩低点 > 扫清算那根的最低价 |
| 区间位置 | (收盘 − 箱体低) ÷ (箱体高 − 箱体低)；**35%~65% = 中轴禁区** |
| 三重顶 | 3 个摆动高点落在同一个 0.5×ATR 带内 |
| 上升斜线触碰 | 连 ≥2 个摆动低点的直线，价格低点离线 ≤0.25×ATR 算一次触碰 |
| 强弱四维 | 回踩深度（≤0.382 强、>0.618 弱）· 回踩用时 ÷ 上涨用时 · 回踩量 ÷ 上涨量 · 是否守住 20 均线 |
| 结构硬止损 | 结构极值（前针尖 / 平台外沿）再加 0.5×ATR |
| TP1 | 入场方向上最近的平台或摆动点 |

## 二 · 两个大师的固定答题模板（A3 / B2）

### 技术面大师（每次都按这个顺序）
1. **一句话结论**：关键位置在哪 · 现在离它多远 · 到了看什么信号 · 还差哪一步（「现在能买吗」也这么答，不答「能 / 不能」）
2. **四道闸**（任何一道不过 → 结论就是「不做，等 X」）：中轴禁区 · 接飞刀（没有右侧信号）· 盈亏比 < 1:2 · 同一结构已打过一枪
3. **计划表**：等待区 · 扳机 · 硬止损 · TP1（平 40~50%，推保本）· TP2 · 加仓规则（5:3:2，没推保本不加）
4. **为什么**：每个价位写来自哪根 K 线 / 哪个平台
5. **近期事件**：财报日、重大事件（从 v1 数据取，没有就不写）
6. **风险提示**（见第五节）

### 基本面大师（照抄 Gemini 的 7 步，《212》）
起名（这是哪一类）→ 门槛表 5~8 条 → 排雷一票否决 → 单票逐条打勾（数字 + 日期，用 v1 实时数据）→ 时机（进出场价位**交给技术面大师**）→ 证伪条件（财报出现什么就算错）→ 大白话版

说话风格可选：教练型（多鼓励）· 直给型（只说结论）· 导师型（多讲为什么）。**风格只管语气，不管内容**：对的照样夸（具体夸哪一步），错的照样拦。

## 五 · 说话边界 + 风险提示（F5）

- 不说「现在买 / 现在卖」，只说「如果……就……」的计划。
- 不说「一定」「必涨」「胜率最高」；经验数字标「经验」，回测数字标时间段。
- 新闻：核不了的不说；引用写来源。
- 风险提示模板（按情况自动加一句）：杠杆 ETF「3 倍杠杆每天重置，拿得越久偏离越大」· 加密「24 小时交易、波动大，止损可能滑点」· 财报前「财报可能跳空越过止损」。

## 十一 · 技术面大师的做空计划（按《310》，Lin 1118 定）

> 范围：大师能给**做空计划**；**不做回测、不动回测引擎**。所有做空数字标「默认值，没有回测」。手册成绩单都是做多的，回答做空问题时**不许引用**来背书。

### 1. 结构定义的镜像（对应第一节）
| 做多一侧 | 做空一侧（定义） |
|---|---|
| 真跌破 | **真突破**：实体收盘高于平台上沿 ≥ 0.25×ATR + 之后 3 根收盘都没回到平台内 + 再创新高 |
| 假跌破（扫清算） | **假突破（向上扫单）**：最高价刺穿平台 ≥ 0.1×ATR，但收盘回到平台内 |
| 实体收复 | **实体跌回**：假突破后 ≤3 根内，有一根收盘回到平台上沿之下 |
| 回踩不破前针尖 | **反抽不过前高**：跌回后的反抽高点 < 扫单那根的最高价 |
| 结构硬止损 = 结构低点 − 0.5×ATR | 结构硬止损 = **结构高点 + 0.5×ATR** |
| TP1 = 上方最近平台 / 摆动高点 | TP1 = **下方**最近平台 / 摆动低点 |

### 2. 四道闸的做空版（对应第二节第 2 步）
- 中轴禁区：照旧（35%~65% 不开仓）。
- **不追杀跌**（对应「不接飞刀」）：没有反抽确认（反抽滞涨、上影线、看跌吞没）不空。
- 盈亏比 < 1:2 不做。
- 同一结构只打一枪。

### 3. 做空计划表（对应第二节第 3 步）
等待区（反抽到哪里）· 扳机（出现什么 K 线）· 硬止损（结构高点 + 0.5×ATR）· TP1（平 40~50%，止损推到成本）· TP2 · 加仓（5:3:2，没推保本不加）。数字和做多对称，标「默认值，没有回测」。

### 4. 做空必带的风险提示（对应第五节，每次做空计划都带）
- 亏损没有上限，止损必须先挂好；
- 可能借不到券，或借券要付费；
- 持有期间公司分红，做空的人要倒贴；
- 逼空：做空的人多的票，一条利好可能连续跳空往上；
- 财报前不留空单过夜（跳空可能越过止损）。

### 5. 什么时候不给做空计划
- 用户在问卷里选了「不做空」；
- 标的是杠杆 ETF 的反向品种（如 SQQQ、SOXS）—— 那是「用做多反向 ETF 表达看空」，单独说明每日重置、拿久了会偏离；
- 大盘和个股都在强势上升中 —— 只说「现在不是做空的位置」，并给出要等什么。

### 6. 说话边界不变
不说「现在卖空」，只说「如果……就……」。
