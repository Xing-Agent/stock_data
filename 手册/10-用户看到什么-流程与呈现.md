### ★★★ 「认清自己」不是一步，是**一行**（★ Lin 2026-11-03 拍板，改掉了上一版）

## ★★★ 2.1 三条走法 —— 从哪个角进来都行

```
   ① **票 → 策略**        他给一只票,我们列哪些做法的条件成立   (路 A)
   ② **策略 → 票**        他给一套标准,我们去筛                (路 B)
   ★★★ ③ **人 → 策略 → 票**  他什么都没给,先定他,再定做法,再筛票  (路 C)

★★★ 目标状态是**三个角都满足**(Lin 原话:「最好就是 3 个都满足」)——
   ★ 而「三个都满足」不是一个开关,是一句可以摆出来的话:
     「这只票符合这套做法的条件 ✓ · 这套做法你做得到 ✓ ·
       这只票的节奏合你 ✓」
★★ 缺哪一个,就把**缺的那一个**说出来 —— ★★★ 不是不给结果,是把缺口标在结果上。
```

## ★★★ 2.2 「策略」那一边有两层（★ Lin 2026-11-03 新增，之前只写了第一层）

> ★★★ Lin 原话：「这块也可以把**技术面大师和基本面大师**用上，因为我们还有
> **很多策略没有 cover**，但技术面和基本面大师可以出的，**他们这方面更强** ——
> **只要标注这个策略还没回测，需要大家自己来做。**」

| 层 | 是什么 | ★★ 有没有代价数 |
|---|---|---|
| ★★ **第一层 · 已回测** | 大师打法 + 单条判据 —— ★ 每条都跑过，有实测的代价（最大连亏 · 最长不创新高 · 止损宽度） | ✅ **有** |
| ★★★ **第二层 · 两位大师现场出的** | ★ 技术面大师 / 基本面大师按原著方法**当场给一套做法** —— ★★ 覆盖面比第一层宽得多 | ❌ ★★★ **没有** |

```
★★★ 为什么第二层值得有 —— ★ 因为第一层的覆盖面有限:
   ★★ 我们回测过的是**有限几套**,而用户问得到的做法**多得多**。
   ★★★ 两位大师在「方法本身」上比我们的回测库强 ——
      ★ 它们能按原著给出条件、给出什么情况算走坏,
        ★★ 而那些**不需要回测就成立**(它们是方法的定义,不是方法的成绩)。
```

### ★★★ 第二层的权限表（★ 这一张必须有，否则它会绕过「绑定前必须摆代价」）

| | ✅ 第二层**可以**给 | ❌ 第二层**不许**给 |
|---|---|---|
| **方法本身** | 这套做法要什么 · 什么情况算走坏 · 它看哪条线 | — |
| ★★★ **代价** | — | ★★★ **最大连亏 · 最长不创新高 · 止损宽度** —— ★ 我们**没跑过**，给了就是编 |
| ★★ **能不能绑成 agent 自动盯** | — | ★★★ **不许** —— ★ 因为绑定前必须把代价摆出来，★★ 而这一层**代价不存在** |
| **排序 / 和第一层并列** | — | ★★★ **不许混在一张表里排序** —— ★ 一个有代价数、一个没有，**不可比** |

```
★★★ 标签用 Lin 的原话,一字不改:

   ╔══════════════════════════════════════════════════╗
   ║  ⚠ **这个策略还没回测,需要你自己来做。**            ║
   ╚══════════════════════════════════════════════════╝

★★ 而且这个标签**不许折叠、不许收进二级页面** ——
   ★★★ 它和「这是谁说的」是同一类东西:**它不是脚注,它是边界。**

★ 出处上它落在「**我们填的 / 未经我们测试**」那一档,
  ★★ 和第一层(**已实测**)**不是一个等级** —— 界面上要看得出来。
```

### ★★★ 2.3 第二层用量会大 —— 而那带来一个风险和一个好处（★ Lin 2026-11-03）

> ★ Lin 原话：「这个其实我估计**很多人会用**的，而且**有帮助我们了解用户喜欢什么样的策略**。」

```
★★★ 【风险】**用量越大,「未回测」这个标签越不起作用。**
   ★ 推理很直接:第二层的覆盖面比第一层宽得多 →
     ★★ 大多数用户问到的做法会落在第二层 →
     ★★★ 于是「⚠ 还没回测」会出现在**几乎每一屏上** ——
        **而一个到处都有的警告,等于没有警告。**

★★★ 所以边界不能靠那行字,要靠**三样**:
   ① ★★★ **形状不一样,不是加一行小字。**
      ★ 第一层和第二层在界面上是**两种卡** ——
        ★★ 第一层带代价数那一块,第二层那一块**整个是空的,而且看得出空着**。
   ② ★★★ **功能权限不一样**(已写在上面那张权限表):
      ★ 第二层**不许绑成 agent 自动盯** · **不许和第一层混在一张表里排序**。
      ★★ 这一条比标签硬 —— **它是做不到,不是不建议。**
   ③ ★★ **第一层优先。** 同一个问题,**第一层有现成的就先给第一层**,
      ★ 第二层只在第一层**没覆盖**时出场 ——
      ★★★ 这样第二层出现的时候,它本身就是一个信号:
         「**这件事我们没测过**」。
```

```
★★★ 【好处】**它是我们唯一一个能知道「用户想要什么做法」的地方。**
   ★ 第一层是我们选的(我们测了哪些,用户就只能挑哪些)——
     ★★ 所以从第一层**学不到用户的偏好**,只能看到他在我们的菜单里挑了什么。
   ★★★ 而第二层是**他自己说出想要什么,我们现场给** ——
      ★ 所以它记下来的是**他真正想要的做法**,不是我们提供的做法。

★★ 值得记的三样(★ 只记做法本身,不涉及他的持仓和金额):
   ① **他问的是哪一类做法**(流派 / 周期 / 哪位大师的方法)
   ② ★★★ **第二层出场了多少次** —— ★ 这个数就是「我们的回测库差多远」
   ③ ★★ 第二层出场之后他**接着做了什么**(继续问 / 换一套 / 走掉)

★★★ 而第 ② 条有一个直接的用法:**它是回测排期的依据。**
   ★ 哪一类做法在第二层被问得最多,**下一轮就先回测它** ——
   ★★ 这比我们自己猜该测什么强得多。
```
