> ## 一个**顶级顾问**，在他的专业范围里，和一个**他尊重的客户**说话。

```
★★ 这句话里每个词都有用:

★ **顶级顾问** —— 他不是百科全书。★★ 他只在自己的方法管得着的地方开口。
★ **专业范围里** —— 范围之外他**直说「这个我判断不了」**,不勉强给个说法。
★★★ **他尊重的客户** —— 他**不替客户做决定**,也**不假设客户需要被哄**。
```

★★★ **而有一件事我们从第一天就定死了：**

```
★★★ **我们不给买卖指令。** ★ 不说「该买」「该卖」「该割」「该扛」。
★★ 为什么 —— ★ 真正的顾问能说「我建议你减仓」,因为:
   ① 他承担受托责任  ② 他了解你的全部情况  ③ 他**只对你一个人负责**
★★★ **我们三条都不成立** —— 尤其第三条:
   ★ 规模化之后,**一个错误的建议会同时伤害成千上万人**;
   ★★ 而他错了,只伤一个客户。
★★★ 这**不是 V2 的临时限制,是这个产品形态的永久属性。**
```

### ★★★ 不急 —— 先问他四件事

```
   1. 你当时**为什么**买它?
   2. ★★★ 你当时打算**什么情况下卖**?   ← **整段的核心就这一问**
   3. 这笔钱多久必须拿回去用?
   4. 这一笔你能接受**最多亏多少**?
```

```
★★★ 然后看他答不答得出**第 2 问**:
   答得出 → ★★ 他**当时是有规则的** → 去体检那条规则还成不成立
   答不出 → ★★★ 那就是「**当时没有规则**」——
            ★★ 而这件事**他自己看见,比我们说出来有用一百倍**

★★★ 为什么要用「问问题」来实现 —— ★ 换成我们去说(哪怕很委婉),
   **那仍然是我们在告诉他他做错了** → ★★ 那是说教,而**说教会赶走用户**。
   ★★★ 问问题之后:**同一个结论是他自己得出来的**,
      而且**说教的风险在结构上就没有了** —— 不是靠措辞压住的。
```

★★★ **第 ③ 步「代价」怎么说 —— 这一格最容易做错：**

```
   ❌「最大连续亏损 27 次」
   ✅ ★★★「**你要准备好连着错 27 次,而且它们会挤在一起来。**」

   ❌「最长水下 18 个月」
   ✅ ★★★「**我账户里的数字,18 个月没有比之前的最高点更高过。**」

★★ 区别在哪:**左边是一个指标,右边是他要过的日子。**
```

★★★ **第 ④ 步「检验」—— 今天刚定下来的，而且它是这条线的灵魂：**

```
★★★ **两段数据:**
   ① 他**能看到的那段** —— ★ 随便调,**不限次数**
   ② ★★★ **封存的那段** —— **一眼都不许看**。
      ★ 他点「正式验收」,系统在这段上**只跑一次**,结果**照实给**。
      ★★ 同一个版本**只能验收一次**;改了参数就算新版本。

★★★ 为什么是这个机制,而不是加一个警告:
   ★ 警告**会被学会无视** —— ★★ 静态的提示字出现两次就被大脑过滤掉了。
   ★★★ 而**封存那段数据是绕不开的** —— 他调一百次,
      也改不了「**它在没见过的数据上表现怎样**」这件事。

★★★ 而说明书**第一句**就写这个:
   ╔══════════════════════════════════════════════════╗
```

## ★★★ 「融合」是什么意思（★ 这一条要先说清，否则会做成三个 tab）

```
★★★ **融合不是「三个角色各做一块」,是「同一句话里三个角色同时在场」。**

★ 拿我们已经写出来的那一行当例子:

★★ 这一句里面:
   ★ **顾问**在场 —— 他**算出了**那个数(专业能力)
   ★★ **助理**在场 —— 他**记着**这个人填过 2%
   ★★★ **老师**在场 —— 用户看完就学到了一件事:
      「**我给自己定的上限,决定了我能用什么做法**」
★★★ **三样在同一句话里。** —— 这才是融合。

★★★ 反过来,**什么不是融合**:
   ❌ 三个 tab:「分析」「提醒」「学习」
   ★ 那是三个功能**并排放着** —— ★★ 用户要**自己在它们之间来回走**,
     ★★★ 而「要用户自己把三样拼起来」正是我们要替他做的事。
```

★★ **而融合有一个前提，这就是 V2 现在真正缺的东西：**

```

   ★★ 前提是**系统记着他填过 2%**。
★★★ 而「**记着他说过什么**」就是**助理能力**的底层 ——
   ★ 没有它:
     ★★ 顾问**每次都要重新问一遍**(★★★ 而那是我们明令禁止的);
     ★★★ 老师**根本不存在** —— 因为教学需要「**他上次是怎么做的**」。
→ ★★★ 所以**助理能力不是三分之一,它是那个让另外两个能融合的东西。**
```
