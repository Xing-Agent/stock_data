1. **出计划时整轮空白，或者出到一半断掉**（NVDA 2 次里 0 次，纳指 1 次里 0 次，TSLA 3 次里 1 次而且断尾）。页面上没有任何报错，用户只看到「想了 3 分钟」，然后一片空白。——**拿不准是卡的问题还是平台的问题**，见第 5 节。

## 4. 作为新用户最难受的三个地方

1. **等了好几分钟，什么都没有。** 问「在哪买、止损放哪」，页面显示「想了 2 分 40 秒」，然后就没了，也不告诉我出了什么问题。我只能再问一遍，结果又等 3 分钟，还是什么都没有。
2. **同一件事被问了三遍。** 「你持有 NVDA 吗？」第 2 题问一遍，第 3 题又问一遍，第 4 题还弹出表单再问一遍。而且表单出来的时候页面没自动往下滚，我差点没看到。
3. **到处是看不懂的英文。** 排队时显示「Queue paused. Resume when ready.」，转圈太久时显示「This has been waiting for over 5 minutes…」，每个回答下面的建议问题也是英文。提醒的设置页也全是英文，而且藏在一个叫「Judgement calendar」的页签里。

## 5. 归类：改卡能修，还是要平台修

| 问题 | 归哪边 | 依据 |
|---|---|---|
| 出计划时整轮空白／断尾 | **拿不准** | 看到的情况：空白前它都跑了 4–11 次计算；Q4 两次都是第一次计算报错「数据范围无效或过大」（ValueError: invalid or excessive data range）。TSLA 第 1 次断在表格中间，像是输出被截断了。但宏观题只想了 4 秒也空白，而且和 TSLA 第 3 次在同一分钟一起断，更像是平台把会话掐了。**建议先让平台查这几个会话的后台日志和额度扣费记录，再决定要不要给卡减负。** |
| 取数报「数据范围无效或过大」 | 改卡（多半） | 是卡里让它取的数据区间太长；也可能是平台接口限得太死。拿不准哪边改。 |
| 额度用完时没提示、问题直接消失 | 平台 | 402 的时候前端什么都不显示，直接跳回首页。 |
| 「你持有吗」问三遍 | 改卡 | 总入口和技术面大师卡各问一遍，表单又问一遍。 |
| 提醒频率说「约每分钟一次」，实际是每天收盘 | 改卡＋平台都要对一下 | 卡里的说法和平台实际建出来的规则不一致；要先确认平台到底支持哪种，再改卡里的那句话。 |
| 没有「打法」那一段 | 拿不准 | 那份计划断尾了，没法判断是卡没让写，还是没写到就断了。 |
| 卡里的话术被原样加引号贴出来（第 9 题） | 改卡 | 那句话在卡里是写给模型的示范，模型直接引用了。 |
| 追问建议、排队提示、卡住提示、监控页都是英文 | 平台 | 界面文字，不是卡生成的。 |
| 表单出来后不自动滚到底 | 平台 | 前端。 |
| 每次进新会话都弹引导框；「Skip」有时点了没反应 | 平台 | 前端。（鼠标点不动也可能是我这边的自动化工具造成的，**请 Lin 手动点一下确认**。） |
| 手机上表格四列太挤，价格被拆开 | 平台（表格样式）＋改卡（可以少几列） | 两边都能改善。 |
| 页面上有 11-17 的财报事件，财务栏却还停在 2027 Q2 | 平台 | 平台财务数据没跟上；卡只是照页面说。 |
| 建专家时「Instructions」必填但没标出来，空着提交会弹一串英文报错 | 平台 | 前端校验。 |
