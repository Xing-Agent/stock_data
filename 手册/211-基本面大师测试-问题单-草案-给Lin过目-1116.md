## 先要定的一件事：用不用「设定」

技术面那次学到的：**Gemini 默认模式答得差，挂上 Lin 的 Sniper 设定才强** —— 本事一半在设定里。
基本面 Lin 没有现成的设定。

**我的倾向：两遍都问。**
- 第一遍：裸问（只贴同题约束）—— 量 Gemini 本身的底子
- 第二遍：先贴下面这段「基本面设定」再问 —— 量设定能拉多少分
两遍差得多，说明设定值钱，那产品里就要做「设定」这一层（和技术面的结论一样）。

```
【基本面设定 · 草案，Lin 可以直接拿去自己用】
假设你是华尔街顶级的基本面分析大师，熟悉格雷厄姆、巴菲特、费雪、林奇、格林布拉特、
施洛斯、德雷曼、茨威格这些人的原著。回答时守这几条：
1. 先说这只票属于哪一类（烟蒂/又好又便宜/成长/困境反转/周期），再按那一派的标准看。
2. 每个结论给出用了哪几个数（估值、盈利质量、负债、现金流、回购），数从哪儿来、哪年的。
3. 必须写「什么情况下我是错的」—— 哪个数变了就推翻这个判断。
4. 必须写「最大的雷」：财务造假信号、稀释、负债、行业见顶。
5. 不知道的数直接说不知道，不要编；原著有的标准写原著，原著没有的标「行业做法」。
6. 不说空话，不先夸问题。
```

## A 类 · 方法框架（5 道）
- A1 一只股票「便宜」到底怎么判断？请分别按格雷厄姆、巴菲特、林奇三个人的标准说，并说三者冲突时听谁的。
- A2 「好公司」和「好股票」区别在哪？一个可以计算的判断流程是什么（按步骤，每步能否决）？
- A3 价值陷阱怎么识别？给可以量化的信号。
- A4 基本面选股什么时候失效？（哪种市场环境、多长时间）
- A5 基本面和技术面怎么结合：基本面选「买什么」、技术面定「什么时候买」—— 具体怎么接？

## B 类 · 单票实战（5 道，两边都给代码和日期）
- B1 KO（可口可乐）：现在按基本面算贵还是便宜？属于哪一派该看的票？
- B2 NVDA：成长股估值怎么看才不算「算命」？现在的价格隐含了多少增长？
- B3 PLTR：估值很高、还没稳定盈利的票，基本面大师会怎么处理？
- B4 一只烟蒂股（从我们 基-7 选出来的名单里挑一只）：值不值得买，最大的雷是什么？
- B5 一只回购很多的票（从 基-12 名单挑一只）：回购是真提升价值还是在掩盖问题？

## C 类 · 带需求来（4 道，模拟用户）
- C1 「我有 10 万美元，想拿 3~5 年，不想天天看盘，基本面上该怎么选？」
- C2 「我手里的 X 跌了 30%，基本面没变，要不要补仓？」
- C3 「财报出来了，营收超预期但股价跌了，基本面大师怎么看？」
- C4 「帮我把这只票的基本面翻译成大白话，我发给朋友。」（Lin 在技术面问过 3 次同类）

## D 类 · 用户挑票（2 道）
- D1 Lin 指定一只票，完整问一遍：属于哪派 → 贵不贵 → 最大的雷 → 什么情况我是错的
- D2 同一只票，问「基本面 + 技术面一起看，现在该怎么做？」—— 看它能不能把两边接上
