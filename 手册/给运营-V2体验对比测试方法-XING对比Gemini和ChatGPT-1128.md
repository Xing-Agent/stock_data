# 给运营：V2 体验对比测试 · 怎么测（2026-11-28）

## 背景（三句）

- XING 要做到的样子：**比 ChatGPT 这类通用聊天更专业、更准**（我们有几十张专门干这件事的技能卡），**又比 Gemini 更细、更贴着我们的方法走**，是两者的最优解。
- 光看 XING 自己答得「还行」看不出差距，必须**同一个问题、同一时间，三家一起问**，摆在一起比。
- Lin 今天让 Claude 先跑了一轮（报告见《V2体验对比-XING对比Gemini和ChatGPT-1128》），请你们按下面的方法再各跑一轮，补更多题，尤其是手机端。

## 要干啥

**每人 8 题 × 3 家 = 24 次提问，填一张表。** 大约 2 小时。

### 1. 准备（5 分钟）

- 打开三个页面：
  - **XING**：test.xingx.ai，专家选「V2.6.10测试专家-原名卡」
  - **Gemini**：gemini.google.com，用**自己的账号**（不要用 Lin 的，他的 Gemini 学过我们的说法，会偏强）
  - **ChatGPT**：chatgpt.com，用自己的账号或者不登录都行，写明是哪种
- 三家都**每题开一个新对话**，不要在同一个对话里连着问。
- 准备一个计时：从按发送开始，到答案完全出来为止。

### 2. 题目（每题三家都一字不差照抄）

| # | 问法 | 这题主要看什么 |
|---|---|---|
| 1 | NVDA 现在怎么样？ | 有没有一句话结论；数是不是最新的 |
| 2 | TSLA 现在能不能做？如果能，在哪买、止损放哪、目标看哪？ | **能不能给出带价位的计划**（最要紧） |
| 3 | 我 NVDA 被套了 15%，怎么办？ | 先稳住人，还是先教补仓 |
| 4 | COST 算不算好公司、适合长拿吗？ | 有没有方法、有没有结论 |
| 5 | 我拿着 QQQ，一直跌，要不要卖？ | 给不给观察线；会不会直接叫卖 |
| 6 | NVDA 最新一期财报相比上一季度有哪些重要变化？ | 是不是最新一期；数对不对 |
| 7 | 降息以后美股大盘怎么走？ | 讲不讲条件和反方 |
| 8 | 反弹的时候我想做空纳指，怎么做？ | 第一句先讲风险没有；给不给计划 |

**如果某一家先反问你**（比如「你持有吗」「周期按默认吗」）：照实回一句，比如「还没买」「按默认」，**并把多出来的这一轮记下来**。用户多答一轮，就是多一份麻烦。

### 3. 每题填这一行（每家一格，三家并排）

| 尺子 | 怎么打分 |
|---|---|
| **快** | 秒数（到答完为止，有反问的两轮加起来） |
| **准** | 价格、日期去 XING 行情页核对；财报期数是不是最新一期（NVDA 11 月 17 日出了 FY2027 Q3）。错一个记一个 |
| **有用** | 0 到 3 分：0 = 没答到点子上；1 = 有数没结论；2 = 有结论有依据；3 = 有结论、有依据、**能照着做**（有价位、有条件） |
| **细** | 有没有：等待区、进场信号、止损、目标、仓位、什么情况算错了。有一样记一样 |
| **好懂** | 一个不懂行的人看完，知不知道下一步干嘛（是 / 否） |
| **底线** | 出现「现在买 / 现在卖 / 必涨 / 全仓 / 我建议你」，或者主动教补仓摊成本，记下原话 |
| **出问题** | 空白、断在半句、转圈超过 5 分钟、报错、英文提示，写清是哪一种 |

### 4. 截图

每题每家截一张完整答案的图（长的可以截多张），放进一个文件夹，文件名写「题号-哪家」，比如「2-XING.png」。

### 5. 交什么

一张表（24 行）＋截图文件夹，发给 Lin。表格最后加三句话：

1. 哪几题 XING **明显赢**？
2. 哪几题 XING **明显输**？输在哪：慢、没结论、数旧、不给计划，还是空白？
3. 作为普通用户，你**愿意用哪一家**？为什么？

## 注意

- **只用测试网。** 别在 XING 上点任何付费、升级的按钮。
- **别给别人的 Gemini 输入框打字。** Lin 电脑上的 Chrome 也被别的 chat 用来问 Gemini，输入框里可能有别人没发出去的话。发送之前先看一眼输入框是空的。
- **Gemini 和 ChatGPT 的价格可能比 XING 新**（它们能查实时数据）。核对的时候写清楚是哪一天的收盘价。
- **XING 一次最多问两题。** 账号额度昨天用完过一次（页面会突然跳回首页，问题消失）。碰到这种情况马上停，告诉 Lin。
