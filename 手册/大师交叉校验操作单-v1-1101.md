# 第二页 · ★★★ 三条前提（★ 少做一条，整轮作废）

## ★★★ 一 · 图必须真盲

```
★ 要抹掉:**股票代码** · **日期轴上的年份** · 公司名 · 任何水印
★ 可以留:相对时间(第 1 天 ~ 第 250 天)· 价格刻度 · 成交量
★★★ 为什么:★ 如果图上写着「NVDA 2014」—— Gemini 见过英伟达的历史,
   ★★ **它可能认得出这是哪一段**,那它答的就不是「从图上看出什么」,
   ★★★ 而是「我记得后来涨了」。
★★ 我们这边**同样不给代码**(用编号),这样双方都是真盲。
```

## ★★★ 二 · 先定抽样规则，再抽图

```
❌ **不许先看后面的走势,再挑图。** ★ 那是挑出来的样本,不是抽出来的。
✅ 先写死规则 → 再按规则抽 → 抽到什么算什么
★★★ 哪怕抽出来的图「看着不典型」,也不许换 —— ★ 换了就不是随机样本了。
```

## ★★★ 三 · 不一致是**调查触发器**，不是判决

```
★ 有可能它对、有可能我们错,★★ 也可能两边都有问题。
★★★ 所以每一处不一致都要记**三样**,第三样才是全部价值:
   ① 它判什么、理由是什么
   ② 我们判什么、理由是什么
   ★★★ ③ **分歧出在哪一步** —— 是**看的东西不同**,还是**同一个东西读法不同**?
```

# 第三页 · 30 张图怎么选

## ★ 为什么是 30 张

★★ 和我们「笔数 ≥30 才给统计结论」同一条规矩 —— ★★★ **少于 30 张不给一致率的结论**，只能当个案看。

## ★★ 抽样规则（★ 先定死，再抽）

```
【第一步 · 定池子】
★ 从老池 300 只里抽(★★ 不要用考卷那 1,042 只 —— ★★★ 考卷只能考一次,
  不许拿去做这个)
★ 时间范围:2016-01 ~ 2024-12(★★ 留最后一年不用,★ 以后做第二轮备用)

【第二步 · 分层,每层抽固定张数】
★★★ 按**阶段号**分四层,每层抽 6 张(共 24 张):
   阶段一(底部盘整)6 张 · 阶段二(上升)6 张 · 阶段三(顶部盘整)6 张 · 阶段四(下跌)6 张
   ★ 阶段号用我们自己算的(★★ 这是抽样用,不是答案 —— ★★★ 答案要两边各判)
★★ 再抽 6 张「我们自己也说不清的」(★ 阶段号算不出来 / 两套口径打架的)
   → ★★★ 共 **30 张**

【第三步 · 每层内部随机】
★ 用固定种子随机抽(★★ 比如 `random.seed(20261101)`),★★★ 把种子记下来
★ 不许「看一眼觉得不好换一张」
```

## ★★★ 分层要加的三条多样性约束

```
□ ★ 同一只票最多出现 **2 次**(★★ 否则 30 张可能都是同几只票)
□ ★ 大盘 / 中盘 / 小盘 **各至少 8 张**
□ ★★★ **至少 10 张来自后来退市或大跌的票** —— ★ 否则样本里全是活下来的,
     ★★ 那就是幸存者偏差的图版
```

# 第七页 · 一致率和 kappa 怎么算（★ 手算例子）

## ★ 一致率

```
★ 一致率 = 两边判断相同的张数 ÷ 总张数
★★ 例:30 张图里,阶段号两边相同的有 18 张 → 一致率 = 18 ÷ 30 = **60%**
```

## ★★★ 但一致率会骗人 —— 所以要算 kappa

```
★ 阶段号只有四个选项。★★ **瞎猜也有大约 25% 会对上。**
★★★ 所以 60% 的一致率,扣掉瞎猜那部分,剩下的「真一致」其实不多。
```

## ★★ kappa 的手算例子（★ 用上面那组数）

```
★ 第一步 · 实际一致率        Po = 18 ÷ 30 = 0.600
★ 第二步 · 算「碰巧一致率」   Pe
   ★★ 做法:看两边各自判每一档的比例,相乘再相加
   假设 30 张里 ——
      我们判: 一 6 张 · 二 10 张 · 三 8 张 · 四 6 张  → 0.20 / 0.333 / 0.267 / 0.20
      它判:   一 5 张 · 二 12 张 · 三 7 张 · 四 6 张  → 0.167 / 0.40 / 0.233 / 0.20
   ★ Pe = 0.20×0.167 + 0.333×0.40 + 0.267×0.233 + 0.20×0.20
        = 0.0334 + 0.1332 + 0.0622 + 0.0400 = **0.2688**
★★★ 第三步 · kappa = (Po − Pe) ÷ (1 − Pe)
   = (0.600 − 0.2688) ÷ (1 − 0.2688) = 0.3312 ÷ 0.7312 = **0.453**
```

## ★★ 怎么读这个数

| kappa | 怎么读 |
|---|---|
| **< 0.2** | ★★★ **几乎没有一致性** —— ★ 和瞎猜差不多 |
| 0.2 ~ 0.4 | 弱 |
| **0.4 ~ 0.6** | 中等 ★（★★ 上面那个 0.453 落在这里） |
| > 0.6 | 好 |

★★ **我们自己用过这把尺子，而且正是它救了我们两次：**
```
★ 量价那一轮:kappa **0.0865** → ★★★ 纯噪音
★ 假突破率那一轮:kappa **−0.13** → ★★★ 比瞎猜还差
★★ 两次的一致率看着都不难看,★★★ **是 kappa 让我们看出来那是噪音的。**
```

## ★ 位置类（压力位/支撑位/止损）怎么算

```
★ 这三样不是分类,是数字 —— ★★ 所以不算 kappa,★★★ 算**三桶占比**:
   一致(<0.5 ATR)占几成 · 接近(0.5~1.5)占几成 · 分歧(>1.5)占几成
★★ 过关参考线(★ 第一版,待我们自己跑过再定):
   ★★★ 「一致 + 接近」合计 ≥ **70%** 算可接受
   ★ 分歧 >1.5 ATR 的超过 **30%** → ★★ 说明两边读图的方法有系统性差别,要查
```
