## 一 · 逐题对照

### 题 1（v3·50）「怎么算是真跌破？」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 三步：实体收盘砸穿 → 反抽收不回原平台 → 再破前低 | 同意，照收 |
| 能照做 | 有，但「多远算砸穿」「几根算收不回」靠眼看 | **写成能算的**：① 实体收盘低于平台下沿 ≥ 0.25×ATR ② 之后 3 根 K 线收盘都没回到平台下沿上方 ③ 再创新低 —— 三条都满足才叫真跌破，任何一条不满足就是「待定」 |
| 纪律 | 提了：第一根大阴线不追空、等反抽滞涨再空、止损在反抽高点外 | 同，加 Sniper 的「止损 = 反抽高点 + 0.5×ATR」 |
| 附和 | 无 | 无 |
| 数字出处 | 价位来自图（无法核） | 定义里的 0.25×ATR、3 根是**我们定的默认值，待回测** |

### 题 2（v3·57）「真假突破的进场点，回踩不能回到前面那个位置，对吧？」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 对：扫清算 → 实体收复 → 回踩不破前针尖 = 最佳进场；回踩跌破前针尖 = 变真跌破 | 同意，照收 |
| 能照做 | 有：止损锁在前针尖外 | 同，加上**盈亏比先算**：入场价到前针尖的距离 × 2 以内必须有 TP1 空间，否则一票否决（Sniper 第二节第 3 条） |
| 纪律 | 提了 | 同 |
| 附和 | ⚠ 开口「你的理解完全正确，而且已经精确地抓住了灵魂」—— 用户这次确实说对了，但夸得太满 | 按 Lin 定的规矩：说对了就夸，但具体说夸哪一步（「你说的回踩不破前针尖，这是这个打法最关键的一条」） |
| 数字出处 | 无数字 | 无数字 |

### 题 3（v3·58）「平仓老是着急，平在最低点，怎么办」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 四条：硬止损交给系统 · 未收盘不决断 · TP1 先平一半推保本 · 分清正常回踩和结构破坏 | 同意，照收 |
| 能照做 | 有，「平仓三问」 | 同，再加我们能做、它做不到的：**帮我盯模式里替用户守这几条** —— 盘中触发「想手动平」时先弹出「这根 K 线还没收，结构没破，硬止损没到」 |
| 纪律 | 提了 | 同 |
| 附和 | 无 | 无 |
| 数字出处 | 「80% 的平在最高点都是盘中冲高吓得平仓」—— 没出处 | 不说这个百分比；改说「可以用你自己的成交记录统计你提前平仓后价格的走向」（复盘层能算） |

### 题 4（v1·7）「三重顶 + 斜线跌破，是不是一起出现才最强？」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 是：两者叠加最强；单独出现常常只变震荡 | 同意，照收 |
| 能照做 | 有：只有斜线跌破 → 等反抽不过前高再空；只有三重顶 → 当箱体上沿空，TP1 设箱体下沿 | 同 |
| 纪律 | 提了 | 同 |
| 附和 | 无 | 无 |
| 数字出处 | ⚠ 「Al Brooks 价格行为学有一条铁律：70% 以上的单纯趋势线跌破只会变震荡」—— 数字没核过 | **这个可以回测**：用我们的日线库数「趋势线第一次被实体跌破后 20 天内，多少次变成震荡 / 多少次走成下跌」，用我们的数代替 |

# 第三批：能用数据数出来的「经验题」（2026-11-18 晚）

> 数据：`market_tech_exam_1117/`，2026-06-01 ~ 2026-11-17，约半年。**样本短，只能当初步结论**；长期版交主 chat 用 2004~2025 日线数（已进《经验说法清单》）。

## 三秒版
```
① 「行情多在下午和凌晨，白天轻松」—— 对一半：最大的波动在北京时间晚上 8 点到 12 点（美股开盘前后），是安静时段的 2 倍；下午 2~3 点、傍晚 6~7 点最安静。
② 「ETH 是 BTC 的提前预警」—— 按 1 小时线看不成立：两者同一小时同涨同跌（相关 0.88），前后错开一小时几乎没有关系（±0.03）。
③ 「SOXL、KORU 性格不一样（回踩、反弹幅度不同）」—— 半年数据分不出来：每个只有 11~12 段行情，差别在噪声里，要用更长的历史。
```

## 1. 行情集中在哪个时段（v3·71，Lin：「行情一般在下午或者凌晨，白天挺轻松」）

BTC 每小时平均涨跌幅（绝对值，%），按北京时间：

| 时段 | BTC | ETH |
|---|---|---|
| 22~23 点（美股开盘后） | **0.45~0.47** | **0.57~0.59** |
| 20~21 点（美股盘前） | 0.33~0.39 | 0.42~0.50 |
| 9~10 点（亚洲早盘） | 0.30~0.31 | 0.36~0.38 |
| 16 点（欧洲开盘） | 0.32 | 0.38 |
| 0~1 点（凌晨） | 0.24~0.26 | 0.33~0.39 |
| 14 点、18~19 点（最安静） | 0.19~0.21 | 0.26~0.27 |

→ **白天确实相对轻松**；但最猛的不是「下午」，是**晚上 8 点到 12 点**；凌晨只是中等。
→ 产品里可以直接用：「帮我盯」在这个时段提醒更密，白天提醒放宽。

## 2. ETH 是不是 BTC 的提前信号（v3全·57 / 71；Gemini：「拿 ETH 当提前预警机」）

| ETH 和 BTC 错开 | -2 小时 | -1 小时 | 同一小时 | +1 小时 | +2 小时 |
|---|---|---|---|---|---|
| 相关 | -0.01 | 0.01 | **0.88** | -0.03 | -0.03 |

→ 1 小时级别上**没有谁领先谁**，就是一起动（4,062 根 1 小时线）。「ETH 先站上中轴、BTC 大概率跟上」这类说法，至少在小时线上数据不支持；15 分钟线上可能有，待数。

## 3. SOXL、KORU 的「性格」（v2全·96~102）

4 小时线，按「反向走出 2 倍 ATR 才算一段」切段：

| | 涨一段后回撤了上涨的多少（中位） | 跌一段后反弹了下跌的多少（中位） | 段数 |
|---|---|---|---|
| SOXL | 1.39 倍 | 0.76 | 11 / 12 |
| KORU | 1.54 倍 | 0.57 | 11 / 12 |
| TQQQ（对照） | 1.56 倍 | 0.82 | 15 / 16 |

→ 三个都「涨一段跌回去还多」—— 说明这半年是下跌 / 宽幅震荡的环境，不是品种性格。段数太少，**分不出 SOXL 和 KORU 的差别**。要用更长的历史才能定「按品种性格定参数」。
