## 一 · 逐题对照

### 题 1（v3·50）「怎么算是真跌破？」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 三步：实体收盘砸穿 → 反抽收不回原平台 → 再破前低 | 同意，照收 |
| 能照做 | 有，但「多远算砸穿」「几根算收不回」靠眼看 | **写成能算的**：① 实体收盘低于平台下沿 ≥ 0.25×ATR ② 之后 3 根 K 线收盘都没回到平台下沿上方 ③ 再创新低 —— 三条都满足才叫真跌破，任何一条不满足就是「待定」 |
| 纪律 | 提了：第一根大阴线不追空、等反抽滞涨再空、止损在反抽高点外 | 同，加 Sniper 的「止损 = 反抽高点 + 0.5×ATR」 |
| 附和 | 无 | 无 |
| 数字出处 | 价位来自图（无法核） | 定义里的 0.25×ATR、3 根是**我们定的默认值，待回测** |

### 题 2（v3·57）「真假突破的进场点，回踩不能回到前面那个位置，对吧？」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 对：扫清算 → 实体收复 → 回踩不破前针尖 = 最佳进场；回踩跌破前针尖 = 变真跌破 | 同意，照收 |
| 能照做 | 有：止损锁在前针尖外 | 同，加上**盈亏比先算**：入场价到前针尖的距离 × 2 以内必须有 TP1 空间，否则一票否决（Sniper 第二节第 3 条） |
| 纪律 | 提了 | 同 |
| 附和 | ⚠ 开口「你的理解完全正确，而且已经精确地抓住了灵魂」—— 用户这次确实说对了，但夸得太满 | 按 Lin 定的规矩：说对了就夸，但具体说夸哪一步（「你说的回踩不破前针尖，这是这个打法最关键的一条」） |
| 数字出处 | 无数字 | 无数字 |

### 题 3（v3·58）「平仓老是着急，平在最低点，怎么办」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 四条：硬止损交给系统 · 未收盘不决断 · TP1 先平一半推保本 · 分清正常回踩和结构破坏 | 同意，照收 |
| 能照做 | 有，「平仓三问」 | 同，再加我们能做、它做不到的：**帮我盯模式里替用户守这几条** —— 盘中触发「想手动平」时先弹出「这根 K 线还没收，结构没破，硬止损没到」 |
| 纪律 | 提了 | 同 |
| 附和 | 无 | 无 |
| 数字出处 | 「80% 的平在最高点都是盘中冲高吓得平仓」—— 没出处 | 不说这个百分比；改说「可以用你自己的成交记录统计你提前平仓后价格的走向」（复盘层能算） |

### 题 4（v1·7）「三重顶 + 斜线跌破，是不是一起出现才最强？」

| | Gemini | 我们 |
|---|---|---|
| 结论 | 是：两者叠加最强；单独出现常常只变震荡 | 同意，照收 |
| 能照做 | 有：只有斜线跌破 → 等反抽不过前高再空；只有三重顶 → 当箱体上沿空，TP1 设箱体下沿 | 同 |
| 纪律 | 提了 | 同 |
| 附和 | 无 | 无 |
| 数字出处 | ⚠ 「Al Brooks 价格行为学有一条铁律：70% 以上的单纯趋势线跌破只会变震荡」—— 数字没核过 | **这个可以回测**：用我们的日线库数「趋势线第一次被实体跌破后 20 天内，多少次变成震荡 / 多少次走成下跌」，用我们的数代替 |

## 二 · 第一批的小结
