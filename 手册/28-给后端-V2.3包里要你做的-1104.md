## ★★ 四 · 不许静默降级

```
★ **背景**:数据缺的时候,★★★ 不许用「别的办法算一个差不多的数」顶上。
★ 包里原话:「**不要静默降级** —— 返回确切缺失项,★★ 可以提供替代研究流程,
  ★★★ 但**不能用替代结果冒充原始请求成功**」。
★ **要干啥**:缺数据的时候,接口要明确返回「**缺的是哪一项**」,
  ★★ 而不是返回一个空值、零、或者一个近似值。
★★★ **验收**:★ 故意抽掉几个字段,★★ 看返回里有没有「缺哪一项」;
  ★★★ **返回里不许出现任何具体数字**。
```

## ★★ 六 · 两个数据面物理隔开

```
★ **背景**:★★★ V1 那套数据**只有当前值,没有历史时点值**。
  ★ 拿只有当前值的数去跑历史回测 = **偷看未来**。
```
