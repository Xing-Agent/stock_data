# 一 · 背景（★ 大白话，两段）

```
★ 我们的产品里,用户问一只票的时候,屏幕上要同时给两半:
   **技术面那一半**(图、位置、三条线)—— ✅ 全池都有,没问题
   **基本面那一半**(贵不贵、赚钱能力、欠多少钱、成长率)—— ❌ 只有 250 只有

★★★ 而这 250 只不是「随便 250 只」,它是我们**做回测时用的开发池**的子集。
   实测结果:
      NVDA ✗   AAPL ✗   MSFT ✗   AMZN ✗   GOOGL ✗   META ✗   AMD ✗
      TSLA ✓   ← 七大只有一只在
   ★ 名单头部长这样:AAL · ABMD · ABT · ACIW · ACOR · AGNC · AIG …

★★ 后果很具体:**用户问 NVDA,基本面那四行全是空的。**
   ★★★ 而空着不能不写 —— 用户会把空白读成「**没问题**」,
      可「**我们没看**」和「**我们看了没事**」是**完全相反**的两件事。
```

# 三 · 「2,000 只」具体是哪 2,000 只（★ 这一节是技术组要的）

| 项 | 值 | ★ 出处 |
|---|---|---|
| 池子口径 | ★★★ **`large_mid` = 当年成交额排名 1–2,000 名** | `engine/pool_scope.py` 的 `DEFAULT_SCOPE` —— ★★ **全仓库唯一**一个「我们做哪些票」的开关 |
| 排名怎么算 | 每年年初回看 **60 个交易日**的日均成交额 | 同上 |
| 名单在哪 | `probe/survivorship_1029/pool_FULL_ALL.csv`，**74,268 行** | ★ 取 `year = 最新年份` 且 `rank <= 2000` |
| ★ 每年只数 | **2,000 只**（固定，定义如此） | 实测 |
| ★★ 这次只要 | **当前年份那一组 2,000 只** | ★★★ Lin 拍板方案 A |

```
★★★ 两个容易搞混的数,先说清:
   · `pool_FULL_ALL.csv` 里**每年约 6,000 只**(实测逐年 5,979 ~ 6,780)——
     ★ 那是**全池含小盘**。
   · ★★★ 我们**没在筛小盘** —— 策略组 2026-10-30 拍板「初期只做大+中」,
     所以**上线要的是 2,000 只,不是 6,000 只**。
   ★★ (如果以后把小盘加回来,`pool_scope.py` 改一个参数就行,
      不需要重建池子 —— 那是设计好的。)
```

★ **为什么只做当前这一组、不做历史全部：**

```
★ 回测要的是**逐年**池子(8 年去重 **3,591 只**);
★★★ 上线要的是**现在池子里那 2,000 只** —— 因为**用户问的是现在的票**。
★★ 而 engine 现在跑的还是老池,回测这一版用不上那 3,591 只。
→ ★ 所以先做 2,000 只。**3,591 只那一版以后再说,不是不做。**
```

# 五 · ★★★ 真正要讨论的三件事（★ 不是「加多少只」）

| # | 事 | ★ 为什么它才是真问题 |
|---|---|---|
| ★★ **1** | **抓取要跑多久** | ★ SEC 有访问限速。★★ 数据组跑过 300 只 —— **乘一下就有数**，不用猜 |
| ★★★ **2** | **上线之后怎么保持更新** | ★★ 财报**每季度来一批**，PIT 表要跟着长。★★★ **这才是真正的持续成本** —— 一次性抓取只是开头 |
| ★★ **3** | **池子每年换人** | ★★★ `large_mid` 是「**当年年初**排名」，所以每年有票进出。★ 实测：8 年 × 2,000 = 16,000 个席位，但只有 **3,591 只不同的票** → **平均每只票在池里待 4.4 年**。★★ 所以每年换池的时候，**新进来的票要补抓历史** |

# 六 · ★★★ 一件扩了也解决不了的（★ 先说清，免得以为扩完就全好了）

```
★★★ 「**欠多少钱**」那一行,**扩到 2,000 只照样是空的。**

★ 原因不是我们少抓了,是**字段在 SEC 上就不是那个口径**:
   `LongTermDebtNoncurrent`(真正的长期负债)和
   `InterestExpense`(利息费用)—— ★★ 在那 250 只上**根本不存在**;
   只有「**一年内到期那部分**」,79/250 ready。
★★ 连**利息覆盖倍数**也因此算不出来。

★★★ 而这一行卡的东西不小:**6 项指标、17 条基本面策略** ——
   ★ 它不是小缺口,**是基本面这一整派的总开关**。
→ ★★ 这一条**单独立一件事**,不在这张单子里。
```
