## ★★★★★ 一 · 第 54 处错：重建净值在离场日漏了一天（★ 这一条最先说，因为它影响下面所有数）

```
★ 代码在 `probe/账户百分比_1106/按净值百分比_1106.py` 的 `逐日净值()`：
    实现 = (按 exit_date 累加 net_pnl).cumsum()
    浮盈只算到  index < exit_date
    eq = 100万 + **实现.shift(1)** + 浮盈
★★★ 问题：`shift(1)` 把已实现推到**离场日的下一天**，
   而浮盈在**离场日当天**就已经撤掉了 → ★★ 离场那一天这笔仓位**两头都不算**。
→ ★ 一笔一笔散着离场时，这只是曲线上的小毛刺；
  ★★★ 但**同一天有一大批离场时，就是一个悬崖**。
```
