# 473 · 《459 拍板》第 4 件：核心位置分两档

**一句话：普通位置（只有一个地基、不够强的）在 BTC、ETH、SOXX 上做空都是亏的，照拍板「普通档每笔是亏的就去掉」，去掉。强位置一年只有一两笔：BTC、ETH 是正的但各只有 4 笔，SOXX 20 笔是亏的。**

脚本 `probe/核心位置_第三版_1125/分两档_1126.py`。扳机统一用「假突破收回」（右侧），止损、出场、成本同《437》；到 3R 平；每笔净 R。BTC、ETH 用 2017–2021 加 2026 年，SOXX 用 2005–2021 年（2022–2025 封存不看）。

| | 强位置：笔数 / 每笔 / 一年几笔 | 普通位置：笔数 / 每笔 / 一年几笔 | 对照（把位置挪开）：强 / 普通 |
|---|---|---|---|
| BTC | 4 / +2.17R / 1.3 | 55 / **−0.11R** / 9.2 | +0.91R（8 笔）/ −0.32R（117 笔） |
| ETH | 4 / +0.98R / 1.3 | 63 / **−0.33R** / 10.5 | +0.15R（14 笔）/ −0.06R（94 笔） |
| SOXX | 20 / **−0.49R** / 1.5 | 177 / **−0.51R** / 8.8 | −0.47R（28 笔）/ −0.23R（190 笔） |

- **普通位置**：三个品种都是负的。BTC 上比把位置挪开的对照略好（−0.11 对 −0.32），ETH、SOXX 上比对照还差。两段时间都是负的（BTC 2017–2021 −0.03、2026 −0.57；SOXX 2005–2014 −0.62、2015–2021 −0.31）。加上状态机开关也没变正（BTC 可空的 27 笔 −0.35R）。
- **强位置**：BTC、ETH 各 4 笔，是正的，但 4 笔什么都证明不了，而且对照（挪开的位置）在 BTC 上也是 +0.91R。SOXX 20 笔是亏的，和对照一样亏。
- 放回行情背景：SOXX 2005–2021 年整体大涨，做空天然逆风；BTC、ETH 的 2018 年和 2026 年有大跌，对做空有利。
- 拍板里「第一目标盈亏比至少 2 才做」：回放的目标本来就是固定 2R / 3R，没有另筛。

## 结论（照拍板的写法）

- 普通档每笔是亏的 → **去掉**，不加这一档。
- 核心位置这条线现在的状态：位置能认得比以前准（有核心带的日子从 84% 降到一成多，打分不再越碰越低），但「在核心位置做空」本身，样本够的地方（SOXX）是亏的，正的地方（BTC、ETH）只有几笔。**还不能当有成绩的规则进卡。**
- 这是核心位置做空的第三版（《428》《437》、这一版）。照规矩不再换写法测。
