# ★★★ 排的过程里查出一件（★ 我之前没说，而它影响说明书）

```
★★★ **实测那 5 份已跑的基本面配置,槽位是这样的:**
   ①只买什么票 = 1~2 条  · ②大盘才开工 = **空**
   ③什么时候买 = **空**   · ④什么时候卖 = 1 条
   ⑤止损      = **none** · ⑥买多少 = 有 · ⑦满了选谁 = 有
★ 也就是说:**所有基本面策略都没有「什么时候买」和「止损」。**
★★ 这**不是漏填** —— ★★★ 原著就是这样:机械再平衡,不设止损。
```

## ★★ 但它有两个后果，★★★ 必须写进说明书

```
★★★ **后果一:它们的「R」不是风险倍数,是收益率。**
   ★ R 的定义是「赚的钱 ÷ 当初准备亏的钱」,★★ 而「准备亏多少」就是止损。
   ★★★ 没有止损 → 分母没了 → 那个「R」**退化成收益率**。
   ★★ 所以**不能和有止损的技术面策略排在一列比名次** —— ★ 这条我们已经登记过。

★★★ **后果二:「最大一次亏多少」这一格,对它们的含义不一样。**
   ★ 对有止损的策略:那是「止损线被打到」的损失,★★ 是设计出来的。
   ★★★ 对没止损的策略:那是「它一直拿着,拿到最低点」的损失 —— ★ 没有上限。
   ★★ 所以这一格在基本面策略的说明书里,★★★ 要多写一句:
      **「这套做法不设止损,所以单笔亏损没有设计上限。」**
```
