# 第二页 · ★★★ 那一个要先问的问题（★ 免费，但它决定一切）

## ★ 请原话问 FMP（★★ 要书面答复，不要销售口头保证）

> 「你们的一致预期（consensus estimate）记录，**每一条是否带一个 as-of 日期**？
> 我需要能够只取『**某只票某个财季、在财报公布日之前的最后一条**』那个值。
> 如果带，请说明那个日期字段叫什么。
> 如果不带 —— 请直接说不带。」

## ★★★ 为什么这一问是生死线（★ 大白话）

```
★ 我们要算的东西是:**财报实际数 − 财报公布前市场预期的那个数**。
★★ 这一减,就是「超预期多少」。

★★★ 问题在于:如果 FMP 给的只是「2019 年三季度的一致预期 = 1.25 美元」
   这么一个**光秃秃的数字,不带日期** ——
   ★ 那我们**没有任何办法知道**:这个 1.25 是财报出来**之前**的预期,
     ★★ 还是财报出来之后、分析师回头把记录改过的版本。
★★★ 而如果是后者,我们算出来的「超预期」里就**掺进了答案** ——
   ★ 行业里叫**未来函数**:用未来的信息去预测未来,
   ★★ 回测会漂亮得不像话,★★★ **而实盘一上去就塌**。
```

★★★ **所以选项 B 的风险不在「精度低一点」，在「那个数可能是事后改过的」。** ★ 这不是严格不严格的问题，是**对不对**的问题。

## ★★ 两种答复，两条路

| FMP 怎么答 | ★★★ 我们怎么办 |
|---|---|
| ✅ **「带 as-of 日期」** | ★★ **直接买 B，够用。** ★ 我们取「财报日之前最后一条」，★★★ 这就是严格 PIT 的「超预期」那一半 |
| ❌ **「不带」** | ★★★ **两个都先不买。** ★ 把基-18 标成「做不了」，★★ 等预算宽裕再上 A。★★★ **不许用不带日期的数据凑合** |

# 第三页 · A 和 B 买的不是「同一样东西的两个精度」

★★ 这一点原来的两个选项没说清，★★★ 而它是这次采购最该搞明白的一件：

| | 它能算什么 | ★ 需要什么 |
|---|---|---|
| ★★★ **超预期幅度**（earnings surprise） | 「这家公司这次财报比市场预期好／差多少」 | ★★ **只要「财报日之前最后一条预期」** → **B 就够** |
| ★★ **预期修正动量**（estimate revision） | 「分析师这一个月在往上调还是往下调」 | ★★★ **必须有整条修改流水 + 时间戳** → **只有 A 能做** |

```
★★★ 所以 A 比 B 多出来的那部分,买的是**第二个因子**,不是「同一个因子更准」。
★ 而那第二个因子(预期修正动量)**现在不在我们的路线图上** ——
  ★★ 基-18 的核心是超预期漂移,修正动量是它的一个增强项,不是前提。
★★★ **先买能做核心的那一半,别为一个还没排期的增强项多付钱。**
```
