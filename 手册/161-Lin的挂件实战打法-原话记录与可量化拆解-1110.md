## 二、★★ 拆解：哪几条现在就能编码，哪几条卡在定义上

| # | 他说的 | 能不能编码 | 卡在哪 |
|---|---|---|---|
| ① | 整体是上涨 | ✅ **能** | ★ 我们引擎里已有 `index_above_ma` / `index_ma_slope`，★★ 环境面板用的就是这个 |
| ② | 小周期指标见底 | ⚠ **要定义** | ★★★ 「哪个指标」「什么叫见底」原著没给 —— ★★★★★ 图上那个带「背离」标签的副图是**第三方指标**，我们没有它的算法 |
| ③ | 二次确认 + 没跌破前低 | ✅ **能**（★★ 这条最干净） | ★ 「前低」= 前一个摆动低点，**可计算**；「二次确认」= 第二次触及后不破，**可计算** |
| ④ | 拿着 | ✅ 能 | — |
| ⑤a | 较大的背离形态 | ⚠ **要定义** | ★★★ 「背离」本身可算（价格新高 / 指标不新高），★★★★★ 但「**比较大**」没有门槛 |
| ⑤b | 派发形态 | ⚠ **要定义** | ★★ 威科夫体系里有定义，★★★ 但我们技-11 的实现是**量价洗盘**，不是派发 |
| ⑤c | 不像原来那么强势 | ✅ **能，而且我认为这是最值钱的一条** | ★★★★★ 它本质是**涨速衰减** —— 可以用「近 N 根的斜率 / ATR 比前 N 根」量化 |
| ⑤d | 震荡区间假跌破 | ✅ **能** | ★ 跌破区间下沿后 K 根内收回 = 可计算（★★ 技-10 海龟汤就是这个形状） |
| ⑥ | 再突破再进 | ✅ 能 | ★ 和 ③ 同一套 |
| ⑧ | 三步一回踩 / 背离越来越多 | ✅ **能** | ★★★ 「回踩次数」「单位时间内背离次数」都可计数 |

```
★★★★★ 所以结论是：**十条里六条现在就能编码，四条卡在「门槛没定义」。**
★★★ 而那四条全都是同一类问题 —— ★★ 「**比较大**」「**见底**」「**派发**」这些词
   **原著没给数**，★★★★★ 我们自己定一个就撞红线①。
→ ★ 按 11-04 定的次序走：**原著 → Gemini 行业做法 → 我们自己跑相邻三点**。
```

## 三、★★★ 两件我必须先说清的（★ 免得这套打法被高估或低估）

### ① ★★★★★ 它和我们已经测过的东西**不是一回事**，所以「我们测过了」不成立

```

   ★★★★★ 他对，三样全都比他描述的粗：

   · 我拿「技-1 趋势跟随」比 → ★ 那是整条策略，他说的是**覆盖层**
   · ★★★★★ 最关键：他说的是「**减仓**或者空仓」——
     而**引擎不支持分批离场**（`pat6_make_configs.py:990`）
     → ★★★ 「减仓」这一半我们**现在根本测不了**，只能测「空仓」那个二元版本。
```

### ② ★★★★★ 有一组我们自己的数，对这套打法是**反向证据**，必须摆出来

```
★★ 1110 实测：SPY 这 11 年涨最多的 10 天，相对「那一轮最低点」的位置 ——
   · **4 天在见底之前**（2020-03-02 / 03-10 / 03-13 / 03-17）
   · **4 天在见底后第 1~3 个交易日**，★★★★★ 含最大的两天：
     **2020-03-24 +9.06%**（底后第 1 日）· **2025-04-09 +10.50%**（底后第 1 日）

★★★★★ 对这套打法最硬的一点：**「二次确认」至少要 1~3 天，而最大的两天就在底后第 1 天。**
   ★ 加上见底前那 4 天，**10 天里有 8 天不在场**。

★★★ 但还有一层，★ 这一层对这套打法是**有利的**：
   ★★ 那 10 天里只有 **4 天是干净的 V 型反转**（前 20 日跌超 5% 且后 20 日涨超 3%）；
   ★★★★★ 另有 **3 天是「下跌途中的反弹」** ——
      2020-03-02 当天 +4.33%，**之后 20 日还要跌 15.3%**；
      2020-03-10 当天 +5.17%，**之后再跌 8.1%**
   → ★★★ 也就是说：**那 3 天就算吃到了，也会马上被打回去。**
   → ★★★★★ 所以「等二次确认」**不是纯损失** —— ★★ 它在 V 型那几次上少吃一截，
      ★★★ 但在下跌途中反弹那几次上**替你挡了刀**。

★★★★★ 这正是这套打法**必须真跑一遍才能定论**的理由：
   **少吃的和挡掉的，哪个大？—— 现在没人知道，我和 Lin 都只是在猜。**
```
