# 基本面大师卡 · 改动单 v0.1（2026-11-21，来自《242》考试）

**一句话：5 只票对照 Gemini，2 只（FTDR、KO）被卡里的「商誉占净资产 > 40%」误杀成「不算」—— 回购公司净资产被压小，比例天然高。改成看总资产，并补 4 处取数口径。以 Gemini 为正确度基准，这几条不涉及策略取舍，不用 Lin 拍板。**

## 1. 排雷「商誉虚胖」改写（第四节）
原：「商誉虚胖：股东权益减去商誉和无形资产后大幅缩水或为负；商誉占净资产 > 40%。」
改为：
> **商誉虚胖**：商誉 + 无形资产占**总资产** > 40%，或者最近 3 年有大额商誉减值。
> 🔴 只看「商誉 / 净资产」或「有形净资产为负」不算命中 —— 先看是不是回购造成的：库存股金额大、净负债 / EBITDA < 2 → 写「这是常年回购把净资产压小造成的会计假警报，不算排雷」（例：KO、FTDR）。

## 2. GARP 门槛「负债 / 股东权益 < 0.8」加一句（第三节）
> 常年大额回购、净资产很小的公司，这一条改看「净负债 / EBITDA < 2」，并写明换了口径。

## 3. 第五节「单票体检」加三条口径
- **一次性现金要剔除**：自由现金流里有养老金返还、卖资产、诉讼赔款、税款返还这类一次性项目，剔除后再算自由现金流收益率；剔不出来就写「可能含一次性现金，这一条暂不打勾」（例：KODK 按财报算 63%，实际主业现金流前 9 个月只是打平）。
- **现金 = 现金及等价物 + 短期投资 + 流动的可交易证券**（例：INTC 只算现金是 218 亿，算上短期投资是 540 亿，净负债的结论会反过来）。
- **科目日期必须和最新一期财报一致**：取到的某个科目停在更早的期间（例：有公司的短期借款科目停在 2017 年），不用，写「这一项缺最新数」。

## 4. 没有分析师预期数据时（第三节高质量成长、GARP）
> 「未来一年预期增速」「远期 PEG」「远期市盈率」取不到 → 用过去 3 年实际增速、静态市盈率替代，并写明「用的是历史数，不是预期」。不要整条写缺。

## 5. EBITDA 口径（第五节）
> 默认按财报口径（营业利润 + 折旧摊销），写明「按财报口径」。公司另报调整后口径的，并列给出，标明「公司口径」。

## 给技术端（取数工具）一并转
第 3 条的「现金含短期投资」「科目日期要一致」主要是取数工具的事，建议工具直接返回算好的「现金合计」和每个科目的期末日期。
