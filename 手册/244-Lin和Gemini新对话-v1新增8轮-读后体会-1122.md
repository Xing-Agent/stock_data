## 一 · 具体学到的
1. **分界线破位后的「贴线整理」进场**（第 74、75 轮，最有价值）：
   - 先画出最关键的那条多空分界线（大级别平台的顶底转换、趋势线、布林中轨 / 下轨）。
   - 放量实体 K 线穿过它 → 马上放下原来的方向。
   - 不追穿线的那根大 K 线；等后面 3~6 根同级别 K 线紧贴在线外侧窄幅横走，一直不收回线内 → 在这段整理的尾巴进场。
   - 止损放在这几根 K 线回头试探分界线时留下的针尖外侧。
   - 道理：假突破 / 假跌破 1~2 根就被拉回去了，不会在线外慢慢磨；能贴着线磨说明对手盘没力气反扑。好处是不用等深回踩（强行情往往不给），止损又很窄。
   - 我们卡里「思维切换」写了「放量冲回压制线 → 回踩不破 → 缩量横盘 → 改找多」，**方向判断是有的，但进场扳机仍是「回踩到等待区 + 长下影 / 吞没」**，没有「贴线横盘不回穿就直接进、止损在贴线针尖外」这一种进法。
2. **高位第一次横盘不猜顶**（第 73 轮）：87K 那里只是涨累了横着，结构没坏、回踩多深没人知道，空了也不知道止损放哪 → 不做。卡里「顶部做空要派发形态 + 假突破两个都要」已经覆盖，不用改。
3. **破位后反抽原支撑、插上影针 = 最好的空点**（第 72 轮）：卡里「顺势反抽」+「刚跌破的那个平台的下沿」已覆盖。
4. **周线还是牛、日线已破位 → 按日线做空**（第 72 轮）：卡里本来就是日线定方向，覆盖。
5. **到第二目标区后剩下一半怎么处理**（第 76、77 轮）：
   - 砸进目标区后打出长下影收回、随后几根贴着支撑上沿小阳磨、不再创新低 → 剩下的全平，防逼空。
   - 实体直接砸穿、随后贴着线下方阴跌、连反抽碰线都没有 → 剩下的拿着，跟踪止损放在贴线阴跌时向上试探那根的针尖外。
   - 三倍杠杆品种在大支撑附近反抽常常 3~5 分钟拉 8%~12%，所以平掉一半的同时给剩下的挂好止损单，别靠手点。
   - 卡里有「到第一目标平一部分、剩下推保本」和「第二目标位 = 再下一个平台」，**但没写到了第二目标区剩下的仓位看什么信号走 / 留**。
6. **扫完大底后的弱收回**（第 78、79 轮）：BTC 扫到 55,162 后收回很弱、4 小时均线还往下压 → 不抄底（可能二次探底）、不追空（已刺穿周线布林下轨、超卖）。做多等站稳 59,500~60,000；做空等反抽 60,000~61,500 出上影针，或彻底砸穿 55,162 后贴线阴跌。卡里「扫完低点后等二次回踩、第一腿反弹不追」已覆盖大部分。
