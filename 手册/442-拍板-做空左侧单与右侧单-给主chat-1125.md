# 442 · 拍板 + 要干啥 · 做空的左侧单和右侧单(2026-11-25)

> 依据:《442-Gemini原文回答-做空左侧单与右侧单-1125.md》《442-Gemini回复与判断-做空左侧单与右侧单-1125.md》。Lin 11-25 13:25–13:32 逐条同意。和 431 拍板配套使用。

## 一句话
**做空改成一套:左侧小仓试 → 跌破不全平、只减一部分 → 反抽没过加满。核心位置必须有一条水平位打底。大周期在涨就不空,四类品种各有打法。**

## 拍板(3 条)
### 1. 开法合并(替代「全平再重开」)
1. 左侧(UTAD / 破位前 LPSY)开 30%;止损在那个局部高点上方 + 0.5 ATR。
2. 跌破后出现停止行为 → 减 1/3~1/2,剩余止损移到成本。停止行为:破位后 1~2 根实体小且缩量的 K 线;或放量、长下影、收在上半截的 K 线。
3. 反抽到原支撑下沿(破位很猛时到破位大阴线 50% 也算)没过 → 加到满,整体止损移到反抽高点上方。
4. 不反抽直接跌 → 底仓照拿;跌出第一个熊旗(下跌中途的小平台)再破时补。

### 2. 核心位置:水平位打底
- 硬条件:≥ 1 个水平位(前高前低 / 箱体边 / 成交密集区)+ ≥ 1 个 30 周线、200 日线或趋势线。
- 加分:斜趋势线、未回补缺口。只能加分、不能单独成立:0.382 / 0.5 / 0.618、小周期形态。
- 加在 411 打分(≥ 3 样、≥ 2 类)之上。

### 3. 大周期总开关 + 分品种
- 30 周线向上 → 一律不开空。
- 大指数:不做左侧,只减多(同 431 第 3 条)。
- SOXX、个股:只做右侧。
- BTC、ETH:以左侧「插针扫止损后收回」为主,不追跌破。

## 右侧「反弹没过」再补两样(工程,我定)
在 431 第 1 条的基础上加两样:
- 反弹期间的量 < 破位那段的量;
- 向右确认:出现上影线或阴包阳后,下一根跌破这根的低点,或小周期转成高点下移(BOS)。

在阻力区磨了 5~8 根 K 线还不跌,放弃。收回核心位置上方 → 马上撤;熊市里不反手。

## 要干啥(主 chat)
1. 改核心位置打分:加水平位硬条件。核一下「有核心带的日子」占比从 85% 降到多少,以及 BTC 9 月下旬 8.7 万那一笔能不能认出来。
2. 改右侧扳机:加量和向右确认,再加 5~8 根放弃。
3. 按第 1 条跑合并开法;对照组是「全平再重开」(Lin 原做法)和「只等反抽」(开法 C)。
4. 加 30 周线过滤,有 / 无两版对比,看砍掉多少亏损单(Gemini 说约 70%,没出处,要我们核)。
5. 按第 3 条分品种重跑 24 个品种,报时间段 + 副指标(胜率、利润因子、回撤、t),并放回行情背景讲。
6. 比例参数(30/70、减 1/3~1/2、5~8 根、2 倍量)都是行业惯例,不是原著。每个各试相邻三个值。
