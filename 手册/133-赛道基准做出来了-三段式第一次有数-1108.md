## 五、★★★ 三段式（第一次有数）—— ★★★★★ X 全部**待配对检验**

★ 读法：X = 策略 − 赛道（「在自己赛道里赢没赢」）· Y = 赛道 − 标普 · Z = 策略 − 标普（= X + Y）

| 窗口·族 | 策略年化 | X（W1 / W2 / W3） | Y（W1 / W2 / W3） | Z |
|---|---:|---|---|---:|
| B·大波段 技-1 | +5.96% | **−4.77 / −7.58 / −6.96** | −2.74 / +0.07 / −0.55 | **−7.51** |
| B·突破 技-6 | +3.25% | **−7.48 / −10.29 / −9.67** | 同上 | **−10.22** |
| B·震荡 技-14 | −5.74% | **−16.47 / −19.28 / −18.66** | 同上 | **−19.21** |
| A·大波段 技-1 | −0.41% | **−10.78 / −9.35 / −15.08** | +2.55 / +1.13 / +6.85 | **−8.23** |
| A·突破 技-6 | +4.14% | **−6.23 / −4.80 / −10.53** | 同上 | **−3.68** |
| A·震荡 技-14 | −5.46% | **−15.83 / −14.40 / −20.13** | 同上 | **−13.28** |

```
★★★★★ **18 个 X 全部为负，没有一个例外**，范围 −4.77 ~ −20.13pp/年。
★★★★★ 而每一个 X 后面都必须跟上四个字：**待配对检验**。
   ★★★ **不许写「我们在赛道内更好」，也不许写「分不出」**（规矩㊸v2 ·《132》第三节）。
   ★★ 为什么这四个字这次特别要紧：★ 《130》里 Z = −7.51 那一格配对 NW t 只有 **−1.23，没过**
     → ★★★ 连「输 7.51pp」都还没在统计上站住，★★★★★ 所以 X = −4.77 **一定**不许当成站住的。
★★ 补配对要什么：策略侧日净值（`日净值_修分红_1108/`，派生物、按口径④不入库，本容器没有）
   → ★★★ 要么重跑那 6 条 A原样 臂（约 20~40 分钟），要么下一轮跑批时顺手留下来。
   ★ 门槛《132》第三节已写死：逐日相减 + NW 滞后 8 · **|t| > 3**（6 次检验）—— 跑完不许动。
```

## 六、★★★ 这一份对**外部口径**意味着什么（★ 必须和《93》第四节一起读）

```
★★★ 《93》第四节 3. 那句三段式是：
   「赛道内我们赢 X% ｜ 赛道整体落后标普 Y% ｜ 所以整体输 Z%」
★★★★★ 本份实测的结果是：**第二段不成立**。
   · A 段：赛道**赢**标普 +1.13 ~ +6.85pp → ★★ 说「赛道落后」是**反的**
   · B 段：赛道和标普差不多（−2.74 ~ +0.09，符号随加权翻）→ ★ 说「落后」站不住
→ ★★★★★ 所以三段式**退化成一段**（这正是《132》第四节情形二预先写死的）：
   **「在我们自己能买的这个池子里，我们挑票的成绩比把池子整个买下来放着差 X 个百分点/年
     —— 而这个 X 还没过配对检验。」**
★★★ 这一句**不许缩短成「我们输给标普」**（那反而是轻的说法）。
★★ 也**不许**反过来用：★★★ 「X 没过配对检验」**不等于**「我们和赛道打平」——
   规矩㊸v2 明写：没做配对之前不许写「分不出」。
```
