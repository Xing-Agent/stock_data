```

### ✅ 2「风险怎么说」→ **两句话，按有没有成绩分开用**

```
【**有成绩的**】「★ 这套方法我们回测过 —— **结果是〈下面那三层〉**。
                ★★★ 这是**方法视角**，不是对这只票的判断。」

【**没成绩的**】「★ 这是一套**分析镜头**，不是可执行策略 ——
                ★★★★★ 它**没有进场、出场、仓位规则，所以没有可回测的东西**，

┌──────────────────────────────────────────────────────────┐

│                                                          │
│ ★★ ② **和主参考比**（★ 两把，都要报）                       │
│    · 「同样时间进出、随机挑票」→ 我们**赢 / 输**             │
│       ★★★ 这把只量**挑票有没有信息**（进出场时机被固定住）    │
│    · 「把这一池子全买了躺着」→ 我们**赢 / 输**               │
│       ★★★ 这把量**一整条策略**（挑票+时机+仓位+手续费）       │
│                                                          │
│ ★★★ ③ **和副参考比** —— 满仓标普全收益 **+14.55%/年**        │

**★★★ 两把主参考方向相反 —— ★★★★★ 这不是矛盾，是两件事：**

```
★★ 技-14 就同时满足这两条：**赢了「同池随机」**，却**输给「全池买了躺着」**（一年输 16.4 个百分点）。
★★★ 大白话：「**我们挑票比扔飞镖好**」和「**我们挑票不如全买了放着**」可以同时成立 ——
   ★★★★★ **挑票挣来的那点优势，被「什么时候进出 + 仓位 + 手续费」吃光了，还倒亏。**

```

## 二、★★★★★ 五种结果分开说 —— 不许混成「未验证」

| 结果 | 怎么说 | 例 |
|---|---|---|
| **测出来了 · 负** | 「测出来了，是负的 —— **不如同期买大盘**」 | 威科夫（技-11） |
| **测不出** | 「**分不清是本事还是运气**」 | 温斯坦（技-3，★ 三个版本全是） |
| **算不出 · 引擎做不到** | 「引擎只交易个股，而这套买的是 ETF」 | 肯尼斯·费雪（基-11） |
| **算不出 · 数据不够** | 「这套要分析师预期数据，我们没有」 | 彼得·林奇（基-15） |
| **算不出 · 笔数太少** | 「跑了，★★ **但只有 11 笔** —— 撑不起结论，所以不报」 | 早期巴菲特（基-7） |
| **研究框架没信号** | 「这是分析镜头，没有进场/出场/仓位规则，所以没有可回测的东西」 | 阿克雷（基-13）等 |
| 🔀 **主路在做** | 「**在跑**」—— ★★★★★ **不许写成「算不出」或「没测」** | PEAD（基-18） |

```
★★★ 两条硬规矩：
   ① 「**算不出来**」和「**分数差**」分开记，★ 不许混成一个数
   ② ★★★★★ 「**测出来是负的**」（**坏消息**）和「**分不清是本事还是运气**」（**没消息**）
      是两件事 —— ★★ 两句话必须分开写。
```

### ★★★★★ 给用户的输出里不出现 t，也不出现「显著」

```
★★ 先说清 t 是什么（★ 你们在内部表格里还会看到它）：
   ★★★★★ **t 就一句话：这个结果，有多可能只是碰巧。**
   ★ 比方：我说我会猜硬币 ——
      · 猜 **10 次对 6 次** → ★★ 你不会信，瞎猜也常有这结果 → **t 小**
      · 猜 **1000 次对 600 次** → ★★★★★ 瞎猜几乎不可能这么准 → **t 大**
   ★★ 同样是「六成准」，★★★ 证据的分量完全不同。
   ★★★★★ **t 小不代表结果假，也不代表策略差 —— 只代表证据不够。**

★★★ 所以分两件事，★ 免得判错：
   · **内部表格里 t 照旧有**（★ 策略台账里能看到）
   · ★★★★★ **给用户的输出里不许出现 t，也不许出现「显著 / 不显著」这类词**
     → ★★ 换成上面那两句话
```
