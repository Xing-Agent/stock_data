## ★★★ 这一页的两个已知风险

```
★★★ 一 · **判错了,用户不知道。**
   ★ 他不选入口,系统猜。★★ 选按钮选错了他自己知道;
   ★★★ 系统猜错了,他只会觉得「这个 AI 答得不对」。
   ★ 实测:全卡 **一处都没写**「判错了怎么办」(grep 0 处命中)。
   → ★★ **至少要一条**:答完给一个「**你要的是不是这个?**」的出口,
     ★★★ 而且那个出口能**一句话跳到另一条路**,不是让他重新描述一遍。

★★★ 二 · **第 ⑪ 条没有主人,而它最可能被走到。**
   ★ 入口是对话框 → ★★ 用户第一句话可以是任何东西。
   ★★★ 一个**没路由**的问题 = 一个**在共用边界之外被回答**的问题 ——
      没有出处等级、没有「不给买卖指令」、没有措辞红线。
   ★ 最糟的组合:★★★ **最常走的那条路,恰好是唯一没有边界的。**
```

## ② 我被套了 —— ★★★ 目的不是帮他解套

```
★ 走的是 quote 的**持仓分支**(和「还在看」是两套说法)
★★★ 目的:**让他自己看见「我当时没有规则」**
   ★ 因为「怎么解套」在他没有规则的情况下**无法回答** ——
   ★★ 任何答案都只是我们替他赌一次,而赌错了是他的钱。

★★★ 而他开口就要方案时,必须给**四样出口**(共用边界 §6.3 规定的):
   ① 这套方法要求什么  ② 现在卡在哪一条

★★★ **不给的只有一样:「该割/该扛/该补」三选一** —— 那是买卖指令。
★★ 共用边界原话:「**不给个性化买卖点是对的;不解释原理是另一件事,
   而且是错的。**前者是合规边界,后者是我们欠用户的。」

★★★ 一条顺序硬要求:**先给那四样,再(如果合适)才说规则那件事。**
   ★ 反过来说会变成**说教**,而说教会赶走用户。
   ★★ 说法是「**下次要不要我们帮你把这几条先定下来**」,
      不是「你当时没定」—— ★★★ 一个往前看,一个往后看。
```

## ③ 今天大盘怎样 —— ★★★ 四行，不给一个分数

```
① 指数在涨还是在跌   ← SPY vs 200 日线 + 200 日线 20 日斜率
② ★★★ **大多数票在涨还是在跌** ← 在 50/200 日线上方的票占比 + **历史分位**
③ 创新高的多还是创新低的多 ← 52 周新高/新低只数 + 涨跌家数
④ 波动大不大        ← VIX + 历史分位
⑤ ★★ **算不出来的**(必须显示):VIX 期限结构 · 道指运输确认 ·
   广度那两个月少计 3.5%

★★★ **为什么不给「市场温度 XX 分」** —— ★ 用 2026-10-09 实测那天说明:
   指数在 200 日线**上方 8.8%**、均线往上        → 指数在涨
   只有 **39.2%** 的票在 200 日线上方            → **24% 分位**
   创新高 71 只 vs 创新低 **201 只**              → 净新高 15% 分位
   VIX **14.84**                                → **31% 分位(一点都不害怕)**
★★★ 这是「指数被少数大票抬着、大多数票在跌」的分化 ——
   ★ 压成一个分数,第 ① 行的涨和第 ② 行的跌会**互相抵消**,
   ★★★ **而被抵消掉的那个矛盾恰好是最值钱的信息。**
```

## ④ 找机会 —— ★★ 两条路：他有标准 / 他没标准

```
★★★ 他**有**标准（主入口最常见）:
   ① 听懂他要什么 —— ★★★ **不打断,不先问那三个问题**
      (★ 他已经说了他要什么,先审他是不尊重)
   ② 照他说的筛,**先出结果**
   ③ ★★★ **把三类冲突标在结果上 —— 不是拦在前面**
   ④ 给一句话就能改的出口

★ 他**没有**标准 → 才走那三个问题:
   ① 你能什么时候看盘?        ← ★★ **物理约束**,一票否决他执行不了的
   ② ★★★ 面对亏损,你更厌恶哪种痛苦? ← 整套引导的关键设计
   ③ 这笔钱最长多久必须抽走?   ← ★ 击碎「拿短线的钱做长期价值投资」

★★★ 第 ② 问为什么关键:
   ❌ 「你想要机会多一点还是准一点」→ **100% 的人会说准一点**
      ★ 系统把所有人标成高胜率偏好 → ★★ 全量推高胜率、极低赔率、左尾暴雷,
      ★★★ 一次单边大跌**一单亏光一年利润**
   ✅ 「你更厌恶哪种痛苦」—— ★★ 两边都是痛苦、没有正确答案
   ★★★ 一句话:**人对痛苦的偏好是真实的，对「好」的偏好不是。**
```

★★★ **三类冲突，三种说法（★ 说法错了，对的判断也会被当成冒犯）**

| 冲突 | ★ 怎么说 | ★★ 为什么 |
|---|---|---|
| ① 要求之间互斥 | ★ **直说**（「同尺度冲突，建议分两套」） | ★★ 这是**逻辑**问题，不是关于他的 |
| ★★★ ② 要求 vs 他真正愿意做的 | ★★★ **不说「你做不了」，说「这是代价」** | ★ 这是**关于他自己**的 —— 判断句会引起抵触，★★ 而他一抵触，**对的判断也白给了** |
| ③ 要求 vs 我们能做的 | ★ 说清**缺哪一样** + 现在能做哪一半 | ★★ 归属不许错 |

★★★ **原则：不要替他否决，要把代价标在结果上。**

| ★ 现在缺什么 | |
|---|---|
| ❌ **§5 输出样例** | ★ 骨架已定（池子 N 只 · 符合 M 只 · 前提成立 x/10 · 不成立的那条 · 上方空间 · 最大浮亏），★★ 要贴真实输出 |
| ⚠ ★★★ **基本面筛选这一版没开** | ★ 真原因是**池子对不上**（基本面 **250 只** vs 选股池约 **6,000 只/年**），★★★ **不是「我们没有基本面数据」** |
