## 三秒版
1. **「核心位置」怎么算:**
   - 至少 **2 样不同种类**的阻力凑在一起(最好 3 样)。同一种算两次不算,比如日线 0.618 和 1 小时 0.618。
   - 相隔 **≤ 0.5 倍日 ATR**(1 小时用 0.6 倍),整个区宽度 ≤ 1 倍日 ATR。
   - 打分:颈线 / 前低变压力 3.5、成交密集区 2.5、斐波那契 0.618 记 2.0(0.5 记 1.5、0.786 记 1.0)、向下的 50 / 200 日线 1.5、未回补的向下缺口 1.5。**美股 ≥ 5 分才算。**
2. **「没过」看收盘:** 碰到了、收盘没站上就算没过,留长上影最典型。
   - **小周期派发最少要有:** 两次冲高不过 + 动能衰减(放量滞涨 / 缩量冲顶 / RSI 背离,三选一)+ **放量收盘跌破小颈线**。
3. **「过了」:**
   - 连续 2 根收盘在核心区上方 0.25 倍 ATR 以上(Murphy 的「两日规则」);
   - 或者一根大阳线收在上方 0.75 倍 ATR 以上。
   - **过了先全部止损,不马上反手。** 等回踩不破再考虑做多。
4. **美股替代资金费率和持仓量:**
   - **O'Neil 的「派发日」:** 指数跌 ≥ 0.2% 且量比前一天大,25 天里有 ≥ 5 个,就是机构在出货。只用日线就能算。
   - 半导体比纳指弱(相对强弱线);
   - 市场宽度、VIX 底部抬高(这两样要外部数据)。
5. **美股范围:**
   - 大指数最不适合这套(V 回多、板块轮动托底);
   - **行业 ETF(比如半导体)最适合**;
   - 个股收益最高,但财报跳空、逼空风险最大。
   - **大指数空单默认只赌 C = A**(第三段和第一段一样长),到了就全平。只有月线级破位、或顶部横了 9 个月以上,才赌更远(2000、2008、2022 那种)。
6. **最大的死穴:** 空在 B 浪反抽的疲态上,当晚出了大利好(紧急降息),第二天跳空开在核心位置上方,止损单都来不及成交。

## 一、各窗口要点

### A · 美股顶部派发能否事先看到 + 假突破 = 盘整
- **能看到,而且比 BTC 慢、信号更充分。** 机构出货要几周,会留下痕迹。
- **日线四个条件:**
  1. 20~60 天里有两个顶,相差 ≤ 2.5%;或者第二个顶冲过第一个、但收盘站不稳 2 天。箱高 5%~15%。
  2. 周线 RSI 顶背离(第一顶时 RSI > 70);日线 MACD 至少两次峰值递减。
  3. **派发日:** 25 天里 ≥ 5 个,价格离 52 周高点 < 5%。
  4. 收盘同时跌破颈线和 50 日线,确认派发完成。
- **美股替代资金费率 / 持仓量:**
  - 派发日 + 上涨日均量与下跌日均量之比 < 0.85;
  - 相对强弱线(SOXX / QQQ、QQQ / SPY)跌破 20 日线并背离;
  - 市场宽度:站上 50 日线的股票比例从 > 70% 掉到 < 50%(要外部数据);
  - VIX 底部抬高(要外部数据)。
- **假突破 vs 正常突破回踩,五条:**

| 看什么 | 假突破(判为盘整) | 正常突破回踩(别空) |
|---|---|---|
| 站稳 | 收盘从没连续 2 根站在前高上方 | 至少连续 2~3 根收在上方,突破阳线实体饱满 |
| 跌回 | 1~3 根日线内收盘跌回前高下方 | 回踩时收盘一直在前高上方 |
| 量 | 突破时量不够,跌回那根放量 | 突破放量,回踩缩量 |
| 冲多远 | 只冲出 0.3~1.2 倍日 ATR 就掉头 | 先远离 > 1.5 倍日 ATR,再回踩 |
| 小周期 | 跌回后 1 小时线跌破起涨低点 | 1 小时线守住起涨低点 |

- **和 2B、扩散形态的关系:**
  - 动作上和 Sperandeo 的 **2B 是同一个**:冲过前高又跌回来。
  - 但你的处理更稳:**还没跌破颈线时,先当「盘整」处理**,只空到箱底;跌破颈线后才升级成转空。
  - 扩散形态是上沿、下沿都往外扩,不是一回事,也更难做。
- **判成盘整后怎么做:**
  - **进场:** 跌回前高下方后,等 1 小时线第一次反抽不过、或跌破起涨小低点再空。
  - **止损:** 假突破针尖 + 0.2 倍 1 小时 ATR。
  - **门槛:** 到箱底的空间 ≥ 2 倍止损。
  - **到箱底:** 平 70%~80%;剩下的推保本。
  - **之后两种情况:**
    - 在箱底止跌,剩下的保本走掉;
    - **直接跌破箱底:** 切成「主跌」,反抽不过再加回空单,目标看一个箱高。

### C · 核心位置和过不过
- **几样、多近:**
  - 原著没规定数量。行业常用「2 + 1」:2 个不同种类的阻力 + 1 个小周期确认。
  - **同一种不算两样**(日线 0.618 和 1 小时 0.618、EMA20 和 EMA21)。
  - 按 ATR 合并,不用固定百分比:QQQ 和 SOXX 的波动差一倍,固定百分比会合错。
- **美股打分:**
  - **空间分**(满分 10,≥ 5 才算):颈线 / 前低变压力 3.5、成交密集区 2.5、斐波那契 2.0、向下均线 1.5、未补缺口 1.5;
  - **量价确认分**(满分 5,≥ 3 才进):反抽缩量(≤ 前段下跌均量的 70%)2.0、收在当天振幅的下三分之一 1.5、和同类标的强弱背离 1.5。
- **没过:** 收盘没站上就算。小周期派发的四条:
  1. 至少两次冲高不过,中间回落 ≥ 1 倍 1 小时 ATR;
  2. 动能衰减,三选一;
  3. 收盘跌破小颈线 0.15 倍 ATR 以上,且放量 1.2 倍;
  4. **进场:**
     - 激进:跌破当根就空;
     - 稳健:1~5 根内反抽小颈线不过再空;
     - **止损都放在:** 最高的那个顶 + 0.25 倍 ATR。
- **过了:**
  - 连续 2 根收盘 > 区上沿 + 0.25 倍 ATR;
  - 或者一根实体 ≥ 1.5 倍 ATR 的大阳线,收盘 > 上沿 + 0.75 倍 ATR。
  - **怎么处理:** 先全部止损。直接反手胜率低,因为突破后 30%~40% 会深回踩(无出处)。要等回踩上沿不破、小周期出看涨形态,才做多。
- **0.5、0.618、0.786 各是什么:**
  - 0.382:强趋势的浅回撤;
  - 0.5~0.618:最核心的埋伏区;
  - 0.786:高波动品种的最后一道防线。
  - **没有学术统计给出「过了 0.618,下一段走不出来的概率」**,它直说无出处。
  - 只有原著的定性说法:反弹越深,下一段越弱(Prechter、Bulkowski、Brooks)。
- **「每段问一次过不过」对应什么:**
  - 最精确的对应是 **Sperandeo 的 1-2-3**:跌破趋势线 → 反弹测高不过 → 跌破中间低点。
  - 其他对应:道氏的次级折返、威科夫的 LPSY 一级一级往下、SMC 的「结构破坏 / 性质改变」(已有 TradingView 开源代码)。
  - **公开统计:**
    - Bulkowski:反抽不过再跌破的单,达到 1 倍形态高度的胜率 60%~68%;
    - Kaufman:摆动高低点系统,胜率 40%~48%、盈亏比 2.2~3.0。
    - **这两个数我没核到。**

### D · 美股版
- **适合度:**
  - 大指数最差:V 回多,养老金和定投会在跌破 200 日线时机械买入;
  - **行业 ETF 最好:** 同涨同跌,A 浪杀估值、B 浪反抽无力、C 浪杀业绩,结构清楚;
  - 个股收益最高、风险最大:要避开财报季,只做好借券的。
- **C = A:**
  - 大指数默认只看到 C = A,到了就大规模平仓;
  - 只有月线跌破前一个月线摆动低点且 MACD 放大,或顶部横了 9 个月以上再跌破,才看到 1.618 或更远。
- **凭什么比固定反弹空好:**
  - 「派发已形成」过滤掉了牛市里的正常回调;
  - 「过不过」过滤掉了强势洗盘:大阳线直接穿过 0.618 就放弃。
- **美股完整规则(六步):**
  1. 四档,和 BTC 一样;另外个股 / 行业 ETF 相对 SPY 的强弱线要在周线上创新低或背离。
  2. 必须有派发结构(右肩 / 第三个顶缩量)或动能背离,否则不空。
  3. 放量(1.5 倍)收盘跌破颈线;核心区 = A 浪的 0.5~0.618,和颈线相差 < 1%。
  4. **过不过:**
     - 没过:1 小时双顶派发,或 0.618 附近长上影,且缩量;
     - 过了:日线放量大阳线收在 0.618 之上,计划作废。
  5. **仓位:** 左侧 0.5%,止损 1 小时最高点 + 0.5 倍 ATR;右侧 1.5%,止损 B 浪最高点 + 1 倍 ATR;财报前平仓。
  6. **出场:**
     - 跌破 A 浪低点:平 50%,推保本;
     - 到 C = A:再平 30%;
     - **大指数到 C = A 就全平;**
     - 个股 / ETF 剩下 20%,跌回 20 日线上方或财报前一天走。

## 二、我核
- ✅ **O'Neil 的「派发日」:** 指数跌 ≥ 0.2%、量比前一天大;4~5 周里 5~6 个 = 见顶警告。这条出自《笑傲股市》,和我们 361 用过的一致。
- ✅ **Murphy《金融市场技术分析》讲突破过滤:** 两日规则、3% 规则。对得上。
- ✅ **Carney《The Harmonic Trader》(1999)引入 0.786:** 对得上。
- ✅ 其他:Sperandeo 的 2B 和 1-2-3、Edwards & Magee 的扩散形态和「形态越久跌得越狠」、Pring《技术分析解释》的市场宽度、Siegel《股市长线法宝》。
- ⚠ **没核到:**
  - **Bulkowski「反抽不过再跌破,60%~68% 达到目标」**:像是 Gemini 的概括,具体页码和数字要核。
  - **Kaufman「胜率 40%~48%、盈亏比 2.2~3.0」**:同上。
  - 「突破后 30%~40% 会深回踩」:无出处。
  - 这几条都只当方向参考。
- ⚠ **它前后不一致的地方(工程问题,我两边都跑):**
  - **核心区门槛:** ≥ 4.5 分(393 窗口 C)/ ≥ 5 分(美股)/ 「两类重合在 ±0.8% 内」(393 窗口 D)/ 「0.5~0.618 和颈线相差 < 1%」(395 窗口 D)。
  - **右侧止损:** B 浪最高点 + 0.25 倍 ATR(C)/ + 1 倍 ATR(D)。
  - **美股右侧仓位:** 1.5%,又比你定的 1R 重。按【周 3】处理:右侧反抽 = 1R 最重。
- **对我们最要紧的两条:**
  - **「派发日」只用日线就能算**,而且我们 361 已经写过。美股的「顶部派发已形成」可以直接从这里起步。
  - **「每段问一次过不过」= Sperandeo 1-2-3 + SMC 的结构破坏 / 性质改变。** 这套是成文的、能编程的,不需要事先数浪。这正好回答你那句「A、B、C 就是一、二、三浪」:我们不数浪,只每段判一次过不过。

## 三、要定的

**【周 5 / 5】美股版:只在「行业 ETF + 高弹性个股」上做,大指数只赌 C = A**
- **范围:**
  - 先测行业 ETF(SOXX、XLK、XBI 等)和高弹性个股(好借券、避开财报);
  - 大指数(SPY、QQQ)只当对照。
- **顶部派发确认(至少满足一样):**
  - 25 天里 ≥ 5 个派发日,且离 52 周高点 < 5%;
  - 周线 RSI 顶背离;
  - 两个顶相差 ≤ 2.5%,或第二个顶是假突破。
  - 个股 / ETF 还要相对 SPY 的强弱线走弱。
- **跌破:** 放量收盘跌破颈线和 50 日线。
- **核心位置:**
  - 至少 2 种不同的阻力,相隔 ≤ 0.5 倍日 ATR;
  - 打分 ≥ 5;
  - 反抽缩量等量价确认 ≥ 3。
- **过不过:**
  - **没过:** 收盘没站上 + 小周期两次冲不过 + 放量跌破小颈线;
  - **过了:** 连续 2 根收在上方 0.25 倍 ATR 以上,或一根大阳线收在上方 0.75 倍 ATR 以上。过了就全部止损,不马上反手。
- **假突破:** 还没跌破颈线时,只当盘整,空到箱底就平 70%~80%;跌破颈线后升级成主跌。
- **目标:**
  - 大指数到 C = A 全平;
  - 行业 ETF / 个股剩 20% 用 20 日线跟踪,财报前一天走;
  - 只有月线级破位,或顶部横了 9 个月以上,才看更远。
- **仓位:** 左小右重,按【周 3】:左侧 0.3~0.5R,右侧反抽 1R。
- **回测范围:** 2005–2014、2015–2025 两段都跑;2000–02、2008、2022 单独报;同时报大指数对照。
