## 1  这个 Skill 管什么

★ 一件事：**用户设的条件碰到了，我们怎么跟他说。**

```
★★★ 它的立场只有一句:**不说「你该卖了」,说「你当初说的那条线,今天碰到了」。**
★ 推送不是结论,是**回执**。
```

★★ 它**不管**：挑票（走筛选）· 看单票（走 quote）· 创建 agent（走 agent-builder）· 下单（我们不下单）。

## 2  ★★★ 第一道闸：这条条件**准不准进来**（★ 不在表里的，一条都不许触发）

| 档 | 条件从哪来 | 例子 | ★ 能触发吗 |
|---|---|---|---|
| **A1** | ★★★ **他明确设的** | 「跌到 180 我要知道」 | ✅ **能** |
| **A2** | ★★ 他**自己的 agent** 按他定的规则产生的 | 「我的『波段提醒』触发了」 | ✅ **能（走乙档）** |
| **B1** | ★★ 他绑的策略里，**原著自己写的规则** | 「收盘跌破 145 日线离场」 | ✅ **能**（★ 绑定即授权） |
| **B2** | ★★ 他绑的策略里，标「**我们填的**」的规则 | 「斜率阈值」「宽幅箱体多宽」 | ✅ **能 —— ★★★ 但归属必须显示** |
| **C** | ★★ 三问里的**物理死线** | 「这笔钱 8 个月后要用」 | ✅ **能**（★ 这是事实不是判断） |
| **D** | ★ 他绑的打法，**原著写的使用条件**现在不满足 | 「这套原著写明只在牛市中段用」 | ⚠ **原则上能，★★★ 实际几乎没有**（见 §6） |
| **E** | ❌ **我们自己发现的「机会」** | 「这只票形态很好」「这个板块在轮动」 | ❌ ★★★ **永远不能** |
| **F** | ❌ **宏观预测** | 「我们认为要降息了」 | ❌ ★★★ **永远不能** |

```
★★★ E 和 F 为什么是永久禁止:★ 它们是**纯粹由我们下结论** —— 撞在红线正中间。
★★ 而且这两类最容易以「善意提醒」的形状溜进来 —— ★★★ 看到就拒,不要找理由。
```

### ★★ 每条条件必须带两个字段

```
source ∈ { A1 · A2 · B1 · B2 · C · D }
voice  ∈ { 甲档 · 乙档 }
★★★ 写不进这两个取值集的条件,**引擎必须拒绝创建** —— ★ 不是警告,是拒绝。
```

## 3  ★★★ 第二道闸：说话分两档

### ★★ 甲档 · **系统自己发的推送（我们说话）** —— ★★★ 三条全守

```
★★★ ① **永不出现这几个词**:建议 · 应该 · 该卖 · 该买 · 机会 · 别错过 · 注意
      ★ 理由:这几个词**每一个都在替他下结论**。

★★★ ② **第一行永远是「这条是你哪天说的 + 你当时的原话」。**
      ★★ 不是放在底部的小字,是**第一行**。
      ★ 理由:它是这条推送的**合法性来源** —— ★★★ 合法性不许折叠。

★★★ ③ **「为什么现在叫你」的完整链条永远一键可见**:
      条件原文 · 设定日期 · 今天的数 · ★ 当初他为什么设
      ★★ 做到这一条,推送就不是结论,是**回执**。
```

### ★★ 乙档 · **他自己的 agent 发的推送** —— ★★★ 按他的要求来

```
★★★ 他要「该卖了」就给「该卖了」。
★ 这是**他的 agent、他定的规则、发给他自己**。
★★ 理由(Lin 2026-11-04):我们给的是**依据**,★★★ 他拿依据做成什么形状,**是他的选项** ——
   ★ 管着不让他说,那是我们替他决定**怎么跟自己说话**。
```

★★ 但乙档有**三条不让**（★ 不是限制他，★★★ 是防止我们被冒名）：

| | ★ 不让什么 | ★★ 为什么 |
|---|---|---|
| **1** | ★★★ **不许把结论归属给我们** | ★ 他的 agent 可以说「该卖了」，★★★ 但不许显示成「XING 建议卖出」。★★ 要写清是**他的 agent**：「你的『波段提醒』按你 10 月 14 日设的规则发的」 |
| **2** | ★★★ **归属标注必须对他可见** | ★ 他的 agent 可以用我们标「我们填的」那类阈值（★★ 甲档禁止用它触发推送，乙档允许）—— ★★★ 但界面必须显示那个标注，**让他知道这个数是我们填的、不是原著的**。★ 不是禁止，是必须标注 |
| **3** | ★★★ **一旦要分享给别人或上架，回到甲档** | ★★ 他自己用随便；★★★ **分享出去就要过我们的要求**（★ Lin 11-02 定的红线原样） |

### ★ 一句话分界（★★ 背下来这三行就够）

```
★   发给他自己      → 他的规则,他的措辞
★★★ 署我们的名      → 甲档三条全守
★★★ 分享给第三方    → 甲档三条全守
```

## 4  推送长什么样（★ 甲档的模板）

```
★ 第一行(★★★ 不许折叠、不许挪到底部):
   「你 10 月 14 日说:『跌到 180 我要知道』。」
★ 第二行:
   「今天收盘 179.3。」
★ 第三行(一键展开):
   条件原文 · 设定日期 · 今天的数 · 当初你为什么设
★★★ **到此结束。不加任何一句「所以……」。**
```

### ★★ B2 的额外一行（★★★ 空了就不许发）

```
★ 「这条里的『斜率阈值 0.5%』是**我们填的**,不是原著给的。」
★★★ `source = B2` 的推送,**归属标注字段不许为空** → ★ 空了**拒绝发送**。
★★ 注意这不是拒绝创建条件(条件合法)——
   ★★★ 是**不许在不告诉他来源的情况下叫他**。
```

## 5  ★★★ 「替他做」的边界（★ Lin 2026-11-04 定）

```
★★★ **我们的系统从不动手。**
★★ 他要「替他做」,形状是:**他自己的 agent + 他的授权**。
★ 授权粒度 = **按规则 + 按限额**(★★ 不是全权,也不是逐个点确认)。
★★★ 所以条件引擎的输出永远止于**告诉他**;★ 动手那一步在他的 agent 里,不在我们这儿。
```

## 6  ★★★ 两条「现在就要如实说」的

```
★★★ ① **D 档现在基本触发不了。**
   ★ 实测 **44/45 条链的环境开关是空的** → ★★ 「原著写的使用条件现在不满足」这类推送,
     ★★★ 现在**几乎没有能触发的**。
   ★★★ **不许为了让它能触发而去补条件** —— ★ 补出来的条件就是我们发明的闸。

★★★ ② **「绑定即授权」有一个前提:他绑的时候看见了他在授权什么。**
   ★★ 所以绑定那一屏必须显示这套策略的**归属分布**
     (几条原著 · 几条我们填的 · 几条行业惯例)。
   ★★★ 绑定时没显示过、推送里才显示 —— **那是补票,不是授权。**
```

## 7  边界

★ 本卡在任何具体措辞之前，先受 `_shared/common_boundaries.md` 约束。
★★ 本卡**不产生**股票状态、买卖信号、收益统计或目标价 —— ★★★ 它只把**用户自己说过的话**连同**今天的数**返还给他。
★ 数据缺失时：明说缺哪一样，★★ **不许用近似值顶替后仍然发出推送**。
