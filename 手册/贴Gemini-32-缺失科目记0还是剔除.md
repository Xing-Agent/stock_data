# 给 Gemini 的原文（★ 从这里往下整段贴过去）

假设你是一位做实证资产定价研究、并且亲手复现过经典因子论文的研究员。

我们在复现几条经典的基本面策略，遇到一个**数据处理**的问题，不是策略问题。

## 问题

SEC 的结构化财务数据只记录公司实际申报的科目。如果一家公司某年**没有发生**某项业务（比如没有增发股票），它的财务报表里**就没有这一行** —— 而不是写一个 0。

于是我们分不清两种情况：
- **(a) 没发生**：现金流量表是完整的，只是没有「增发」这一行 → 实际上就是 0
- **(b) 真没报**：整张表都没有，或者并进了别的科目（比如应交所得税并进「其他应计负债」）→ 真的不知道

## 请逐条回答（★ 每条都要给出处）

### 第 1 题 · Sloan (1996) 的应计
Sloan 的资产负债表法应计公式里有「**Δ应交所得税**」这一项。
- **原文有没有写这一项缺失时怎么处理？** 如果有，请给**章节或页码**和原话。
- Richardson 等 (2005) 在扩展这个口径时，有没有写缺失处理？

### 第 2 题 · 短期有息负债
Sloan 公式里还有「Δ短期负债」。同样问：**原文写了缺失怎么处理吗？**

### 第 3 题 · 净派现（分红 + 回购 − 增发）
Boudoukh, Michaely, Richardson, Roberts (JF 2007) 的净派现率。
- **原文对「某一项缺失」是怎么处理的？** 请给**页码**和原话。
- 特别是：**增发**那一项缺失时，是记 0 还是把这只股票剔除？

### 第 4 题 · 行业通行做法
在实际的因子研究和买方投研流程里：
- 「报表完整、但没有这一行」这种情况，**通常记 0 还是剔除**？
- 有没有一个判断标准（比如「只要主表是完整的就记 0」）？★★ 如果有，**这个标准是谁提出的、出处在哪**？
- ★★★ 如果**没有公认做法**，请直说没有。

## 三条硬约束

1. **不要给我「一般都这么做」这种无出处的说法。** 如果你不确定某条是原文写的还是后人的惯例，**请直说你不确定** —— 这对我们比一个确定的错误答案有用得多。
2. ★★★ **请区分「原著作者自己写的处理方式」和「复现者（包括教材）自己的选择」。** 我们见过一本公开教材在复现 Sloan 应计时用了「缺了就记 0」，但**教材自己明说这是它的选择，还在习题里问读者这样合不合适** —— 这种就不能算原著的做法。
3. **不要建议我们「用行业中位数填补」或类似的插值。** 我们的规矩是：算不出来就写算不出来，不用近似值顶替。
