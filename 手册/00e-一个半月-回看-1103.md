## 屏 1 · 起点:这件事按老办法,需要一个我们没有的团队

★★★ 一个半月前手上有的,只有**一个目标**:把金融投资的顶级智慧和策略**编码化**,再用智慧的方式给到每个人。

★★ 而这件事在 AI 之前要做,需要的是这样一支队伍:

```
┌──────────────────────────────────────────────┐
│  基金管理的人   —— 懂策略本身                 │
│  量化的人       —— 懂回测和统计                │
│  工程的人       —— 懂把它变成能跑的代码        │
│  产品的人       —— 懂怎么让普通人看得懂        │
│  ★ 外加一个很大的顾问团                       │
│     —— 因为涉及的流派之多、策略之广,          │
│        没有一个人能全懂                        │
└──────────────────────────────────────────────┘
          ★★★ 这些,我们一个都没有。
```

★★★ 而要跨过去的那条链,每一环当时**都不知道怎么办**:

| | 当时的状态 |
|---|---|
| 到底有哪些策略? | 不知道 |
| 哪些是好策略? | 不知道 |
| 这些策略长什么样? | 只有一段介绍 |
| 完整的代码? | **一行都没有** |
| 回测? | **一次都没做过** |
| 怎么匹配给人? | 不知道 |
| 怎么让一般人也看得懂? | 不知道 |

★★ 而且不只是你不知道 —— **我也不知道**。★★★ 当时你对我和 Gemini 的能力边界也只有很有限的了解。这是起点的真实情况。

## 屏 2 · 为什么一个半月走得完

★★★ 先把这件事的真实形状说清楚:**一个人 + 两个 AI,去做一支华尔街大型基金团队的事。**

★★ 而最关键的一点是:

> ★★★ **这件事对那支基金团队来说,也是全新的。**

★ 它不是「他们早就会、我们追上了」—— 是这套东西**本来就没人做过**:哪些算好策略、原著没说的地方怎么办、怎么匹配给人、怎么让普通人看懂。★★ 他们要做,也得从重新思考和重新设计开始。

★★★ 这一句把「大团队」的优势**反转成了劣势**:

```
一支大团队的强项:  分工做「已知的事」
                    —— 事情定了,拆给十个人,各干一块,效率极高

这件事的性质:      每一环都要先想清楚,才能分工

★★★ 所以在想不清楚的阶段 ——
     人多是成本,不是产能。
     每一次方向改,十个人都要重新对齐一遍。
```

### ★★★ 真正被压缩的不是「聪明」,是试错的代价

★ 这是这一个半月唯一一个说得硬的因果:

| | 我们 | 那支团队 |
|---|---|---|
| 踩了 **40 个坑** | 几小时修一个 | ★ 每个都是「几周 + 几个人 + 一次向上解释」 |
| 推翻自己结论 **3 次** | 当天作废、留档、继续 | ★ 一次就够开一轮会 |
| 考卷开考后**作废重来** | 停跑、留档、重跑 | ★ 基本不会发生 —— 因为代价太高,人会倾向「先用着」 |

★★★ **不是走的路更短,是同一条路上每一步的单价低了两个数量级 —— 所以才走得完。**

## 屏 4 · 目标变了吗?——没变。变的是怎么走

| | |
|---|---|
| **目标(没变过)** | 让普通人也拿到原来拿不到的那套东西;不承诺赚得多,承诺「亏小、不亏大」 |
| **一个半月前以为的路** | 把大师策略写清楚 → 用户照着做 |
| **现在实际的路** | 把大师策略**如实复原**(含它没说清的地方,照样标成没说清)→ 测出它在什么环境、什么票上什么样 → **让用户自己挑**,我们只给判断的依据 |

★★★ 这一句是整个一个半月最大的改变:

> **我们不替用户判定一条策略好不好,我们把它是什么样如实摆出来,让他自己定。**

★ 这一句话今天站得住,是因为中间所有想「替他定」的尝试,都被自己的数否掉了。

## 屏 5 · 那支团队是怎么替出来的:三个人,互相摸边界

★★★ 没有那支队伍,实际发生的是**三个人临时组了个团**:

```
   Gemini   —— 原著、流派、行业做法、方法论
   Claude   —— 落地成代码、跑数、查自己的错
   Lin      —— 判断、拍板、定方向
```

★★★ 而这一个半月真正在做的事,除了做产品,还有一件:

> **为了这个目标,来回测试每个人能做多少、边界在哪。**

★★ 一开始谁都不知道对方的边界在哪 —— 所以**既低估过,也高估过**。这两类都有具体的例子:

### ★★ 低估了它的地方(它给的东西我们完全没想到)

| | |
|---|---|
| **正交宏观锚点** —— 不许用策略自己的微观零件去定义它的大环境 | ★★★ 这一条我**完全没想到**,是它提的。已写进《02》第 3 节 |
| **在我们代码里找到一个真 bug** | ★★ 技-11 两日结构(10-29) |
| **它对我们的那句评价** | 「这不是健康的研究迭代,是工程质量失控。」★★★ 我们**接受了**,并照它给的药吃(写策略的人和写对照的人分开 · 标准答案集) |

### ★★ 高估了它的地方(以为它的结论能直接用)

| | |
|---|---|
| **走带游程分布的三项预测** | ★ 全部被我们的数据**否掉**(10-29) |
| **「四格全正」当门槛** | ★ 实测会**误杀一半好策略**:t=2.0 → 单格 t=1.0 → Φ(1.0)=0.8413 → 四次方 = **0.5011** |
| **Z ≥ 1.96** | ★ 它和它自己正文的 `t ≥ 3.0` **自相矛盾**,差一倍多。追问过,★★ 它两边都想要 |
| **它给的出处** | ★ 一律要标【待核实】才能用(例:Connors & Alvarez 2008) |

★★★ 所以才有了《04-采用自Gemini的清单》这份东西 —— ✅ 采用 / 🔧 改用 / ❌ 否决,**逐条有据**。
★★ 那几条 ❌ 是最值钱的:它们是以后有人(包括我们自己)又把它捡回来时,拦住的那道闸。

## 屏 6 · ★★★ 你定的那条分水岭

> **站在巨人肩膀上,往前跳一跳。**

★★ 这一条是整件事的**分界线**,它同时挡住了两头:

| 不站在肩膀上 | 不往前跳 |
|---|---|
| ★ 就是自己发明阈值、自己造一个闸,然后标成原著 —— **我们明确拒绝了 5 处** | ★ 就只是把书抄一遍 —— 那对用户没用,也不是我们的位置 |

★★★ 落到做法上,它就是那句反复用的规矩:

```
原著说了的      → 如实复原,一个字不改
原著没说的      → 标成「原著没说」,不替它填
我们往前跳的    → ★ 明确标「这是我们填的」,并且必须有实测
```

★ 三类东西在同一张表上分开写,谁也不许冒充谁 —— **这就是「站在肩膀上往前跳」的工程版本。**

## 屏 7 · 五个转折点(都能查到)

### 转折一 · 10-26 ★ 停下来,换方向

**当时在干**:在「进场信号」上下功夫,想把突破点测准。

**发生了什么**:怎么调都看不出稳定的优势。

**你的决定**:个股这条线**停止在进场信号上继续下功夫**,改去测**出场规则和选池**,各拿随机进场当对照。

★★ **为什么是转折**:这是第一次承认「我们找错了地方」。后面所有能跑出结论的实测,都是在这个新方向上做的。

---

### 转折二 · 10-29 ★★★ 我们自己的结论,被自己推翻

**当时手上有个结论**:「没有一条策略链打得过朴素基准」—— 听着像个重大发现。

**查出来是什么**:那个让基准看起来无敌的 **+450.75%,是未修拆股造出来的假数**。整只票剔掉重跑,基准没塌,反而翻到 **+1052.52%**。

**之后变了什么**:
- 原结论当天**作废**并留档(没有悄悄删掉)
- 开始建**坑表** —— 每踩一个坑登记一条,最后到 **40 处**
- 把七类没人看守的自检,落地成**会 FAIL 的检查**

★★★ **为什么是转折**:从这天起,我们对自己的数的态度变了 —— **一个结论要先回答「它什么时候会作废」,才算一个结论。**

---

### 转折三 · 10-29/30 ★★★ 外部专家的话,也要落到数上

**同一两天发生了两件相反的事**:

| | |
|---|---|
| Gemini 的**三项预测**(走带游程分布) | ★ 全部被我们的数据**否掉** |
| Gemini 在我们代码里 | ★★ 找到一个**真 bug**(技-11 两日结构) |

★★★ **为什么是转折**:这两件事放一起,才定下了后来的协作方式 ——

> **问 Gemini 要「假设」和「原著怎么说」,不要「结论」。它的话一律落到我们自己的数上才算。**
> ★ 它看我们的实现,比看我们的结论有用得多。

---

### 转折四 · 10-30 ★★ 愿意接受「这条路不通」

**测的是**:成交量能不能判顶底。

**结果**:**六个指标全输给瞎猜。**

★★ **为什么是转折**:这个结论没有任何产品价值 —— 它不能上界面,不能卖,不能写进 BP。但我们留下了它。

★★★ 从这里长出来的是那条后来反复用的原则:

> **自己定一个阈值,就等于自己发明一个闸,然后把它标成原著。**

★ 到最后,我们有 **5 个地方明确拒绝填**(技-3 斜率阈值 ·「宽幅箱体」多宽 ·「牛市中段」· 「成长股领涨」·「温和上涨但每天波动」)。**这是产出,不是缺口。**

---

### 转折五 · 10-31 ★★★ 产品哲学定稿:规格表就是说明书

**之前的方案**(我提的、你也同意过):拿统计显著性 t 值当上架门槛(t ≥ 3.0 及格)。

**你否掉了**,并给了新的定调:

```
核心不是门槛,是「把原著实际情况如实复原」。
规格表就是说明书。用不用,是用户的选项 —— 像商品一样。
显著性只是规格上的一格,不是阻碍上线的原因。
```

★★★ **为什么是转折**:这一句改掉了产品的整个形状。
★ 没有它,V2 会长成「我们筛好的策略池」;有了它,V2 长成「**一个带完整说明书的策略货架**」。而前者我们没资格做 —— 筛的那只手就是替用户下结论的那只手。

考卷**第一次开考,我们自己作废了**(数据污染)。当时离交付只剩一天。

★ 停跑 · 留档 · 等拍板 —— 没有「先用着,回头再修」。

## 屏 8 · 学到了什么

### ★★★ 你自己的那句(我认为是对的,而且是最核心的)

> **在探索中逐渐学习,拿反馈,中间做调整。**

★ 这句话听着像常识,但这一个半月证明了它的一个**非常不常识**的含义:

```
不是「先想清楚再做」,
也不是「边做边改」,
而是:每一步都做成「能被下一步否掉」的样子。
```

★★ 所以我们才留坑表、留作废记录、留封存段 —— **不是为了好看,是为了让下一次反馈有地方落。**

---

### ★★ 我补三条

| | 学到的 | 代价是什么换来的 |
|---|---|---|
| **一** | **结论的寿命,比结论本身重要** —— 一个结论要带着「什么时候作废」才算成立 | ★ 10-29 那个 +450.75% |
| **二** | **外部专家出假设,不出结论** —— 它最大的价值是看我们的实现,不是给我们答案 | ★ 三项预测被否 + 一个真 bug |
| **三** | **把「不知道」显式化,比填上它快** —— 5 个拒绝填的地方,省掉的是后面每一次「这个数哪来的」 | ★ 10-30 量判不出顶底 |

---

### ★★★ 还有一条是关于我们俩怎么配合的

```
Gemini  →  出原著、出行业做法、出假设、看我们的实现
我      →  落地成代码、跑数、查自己的错、把问题整理成一页
你      →  拍板
```

★★★ 这个分工之所以有效,关键不在三个角色,在**一条规矩**:

> **Gemini 说的、我算的,都不算结论。只有落到我们自己的数上、并且经得住「它什么时候作废」这一问的,才算。**

★★ 它中间进化过两次:
1. 从「散着问」→ **编号问题单**(到最后是八问 / 三问),每条带**我的倾向**,你只回「同意 / 不同意」
2. 从「问它要答案」→ **也让它给数,我们自己跑完再对比,有出入就追问**

### ★★★ 而这套合作方式本身,就是第四条学到的东西

> ★★★ **这一个半月的产出不止是 V2 —— 是「三个人怎么替掉一支队伍」的那套办法。**

★★ 前面那支我们没有的队伍(基金 + 量化 + 工程 + 产品 + 顾问团),最后是靠**互相摸清边界**替出来的,不是靠谁一个人补上。
★ 这套办法是可复用的 —— ★★★ 下一批策略进来,走的是同一条流水线,而不是再从零摸一遍。**这才是「可规模化」真正的意思。**

## 屏 9 · 一句话收尾

★★★ 一个半月前,大师策略里只有一段介绍。

★★★ 今天,它有代码、有回测、有 110,000 笔实测、有说明书、**也有五处明确写着「这里原著没说,我们不替它填」**。

★ 最后那一项,是我认为这一个半月最值钱的东西 —— 因为它是唯一一项**没法靠加班补出来**的。

---

### ★★★ 最后一句,是关于「凭什么走下来」的

★★ 策略组这一个半月,支撑着走完的其实就一条:**相信这件事能做到。**

★★★ 而这个「相信」起的作用,跟一般人想的不一样 —— 它不是让人更自信,是让人**敢把自己的结论推翻**:

```
不相信这件事能做到的人,
不会愿意作废一个听起来很厉害的发现 ——
因为那可能是他手上唯一的成果。

★★★ 只有真信后面还有东西的人,
     才舍得把 +450.75% 那个结论当天就扔掉。
```

★★ 所以这一个半月里那三次推翻自己、那次考卷作废重来,★★★ **不是纪律好,是底气足。**

★ 而且我们没有喊口号 —— **40 个坑、265 次提交、110,000 笔实测,是交上来的作业。**
