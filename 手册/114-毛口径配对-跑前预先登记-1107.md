## 四、怎么比（规矩㊸v2 配对检验）

```
1. 同一族、同一窗口、同一批信号，取 【A原样(ADV20)】 和 【R随机sd】 两条臂
2. ★★★ 取两条臂的**毛净值**曲线，各自转日收益，**逐日相减** → 差值序列
```

### 4.2 ★★★ 预先写死：三种结果各对应什么话

```
★★★ 情形一：毛口径配对 t 仍然为正且过 |t|>3
→ ★★ 写：「**ADV20 排序在摩擦之外也有优势** —— 不是成本档位给的。」
   ★ 这时候《113》第五节那句「全部利润挂在这个旋钮上」要升级成
   「这个旋钮本身有选股作用」，★★★ 并且必须接着问「为什么」（文献上没有支持）。

★★★ 情形二：毛口径配对 t 掉到 |t|<3，而净口径更高
→ ★★★ 写：「**ADV20 的优势有一部分（或全部）是成本模型给的，不是选股给的。**」
   ★ 这时候该动的是**对照的设计**：随机排序这把尺子要么改成**同成本档位**内比，
   ★★ 要么两边都用一刀切摩擦（`flat_friction_bps`）。
   ★★★ **不是继续在净口径上找显著** —— 那是拿一个构造性优势当成绩。

★★★ 情形三：毛口径配对 t 变成**负的**且过门槛
→ ★★★ 写：「**ADV20 排序在摩擦之外是在伤害成绩** —— 它赢只因为它买的票便宜交易。」
   ★ 这是最该发生就发生的那种结果；★★ 真出现了，拍板项① 就不是「要不要换」，是「必须换」。

★★ 另：**毛口径只剥摩擦，不剥别的** —— ★★★ 毛口径下大家都不付成本，
  这不是「更真实」，是「把一个变量关掉」。★ 对外成绩一律仍用净口径（《104》）。
```
