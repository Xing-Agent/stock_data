### 1. 手动交易员判「区间顶、可以空」时实际在看什么？（按重要性排序）

一个顶级交易员绝不会孤立地看一根 15 分钟线破了 24 小时高点就做空，他们脑子里的决策漏斗严格遵循「大周期定生死 → 结构定边界 → 微观定强弱 → 指标与时间做过滤」的顺序：

#### 第 1 顺位（决定生死的锚点）：大周期的位置（1D / 4H 阻力、未回补前高、均线带）
- 理论依据：【书上原话】（《以交易为生》Trading for a Living，Alexander Elder —— 三重滤网系统：大周期潮汐决定交易方向，逆大周期关键位交易胜率骤降；《价格行为交易：震荡区间》Trading Price Action Trading Ranges，Al Brooks —— 只有当小周期区间顶部与大周期主要阻力重合时，突破失败的概率才显著高于真突破）。【行业里有人在用】（多周期共振区 HTF Confluence Zone）。
- 人实际在看什么：1 小时的箱体如果在 4 小时/日线图上是「悬空位（Mid-air）」，主力资金根本不会在这里派发，它只是大周期上涨途中的中继旗形。人只会在 1H 箱顶恰好撞上 4H/1D 级别前高、4H 顶底转换位（S/R Flip）或向下倾斜的 4H 均线带时，才把这里当成真顶部。
- 代码定义（【我自己的建议】，所有参数均无出处，为工程化落地设定）：

```python
atr_4h = calc_atr(df_4h, period=14).iloc[-1]
tol = 0.5 * atr_4h # 阻力共振容差带（无出处）

# 1. 4H 过去 120 根（20天）内的未破坏结构摆动高点，或前期有效支撑跌破后的顶底转换位

# 2. 4H 均线带阻力（EMA50 与 EMA200 均向下倾斜，且价格从下方反抽触及）

falling_ma_zone = (
ema50_4h.iloc[-1] < ema50_4h.iloc[-4] and
abs(box_high - ema50_4h.iloc[-1]) <= tol
)

level_hit = any(abs(box_high - lvl) <= tol for lvl in (htf_swings + htf_flips))
return level_hit or falling_ma_zone
```

#### 第 2 顺位（结构骨架）：箱体是怎么画出来的（多点摆动高低点 + 边界拒收）
- 理论依据：【书上原话】（《期货市场技术分析》Technical Analysis of the Financial Markets，John J. Murphy —— 有效水平阻力至少需要两个以上时间上分离的波峰确认，触及次数越多阻力越强；《价格行为交易：震荡区间》Trading Price Action Trading Ranges，Al Brooks —— 真正的震荡区间必须表现出双向交易特征，即上下边界均出现过明显的突破失败与向中轴折返）。
- 人实际在看什么：人画箱体画的是肉眼可见的水平折返带——至少有两个以上时间拉开距离的波峰，中间隔着明显的回调波谷，且 80% 以上的 K 线实体乖乖待在箱体内部。

```python
def is_valid_structural_box(df_1h, box_high, box_low):
atr_1h = calc_atr(df_1h, 14).iloc[-1]
tol = 0.25 * atr_1h # 边界聚类容差（无出处）
window = df_1h.iloc[-72:] # 动态回看72小时（无出处）

swing_highs = get_fractal_swing_highs_with_idx(window, left=2, right=2)
swing_lows = get_fractal_swing_lows_with_idx(window, left=2, right=2)

top_touches = [idx for idx, p in swing_highs if abs(p - box_high) <= tol]
bot_touches = [idx for idx, p in swing_lows if abs(p - box_low) <= tol]

# 至少 2 个独立波峰、2 个独立波谷，且首尾波峰间隔大于等于 6 根 1H K线（无出处）
if len(top_touches) < 2 or len(bot_touches) < 2:
return False
if (max(top_touches) - min(top_touches)) < 6:
return False

# 实体包容度：箱体形成期间，大于等于 80% 的 1H 收盘价必须位于箱体内部（无出处）
sub = window.iloc[min(min(top_touches), min(bot_touches)):]
inside_ratio = ((sub['close'] <= box_high + 0.1 * tol) & (sub['close'] >= box_low - 0.1 * tol)).mean()
return inside_ratio >= 0.80
```

#### 第 3 顺位（微观博弈证据）：小周期（15m）上的派发与吸筹失败痕迹
- 理论依据：【书上原话】（《威科夫量价分析》Trades About to Happen，David H. Weis —— 「努力与结果背离（Effort vs. Result）」：在阻力位出现高成交量但价格无法推进、收盘价位于 K 线低位，说明被动限价卖单正在吸收主动买盘；《价格行为交易：震荡区间》Trading Price Action Trading Ranges，Al Brooks —— 区间顶部的连续上影线尾巴与二次冲高失败是最佳做空结构）。【行业里有人在用】（SFP 扫流动性 + Lower High 次高点确认）。
- 人实际在看什么：注意，微观量价结构排在技术指标前面。人在 15 分钟图上看的是「买盘用力撞墙却撞不动」——要么是连续几根长上影线戳向同一个位置，要么是放巨量拉出一根冲高回落针（大努力、小结果），紧接着反弹无力形成更低的高点（Lower High）。

```python
def has_15m_distribution_footprint(df_15m, box_high, atr_1h):
recent = df_15m.iloc[-6:] # 最近 1.5 小时内的 6 根 15m K线（无出处）
vol_ma20 = df_15m['volume'].rolling(20).mean().iloc[-6:]

# 1. 上影线占整根振幅比例
bar_range = (recent['high'] - recent['low']).replace(0, 1e-9)
upper_wick = recent['high'] - recent[['open', 'close']].max(axis=1)
wick_ratio = upper_wick / bar_range

# 2. 努力与结果背离（放量滞涨/冲高回落：量大于等于 1.4 倍均量，但收盘在下半部 <= 0.35）
close_pos = (recent['close'] - recent['low']) / bar_range
absorption_bars = (recent['volume'] >= 1.4 * vol_ma20) & (close_pos <= 0.35) & (recent['high'] >= box_high - 0.2 * atr_1h)

# 满足：至少 2 根长上影（>= 0.5），或者出现放量吸收针且最新一根 K 线收阴并跌破前一根低点
multi_wicks = (wick_ratio >= 0.50).sum() >= 2
confirmed_absorption = absorption_bars.any() and (recent['close'].iloc[-1] < recent['open'].iloc[-1]) and (recent['close'].iloc[-1] < recent['low'].iloc[-2])

return multi_wicks or confirmed_absorption
```

### 2. 「过去 24 根 1 小时线最高最低」和人画的箱体差多少？给 3 种更接近人画法的算法

你们的 24 根滚动高低点，和人类交易员画的箱体之间隔着四道鸿沟（【我自己的建议】）：

- 单针污染：24 小时内哪怕只有 1 根新闻插针，就把箱顶拉高 1.5%，导致后面 20 小时价格都在真实箱顶下方运行却碰不到你的假箱顶；人画箱体画在多次折返的水平带上，会忽略单根极端毛刺。
- 滑动窗口悬崖效应：24 小时前的老高点一旦滑出窗口，箱顶瞬间掉下来，制造大量根本不存在的「假突破」。人的箱体是事件锚定（Event-anchored）的——从脉冲行情结束出现高点开始，直到被有效突破才作废。
- 斜率通道误判：缓慢爬升的阶梯通道，ADX(14) 依然低于 22，过去 24 根的最高点永远在最右边、最低点永远在最左边——这是上升通道，不是水平箱体。
- 缺少双向中轴穿越：真箱体里价格必须在上下沿之间反复拉锯；单边横盘紧贴上沿（贴线阴涨）是蓄力突破前兆，不是箱体震荡。

下面给你 3 种贴近人眼画法、且仅依赖 OHLCV 即可精确计算的箱体定义：

#### 算法一：结构摆动点聚类 + 交替验证箱体（Swing Pivot Clustering）
- 依据：【书上原话】（《期货市场技术分析》Technical Analysis of the Financial Markets，John J. Murphy —— 水平支撑阻力线连接多个波峰或波谷；《价格行为交易：震荡区间》Trading Price Action Trading Ranges，Al Brooks —— 上下边界交替测试构成震荡区间）+ 【我自己的建议】（算法参数无出处）。
- 算法步骤：
  - 提取分形拐点：在 1H 周期过去 N = 96 根 K 线（4 天，无出处）内，找出所有局部摆动高点（前后各 2 根 K 线均低于该高点）和摆动低点。
  - 水平带聚类：以 tol = 0.25 * ATR(1H, 14)（无出处）为带宽，对所有摆动高点做一维聚类。选出触及次数大于等于 2 次、且首次触及与最近一次触及间隔大于等于 6 根 1H K 线的最高聚类簇，取簇内高点的中位数作为 box_high（用中位数天然过滤单根极端长针）。同理得到 box_low。
  - 防通道交替检验（关键一步）：检查触及 box_high 的时间点集合 $T_{high}$ 与触及 box_low 的时间点集合 $T_{low}$ 是否存在时间交错（例如出现过 低 -> 高 -> 低 或 高 -> 低 -> 高 的完整折返）。如果所有低点全在左侧、所有高点全在右侧，判定为斜率通道，直接剔除！
  - 实体包容与未破坏检验：从箱体首个锚点至今，至少 80%（无出处）的 1H 收盘价位于 [box_low - 0.1*tol, box_high + 0.1*tol] 内，且从未出现连续 2 根 1H 收盘价站稳在 box_high + 0.25 * ATR(1H) 之上。

#### 算法二：OHLCV 近似成交量分布与 70% 价值区箱体（Approximate Volume Profile / VPVR Value Area）
- 依据：【书上原话】（《市场轮廓理论》Mind Over Markets，James F. Dalton & Steidlmayer on Markets，J. Peter Steidlmayer —— 70% 成交分布价值区 Value Area、控制点 POC 与边缘拒绝尾 Excess）+ 【行业里有人在用】（加密永续 VPVR 固定范围成交分布交易法）+ 【我自己的建议】（OHLCV 分桶重构算法与参数无出处）。
- 为什么可行：虽然你们没有逐笔成交，但将每根 15m 或 1H K 线的成交量均匀切分到其 [low, high] 价格区间内，在 48~96 小时的周期上与真实 VPVR 价值区重合度极高。人眼画的「密集成交箱体」，本质上就是 VAH（价值区上沿）到 VAL（价值区下沿）！
- 算法步骤：
  - 定位整理窗口：寻找最近一次振幅大于等于 3.0 * ATR(1H, 14)（无出处）的脉冲行情结束点，取其后的 36 ~ 96 根 1H K 线作为整理窗口。
  - 价格分桶累加成交量：将窗口内 [min_low, max_high] 均分为 40 个价格档位（Bins，无出处）。遍历窗口内每根 15m K 线，将其 volume 平均分配给它所覆盖的所有价格档位。
  - 计算 POC 与 70% 价值区：成交量最大的档位即为 POC（控制点）。从 POC 开始，每次向成交量更大的相邻上下档位扩展一格，直到累计成交量达到窗口总成交量的 70%（【书上原话】Dalton 70% 价值区标准）。上边界即为 box_high (VAH)，下边界即为 box_low (VAL)。
  - 对称性验证：要求 POC 位于价值区中部（0.35 <= (POC - VAL) / (VAH - VAL) <= 0.65，无出处），确保是双向均衡震荡而非单边趋势；做空区域即价格刺穿 VAH 进入上方低成交量拒收尾（LVN / Excess）后跌回 VAH 下方。

#### 算法三：关键时间锚定箱体（前日高低点 PDH/PDL 与亚洲盘区间 Asia Range）
- 依据：【行业里有人在用】（ICT / 机构日内流动性池理论：PDH/PDL 与亚洲盘区间猎杀）+ 【书上原话】（《日内短线交易模式与开盘区间突破》Day Trading with Short Term Price Patterns and Opening Range Breakout，Toby Crabel —— 前日极值与开盘区间锚定逻辑）+ 【我自己的建议】（UTC 时段参数无出处）。
- 为什么可行：全市场日内交易员的图表上都画着两根完全客观的水平线——前一日最高/最低价（PDH/PDL）和亚洲盘最高/最低价（00:00–07:00 UTC），全市场的止损单与爆仓单天然聚集在这两条线外侧。
- 算法步骤：
  - 客观划定边界：以每日 00:00 UTC 为界，计算前一日 PDH = max(high)、PDL = min(low)（或当日 00:00–07:00 UTC 的 Asia_High / Asia_Low，无出处）。

### B 组问题 5：箱高 ATR 区间、止损下限的出处，以及「24 根极值 vs 4 倍 ATR」的冲突
#### 5.1 「箱高 1.5~4 倍 ATR」和「止损距 ≥ 0.45%」有出处吗？
- 【书上原话】（《New Concepts in Technical Trading Systems》J. Welles Wilder Jr.） Wilder 提出了 14 周期 ATR 用于衡量真实波幅，并用 2.8 ~ 3.0 倍 ATR 作为抛物线/波动率跟踪止损的参考量级，但原著中从未提出过「箱体高度等于 1.5~4 倍 ATR」或「止损距离大于等于 0.45%」（这两个具体数字均 无出处）。
- 【书上原话】（《Trading Price Action Trading Ranges》Al Brooks） Brooks 对交易区间的结构定义是定性而非固定倍数：他指出一个有效的日内交易区间，其高度通常至少需要达到「平均单根 K 线实体/波幅的数倍」，否则扣除点差与手续费后区间内部没有足够的波动空间可做（具体倍数阈值 无出处）。
- 【行业里有人在用】 止损距 ≥ 0.45% 本质上不是技术分析规律，而是币圈吃单（Taker）手续费倒逼出来的算术门槛（具体 0.45% 这个数字 无出处）。按 Binance 吃单双边 0.10% 加上止损滑点（约 0.03%～0.05%）计算，单笔摩擦成本约 0.13%～0.15%；若要将成本控制在 0.3R 以内，止损距离就必须大于 0.45%。但问题在于：你不能为了凑手续费分母，强行把本来只需要 0.25% 止损的紧凑假突破过滤掉。

#### 5.2 「24 根 1H 极值」与「箱高 ≤ 4 倍 ATR」在数学上确实直接冲突
- 【我自己的建议】 你们的判断完全正确，这两条规则在数学上是自相矛盾的，直接砍掉了 77% 的样本，而且留下来的恰恰是质量最差的 23%：
  - 随机游走尺度律（$\sqrt{N}$ 冲突）：假设 1 小时价格波动近似零漂移随机游走，单根 1H 的 $\text{ATR}(14)$ 约为单步标准差 $\sigma$ 的 $1.5 \sim 1.8$ 倍；而连续 $N=24$ 根 K 线的极差（HH(24) - LL(24)）的数学期望约为单根波幅的 $\sqrt{24} \approx 4.9$ 倍（无出处，此为布朗运动极差标度律推算）。也就是说，哪怕市场完全没有趋势、纯随机震荡，24 小时最高最低跨度的平均值也在 4.9 倍 ATR 左右。

### 第 7 题：更贴近人类交易员的第二版规则（V2）

#### 模块一：人类视角的箱体定义（取代「滚动 24 根高低点」）

  - 量化参数： 15m 最高价 刺破 箱顶 达 0.05 × 箱高 至 0.40 × 箱高，且在刺破后的 1 至 3 根 15m K 线内（放宽 V1 必须当根收回的死板限制），出现一根 15m 阴线 收盘重新跌回 箱顶 下方，且该阴线收盘价位于自身振幅的下半部分（收盘价 ≤ 最低价 + 0.40 × (最高价 - 最低价)）。【我自己的建议】
- 路径 B：二次/三次触顶不破 + 小结构破位（Lower High & Micro-BOS）：
  - 定性原则： 区间顶部常见的双顶（Double Top）或三推楔形（Three Pushes Up）结构，当价格多次测试顶部无力突破，并跌破两次冲顶之间的回调低点（颈线/微结构支撑）时，空头趋势在局部确立。【书上原话】（《Trading Price Action Trading Ranges》，Al Brooks，具体回调深度无出处）
  - 量化参数： 价格第 2 次或第 3 次进入 箱顶 阻力带（箱顶 - 0.20 × ATR(1H, 14) 至 箱顶 + 0.05 × 箱高），未能突破前一次触顶高点（形成 15m 次高点 Lower High）；随后一根 15m 阴线 收盘跌破两次触顶之间的 15m 局部回调低点（该回调低点距离箱顶深度需 ≥ 0.35 × ATR(1H, 14)，确保有明确的颈线结构）。【我自己的建议】

#### 模块五：执行方式、止损定位与分批止盈（修复摩擦成本）
- 5.1 挂限价单微幅反抽入场（降低吃单费率与滑点）：
  - 定性原则： 在确认信号出现后的小幅回抽中挂限价单（Limit Order）成交，可显著降低滑点并获取挂单费率优势。【行业里有人在用】
  - 量化参数： 触发 K 线收盘后，在 收盘价 + 0.25 × (止损价 - 收盘价) 处挂限价空单，有效期 2 根 15m K 线（30 分钟）；若 2 根内未成交则撤单放弃（价格直接瀑布下跌不追空）。回测按 Binance 挂单（Maker）0.02% 计费（若限价未触发但触及止损则不计成交）。【我自己的建议】
- 5.2 结构针尖止损与取消止损下限：
  - 定性原则： 止损必须放在证明交易逻辑失效的结构极值外侧，且仓位大小由 1R / 止损距离 决定，而非用固定百分比剔除窄止损交易。【书上原话】（《Trade Your Way to Financial Freedom》，Van K. Tharp，阐述基于 R 乘数的头寸规模模型，具体缓冲系数无出处）
  - 量化参数： 止损价 = max(本轮冲顶最高价, 箱顶) + 0.15 × ATR(15m, 14)。取消 V1 的 止损距 ≥ 0.45% 限制，改为 0.25% ≤ 止损距 ≤ 0.40 × 箱高（只过滤极端的毛刺噪声，完整保留高盈亏比窄止损交易）。【我自己的建议】
- 5.3 盈亏比门槛、中轴推保本与时间止损：
  - 定性原则： 区间交易中，区间中轴（50% 均衡位）是第一道强磁力与获利了结区，到达第一目标后将止损移至保本位可消除本金风险。【行业里有人在用】
  - 量化参数： 入场前要求 到箱体中轴（箱底 + 0.50 × 箱高）的潜在空间 ≥ 1.0R（因限价入场优化了盈亏比，门槛从 1.2R 调至 1.0R）。触及中轴平仓 50%，剩余仓位止损移至 入场价 - 0.05%（覆盖双边手续费的真保本）；第二目标 箱底 + 0.15 × 箱高。时间止损放宽为：32 根 15m K 线（8 小时）未触及 TP1 平仓；96 根 15m K 线（24 小时）未触及 TP2 全部平仓。【我自己的建议】

#### 模块六：资金费率与风控护栏
- 6.1 资金费率顺拥挤度过滤（反人挤人）：
  - 定性原则： 永续合约资金费率为正代表多头向空头支付费用，极端正费率反映多头杠杆拥挤；极端负费率反映空头拥挤，容易触发轧空。【行业里有人在用】
  - 量化参数： 当最新 8 小时资金费率 ≤ -0.01% 时禁止做空（V1 的 -0.02% 太宽松，在 -0.01% 至 -0.02% 区间币圈已经开始频繁轧空）；当资金费率 ≥ +0.01% 时优先放行（多头拥挤，空单享有正费率补贴与平仓踩踏红利）。【我自己的建议】
- 6.2 波动率异常与同箱体止损熔断：
  - 量化参数： 1H ATR(14) / SMA(ATR(1H, 14), 20) ≥ 1.8 时不做（V1 的 1.5 过于敏感，把正常活跃行情全过滤了）；取消「周末不做」（周末流动性偏低、缺乏机构破位资金，恰恰是 BTC/ETH 区间高抛低吸胜率最高的时段）；同一箱顶最多做 1 次（一旦被止损说明阻力已被消化，禁止在同一箱顶二次送人头）；每天最多 2 笔；连亏 3 笔强制停机 24 小时。【我自己的建议】

### 第 8 题：最强反方意见（如果 V2 测出来还是不赚，根因与破局）

如果把 V2 跑完 2020–2026 的回测，净期望依然在 0R 附近徘徊甚至微亏，作为反方，我不会建议你们继续写 V3 参数，而会直接指出三个更底层的残酷事实。

#### 1. 如果 V2 依然不赚，最可能的三个底层原因
- 加密永续合约的「负凸性（Negative Convexity）」结构宿命：在高度杠杆化的永续合约市场，价格分布具有显著的右偏厚尾特征（正偏度）——下跌往往伴随流动性抽干后的阴跌或分段插针，而上涨突破阻力时，由于空头强制平仓（Liquidation Engine）必须以市价买单平仓，会在极短时间内制造出剧烈的向上瀑布（Gamma/Liquidation Squeeze）。做空区间顶部在数学本质上等于「卖出波动率（Short Volatility）」——平时赚的是固定的 1R～2R 区间波动，一旦遇到一次真正的箱体向上突破，止损滑点加上跳空会让实际亏损远超预设的 1R。
- 信息催化剂的完全盲区（Catalyst Blindness）：币圈的箱体突破有很大比例是由盘外事件驱动的（ETF 资金流突变、CPI/FOMC 数据、交易所上币公告、监管新闻、巨鲸链上异动）。在纯 OHLCV 视角下，一根「放量突破箱顶的阳线」和一根「诱导突破的假动作阳线」在启动前 5 分钟长得一模一样。人类交易员看到盘面突然因为某条突发新闻拉盘时会立刻撤单或停手，而纯 K 线规则会机械地冲进去当炮灰。
- 创始人的「后视镜记忆偏差（Hindsight & Selection Bias）」：创始人觉得自己手动做区间顶底做得好，这里面有极强的隐性过滤：他在盯盘时无意识地跳过了一半「感觉不对劲」的破位前兆（比如拉升速度太快、大饼正在带节奏、盘口卖单被瞬间吃掉），而且人脑天然会记住漂亮的摸顶神单，把止损单归因为「当时手滑/新闻影响」。把主观经验强行翻译成静态规则时，把「主观过滤掉的那 50% 烂单」全放进了回测里。

#### 2. 这件事本质上是否依赖「盘感」？规则化后优势会消失吗？

答案是肯定的：在「执行扳机（Trigger）」这一层，纯 OHLCV 规则化确实会丢失核心优势。

专业日内交易员在区间顶部真正依赖的「盘感」，并不是玄学，而是高频订单流（Order Flow）与微观盘口信息，这些在 15 分钟 OHLCV K 线上被彻底压缩抹平了：

- 被动吸收（Absorption / Iceberg）： 价格顶在箱顶时，盘口卖一/卖二挂出隐藏冰山单，主动买盘（Market Buy / CVD）持续放量往上砸，但价格纹丝不动——这是大资金在顶部派发的最强铁证，但 15m K 线只显示为一根普通的横盘小星线。
- 持仓量（Open Interest）与爆仓清算簇： 刺破箱顶那一瞬间，如果伴随 OI 暴跌、连续多头爆仓，说明这是主力在「扫损洗盘（Liquidity Grab）」，随后大概率收回；如果刺破瞬间 OI 暴增且主动买盘持续涌入，说明是真突破资金进场，绝对不能空。
- 跨品种联动（Lead-Lag）： 做空 ETH 箱顶时，人类会扫一眼 BTC 是不是正在强力突破关键阻力；如果 BTC 正在主升浪，ETH 的箱顶就是纸糊的。

当你们把订单簿、CVD、OI、新闻和跨币种联动全部剥离，只剩单币种 1D/1H/15m OHLCV 时，规则引擎看到的只是真实博弈投射在墙上的二维影子。 在高度内卷的 Binance 永续市场（做市商与量化机构专门狩猎标准形态的止损），静态的纯 K 线入场信号很难长期维持显著正期望。

#### 3. 产品形态该如何转向？（从「机械喊单机器」转向「结构与情境教练」）

既然你们的产品定位是给个人投资者用的「技术面老师」，而不是全自动量化基金，强行输出「现价做空、止损 X、止盈 Y」的机械信号反而是产品自杀——因为只要用户在实盘连续止损 4 笔，就会直接流失。

更符合商业与交易逻辑的产品设计是「人机协同的决策辅助系统（Context & Checklist Copilot）」：

- 机器负责「找位置 + 算风控」（这是机器比散户强 100 倍的地方）：
  - 自动在图表上标注出大周期共振区（4H/1D 阻力带、PDH/PDL、多触点箱体中枢），用视觉围栏把散户拦在「悬空位置」之外——散户亏钱的第一大原因根本不是入场时机差，而是在区间正中间（中轴附近）乱开单。
  - 自动根据用户设定的 1R 金额与当前结构止损位，一键反算出精确开仓张数与杠杆上限，解决散户乱扛单、重仓爆仓的痛点。
- 机器提供「多维情境体检表（Context Diagnostics）」，把最终扳机交给用户：
  - 当价格进入箱顶预警区时，不直接喊「空」，而是弹出结构化诊断面板（这才是「老师」该做的事）：
    - 位置评分： 命中 4H 前高 + 日线 EMA50 反压（高价值区）；
    - 动能状态： 15m RSI 出现顶背离，且最近 3 根阳线缩量（买盘衰减）；
    - 情绪/拥挤度： 当前资金费率 +0.035%（多头拥挤，有利于空头）；
    - 逆风警告： 日线仍处于 20 日均线上方多头结构，建议轻仓或等待跌破 15m 颈线后再动手。
- 交互式「触发确认清单」与事后复盘归因：
  - 要求用户在下单前手动勾选他看到的 15m 触发形态（例如：[ ] 刺破收回 或 [ ] 二次冲高不过且跌破前低），并允许他结合当下的新闻/大盘氛围做最终否决（Veto）。
  - 事后复盘时，系统自动统计该用户「在系统标注的高价值结构区开单」vs「在悬空区违背系统警告开单」的真实盈亏对比——用数据向用户证明纪律的价值，这才是个人投资者愿意长期付费的「技术面老师」。

#### 4. 公开研究与可信证据：主观交易员在区间/形态交易上是否优于机械规则？

学术界与业界对此有大量实证研究，结论非常清晰且呈现「两极分化」：普通散户的主观裁量远差于机械规则，但顶尖专业交易员在结合微观结构与非结构化信息时，确实能超越低频 K 线规则。

- 支持「机械规则优于主观判断」的实证证据（针对普通投资者）：
  - Barber & Odean (2000), "Trading Is Hazardous to Your Wealth" (Journal of Finance) 及 Barber, Lee, Liu & Odean (2009), "Just How Much Do Individual Investors Lose by Trading?" (Review of Financial Studies)：通过对数万名个人投资者真实交易账户的实证追踪，证明散户主观交易频率越高、越依赖主观择时，净收益越差，核心原因在于过度自信、处置效应（拿住亏损单、过早平掉盈利单）以及忽视交易摩擦成本。
  - Paul Meehl (1954), Clinical vs. Statistical Prediction（以及诺贝尔奖得主 Daniel Kahneman 在 Thinking, Fast and Slow 中对金融预测的引用）：跨领域数十项实证表明，在存在高度噪音的预测任务中，简单的线性/规则模型通常优于人类专家的主观判断，因为人类在疲惫、情绪波动下会产生严重的「决策噪音（Noise）」，无法稳定执行自己的标准。
  - Park & Irwin (2007), "What Do We Know About the Profitability of Technical Analysis?" (Journal of Economic Surveys)：系统梳理了 1960–2004 年间 95 篇现代实证研究，指出在市场效率提升（如电子化交易普及后）与计入真实交易成本、滑点后，绝大多数基于历史价格（OHLCV）的机械技术规则难以产生稳健的净超额收益。
- 支持「专业主观交易员优于静态 OHLCV 规则」的证据（解释为何你们创始人能赚钱而规则亏钱）：
  - Andrew Lo (2004 / 2017), Adaptive Markets Hypothesis (适应性市场假说)：指出金融市场并非静态物理系统，而是生态竞争系统。当某种基于 K 线的区间套利规则变得公开或可预测时，做市商与高频算法会针对该规则的固定止损位（如 box top + 0.15 ATR）进行流动性狩猎，导致静态参数迅速失效；专业人类交易员能通过观察盘面演化动态调整节奏，而固定回测规则不能。
  - Lo, Mamaysky & Wang (2000), "Foundations of Technical Analysis" (Journal of Finance)：通过非参数核回归算法识别头肩顶、双顶、矩形区间等经典形态，发现这些形态在统计上确实包含增量信息（改变收益率分布），但形态本身并不构成完整的交易系统——它必须结合外部宏观/市场情境过滤才能转化为净收益，这解释了为什么机器适合做「形态与位置识别」，而人类适合结合大背景做「情境过滤」。
  - Coates & Herbert (2008, Proceedings of the National Academy of Sciences) 与 Brett Steenbarger (The Psychology of Trading / Enhancing Trader Performance)：针对伦敦金融城与华尔街自营交易室（Prop Desk）日内交易员的跟踪研究表明，长期存活的顶尖日内交易员依赖的是通过数千小时实时盯盘训练出的内隐学习（Implicit Learning）与躯体化盘口直觉——他们能从成交速度、买卖盘挂单撤单节奏的微妙变化中提前感知阻力位的承接强度，这种多模态高频信息在低频 OHLCV 数据中是结构性缺失的。
