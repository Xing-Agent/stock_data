## ★★★ 二 · #72 这个 bug（★ 这一条是真的，要修，但不急）

```
★★ 位置：`probe/newpool_1106/烤新池_1106.py` · `新manifest()`
★ 现在：`cand = dirs.get(sym)`，其中 `sym = r["symbol"]`（原样取 manifest 字段）
★★★ 而 `目录表()`：`sym = d.split("__")[0]` —— **键是裸代码**
→ ★★★★★ 145 行 `SYM__CIK` 全部查不到 → 静默 `continue`

★ 修法一行：`sym = (r.get("symbol") or "").strip().split("__")[0]`
  ★★ 外加一件：同一裸代码多行时要**选一行**（我的影子版按市值最大那行取元信息）。
★★★ 代价：**面板变了 → 所有成绩都要重跑**。
★★★★★ 收益：**+0.04 个百分点**（标尺）。→ ★ 所以我**没有修**，列成拍板项。

★★ ⚠ 但有一处它**可能真的有影响**，和标尺无关：
   ★★★ 选票层那个 `ranking = ADV20 降序`（成交额最大的先买）——
   ★ 补回来的 55 只里有 16 只 large（B/FERG/AU/COHR/VG/SN/FOX…），
   ★★★ 它们会排在**每一天 ADV 榜的很前面** → ★★ 「先买最大的」那条规则**会买到它们**。
   → ★ 所以：**标尺不用重跑，但如果要测 `ranking`（规格书第六节第 2 条），应当先修这一行。**
```
