# 253 · 取 FRED 宏观数据：给 Lin 粘贴的命令（2026-11-25）

**一句话：在 Mac 的「终端」里粘贴下面这一段，大概 1~2 分钟跑完，文件会存到「下载」文件夹，我自己去取。不用推 GitHub。**

用途有两个：
- 补宏观大师考试里 9 道「待核」：信用利差、流动性、通胀预期、历史统计；
- 现金比例回测：在不同宏观环境下留多少现金，回撤和收益怎么变。

《163》（11-10）那版命令没跑回来，这版把它也包进去了。

## 粘贴这一段

```bash
mkdir -p ~/Downloads/fred_1125 && cd ~/Downloads/fred_1125
for S in UNRATE PAYEMS CPIAUCSL CPILFESL PCEPILFE FEDFUNDS DFF DGS10 DGS2 DGS3MO T10Y2Y T10Y3M \
         BAMLH0A0HYM2 BAMLC0A0CM NFCI WALCL WTREGEN RRPONTSYD WRESBAL T5YIE T10YIE \
         DTWEXBGS DCOILWTICO USREC SAHMREALTIME INDPRO; do
  curl -sS -L -o "$S.csv" "https://fred.stlouisfed.org/graph/fredgraph.csv?id=$S"
  echo "$S  $(wc -l < "$S.csv") 行  最后一行: $(tail -1 "$S.csv")"
  sleep 1
done
ls -la ~/Downloads/fred_1125 | tail -30
```
