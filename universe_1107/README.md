# 全市场名单 + 年初日均成交额（回复手册 94 · 4.4 / 4.5）· 2026-11-07

> **三秒版：2004～2026 年，每年年初还在挂牌的全部美股股票（含当年后来退市的），每只附「年初往前 60 个交易日的日均成交额」。不排名、不筛，`type` 和交易所都原样给，你们自己重建排名。**
> 普通股（CS）每年约 2,800～5,700 只；含 ADR 和类型没标清的，全部约 5,000～8,000 行。

## 一 · 文件

`universe_<年>.csv.gz`，一年一个，共 23 个。每行一只票，列如下：

| 列 | 意思 |
|---|---|
| `year` / `base_date` | 年份 / 当年第一个交易日 |
| `list_as_of` | 名单取自 Polygon 哪一天的代码表（上一年最后一个交易日） |
| `ticker` / `name` / `cik` / `composite_figi` | 代码、名字、SEC 编号、FIGI，都是 Polygon 当时的原样 |
| `type` | CS 普通股 · ADRC 存托凭证 · OS / NYRS / GDR 外国股。**2016 年以前很多票 Polygon 没标类型**，见第二节 |
| `type_source` | 类型从哪来：`polygon` 原样 / `inferred_from_later_list_by_figi` / `inferred_from_name` / `inferred_from_later_list_by_ticker(弱)` / `none` |
| `primary_exchange` / `is_otc_or_other` | 主交易所；不在纽交所、纳斯达克、美交所、Arca、Cboe 的，后一列写 1 |
| `avg_dollar_volume_60d_close` | **主用这一列**：60 天里每天「成交量 × 收盘价」相加 ÷ 60，没交易的日子算 0 |
| `avg_dollar_volume_60d_vwap` | 同上，但用当天成交均价。**2021 年底以后数据源不再给成交均价，这一列就等于用收盘价算的那列** |
| `days_traded_in_window` / `window_days` | 60 天里真交易了几天 / 窗口天数 |

`summary.csv` 是逐年计数；`SHA256SUMS.txt` 是指纹。名单的原始数据在 `probe/universe_1107/raw/`（2004～2016 年初）和 `probe/fund_expand_1103/`（2017 年以后），脚本是 `probe/universe_1107/build_universe.py`。

## 二 · 要知道的

1. **包含当年退市的票**：名单是年初那一刻还挂牌的，当年后来退市的照样在里面，没有生存者偏差。
2. **2004 年没有成交额**：日线库从 2004-01-02 才开始，年初往前取不到 60 天，所以只给名单，成交额留空。
3. **2016 年以前的类型不全**：Polygon 早年的代码表里，很多票（多半是纳斯达克的）没标类型。我按以下顺序补，结果写在 `type_source`：
   1. 同一个 FIGI 在 2016 年以后标的是什么；
   2. 名字里有 ETF、FUND、iShares、SPDR、PREFERRED、WARRANT 这类词的，标 `fund_like`；
   3. 同一个代码以后标的是什么（弱推断，`type` 后面带 `?`）；
   4. 还是不知道的，写 `unknown`。

   **所以 2016 年以前想要「只要普通股」，建议留 `CS`，`CS?` 自己决定要不要。** `fund_like`、`ETF?`、`unknown` 里混着 ETF 和优先股，比如 2005 年的 QQQQ。
4. **2016 年那一份**（名单取自 2015-12-31）是这次重新拉的，比 11-01 那份全（11-01 那份只有普通股）。

**每年按成交额排、纽交所和纳斯达克的普通股前 2,000 名里，有多少在研究行情库、多少在考卷：**

| 年 | 在研究行情库 `market_ext_1105` | 在考卷 `exam_1042` |
|---|---:|---:|
| 2010 | 559 | 603 |
| 2016 | 876 | 954 |
| 2020 | 1,052 | 799 |
| 2025 | 1,218 | 654 |

两边加起来不到 2,000：剩下的一部分是代码对不上文件夹名（行情库按公司命名，同一家改过名的只算一次），一部分是选股池建库时没进来的。**怎么补齐，要等手册 95 第三节（考卷怎么切）拍板后一起定。**
